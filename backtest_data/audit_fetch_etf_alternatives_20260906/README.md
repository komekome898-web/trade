# audit_fetch_etf_alternatives_20260906 — JPX400 / グロース250 / TOPIX / 日経225 連動ETFの悉皆調査

取得日: 2026-09-06(JST)。目的: `docs/PHASE2/RESOURCES.md` R5・R6・R8 の横展開候補として、
東証上場ETFのうち上記4指数に連動する全銘柄の一次資料(コード・名称・運用会社・売買単位・

## 手順

1. **一次資料**: `backtest_data/audit_fetch_etf_units_20260906/jpx_etf_issues_01.html`
   (JPX「銘柄一覧（ETF）」全銘柄表、2026-09-06取得済み)をパースし、「連動対象指標」列が
   TOPIX/日経平均株価/JPX日経インデックス400(配当込み含む)/東証グロース市場250指数と
   完全一致する行を抽出(TOPIX-17セクター指数・TOPIX Core30・TOPIX Ex-Financials・
   JPX/S&P設備人材投資指数などの派生指数は対象外)。
2. 抽出した各コードについて、JPX銘柄別ファクトシート `jpx_<code>-j.pdf` を
   `https://www.jpx.co.jp/equities/products/etfs/issues/files/<code>-j.pdf` から取得
   (curl --cacert /root/.ccr/ca-bundle.crt)。売買単位・信託報酬・純資産総額の一次資料。
   **注意**: このPDFの「市場価格（終値）」は更新頻度が低く、23銘柄中21銘柄が
   「2026年2月27日現在」のスナップショットのまま(7ヶ月前)。売買単位は現行値。
3. 直近の参考株価は Yahoo!ファイナンス個別銘柄ページ
   `https://finance.yahoo.co.jp/quote/<code>.T`(現在値カードのみ、日足履歴は取得していない)
   から1点だけ取得(`9/4`表示 = 2026-09-04終値)。`yahoo_2526.html`は「---」(気配なし、
   薄商いのためJPX資料の2026-02-27値を代用)。`yahoo_630A.html`は上場前(上場予定
   2026-09-08)のため価格なし。
4. 分割・売買単位変更の告知は野村アセットマネジメント 2026-08-25 適時開示
   (`backtest_data/audit_fetch_etf_units_20260906/td_260825a.pdf`、既存一次資料を参照。
   本ディレクトリには再取得していない)とWeb検索(WebSearch、価格データではなく告知文の
   有無のみ確認)で裏取り。三菱UFJ・大和・ブラックロック・アセットマネジメントOne・
   農中全共連・シンプレクスの各ETFについては同種の分割告知は本日時点で見つからなかった
   (発行体ごとの適時開示ページの悉皆巡回はしていない。「見つからなかった」は「ない」の
   証明ではない)。

## 主要な発見(詳細は `docs/PHASE2/ETF_ALTERNATIVES.md`)

- TOPIX連動の1306・1475は売買単位10口・1口あたり420円台まで下がっており、
  呼値(1円)が片側23bps超と非常に重い(1306は2026-04-01に1→10分割済み、R5の
  「分割後430円で片側23bps」と整合)。同じTOPIX連動でも1口4,000円台を維持する
  1305/1308/1348/1473/2524/2557/2625は片側2.3〜2.4bpsと軽い。
- JPX日経400の7銘柄は現状すべて片側2.6〜3.0bps(往復5.3〜5.9bps)に収まるが、
  1591は2027-01-28(売買単位変更)/2027-02-01(分割効力発生)で1→100分割・単位1→10口化
  が確定しており、分割後は片側27bps級になる(R8と同じ結論)。他の6銘柄には
  同種の告知は見つかっていない。
- グロース250は東証グロース250ETF(2516)のみで代替候補が存在しない(R6と同じ)。
- 日経225の5銘柄(1330,1346,1369,1397,1578)は片側1.5〜1.9bpsと4指数中最も軽い。
  参考として最大級のNEXT FUNDS日経225連動型上場投信(1321、対象指標は日経平均
  トータルリターン・インデックスで価格指数版とは技術的に別指数)も同水準だが、
  2026-10-07に1→100分割・単位1→10口化が確定している(野村2026-08-25開示)。

## 平均出来高について

JPXファクトシート・Yahoo現在値カードのいずれにも平均売買高の数値は含まれない。
個別銘柄ごとの出来高統計ページを追加取得すると株価時系列に近い調査になり本タスクの
禁止事項(価格履歴取得)に抵触しかねないため、本調査では取得していない。代わりに
JPXファクトシート記載の純資産総額(億円)を流動性の代理指標として `ETF_ALTERNATIVES.md`
に記載した。
