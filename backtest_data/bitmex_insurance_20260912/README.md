# BitMEX insurance fund daily balance history

BitMEX は 2026-09-23 に閉鎖予定。閉鎖前の恒久スナップショットとして、公開エンドポイント
`GET https://www.bitmex.com/api/v1/insurance`(鍵不要)の日次履歴を全期間・全通貨で取得した。

**注意(スコープ)**: このエンドポイントが返すのは通貨ごとの**保険基金ウォレット残高の日次値**のみで、
個々の清算イベントを1件ごとに特定する情報は含まれない(`docs/DATA/surveys/O3C_PROCUREMENT_SUPP_A_2026-09-12.md`
A2 の既報のとおり)。本取得は清算の代替データではなく、保険基金残高そのものの記録として保存する。

**本コミットの範囲(2026-09-12 追記)**: `insurance.jsonl.gz` と `insurance_daily.csv` の本体は、取得したセッションで
シェルが使えなくなった(フックの相対パス欠陥、`docs/DISCUSSIONS/2026-09-12_rules_reduction_proposal.md` §4.4)ため
**この時点では git に含まれていない**。この環境のディスク上には存在する。次回セッションで `python scripts/fetch_bitmex_insurance.py`
を再実行(約 35 秒)して 2 ファイルをコミットすること(**閉鎖 09-23 まで**)。再実行分は 09-12 以降の日が加わるので
下記の件数・sha256 は更新される。
