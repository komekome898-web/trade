> 日経225先物取引は取引できる期間が決まっています。この満期月を限月（げんげつ）と呼び、株式でいう銘柄にあたります。

## 結論
JPX の一次資料で確認: **日経225先物(ラージ)の限月は3月・6月・9月・12月のみ**、SQ日は各限月の
第2金曜日。225Labo のダウンロードページのスクリーンショット(`backtest_data/n225f_225labo_20260828/
README_SOURCE.md`)と合わせ、`docs/PHASE2/P2-01/PREREG.md` の「限月ロールの扱い (b)」の条件
(「ラージ日経225先物、限月は四半期限月のみ、と判明したら (a) を四半期規則に切り替え」)が満たされたと判断する。
