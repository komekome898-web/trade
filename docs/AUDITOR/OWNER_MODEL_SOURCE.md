# オーナーのモデル — 素材集(逐語)

**この文書の目的**: オーナーの指示「私の求めること、嫌うこと、許さないことなどをピックアップしてください。
それを私のモデルとしてください。そして監査役としてあなたの全ての行動を監査させてください。」
に対する**素材集**である。判断・設計はここでは行わない。

**この文書の規則(作業指示より逐語)**:

> **オーナーの言葉を、あなたの言葉に言い換えてはいけません。**
> このプロジェクトは今日、**「オーナーの原文をリードが自分の語彙に翻訳して中身を落とした」**ことで破綻しました。
> **同じ失敗をこの作業で繰り返さないこと。**

- 原文は「」で囲んで逐語で引用する。一字一句変えない
- 引用には必ず出典を付ける
- 解釈は引用と分けて「(解釈)」と印を付ける
- 要約して 1 行にまとめない
- 拾いすぎて困ることはない。落とす方が害

**注記**: 本書に引用したオーナーの言葉のうち、`docs/OWNER_LOG.md` の 4 列目に
「(要旨、原文があれば引用)」として記録されているものは、**台帳に残っている形のまま**引用している。
台帳の時点で要旨化されているものは末尾に **(台帳が要旨)** と印を付けた。
**逐語が確実なもの**(`docs/DISCUSSIONS/2026-09-13_worst_day.md`、
`docs/PHASE2/O3C/OWNER_INTENT_2026-09-12.md` §1・§1.1、各議論記録の引用ブロック)は印を付けていない。
