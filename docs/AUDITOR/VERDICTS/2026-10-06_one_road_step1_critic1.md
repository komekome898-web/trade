## 検査のツール(check_scenes.py・check_delete.py、CLI の終了コードで見た)

置き場はすべて `write_store` で書いた。手で書き換えていない置き場では通過する(exit 0)。

**約定を 1 件だけ消す(check_delete.py、S8 の 5 件から 1 件ずつ)**

- 約定 4(途中の取引の一部決済)を消すと `exit 0 検査 通過: del4`。

**安値ちょうど・高値ちょうど**
- 値段を足の安値ちょうど・高値ちょうどにした置き場は exit 0(端を含む)。
- 高値を 1 円下げると `約定の値段 10200 がその分の足(bar 3)の安値 10200.0〜高値 10199.0 の外` で exit 1。1e-9 円下げても失敗した。

**足の時刻を 1 ns ずらす**
- 約定が分の途中にあるとき: +1 ns・−1 ns とも `分の区切りから 1 ns ずれている` / `59999999999 ns ずれている` で exit 1。
- 約定が分の区切りちょうどにあるとき:
  - +1 ns: 行 0 は `を含む 1 分足が無い`、ほかは「ずれている」で exit 1。
  - −1 ns: 全部「ずれている」で exit 1。
- 足の終わり(s+60 秒)ちょうどの約定は次の足の扱いになり、次の足が無ければ `を含む 1 分足が無い` で失敗する。

**まとめの鍵と値**
- 余分な鍵 → `帳簿のツールが出さない鍵 note がある` で exit 1。
- bool → exit 1。文字列 "1.0" → exit 1。NaN → exit 1。

**浮動小数**
- ツールで書いた `2.9999999999999996`・`5.000000000000018` の置き場は通過した。誤って落とすことは無い。
- 正確な手計算の 3・5.0 に書き換えた置き場は、`書かれた値 5.0 と計算し直した値 5.000000000000018 が違う` で失敗した。
- +1e-9 円・+1 円の書き換えはどちらも失敗した。誤って通すことは無い。
- 手計算の値で落ちるのは検査の誤りではない。上の帳簿のずれがそのまま出ているもの。

**ドル建て**
- 置き場の fx を消すと、計算し直せないとして失敗した。
- fx を 1 円変えると `151.0 と 152.0 が違う` で失敗した。
