## 問 2. 記録の `path` は実際に採った道の向きと一致するか [問題なし]

**`_run_path` の第 2 引数は「上が先」の意味です。** 根拠は 600〜611 行の次の部分です。

```

```

**4 つの場合のコードの読み**は次のとおりです。

- **(a) `one_tp`**: 664〜667 行が正しく書かれています。`ta`(a = 上が先に利確がある)かつ `tb` なしのとき、良い側は `st = a`、path は up です。悪い側は `_run_path(st, tb=False, …, True)` を走らせるので下が先で、path は down です。逆に `tb` のみのときも対称です。`(ta if good else tb)` は、実際に走らせた `up_first` と一致します。
- **(b) `both_tp`・`both_tp_tie`**: `path = "up" if st is a else "down"` で、`st` は `a` か `b` のオブジェクトそのものです。
- **(c) `no_tp`**: `st = a if near_up else b` の `st is a` です。
- **(d) `same`**: `st = a` ですが、`a.events == b.events` かつ `(a.side, a.fills, a.brk) == (b.side, b.fills, b.brk)` で道が分かれないため、`path = "same"` です。
