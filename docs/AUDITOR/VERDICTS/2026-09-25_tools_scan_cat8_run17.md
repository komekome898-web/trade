**それでも `なし` は受け取らない。理由を差し替える**: この候補は有料の講座・テンプレート集で、教材と「AI Trading Lab GitHub repository」(報告の §4.0 の表「言語と動作環境」)は購入しないと読めない。公開されている頁は販売の頁だけで、設計票・委任文の `なし` の条件(候補の文書の全部を読んだ)を満たさない。値は `未判別` のまま、状態を **`登録が要る`** にした(購入が要ることを、報告の §4.0 の表「導入可否」「最小実行の可否」の逐語が示す)。有料の購入は提案しない(§0.2 A-3)。

台帳(`set`): 8-036 の状態を `登録が要る`。
