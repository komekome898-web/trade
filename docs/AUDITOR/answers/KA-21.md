# KA-21 の答え(before/KA-21.md に対応。出典 L-038)

## オーナーの発言

「BITMEX はサービスの終了を発表しており、ユーザーにポジションの整理を促している。この情報は
あなたの元にありますか。BITMEX のデータ収集の方針に関わるので先に確認してください」

## 何が誤りだったか

この記述には「取引所そのものが閉鎖する」という項目が無い。「窓は動く」は**データ提供側の
ローリング窓**(Gate.io の 90 日が徐々に前進する)を指しており、**取引所自体が消滅して以後
一切のデータが取れなくなる**という、質的に異なる危険は台帳に登録されていなかった。

BitMEX は 2026-09-01 付けの告知(`api/v1/announcement`)で、XBTUSD 等を 2026-09-16 に
上場廃止・清算し、取引所自体を 2026-09-23 に閉鎖することを発表していた。リードはこの情報を
持たず、**オーナーに問われるまで、一次資料(取引所自身の告知)を一度も確認していなかった**。
BitMEX は同時に「カツオの原典ベニュー」であり、公開約定アーカイブ(2014-11〜2025-02-22、
47.9GB)を閉鎖前に確保できるかどうかが O-6 層①の検証可否そのものを左右する状態だった。

## 原則

データの取得可否(P1)だけでなく、対象(取引所)そのものがまだ存在するかも一次資料
(取引所自身の告知)で確認する。ベニューの存廃はモデルの学習データに無い出来事であり、
記憶で答えてはならない。
