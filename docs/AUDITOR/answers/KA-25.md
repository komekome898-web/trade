# KA-25 の答え(before/KA-25.md に対応。出典 L-056、層3の推奨「B」)

## オーナーの発言

「今日 1 番論外な提案です。検査を通すことが目的で、ロジックの性能を測るのに 1 番重要とまで
言える箇所を外そうとしています」

## 何が誤りだったか

**測定コードが建玉状態(ドテン・保有中の挙動)を実装していなかった**という道具側の制約に
対し、リードは「機構の中心を測定対象から外して射程を狭める」という形でその制約に**測定対象
そのものを合わせようとした**。「射程」という言葉で正当化しようとしていたが、L-046 で
「○ を外すな」と自分で書いたばかりだったので、外すなら明示的な承認が要る——黙って外すのが
最悪だった。これは KA-06(L-046、固定保有 `h` が意図マップの ○ 項目を黙って外していた)と
同型の違反だが、対象が異なる(保有期間の掃引軸 → 建玉状態の有無)。

## 原則

検査・道具の制約を理由に、測定対象の中核(仮説の意味を最も担う機構)を外してはならない。
「検査を通すこと」が「測ること」に代わって目的化していないかを常に確認する。

## 監査役が出すべき問い(KNOWN_ANSWERS_ADDENDUM.md より)

「この項目(仮説の中核を担う機構)を測定対象から外す理由は、道具の制約か、それとも重要性の
判断か。外す提案の目的は『測ること』であって『検査に通ること』ではないか」
