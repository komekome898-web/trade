# KA-23 の答え(before/KA-23.md に対応。出典 L-045)

## オーナーの発言

「保有は 1 と 2 で見たい。経費について、**post only で指値をだす方式はまさにそのテイカー
手数料を払わないため**です。当時の BITMEX は**メイカーにマイナス手数料、テイカーに手数料**
という形で、なおかつ**流動性が高くスプレッド幅が小さい**という特徴があった。従って
**できるだけメイカーで注文を出すことを目指していました**」

## 何が誤りだったか

「往復 15bp(テイカー往復)」という経費モデルは、**原典が新規も決済もほぼ post only
(`ParticipateDoNotInitiate`)で出す設計**であることを無視していた。戦略の設計そのものが
メイカーで取ることを中心に置いているのに、コスト前提はテイカー×2 という**戦略が実際には
取らない構成**を採用していた——事前登録の数値が、測定対象の戦略の実装・設計と整合していない
という、KA-05・KA-06・KA-07 と同型の「測定と登録の不一致」だが、対象が**決済ルールではなく
コスト構造**である点が異なる。

さらに、この訂正の過程で**手数料の水準(0.025% / 0.075%)自体の出所がリードの記憶**であり
一次資料未確認だったことが発覚し(→ KA-04 / I-004)、最終的にはコストという入力そのものが
K1(上流の単位)の射程外と判明した(→ KA-16 / L-048)。KA-23 はこの連鎖の最初の環
(「コストモデルが戦略の設計意図を反映していない」)を指す。

## 原則

事前登録のコストモデルは、測定対象の戦略が実際に取る執行方式(メイカー/テイカーの配分)を
反映しているかを検証する。「保守的だから安全」という理由で戦略の設計と矛盾する前提を
採用してはならない。
