# KA-28 の答え(before/KA-28.md に対応。出典: 討議 2026-09-08、`external_ecosystem.md` §1)

## オーナーの発言(3 回目、原文)

「結論を急いでいて評価が浅い。**無い情報 / 無い視点 / 既存成果の向上**の観点で深掘りせよ」

## 何が誤りだったか

リードは「このリポジトリを道具として入れるか」という**一点**だけに答え、
「この領域に当方の穴があるか」という**当方の棚卸し**を要する問いには答えていなかった。
2 回目の差し戻し(「オンチェーンの情報を戦略構築のために分析するものとしても不要か」)を
受けてもなお、**「オンチェーン」という主題の内側だけを探索し**、隣接する無料のデリバティブ
データ(Binance Vision の建玉・taker 比率等)には気付かなかった。3 回目の指摘で初めて、
「当方の状態変数がすべて価格由来の内生量である」という自分自身の盲点
(`PHASE2_TEMPLATES.md` §6 を見れば分かった)を発見した。

## 原則

外部の情報源・リポジトリの評価は、「道具として採用するか」の一点で結論せず、(1) 道具
(2) 当方に無い情報 (3) 当方に無い視点 (4) 既存成果の向上、の 4 つを分けて判定する。

## 監査役が出すべき問い(KNOWN_ANSWERS_ADDENDUM.md より)

「この外部ツール・データ源の評価は、道具としての採否だけで結論しているか。情報・視点・
既存成果向上の 3 観点は個別に検討されたか」
