# KA-27 の答え(before/KA-27.md に対応。出典 L-019、討議 `matilda_intent_vs_test.md` §10.2-10.3)

## オーナーの発言

「良い成績は否定されるまで検証され、悪い成績は否定された瞬間に、その否定という事実が
全てに影響していた。構造的に安全側に振れていた…時間と機会の損失は正直かなり痛い。」

## 何が誤りだったか

規律(事前登録・封印・盲検監査・帰無・多重性)はすべて偽陽性(誤って「効く」と言ってしまう
こと)を防ぐために設計されていたが、偽陰性(本当は効くのに「効かない」と誤判定すること)を
防ぐ機構は一つも無かった。棄却方向に効く前提(コスト・スリッページ・逆選択の過大見積り)は
誰にも攻撃されず、採用方向に効く前提だけが攻撃される非対称な検証体制が、6 週間にわたり
誤差を一方向にだけ蓄積させ、その蓄積を「確立済み知識」として次の研究の入口に置いていた。
これが 2026-09-08 の全捨て(CLAUDE.md §5.1・§5.2)の直接の理由である。

## 原則

検証規律は偽陽性を防ぐだけでは片手落ち。陰性(検出力を持って不在を測った)と不明(検出力
不足)を語彙として分離し、棄却方向に効く前提にも一次資料・実測を要求する。MDE を書けない
主張は陰性として引用できない。
