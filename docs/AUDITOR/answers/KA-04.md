# KA-04 の答え(before/KA-04.md に対応。出典 I-004 / L-047)

出典: `docs/PHASE2/K1/PREREG.md` §5.1・§5.2(コミット `7367fb3` の親 `7367fb3` 側の版が `fae8ec8^`)
訂正コミット: `fae8ec8`(「Record I-004: one symbol for three quantities, and a fee rate sourced to nobody」)

## 補足(衛生除去分、2026-09-11。before/KA-04.md から移動)

同じ節の下の表(この版で追記された部分)では、`sd` を**符号あり・1 取引あたりの損益**
という第 3 の意味で使っていた。つまり冒頭の定義(「相場のノイズであって戦略の成績ではない」
= 符号なし)と、実際に使っている値(符号あり・戦略の損益そのもの)が**同じ節の中で矛盾**して
いた。古い定義文は一度も削除されず、そのまま残っていた。

## 補足(§5.1 の版の履歴)

この版の 1 つ前では「BitMEX 2019 の公開手数料【一次資料・仮定】」と表示していた。
このバージョンで「出所はオーナーの記憶」に書き換えたが、オーナーは水準の数字を挙げていない
— 述べたのは符号の構造(メイカーが負・テイカーが正)だけで、0.025/0.075 という数値自体は
リードの記憶が出所だった。

## 補足(§5.2 の見出し)

before/KA-04.md に抜粋した §5.2 の「条件付きの sd を使う」という見出しには、原文では
括弧書きで「訂正」という注記が付いていた(この文書の著者自身が、この段落は前段の定義への
上書きだと自認していた、という事実)。

## オーナーの発言

「突然 sd の定義を説明なしで変えたように見える。§5.2 はどちらの sd か。
一度出した用語の意味を変えて使い回すことは、後で何度でも言い訳できる無限の論点ずらしの許容と
同義。どういう意図か。理由によっては重大なインシデント」

## 何が誤りだったか(訂正コミットのメッセージより)

> sd named three different quantities in turn: forward return over all
> candles unsigned, the same over signalling candles, and finally the
> signed per-trade result under katsuo's exit. Each change was labelled a
> correction, but the old text stayed, so section 5.2 ended up opening with
> the first definition... while its own table used the third.

## 原則

量が変わったら記号も変える。訂正は**古い定義を消してから**行う。数値には出所の
3 分類(一次資料 / 実測 / 仮定)を付け、仮定には誰の仮定かを書く。リードの記憶は「仮定」であり、
一次資料でも実測でもない。
