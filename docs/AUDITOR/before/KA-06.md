## 抜粋 §4(測るもの)

シグナルが出た足の**終値**を基点に、`h` 本後の終値までの符号付きリターン(bp):

```
r = signal × (close[t+h] / close[t] - 1) × 10^4
```

主指標: `mean(r)` の片側 t 検定(帰無 `mean(r) ≤ 0`)。副指標: 勝率、中央値、`h` 別の減衰。

この版は「保有は `h=1,2` の固定本数」という設計で、
カツオの原典が持つ決済ルール(無効化 or 反対シグナル、意図マップ I-8)を
測定に反映していなかった。
