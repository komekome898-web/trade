# PHASE2_TRIAGE — 戦略候補の事前仕分け(2026-09-05)

`docs/PHASE2_SPEC.md` §1・§2.1 に基づく、フェーズ2着手前の棚卸し。リードとオーナーのみが読む(過去の結論を含む)。
フェーズ2研究者に渡すのは末尾「仮説の転記」節(数値・判定なし)のみ。典拠: `docs/KNOWLEDGE*.md`、
`docs/AUDIT_2026-09/{00_packets,01_assumption_register,99_master,99_summary_plain,99b_dissent_adjudication}.md`、
`config/constants.yaml`、`docs/PREREG_*.md`。ID(R/L/FX/JP/AR等)はKNOWLEDGE系・監査文書への相互参照のみに使用。

区分の適用規則: 対象外は構造的理由のみ(空売り不可・資本床<¥20M・サーバ費>収益・規約/安全不変条件・商品消滅、または
戦略自身の恒等式が前提に関係なく利益を禁じる場合)。旧 taker コスト床(往復5.8〜7.9bps、実測2.0〜2.6bps)・PAPER
スリッページ(0.05%/側、実測往復2.0〜2.6bps)・maker逆選択(6〜9bps、実測約1bps/5秒)・データ消失を主因とする棄却は
再研究。検出力不足(判定不能)による棄却は後回し(引き金付き)。判断に迷うものは要相談。
