# マチルダの動き — 作り話の値段での例(L-773 への答え)

値段は説明のための作り話で、データではありません。中心と平均実体(ボラ)は足ごとに動きますが、読みやすくするため、例の中では 中心 = 1,000,000 円・ボラ = 1,000 円 のまま置きます。

よりどころ(逐語):
- L-769「**合図が出るのはcloseのタイミング(前の足) 指値は合図の次の足で出してhighからlowの範囲内であれば約定 指値決済の良い側はその足内で指値があれば通り、悪い側は次の足内から**」
- L-770「**a 足の始値で約定する(出した時点で相場より有利な指値なので、すぐ約定したとみなす) b 建ての指値と一緒に決済の指値を出しておき、建ての約定のあと同じ足の中で決済の値段に届けば約定、とする(決済の値段は合図の足の終値から計算)**」
- L-771「**指値は計算した中心からボラ×設定値分離れた価格でしょ？ 段数の取り方もstepで決めてなかった？**」
- 原典のコメント(`docs/legacy/matilda_for_TaroCamp37.py` 137〜142 行)「中央値から entry_setting×vola だけ現在価格が離れるとエントリー開始。利確は中央値から exit_setting×vola 離れたところ」(entry_setting = 2、exit_setting = 0.8)

線: 売りの線 = 中心 + 2 × ボラ = 1,002,000。買いの線 = 中心 − 2 × ボラ = 998,000。利確の線(形 1)= 売りの建玉は 中心 + 0.8 × ボラ = 1,000,800 で買い戻し、買いの建玉は 中心 − 0.8 × ボラ = 999,200 で売る。

建ての指値が範囲の外のとき(足 3 の別の形):
- 足 3 が 1,002,800・1,003,500・1,002,300・1,003,000(足ごと売りの線より上)→ 売りの指値 1,002,000 は約定する向きに範囲の外 → **始値 1,002,800 で売り約定**(L-770 a)。
- 足 3 が 1,001,500・1,001,900・1,001,000・1,001,200(足ごと売りの線より下)→ 約定しない。

## 例の中のリードの読み(オーナーの言葉が無いところ)

1. 利確の線: 例は 形 1 = 中心 ∓ 0.8 × ボラ(原典のコメント 137〜142 行。L-564「**1 B、マチルダの設定にあるやろ**」)。原典のコードの実際の利確は 形 2 = 建値の平均 ∓ 0.8 × ボラ ÷ 積んだ段の数(881 行)で、カードの第 3 稿でリードが既定を 形 2 に替えた(オーナーの言葉なし)。§8・§9 は 形 2 を使っていた。
2. 段の数え始め: 例は「前に出した建ての指値の値段」から(原典 843・867 行)。前の段の約定の値段から数える読みもある。
3. 段の出し方: 例は「終値が前の指値 + 1 × ボラ を越えたら、その値段の指値を次の足に出す」(原典は相場がそこまで来たら出す)。先にその値段に指値を置いておく読みもある。
4. 合図が消えたとき: 例は建ての指値だけ取り消し、決済の指値は残す(原典は全部取り消して 0.6 秒後に決済を出し直す)。

例に入れていないもの: 20 分の緩め・40 分の時間成行・静観の門・幅の門・反対の向きの合図での成行の決済。
