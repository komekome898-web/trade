## 3. 直した台本の置き場と差分の要約

- **`src/bot/research/liq_cascade_fill.py`**(作り直し)
  - `--fill-side` は `any`(既定)と `quote` の 2 つにしました。`quote` は状態機械を 4 回流します: 元の付け方 → 気配(主)→ (b) → (a)。2 回目以後は、値段の呼び出し回数と行動の並びが 1 回目と同じかを毎回確かめます。
  - `QuoteBook`: 古さ 300 秒越えは欠け、気配を取れなかった日は欠けです。取れた日なのに目標の時刻が表に無ければ止めます。
  - (i): `TakerBook` は、目標の時刻の日の約定ファイルが無いとき、(b)・(a) とも値の欠けにします(前の日の古い約定を使わない)。
  - 経路(`quote`): 時刻が (入りの目標, 出の目標] の約定を両側すべて使い、p0 は気配の入りの値段です。
  - 列: 連鎖の行に `pnl_bp_{anyside,taker_prev,taker_wait}` と `missing_*`。レグの行に経路の列 19 個(`in_quote_age_ms`・`out_quote_age_ms` を含む)と、レグごとの並べる損益。
  - `targets_for_prints`: 本体が値段を引きうる目標の時刻の組です。取得の台本と試験が使います。
- **`scripts/c9_run_a.py`**
  - 引数 `--fill-side {any,quote}` と `--quotes-dir` を足しました。
  - `quote` のときは、元の付け方の結果を元と同じ列で `chunks/{cascades,legs,cascades3,legs3}_any/` にも書きます(4)。
  - (ii): 段 3 の約定の窓は、`quote` のときだけ前の日も読むようにしました。既定は元のとおり当日と翌日です。理由: 既定の値は目標以後の約定しか使わないので、前の日を読んでも値は変わらず、既定の読み方を変えないため。
  - 既定は元のとおり `v2.make_price_fn` → `v2.simulate_bundle` を呼びます。
- **`scripts/c9_fetch_bookticker.py`**(新規)
  - 1 日ずつ zip と `.CHECKSUM` を取り、sha256 を照らし、zip の中の CSV を直接読み(展開物は書かない)、目標の時刻ごとの気配を引いてから zip を消します。
  - 2023-12-17 以後の日を渡すと止まります。
  - 出力は `data/c9_bookticker/` の `days/<日>.csv.gz`・`fetch_log.jsonl`・`fetch_summary.json`・`targets_meta.json`。
- **`check_repro.py`**
  - (4): `quote` の走らせでは `*_any/` を元と比べます。
  - (iii): 主の値の検めを足しました。遅れ ≤ 0、古さ = −遅れ ≤ 300 秒、`order_in` = 束の側 × 順張り/逆張り、`order_out` = −`order_in`、`pnl_bp` を値段から計算し直した一致、`mfe_bp` ≥ 0 ≥ `mae_bp`、連鎖の損益 = レグの和。
