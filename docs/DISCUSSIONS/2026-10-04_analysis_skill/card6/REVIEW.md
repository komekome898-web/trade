## 6. 読み

- 【事実】btc のカードと買いだけの対照は、全期間・前半・後半のどれでも区別がつかない。カードの正(後半だけ 0 より上)は、後半の買いだけの対照(+2.09 [+0.58, +3.61])とほぼ同じ値。
- 【事実】買いの取引(窓が下に開いた週)は正、売りの取引(窓が上に開いた週)は 0 を含むか負。窓の向きではなく、週明けの 1 時間に値段が上がったことが損益を作っている形。
- 【事実】usdjpy の窓で入ると、後半は買いだけより低い(−2.12 [−4.28, −0.11])。後半の売りの取引は 0 より下(−14.749 [−29.889, −0.547]/取引)。
- 【事実】週明けの 59 分の 1 分あたりの上げ(+0.3314 bp/分)は、持っていなかった平日の分(+0.0158)より +0.3156 [+0.0895, +0.5832] 大きい(前半 +0.4013 は 0 を含む、後半 +0.2300 は 0 より上)。
- 【推定】為替の週明けの直後の 1 時間に bitFlyer FX_BTC_JPY が上がる偏りは、カード 5 で見えた「日本の月曜の朝(0:00〜9:55)の上げ +50.63 bp/日」の一部(この 1 時間は月曜の朝の中にある)。月曜の朝の上げのうち、どれだけがこの 1 時間かは、同じ足で時刻ごとに並べないと分からない。
- 止めたもの(スキルの決まりの名前で): **D5 の決まり「建ての時刻からの値動きが対照と区別できないなら、合図に情報があるとは書かず、出口の改良を出さない」**(ここでの対照は買いだけの対照)。窓の大きさで分ける改良(K-046 の「大きな窓だけ入る」)は、窓の向きの情報が見えない形への継ぎ当てになるので出さない(第 1 部 §5)。

3. 【推定】原文の「窓」が何の市場の窓かは決まっておらず(2 つの代理)、日経 225 先物・CME の窓は測っていない。
