## 6. 読み

- 【事実】btc の向きの情報の検めは全期間で 0 より上(+0.6546)。中身は片側: 窓が下に開いた週は上がり、上に開いた週は動かない(0 を含む)。カードの売りの取引の損益が 0 前後(前半 −6.70・後半 +0.94/取引)なのは、売りの合図の週に値段が下がらなかったから。
- 【事実】btc の D1 は「後半だけ」。向きの情報の検めも、後半は 0 より上・前半は 0 を含む。前半は分の数が同じ(3,825・4,484)でも散らばりが大きい(前半の区間の幅は後半の約 3 倍)。
- 【事実】usdjpy の窓の向きでは、買いの合図の分も売りの合図の分も上がっていて、差は 0 を含む。後半の売りの取引が 0 より下(−14.749 [−29.889, −0.547]/取引)なのは、売りの合図の週にも値段が上がったから(週明けの上げ)で、窓が広がったからではない【推定: 売りの合図の分の値動き +0.2505 [+0.0144, +0.4977] から】。
- 【事実】週明けの 59 分の 1 分あたりの上げ(+0.3314 bp/分)は、持っていなかった平日の分(+0.0158)より +0.3156 [+0.0895, +0.5832] 大きい。
- 【推定】為替の週明けの直後の 1 時間は、カード 5 で見えた「日本の月曜の朝(0:00〜9:55)の上げ +50.63 bp/日」の中にある。月曜の朝の上げのうち、どれだけがこの 1 時間で、どれだけが下に開いた窓の戻りかは、同じ足で時刻ごと・窓の向きごとに並べないと分からない。
- 【推定】なぜ下の窓だけ戻るかは分からない。候補: 週末の下げが円建ての薄い板で行き過ぎ、為替の市場が開いて海外との値段の差(円の上乗せ)が埋まる(カード 3 の仕組み)/ 週明けの上げの偏りが下の窓の戻りと重なっているだけ。どちらかを決めるには、週明けの 1 時間の値動きを脚(BTCUSD・USDJPY・上乗せ)に分ける。
