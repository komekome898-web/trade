## 0. 結論(先に)

- 【事実】3 つの窓(幅を決める窓 1 時間・1 日・1 週)のどれでも、バリアに当たった向きの合図に、その後の値動きの向きの情報は見えない。買いの合図(下の線に当たった後)の分 − 売りの合図(上の線に当たった後)の分の 1 分あたりの値動きの差は、1h +0.0067 [−0.0148, +0.0291]・1d −0.0127 [−0.0317, +0.0080]・1w −0.0169 [−0.0386, +0.0050] bp/分で、全期間・前半・後半のどれも 0 を含む。
- 【事実】原文の問い(継続と反転のどちらが優勢か)には、この測りでは「どちらとも区別がつかない」。1d・1w の点は負(継続の向き)、1h の点は正(反転の向き)だが、どれも区間が 0 を含む。
- 【事実】損益の形は 3 つの窓とも「多い小勝ちを少ない大負けが食う」(1h 勝率 64.7%・勝ち平均 +69.88・負け平均 −127.02)。
- 【推定】この勝率(1h 0.647・1d 0.617・1w 0.527)は、値動きに情報が無い(上下が同じ確からしさの)ときにこの形で出る勝率(約 0.6、§6)と大きく違わない。勝率が高いことを「反転が多い」とは読まない。

## 1. 前提と合図の有効期間(P)

- 前提(1 文): bitFlyer FX_BTC_JPY は、窓の値動きの大きさで決めた幅だけ動いた後、反対へ戻る(反転)方が、さらに進む(継続)より多い(原文 #48 は問いだけで向きを決めていない。名前の「逆張り」が反転を期待)。
- 前提の直接の測り(D1b): レースごとの継続・反転の数と、当たった後の時刻ごとの値動きを、年ごと × 窓ごとに。**未実施**(`diagnostics.json`: カードの関数が起点の更新を外に出していないので、継続・反転の数は出していない)。
- 合図の有効期間: 次にどちらかの線に当たるまで(原文の「その後」)。ただしカードは、同じ側の線にもう一度当たったとき(継続)は持ち高を変えずに起点だけを動かし、反対側の線に当たったとき(反転)に持ち替える(`diagnostics.json`: 「持ち高が変わる = 反対側の線に当たった(反転)。同じ側に当たった(継続)は持ち高が変わらない」)。だから 1 つの持ち高の一続き(この文書では「走り」と呼ぶ)は、0 回以上の継続の当たりを含み、最初の反転で終わる。走りの保有の中央値は 1h 112〜130 分、1d 2,112〜2,846 分、1w 15,464〜20,398 分(§6)。
- 用語: **レース** = 起点から次の当たりまでの 1 回(継続でも反転でも 1 回)。**走り** = 同じ向きの持ち高の一続き(取引の表の 1 行)。この文書の表の「取引」はすべて走り。

## 6. 読み

- 【事実】D1 は 3 つの窓とも **決まらない**(前半・後半とも 0 を含む)。
- 【事実】向きの情報の検めは 3 つの窓の全期間・前半・後半の 9 つとも 0 を含む。1w の前半(−0.0333 [−0.0651, +0.0023])が一番 0 に近いが含む。
- 【事実】走りで見ても値段の動きは両方の向きで上がっている。走りの向きごとの値段そのものの動き(向きを掛けない)と保有の長さ:

- 【推定】走りの損益はおおよそ「幅 × (1 − 走りの中の継続の当たりの数)」(継続が 0 回なら +幅、1 回なら約 0、2 回なら約 −幅。幅はレースごとに変わるので近似)。上下が同じ確からしさなら、継続 0 回の走りが半分・1 回が 4 分の 1 になり、損益が正の走りの割合は約 0.5 + 0.25 × (1 回の走りのうち正になる割合 ≈ 半分)≈ 0.6 になる。実際の勝率(1h 0.647・1d 0.617・1w 0.527)はこれと大きく違わず、損益の平均が 0 前後なのとも合う。継続・反転の数そのものは、起点の記録が無いのでこの出力からは数えられない(§10 の 1)。
- 【推定】損益の形(多い小勝ち・少ない大負け)は、継続の当たりを何回も含む走り(一方向に走った相場)で負けが積み上がる形で、合図の情報が無くても出る。
- 止めたもの(スキルの決まりの名前で): **「買いの合図の分 − 売りの合図の分 が 0 を含む → 合図に向きの情報があるとは書かない」**(D5 の決まりを、持ち直すカードの形に移したもの)。だから改良の手順(D2 の門・D7)は進めない。前の日のボラの門(K-032 はカード 8 の門。カード 7 には K-035 の区分の移りの読み)を足すのは、合図の情報が見えない形への継ぎ当てになる(第 1 部 §5)。
