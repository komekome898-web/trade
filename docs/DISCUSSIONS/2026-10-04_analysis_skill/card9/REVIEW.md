## 6. 読み

- 【事実】清算のプリントの後、5 秒から 4 時間まで、値段は清算と逆へ戻る側に動く(全プリントの日の平均、§3)。勢いをそろえた時刻(ii)も 5 分より後は戻る向き(1 時間 −1.357)だが、清算のある時刻の戻りはそれより大きい(組の差 1 時間 −6.946)。プラセボ(iii、出来高の急増)は 1 時間で 0 前後。
- 【事実】無作為の時刻(i)の react は 5〜60 秒で +0.10〜+0.13 bp(± 0.02〜0.08)で 0 でない。対照の向きは直前 10 秒の値動きの符号なので、これは「Binance COIN-M では、直前 10 秒の動きの向きに、次の 5〜60 秒もわずかに続く」こと。300 秒からは 0 前後。勢いをそろえた時刻(ii)も 5〜30 秒は +0.16〜+0.20 で続き、300 秒から戻る。カード 8 の「bitFlyer は直前の数分の向きに次の 1 分も続く」と同じ向きの事実(取引所と時間の細かさが違う)。
- 【推定】1〜5 秒の戻り(−0.28 bp)には、清算の成行の後の最初の約定が気配の片側にあることの跳ね返りが入りうる。ただし 1 時間・4 時間の戻り(−9・−13 bp)は気配の幅よりずっと大きいので、知見 1 は跳ね返りでは説明できない。
- 表の数: react は 12 の時刻 × 約 20 の群を同時に見ていて、多重性の調整はしていない(1〜2 升が偶然 0 を外れることは起きうる)。知見にしたのは、前半・後半の両方で 0 を外れた組の差と、前半で境を決めた量の分けだけ。
- 【事実】組の差は前半・後半とも 0 より下(5 分・1 時間・4 時間)。5 分の組の差は後半に縮んだ(前半 −3.854 → 後半 −1.847)。1 時間・4 時間の差は 0 を含む。
- 【事実】プリントの時点で分かる「連鎖のここまでの数量」が大きいほど、その後の戻りは大きい(1 時間: g60 の 3 分位 1 −4.66 → 3 −17.25)。1 件の数量の 3 分位では差は小さい(−8.34 → −10.35)。直前 60 秒の最大との比が小さい(=そのプリントが直前の最大より小さい)ほど戻りが大きい(−18.77 vs −11.13)。上の表の 3 分位の境は全期間から決めている。
