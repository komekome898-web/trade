## 4. 知見(D10 の型)

1. 【事実】「bitFlyer FX の 40 分のレンジの中心へ戻る動きを、原典 v37 の形(中心 ± 2×平均の実体に指値、建値から按分した幅で利確、40 分で成行)で取る形は、1 分足の指値の再現では、2015-11〜2023-12 に成り立たない(良い側 −82.37・悪い側 −243.93 bp/日、両側とも全期間・ほぼ全部の年で負)」。射程: 1 分の中の往復を数えない・板の位置を代わりの値段で置く・経費の前(L-579・L-581)。0.6 秒ごとに置き直す原典の動きそのものではない。
2. 【事実】「利確を中心から測る形(4:3)と比の門を足した改良した形は、1 分足の中の順序の仮定で符号が変わる(良い側 +81.76・悪い側 −38.17 bp/日)。仮定に左右されない取引だけでは両側とも負(−67.20・−45.59)で、良い側の正は全部、順序が決まらない足を含む取引から来る」(DRY_RUN で出した文と同じ)。
3. 【事実】改良と原典の差は、良い側・悪い側の両方で同じ向き(利確 4:3: +174.64 / +201.24、過去だけの比の門: +28.61 [+26.07, +31.31] / +25.17 [+22.88, +27.58] bp/日。`READ_ROUND2/RESULTS.md` 14〜21 行)。
   - 【推定】差の向きは順序の仮定に左右されにくい。ただしスキルの D8 の決まり(止める = True なら改良の比べから採用・改良を言わない)をそのまま当てると、この差も採用の根拠にしない。**スキルの決まりと、この読みは食い違う**(7 で扱う)。
4. 【事実】損はブレイクで閉じた取引に集まる(K-001)・保有の長い取引が負ける(K-004)は、出の理由・保有時間で分けた【結果で決まる群】で、形の記述にとどめる。比が大きいほど 1 取引あたりが悪い(K-005)は【建ての前に決まる群】で、比の門の根拠になる(D3)。

## 7. スキルの穴の候補(D8 の決まり。L-666 で直した)

- 決まりの目的(スキル D8): 仮定が作った稼ぎを、前提・改良の稼ぎとして読まないこと。
- 目的から見ると、改良の差が仮定で作られていないかは、2 つの形の良い側・悪い側の 4 つの組み合わせのうち、一番不利な組み合わせ(新しい形の悪い側 − 元の形の良い側)が 0 より上かで決まる。本当の値が各形の良い側と悪い側の間にあるなら、本当の差はこの値より下にならない【推定。1 分の中の往復を数えない分(L-581)は外】。
