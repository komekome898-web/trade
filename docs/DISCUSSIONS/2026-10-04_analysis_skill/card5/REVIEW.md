## 0. 結論(先に)

- 【事実】このカードの稼ぎ(+7.68 bp/日)は、「朝の値動きの向きに付いていく」ことからは来ていない。同じ分に**買いだけで持つ**と +17.99 [+9.92, +25.63] bp/日で、カードはそれより −10.30 [−21.49, +1.35] 低い(区別がつかない)。カードの正は、日本時間の平日 0:00〜9:55 に値段が上がっていた偏りの取り分(買いの取引)だけ。
- 【事実】その時間帯の上げの偏りは、前半・後半とも 0 より上(1 分あたり 前半 +0.0607・後半 +0.0322 bp)。持っていなかった時間帯(平日の 9:55〜24:00 と土日)は前半・後半とも 0 を含む。時間帯の差は前半 +0.0489 [+0.0149, +0.0843]、後半 +0.0236 [−0.0023, +0.0503](後半は 0 を含む)。
- 【推定】カードの問い(朝の値動きは続くか)には「1 分の細かさでは、続く向きの情報は見えない」。代わりに出たのは「日本の朝に上がる」という時間帯の偏りで、これはカードとは別の問い。

## 6. 読み

- 【事実】D1 は決まらない。全期間の正は 2015・2022 年の正に寄る(年ごとの表)。
- 【事実】稼ぎの形は「少ない大勝ちで多い小負けを埋める」(勝率 12.7%、勝ち平均 +85.15、負け平均 −11.58)。前半・後半とも同じ形。
- 【事実】買いの取引は前半・後半とも 0 より上、売りの取引は前半・後半とも 0 を含む。カード − 買いだけ は全期間・前半・後半とも 0 を含み、点は負。
- 【推定】朝の値動きの向き(合図)には、1 分の細かさでは、向きの情報が見えない。見えているのは「日本の朝(平日 0:00〜9:55)に値段が上がる」偏りで、カードは買いのときにそれを取り、売りのときに逆らっていた。
- 【推定】日本の朝の上げの偏りは前半の方が大きく、後半は時間帯の差が 0 を含む(縮んでいる向き)。期間全体の上げ(持っていなかった分)は前半・後半とも 0 を含む。
- 止めたもの: 改良の手順(D2 の門・D7)はこのカードの形の上では進めない。合図に情報が見えないので、門(K-033 の前の日のボラ)を足すのは、合図の無い形への継ぎ当てになる(第 1 部 §5)。D4・D5 の道具は指値の再現の形用で、このカードには当てていない(取引の一生の表は、このカードでは保有時間の帯までで切った)。

## 8. 知見の文(D10)
