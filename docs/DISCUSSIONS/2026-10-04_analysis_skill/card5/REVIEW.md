出所: オーナー「**測定したカード全部の分析と残作業整理を、オーナーが納得できる形まで整理すること**」(L-676)。分析のスキル `.claude/skills/analysis-lens`(第 5 版)を呼び出して当てた。新しい走らせはしていない。保存済みの測定の出力(`docs/RESEARCH/cards/c5_tokyo_fix_momentum/measure/default/` の `daily.csv`・`run.npz`・`extra.json`)だけを読んだ。読んだ順: 出力 → 表 → 読み → その後に台帳の前の行(§7)。単位: bp/日 = 1 日あたりの損益(持ち高 1 単位、経費の前)。区間は 95%(日の塊 5 日・1,000 回・種 20261004)。

## 0. 結論(先に)

- 【事実】このカードの合図(0 時からの値動きの向き)に、1 分の細かさで向きの情報は見えない。買いの合図だった 1 分の値動き(+0.0605 bp/分)と売りの合図だった 1 分の値動き(+0.0287)の差は +0.0318 [−0.0072, +0.0745](前半 +0.0225・後半 +0.0394、どれも 0 を含む)。どちらの合図の分も値段は上がっていた。
- 【事実】カードの稼ぎ(+7.68 bp/日)は、日本時間の平日 0:00〜9:55 に値段が上がっていた偏りを買いの取引で取った分。同じ分に**買いだけで持つ**と +17.99 [+9.92, +25.63] bp/日(前半・後半とも 0 より上)。
- 【事実】その時間帯の上げの偏りは、前半・後半とも 0 より上(1 分あたり 前半 +0.0607・後半 +0.0322 bp)。持っていなかった平日の時間帯(9:55〜24:00)と土日は、前半・後半とも 0 を含む。持っていた分 − 持っていなかった平日の分 は前半 +0.0577 [+0.0220, +0.0953]、後半 +0.0188 [−0.0087, +0.0466](後半は 0 を含む)。
- 【事実】曜日で分けると、買いだけの対照が一番大きいのは月曜の朝(+50.63 [+27.10, +73.94] bp/日、前半 +72.71・後半 +28.55 でどちらも 0 より上)。カードは月曜に買いだけの対照より −58.99 [−87.11, −31.09] 低い(前半 −98.44 は 0 より下、後半 −19.54 は 0 を含む)。カードの正は木・金(+37.05・+31.02)に寄るが、木・金のカード − 買いだけの対照 は 0 を含む。
- 【推定】カードの問い(朝の値動きは続くか)には「1 分の細かさでは、続く向きの情報は見えない」。代わりに出たのは「日本の朝に上がる」という時間帯の偏りで、これはカードとは別の問い。

## 6. 読み

- 【事実】D1 は決まらない。全期間の正は 2015・2022 年の正に寄る(年ごとの表)。
- 【事実】稼ぎの形は「少ない大勝ちで多い小負けを埋める」(勝率 12.7%、勝ち平均 +85.15、負け平均 −11.58)。前半・後半とも同じ形。
- 【事実】買いの取引は前半・後半とも 0 より上、売りの取引は前半・後半とも 0 を含む。
- 【事実】向きの情報の検め(買いの合図の分 − 売りの合図の分)は全期間・前半・後半とも 0 を含む。点は正(+0.0318)なので、情報が全く無いとは言えないが、区別がつかない。
- 【推定】見えているのは「日本の朝(平日 0:00〜9:55)に値段が上がる」偏りで、カードは買いのときにそれを取り、売りのときに逆らっていた。
- 【推定】日本の朝の上げの偏りは前半の方が大きく、後半は持っていなかった平日との差が 0 を含む(縮んでいる向き)。持っていなかった平日の分・土日の分は前半・後半とも 0 を含む。
- 【事実】朝の上げは月曜に一番大きい(買いだけ +50.63 bp/日)。月曜の朝は週末の後で、カード 6(週末ギャップ)の窓が開く時間帯と重なる(為替の週明けは日本時間の月曜の朝)。月曜にカードが買いだけより大きく負けるのは、月曜の朝に 0 時から下げていて売り、その後に上がった日があることを示す【推定: 取引の行を月曜だけで並べていない】。
- 【推定】木・金のカードの正は、買いだけの対照と区別がつかないので、木・金に「向きの情報」があるとは言えない。
- 止めたもの(スキルの決まりの名前で): **「買いの合図の分 − 売りの合図の分 が 0 を含む → 合図に向きの情報があるとは書かない」**。これは D5 の決まり「建ての時刻からの値動きが対照と区別できないなら、合図に情報があるとは書かず、出口の改良を出さない」を、毎分持ち直すカードの形に移したもの(合図の後の値動きを、買いの合図と売りの合図で比べる)。だから改良の手順(D2 の門・D7)はこのカードの形の上では進めない。門(K-033 の前の日のボラ)を足すのは、合図の情報が見えない形への継ぎ当てになる(第 1 部 §5)。D4・D5 の道具は指値の再現の形用で、このカードには当てていない(取引の一生の表は、このカードでは保有時間の帯までで切った)。
