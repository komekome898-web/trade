## 0. 結論(先に)

- 【事実】「値段がセッションの始まりからの平均より上なら売り、下なら買い」の合図は、セッションの始まりからの経過時間で向きが入れ替わる。始まりの 10 分は、平均より上にある値段は次の 1 分も上がる(前提と逆、日本時間の日の区切りで −1.1380 [−1.6351, −0.6768] bp/分、前半・後半とも 0 より下)。1〜4 時間は、日本時間の日の区切りで前提どおり平均へ戻る向き(+0.1145 [+0.0461, +0.1791]、前半は 0 より上・後半は 0 を含む)。
- 【事実】区切りの時刻で全体の向きが違う。日本時間の日(0 時)の区切りは全体で区別がつかない(−0.0080 [−0.0264, +0.0118])。bitFlyer の保守(日本時間 4 時)の区切りは全体で前提と逆(−0.0439 [−0.0629, −0.0245]、前半・後半とも 0 より下)で、損益も前半・後半とも負(D1「成り立たない(逆向き)」)。
- 【推定】始まりの 10 分の逆向きは、平均がまだ数本の足しか含まないので「直前の数分の値動きの向きが次の 1 分も続く」(1 分の細かさの順張り)を見ている。保守の区切りの 4〜12 時間の逆向きが何を見ているかは分からない(経過時間と時刻(日本時間 8〜16 時)が重なっていて、この 2 つの区切りの出力だけでは分けられない)。

## 6. 読み

- 【事実】D1: 日本時間の日の区切りは **決まらない**、保守の区切りは **成り立たない(逆向き)**(前半 −42.93・後半 −19.50 bp/日、どちらも 0 より下)。
- 【事実】向きの情報の検めは、経過時間で向きが入れ替わる。日本時間の日の区切り: 0〜10 分 −1.1380(前半・後半とも 0 より下)、10〜60 分 −0.1381(全期間は 0 より下、前半・後半は 0 を含む)、60〜240 分 +0.1145(全期間・前半は 0 より上、後半 +0.0754 [−0.0043, +0.1517] は 0 を含む)、240 分より後は 0 を含む。保守の区切り: 0〜10 分 −1.6523(前半だけ)、10〜60 分 −0.1202、60〜240 分 −0.0832(後半 +0.0005 は 0 を含む)、240〜720 分 −0.0448(前半は 0 より下、後半は 0 を含む)、720〜1440 分 −0.0254(0 を含む)。
- 【推定】始まりの 10 分の強い逆向き(平均より上の値段がさらに上がる)は、平均が直前の数本の足だけで決まるので、「直前の数分に上げた(下げた)値段は次の 1 分も上げる(下げる)」= 1 分の細かさの続きを見ている。2 つの区切り(日本時間 0 時・4 時)の両方で出るので、特定の時刻(日本時間の 0 時)だけの癖ではない【推定: 保守の区切りの 0〜10 分は前半だけ】。
- 【推定】日本時間の日の区切りの 1〜4 時間(日本時間 1〜4 時)の平均へ戻る向きと、保守の区切りの 1〜12 時間(日本時間 5〜16 時)の逆向きは、経過時間の違いか時刻の違いか、この 2 つの出力では分けられない。
- 【事実】損益の形は「多い小勝ち・少ない大負け」(勝率 0.820・0.816、勝ち平均 +9.33・+8.99、負け平均 −44.84・−45.12)。保有 14 分より長い取引(平均から離れたまま戻らなかった取引)に負けが集まる(1 取引あたり −24.48・−25.75)。【結果で決まる群】なので記述だけ。

- 進めたもの・止めたもの: 日本時間の日の区切りの全体は **「買いの合図の分 − 売りの合図の分 が 0 を含む → 合図に向きの情報があるとは書かない」** で止める。経過時間の帯で分けた表は診断(帯は結果を見る前に置いたが、区切りを決めたのは読み直しの中)で、門の材料にしない。帯で見えた 2 つの形(始まりの続き・1〜4 時間の戻り)は、前提の直接の測り(D1b、区切り 24 通り × 経過時間)で確かめてから知見の事実にする。保守の区切りは前提と逆向きに区別がつくが、何を見ているか(経過時間か時刻か)が分からないので、改良(逆に張る形)は出さない(第 1 部 §5: 結果を見てから切り口を探さない)。
