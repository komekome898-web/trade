## 2. 読み

- 【事実】成行の形は 3 つの窓とも前半・後半とも 0 より上で、後半に縮んだ(**続いている(縮んだ)**): 1h 前半 +448.30 → 後半 +235.95、1d +256.25 → +118.43、1w +160.21 → +93.11 bp/日。

- 【事実】成行の形の損益は、記録された約定の値段で売買できる仮定(約定の側の仮定)次第で、1 取引あたり 1.4〜2.9 bp(10-04 の `REVIEW.md` §4)。成行の形の「続いている」は、この仮定の上の数。
- 【推定】指値の模型の後半の大きな負は、指値が逆に選ばれる(値段が不利に来たときだけ約定する)形がカツオの指値と同じに出たもの。ただし模型はオーナーの案ではなく(L-564)、後半に崩れた理由は取引の行が無いので分けていない。
- 止めたもの: 成行の形の水準を稼ぎとして読むこと(仮定次第、D8 の考え)。指値の模型の改良(崩れた・オーナーの案でない)。
