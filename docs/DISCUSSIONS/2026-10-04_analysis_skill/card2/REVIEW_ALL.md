- 【事実】荒れ具合の門を足した終値の形は、同じ合図の門と降り方の 18 通りのうち 17 通りで向きの情報の検めが 0 より上(+0.13〜+0.43 bp/分)。D1 は固定の境で「続いている」3 本、直前 365 日の境で「後半だけ」11 本。【推定】門は 1 分あたりの値動きが大きい日を選ぶので、1 分あたりの差は大きく出やすい。門の中で情報が濃いのか、値動きの大きさで割り増しになっただけかは、この表では分けられない(荒れ具合で割った差を出すのが次の手)。固定の境は K1 の期間から決めた値で、標本の中。
- 【事実】指値で入る形(`limit_*`・`le_cx`・`gate_limit`・`rgate_limit`、66 本)は、向きの情報の検めが 0 より上のものが 2 本だけで、7 本は 0 より下。同じ合図・同じ門でも、指値で入ると情報が消える。【推定】指値は値段が逆に来たときに約定する(逆に選ばれる)ので、約定した取引は合図の向きに動かなかった取引に寄る(K-008・K-039 の「取り逃しで負ける」と同じ仕組みの別の見え方)。
