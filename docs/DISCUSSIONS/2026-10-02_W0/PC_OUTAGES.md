## 2. 結論(3 行)

1. **3 回は同じ原因ではない。** 08-25 の 1 回目は **PC は動いていた**(15 分ごとのタスクが夜通し外部の API から値を取って書いていた)。止まったのは bitFlyer の値の流れで、bot はキルスイッチで止まり、WS の記録器は 60 秒の無受信でファイルを閉じた。原因(bitFlyer に届かなかったのか、別の理由か)は **【未確認】**【事実 + 推定、§3】。
2. **08-27 の 2 回目と 09-10 の 3 回目は、PC 全体が一瞬で止まった型**。全部の記録がほぼ同時に途切れ(2 回目は 17:57〜18:00 UTC の間で、15 分ごとのタスクも止まった。3 回目は 21:08:12 の同じ秒)、2 回目は WS の記録器がファイルを閉じずに消え、3 回目は清算の記録器が切断を 1 行も書かずに消えた。2 回目は bot の値の記録に 196 バイトの NUL(0x00)が残っている。これは「ファイルの長さは伸びたが中身がディスクに届かなかった」跡で、電源断・強制リセット・OS の異常終了(ブルースクリーンなど)と合い、正常なシャットダウンやスリープとは合わない【事実 + 推定、§4・§5】。
3. **3 回とも、戻ったのは日本時間の昼(11:54・13:18・15:18)**。PC のタスクはどちらも「ログオン時 + 繰り返し」で登録されている(`docs/OPERATIONS.md` §5、PC のブランチ)ので、PC が再起動しても**誰かがログオンするまで何も動かない**作りである【事実: 文書】。2・3 回目の 9〜10 時間の欠けの大部分は、止まった原因よりも「戻る仕組みが人のログオン待ち」であることから来ている【推定】。

## 7. PC で確かめる手順(オーナー向けの下書き。手順番号はリードが付ける)

**前提**: Windows のイベントログは古いものから上書きされる。1 か月以上前の 08-26・08-28 は残っていないかもしれない【未確認】。残っていなければ、そのこと自体を共有してもらう(「無い」と決めずに、打ったコマンドと出力で判断する)。

調べる時間帯(日本時間): ① 08-26 03:20〜12:10 ② 08-28 02:50〜13:30 ③ 09-11 06:00〜15:30

1. **電源・再起動・スリープ**(PowerShell、管理者不要。① の例。② ③ は日付と時刻を替える):
   ```
   Get-WinEvent -FilterHashtable @{LogName='System'; StartTime='2026-08-26 03:20'; EndTime='2026-08-26 12:10'} |
     Where-Object { ($_.Id -in 41,42,107,1074,1076,6005,6006,6008,12,13) -or ($_.Id -eq 1 -and $_.ProviderName -like '*Power*') } |
     Select-Object TimeCreated, Id, ProviderName, Message | Format-List
   ```
   見分け方(Windows の標準のイベント ID。この PC で確かめてはいない):
   - 41(Kernel-Power)・6008(EventLog「前回のシステムのシャットダウンは予期されていませんでした」)= 予期しない停止(電源断・強制リセット・異常終了)
   - 1074(User32)= 予定された再起動・シャットダウン。どのプロセスが起こしたか(Windows Update など)が本文に出る
   - 12・13(Kernel-General)= OS の起動・停止 / 6005・6006 = イベントログの開始・停止
   - 42(Kernel-Power)= スリープに入った / 1・107(Power-Troubleshooter・Kernel-Power)= スリープから戻った
2. **ログオン**(再起動のあと誰かがログオンするまで止まっていたかを見る。タスクは「ログオン時 + 繰り返し」):

## 8. この結果から計画に返すこと(リードが決める)

- 並走 3「同時停止の原因」は、**2・3 回目 = PC が一瞬で止まる型(電源・強制リセット・異常終了のどれかは PC のログ待ち)、1 回目 = PC は動いていて bitFlyer の流れだけが止まった型**、に分けて扱う【推定】。
- どちらの型でも、戻るのに人のログオンか人の解除が要った。人の手の一覧(HUMAN_TOUCH.md)の H-1・H-2 の行に入れた。
- 1 回目の型は、並走 3 の「一時停止」(データが古いときは自動で再開、L-544 承認済み・実装中)が入れば、取引の停止は解ける。ただし記録器が 8 時間受け取れなかったことは別に残る【推定】。
