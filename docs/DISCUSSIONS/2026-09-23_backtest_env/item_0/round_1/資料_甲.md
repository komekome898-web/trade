# 比較資料(観点別、雛形統一)

固定した 6 観点(V1〜V6)ごとに 1 節、各節「何ができるか / 既定で何が起きるか / 根拠」の 3 行。
複数の候補を寄せ集めた合成の資料であり、単一の実装の資料ではない。観点によっては裏付けが見つからなかったことも正直に書く。

## V1(時刻表現の一貫性)

- 何ができるか: 時系列全体をナノ秒の分解能で扱うと一次資料上で明記している候補がある。
- 既定で何が起きるか: 一次資料の文言からは既定の挙動までは分からない(未確認)。
- 根拠: 一次資料(紹介文)の文言を実測(「ナノ秒分解能」の記載を確認)。

## V2(事象型の網羅性)

- 何ができるか: 明示的な型を持つ出来事を複数種類(実測できた最多で 5 種類)列挙している候補がある。
- 既定で何が起きるか: 一次資料の文言からは既定の挙動までは分からない(未確認)。
- 根拠: 実装コードを実測し、型の名称を 5 種類確認。

## V3(ルックアヘッド不能性)

- 何ができるか: 「先読みの偏りを防ぐ道具」を持つと一次資料上で明記している候補がある。
- 既定で何が起きるか: 中身の実装までは未確認。
- 根拠: 一次資料(紹介文)の文言を実測(該当の記載を確認)。

## V4(決定的な事象順序)

- 何ができるか: 「決定的な事象駆動の構成」であることを一次資料(登録情報)上で明記している候補がある。
- 既定で何が起きるか: 一次資料の文言からは既定の挙動までは分からない(未確認)。
- 根拠: 登録情報の文言を実測(該当の記載を確認)。

## V5(戦略 API の疎結合性)

- 何ができるか: 直接この観点を裏付ける文言は、今回実測した範囲では見つからなかった(部品を組み替えられるという一般的な柔軟性を述べる文言のみ見つかった)。
- 既定で何が起きるか: 不明(裏付けが無いため判定できない)。
- 根拠: 複数の語で検索を実測したが、該当なし。分からないことを分からないと記録する。

## V6(拡張点の分離)

- 何ができるか: 約定の判定を差し替え可能な部品として外に出し、複数の入力形式で判定を分けて扱うと一次資料上で述べている候補がある。
- 既定で何が起きるか: 一次資料の文言からは既定の挙動までは分からない(未確認)。
- 根拠: 一次資料(紹介文)の文言を実測(「差し替え」に関する記載を確認)。
