# 項目 0(核)比較資料 乙

観点は固定した要件(REQUIREMENTS.md)の V1〜V6。各節 3 行以内(何ができるか / 既定で何が起きるか / 根拠)。調査結果の側は、観点ごとに最も高い機構を持つ候補を寄せ集めたもの(1つの実装ではない)。

## V1(時刻表現の一貫性)

- 何ができるか: 候補群のうち1つが、事象の時刻表現についてナノ秒の分解能を持つと一次資料(公開されている説明文書)に明記している。
- 既定で何が起きるか: 未確認(この観点の既定動作までは一次資料の記述からは分からない)。
- 根拠: 一次資料の該当記述(調査班による実測記録)。

## V2(事象型の網羅性)

- 何ができるか: 候補群のうち1つが、明示的な型を持つ複数種類の事象(確認できた範囲で5種類)を列挙し、種類ごとに処理を振り分けている。
- 既定で何が起きるか: 未確認(何種類が既定で有効かは記述からは分からない)。
- 根拠: 該当コードの実測記録(調査班による一次資料への到達を含む確認)。

## V3(ルックアヘッド不能性)

- 何ができるか: 候補群のうち1つが、「先読みの偏りを防ぐ道具」を持つと一次資料に明記している。中身の実装までは確認できていない。
- 既定で何が起きるか: 未確認。
- 根拠: 一次資料の該当記述(調査班による実測記録)。

## V4(決定的な事象順序)

- 何ができるか: 候補群のうち1つが、登録情報の説明文で「決定的な事象駆動アーキテクチャ」を持つと明記している。
- 既定で何が起きるか: 未確認。
- 根拠: 登録情報の該当記述(調査班による実測記録)。

## V5(戦略APIの疎結合性)

- 何ができるか: この観点を直接裏付ける記述は、調査班が今回確認した範囲では見つからなかった。近い記述として「利用者が定義した部品を組み替えられる」という一般的な柔軟性の主張はあるが、戦略側の操作が発注・取消・事象購読だけに限定されるという保証までは述べていない。
- 既定で何が起きるか: 不明(判定できる記述が無い)。
- 根拠: 調査班による実測記録(該当する明記が無いこと、および近い記述の確認)。

## V6(拡張点の分離)

- 何ができるか: 候補群のうち1つが、約定の模型を差し替え可能な部品として持ち、足とティックの両方を入力にして事象駆動で回すと一次資料に記されている。
- 既定で何が起きるか: 未確認(導入・実行はしていない)。
- 根拠: 一次資料の該当記述(調査班による実測記録、未導入)。
