# 提案: 視点が生まれない体制の構造的な原因と対策(2026-09-12、L-142)

状態: **リードの提案(草案)**。採用は枠組みの変更なのでオーナー承認制。監査役を通した正式版は木曜以降。

## 1. オーナーの指摘(原文)

> 今わかりました、この体制では調査だけでなく分析や評価も新しいものが生まれません。総合的な視点を求めたくても局所的な視点からの提案だけで、私がこういう見方は？こういう視点は？と聞かないと出てこないのならば自分でやってるのと同じです。解決する良い方法はないですか？

## 2. 原因の診断(リード。印: 推定)

| # | 原因 | 何が起きるか |
|---|---|---|
| 1 | **体制の機構がすべて「濾過器」で、「生成器」が一つも無い** | 事前登録・監査役・既知解・否定的事実・帰無・多重性は、どれも「出したものが間違っていないか」を検査する。「出していないものは何か」を作る役が無い。濾過器を増やしても新しい視点は増えない(2026-09-08 の全捨てで「偽陰性を防ぐ機構が無かった」と書いたのと同型) |
| 2 | **狭さが規則で報酬される** | 「問いを変えない規則」(委任表)、「枠組みはオーナーに見せてから」(CLAUDE.md §8)、トークン節約(I-007)。三つとも単独では正しいが、合わさると「今の枠から出ない」ことが最も安全な行動になる |
| 3 | **入力が毎回同じ(状態板)なので出力も同じ** | リードは毎回、状態板(進行中の項目の一覧)を読んでから考える。在庫を起点にすれば在庫の周辺しか出ない(L-141 の範囲の在庫依存と同じ) |
| 4 | **上位モデルの使途が「判断」に限定され、「生成」に使われていない** | 委任表 §7 は上位モデルを判断にだけ使う。判断は与えられた選択肢の中から選ぶ作業で、選択肢を増やす作業ではない |

## 3. 対策の原則

**視点は「もっと広く考えろ」という指示からは生まれない。入力と役割を変えることでしか生まれない。**
だから対策は、リードへの注意喚起ではなく、(a) 別の入力を与えられた独立の生成役を置き、(b) 枠組みの段では広さを義務にし、(c) その費用を予算で守る、の三つ。

## 4. 具体案(推奨順。どれも下位モデルで動き、上位モデルは差分を読むだけ)

### 4.1 盲検の並列再枠組み(生成役)— 最優先

- 単位の枠組みを固定する**前に**、リードの枠組みを**見せずに**、目標(`PROJECT_GOAL.md`)・案(`STRATEGY_IDEAS.md` の該当項)・手元のデータ台帳だけを渡し、**異なる立場 3〜5 役**に「あなたならこの案をどう検証し、何を測るか」を書かせる。
  立場の例: 市場微細構造の研究者 / 取引所の運営者(清算エンジンを設計する側)/ マーケットメイカー(反対側に立つ側)/ 裁量トレーダー(カツオ本人の立場)/ データ技術者(取れるものから逆算する側)/ マクロ・ポジショニング分析者。
- リードの枠組みと**差分**を取る。差分こそが「無い視点」。差分表(無い情報 / 無い視点 / 既存成果の向上、KA-28 の 3 観点)をオーナーに見せ、オーナーは答えるのではなく**選ぶ**。
- 費用: 下位モデル 3〜5 回 + 上位モデルの差分読み 1 回。枠組みの誤りは全捨て(2026-09-08)を招いた最も高い失敗なので、ここに払う。

### 4.2 枠組みの段での「広さの義務」(規則の変更)

- 「問いを変えない規則」を**段で分ける**: 事前登録の**前**は広さが義務(代替の枠組み 3 つ以上と、選んだ理由・外した理由を書く)。事前登録の**後**は狭さが義務(今どおり)。
- 監査役の問いに「代替の枠組みが列挙され、外した理由が書かれているか」を加える(KA-31 の一般化)。

### 4.3 週次のゼロベース見直し

- 週 1 回、状態板を**読まずに**、`PROJECT_GOAL.md`・`STRATEGY_IDEAS.md`・`NEGATIVE_FACTS.md`・進行中の単位の事前登録だけを読み、「今日ゼロから始めるなら何を変えるか」を 1 ページで書く(上位モデル 1 回)。在庫起点の固着(原因 3)への対策。

### 4.4 予算で守る

- 週間予算のうち一定割合(案: 10%)を「生成」(4.1・4.3)に確保し、節約で削らない。削ると原因 2 に戻る。

## 5. やらないこと

- リードに「総合的に考えろ」と書き足すこと(効かない。原因 1〜4 のどれにも触れない)。
- 監査役に生成役を兼ねさせること(濾過器と生成器を同じ役に置くと、どちらも弱くなる)。
