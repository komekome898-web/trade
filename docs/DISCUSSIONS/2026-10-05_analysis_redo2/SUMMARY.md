## 2. カードをまたいで分かったこと(次の測りへの入力。どれも【推定】)

1. **成行の「次の足の始値で約定」の仮定は、合図の向きで効く向きが変わる**(カード 3・5・7・8・9)。合図の足の終値は動いた側の端で付き、次の始値で戻ることが多い。順張り(カード 5)はその戻った始値で買うので損益が楽観的に出る。逆張り(カード 7・8)は戻った始値で売るので、始値 → 始値の値が実際の成行に近く、中ほどの値段の方が楽観的。カード 9(Binance の約定)では、清算の直後の 1〜10 秒は、どの側の約定で値段を決めるかで約 0.6 bp 動き、値動きと同じ桁。
2. **静かな時期(前の日が静か・幅が小さい)ほど、値動きは続く側に寄る**。独立に近い観察は 2 つ: カード 7(幅が小さいレースほど継続)と、カード 5・8 の組(前の日が静かな日に、朝の順張りは勝ち、平均回帰は負ける。2 つは同じ bitFlyer の日の上でほぼ鏡の形で、台帳の相関 −0.36)。物差しは違う。
3. **Binance では、上へ押す清算の連鎖は続き、下へ押す連鎖は戻る側**(カード 9、前半・後半で同じ向き)。カツオの買い(下ヒゲの逆張り)と売り(上ヒゲの逆張り)で稼ぎが違うかを見る材料。
4. **対照の作り方の穴**: 合図の符号がその日の値動きの経路で決まる形(カード 8)では、「24 時間後の同じ時刻・同じ向き」の対照は中立にならない(翌日の同じ時刻の動きが、今日の偏りで決まる)。
