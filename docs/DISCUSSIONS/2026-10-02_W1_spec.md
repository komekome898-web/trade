# W1 の仕様: カードの測定器と検め(計画 第 5 版 §4 W1)

リードが委任の前に書く仕様(F2: 推測で埋める箇所を残さない)。用語は計画 第 5 版 §0 と同じ。

## 0. 目的と範囲

- 目的: 段 2・3 で、カード(足ごとに持ち高 −1〜+1 を出す関数)の**経費前の効果**を、場面ごとに、未来を見ずに、比べる相手(対照)と検出力つきで測る。
- 範囲に入れない: 経費(段 5)、合成器(段 4)、本番の bot への橋(段 7)。
- 置き場: `src/bot/research/cards/`(新)、`scripts/check_card.py`(新)、試験は `tests/research/cards/`(新)。既存の `src/bot/bt/` は、足りない部品(下の C3)だけ足す。

## 1. 部品

### C1 カードの口

```python
class Card(Protocol):
    name: str
    requires: list[SeriesSpec]        # 使う系列と、使えるようになるまでの遅れ
    def exposure(self, view: CardView) -> float: ...   # 足の終わり t に呼ばれる。−1.0〜+1.0
```

- `CardView` は、時刻 t までに使えるようになったデータだけを返す(足の終わりが t 以下の足、使えるようになる時刻が t 以下の参照の系列)。
- 返り値が −1〜+1 の外なら例外にする。NaN も例外。
- カードは内部の状態を持ってよいが、同じ入力なら同じ出力(乱数を使わない)。

### C2 走らせる仕組み

- カードは `bot.bt.core` の事象の流れ(`Strategy.on_event`)を通して呼ぶ。核の未来の読みの禁止(`LookAheadError` ほか)をそのまま効かせるため。持ち高の系列を記録したあとの損益の計算は、まとめて行ってよい。
- **約定の時点**: 足の終わり t に出した持ち高 e_t は、次の足の始値で約定したとみなす。
- **経費前の損益**: P_t = e_t ×(open_{t+2} ÷ open_{t+1} − 1)× 10,000(bp。持ち高 1 単位あたり)。
- **空の足**(約定 0 の足): 次の足が空なら、次の空でない足の始値を使う。空けた時間を記録する。
- 1 本の銘柄の足の系列に対して、1 枚のカードを走らせる。取引所をまたぐカード(海外の値動きで bitFlyer を持つ)は、参照の系列として海外の足を受け取る。

### C3 参照の系列と、使えるようになる時刻

- `src/bot/bt/data` に「参照の系列」(時刻と値の行)の種類を足す。宣言した遅れを行の時刻に足した時刻(available_at)に、事象として届ける。
- 遅れは系列ごとに宣言する(計画 第 4 版 §4-2 の表: CFTC は火曜の値を金曜 15:30 ET、Binance の比率は翌日 07:46 UTC など)。宣言の無い系列は読み込みを拒む。

### C4 場面の変数

| 変数 | 計算 |
|---|---|
| 局所ボラ | 1 分の対数の値動きの標準偏差。窓は 1 時間・1 日・1 週の 3 つ |
| レンジ/トレンド | 分散比(vr)。窓は同じ 3 つ |
| 時間帯・曜日 | 日本時間の時、曜日 |
| 取引所・制度 | 取引所の名前、制度(SFD の時代 / CFD の時代) |

- どれも、その時点より前の窓だけで計算する。
- 位置で表すときは、過去 365 日の自分の分布の中の分位(0〜1)にする。系列の始まりから 365 日に満たない間は、場面別の推定から外す(場面を使わない推定には入れる)。
- 窓の長さを 1 時間・1 日・1 週にした理由: 時計の自然な単位で、測る前に決められ、調整の余地が無い(A-12)。365 日にした理由: 曜日と季節が 1 回ずつ入る。

### C5 出すもの(カード 1 枚につき)

| # | 出すもの | 計算 |
|---|---|---|
| a | 全体と場面ごとの平均の損益 | 全体の平均。場面の変数ごとに、P_t を変数の値(標準化)に回帰した係数。表示用に 3 分位ごとの平均 |
| b | ドリフトを除いた損益 | e_t ×(r_{t+1} − 同じ場面の 3 分位の中の r の平均)。r は C2 と同じ次の足の値動き。測る期間の中の平均を使う(判断ではなく、測定の物差し) |
| c | 信頼区間 | ブロック・ブートストラップ(`bot.bt.validation.bootstrap`)。ブロックの長さ = 持ち高が 0 でない区間の長さの中央値と 1 日(1,440 足)の大きいほう。1,000 回。乱数の種は固定 |
| d | 対照 | 持ち高の系列を、c のブロックの長さ以上ずらした 200 通り(ずらす量は固定の種から決める)で同じ平均を出し、実際の平均がその分布の何パーセンタイルかを出す |
| e | 検出力 | 有意 5%(両側)・検出力 80% で検出できる最小の平均(`bot.bt.validation.power`)。効果が見えないとき、検出力の値と並べて「不明(検出力が足りない)」と「小さい」を分ける |
| f | 頻度 | 持ち高が 0 でない足の割合、持ち高が変わった回数 |
| g | 内訳 | 取引所ごと・年ごと |
| h | 日ごとの損益の系列 | 他のカードとの相関のため。ファイルに保存 |

### C6 カードの欄の検査(`scripts/check_card.py`)

- カードの説明(`docs/RESEARCH/cards/<id>/CARD.md`)に、次の欄が全部あること: 原文(逐語)/ 意図の地図 / なぜ(測る前の 3 問 = 第 4 版 §3-1。§0.2 ではない。`2026-10-02_W3_spec.md` §3 の注)/ 期待する向きと場面 / 反証 / 関数のパス / 水準とその出所 / 使うデータと遅れ / 約定の模型。
- 測る期間が、封印の台帳(`backtest_data/phase2_sealed/*/SEALED.json`)の封印の期間に重なっていないこと。
- 欄の欠け・封印に重なる期間を、拒むこと(下の T7)。

## 2. 検め(答えが分かっている合成データ)。全部通るまで本物のデータに当てない

乱数の種はすべて固定する。合成データは試験の中で作る。

| # | 仕込むもの | 入力 | 期待する答え |
|---|---|---|---|
| T1 | 1 つの場面にだけ効果 | 1 分足 200 日。値動きは平均 0・標準偏差 10 bp の独立な正規分布。場面 S(参照の系列、遅れ 0)を、60 足の塊で全体の 30% にだけ立てる。S が立っている足の次の値動きだけ平均 +2 bp。カードは常に +1 | S=1 の平均の損益の 95% 区間が 2 bp を含み 0 を含まない。S=0 の区間は 0 を含む |
| T2 | 未来の読みの禁止 | 遅れ 3 日を宣言した参照の系列。t に最新の値を読むカード | t で返る値は、行の時刻が t − 3 日以下のものだけ。使えるようになる前の行を読もうとすると例外。次の足を覗こうとすると例外 |
| T3 | 損益の計算の正しさ | 毎足 +1 bp ずつ上がる決まった値段の系列。持ち高 +1, −1, 0 を決まった順に出すカード | 損益の合計が、手で計算した値と一致(誤差 1e-9 以内)。t の持ち高が、t+1 の始値から t+2 の始値までの値動きに当たっている |
| T4 | 相関 | 日ごとの損益の相関が 0.5 になるよう作った 2 枚のカード | 測った相関の 95% 区間が 0.5 を含む |
| T5 | 効かないはずのカード | T1 と同じ独立な値動き(効果なし)。カードは直前の足の値動きの符号 | 平均の 95% 区間が 0 を含み、対照の分布の中で 2.5〜97.5 パーセンタイルの間に入る |
| T6 | 同じ入力で 2 回 | T1 の入力 | 出すもの(C5 の a〜h)が、2 回でビット一致(`bot.bt.repro` の形) |
| T7 | 欄の検査が実際に止まる | 欄が全部ある説明と、欄を 1 つずつ抜いた説明 9 本。封印の期間に重なる期間を宣言した説明 | 全部ある説明だけ通り、ほかは全部拒まれる。検査の中の確かめを 1 つずつ外した壊した版で、対応する試験が落ちる |
| T8 | 空の足 | 途中に 30 足の空きがある系列 | 空きの直前に出した持ち高は、空きの後の最初の空でない足の始値で約定し、空いた時間が記録される |
