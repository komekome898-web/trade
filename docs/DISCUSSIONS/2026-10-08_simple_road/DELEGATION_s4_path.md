## 受け入れ

各項目は、作業者が書き換えた `tests/simple/` の試験が、挙げた場面を持ち、飛ばし 0 で通ること。

- U1: 道筋と約定の場面の表: 陽線・陰線・始値 = 終値で上がって始まった・下がって始まった足の道筋の順。limit・stop が道筋を動いて届いたらその値段(path)、始値に飛んだ時点ですでに約定する側なら始値(open)、足の途中で出した時点ですでに約定する側ならその点の値段(now)。値段が安値・高値ちょうど。1 つの区間で複数の注文に届く順と、同じ値段の注文をまとめて 1 回呼ぶ。呼んだ点で返した注文がすぐ約定するなら同じ点でもう一度呼ぶ。返さなかった注文がその点で取り消される。見張る値段の到達(動いて届いた・折り返しの点ちょうど・返した時点で今いる値段と同じなら到達にしない・始値への飛びの間なら始値で到達)。`"stop"` の ev に足の高値・安値・終値が入っていない。刻みの切り捨て。
