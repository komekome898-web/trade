# W3 の仕様: 案の量産の手順を 1 回回す(計画 第 5 版 §4 W3・並走 1)

リードが委任の前に書く仕様(F2: 推測で埋める箇所を残さない)。用語は計画 第 5 版 §0 と同じ。

## 0. 目的と範囲

- 目的: 案の補給の手順(第 5 版 並走 1 の 1〜3)を 1 回通し、(1) 導出の表の全升から案を出し、(2) 1 案あたりの時間とトークンを測る。この数と、段 9 で要る補給の量から、次の周の速さの目標を決める(第 5 版 並走 1「根拠の無い数を先に置かない」)。
- オーナーの逐語: L-528「**動画のように5000個の戦略から100のエッジを集めるというのはこの研究ではしていないこと(ありとあらゆる多角的な視点から戦略立案をやれと言ってもやってくれなかったこと)です**」、L-531「**この私が挙げた例をそのまま探しまーすなんて怠惰で陳腐な追加案は許しません**」。
- 範囲に入れない: 案の評価(効く・効かないは書かない。`docs/STRATEGY_IDEAS.md` の冒頭の規則)、データの取得(W2)、カードの関数の実装と測定(W4)。データは 1 行も開かない(封印の期間も封印の外も)。

## 1. 3 つの経路と、この周での回し方

| 経路 | この周での回し方 | 待つもの |
|---|---|---|
| ① 導いて出す | §2 の表の 114 升を全部通す | 無し |
| ③ 外から取り込む | ① と同じ升ごとに、その跡を使った売買の公開の記述(論文・note・X・YouTube・ブログ・取引所のリサーチ)を 1 回検索し、見つかった機構を案にする。出所の URL を付ける | 無し |
| ② AI が出す | W4 の最初の 3 枚を測ったあとに、その「なぜ」から次の案を出す(1 枚につき、機構の要素を 1 つだけ変えた案。変えた要素を書く) | W4 の最初の 3 枚 |

- ③ を ① の升に乗せる理由: 外の記述を「どこを読むか」で選ぶと根拠の無い一覧になる。升(誰の・どの段階の跡か)ごとに探せば、探す範囲が導出から決まり、① が思いつかなかった機構を拾う役になる。
- 文章を構造化する読み取り役(第 3 版 §5-1)の精度の検めは、文章を**場面の変数として毎日流し込む**ときに要るもので、案として取り込むときは要らない(案はカードにする関所でリードが原文と並べて読む。第 4 版 §3-2)。

## 2. 導出の表の行(リードが決めたもの)

### 2-1 軸

- **恒等式の項**(第 3 版 §5-1 軸 1): bitFlyer FX_BTC_JPY の価格 ≡ BTCUSD × USDJPY ×(1 + 円の上乗せ)。当方の損益は 3 つの項の動きと**経費**(板・約定)だけで決まる。各案は、どの項に効くかを必ず書く。どの項にも効かない案は、案ではなく誤りである。
- **売買の一生の段階**(第 3 版 §5-1 軸 2): 関心 → 予告 → 移動 → 約定 → 持ち高 → 強制。列は 6 つ。

### 2-3 升ごとに書くこと

各升に 1 行。欄は次の 6 つ。

| 欄 | 中身 |
|---|---|
| 升 | `P<行>-<段階>`(例 `P1-強制`) |
| 跡 | その段階の行動がどこに残るか。第 3 版 §5-1B の表にあればそれを写し、区分(A/B/C/無/未確認/未到達)を付ける |
| 探した記録 | 第 3 版で「無」「未確認」の升は、検索語と結果を書いてから跡を書く(O-2: 調べずに「無い」と書かない)。1 升 1 回の検索で、見つからなければ「この検索で見つからなかった」と書く(「無い」と書かない) |
| ① の案 | その跡から導ける機構を全部書く。数を決めない(A-12)。1 つも書けなければ、書けない理由を 1 行 |
| ③ の案 | その跡を使った売買の公開の記述を 1 回検索し、見つかった機構。出所の URL |
| 在庫との重なり | `docs/STRATEGY_IDEAS.md` の既存の案と同じ機構なら、その番号。重なっても消さず、違う点を書く |

## 3. 案の書式(カードの欄に合わせる)

案 1 つにつき、カードの欄(第 4 版 §3-1、W1 の仕様 C6)のうち、測る前に書けるものを埋める。関数のパスは空のまま(W4 で書く)。

| 欄 | 書くこと |
|---|---|
| 原文 | ① は導出の升の番号と機構の文、③ は出所の記述の該当部分の逐語と URL。要約しない |
| 意図の地図 | 入る条件・出る条件・保有中の判断・強弱の付け方を列挙。決まっていない要素は「未定」と書く |
| なぜ | 測る前の機構の仮説: 誰が損をしているか・なぜ続くか・何で崩れるか(第 4 版 §3-1 の 3 問。下の注) |
| 期待する向きと場面 | どの場面で、どちらの向きに効くと考えるか。どの項に効くか(§2-1) |
| 反証 | 何が測れたら、この「なぜ」が違うと分かるか |
| 段 3 の種類 | (a) 海外で見える跡で bitFlyer を持つ / (b) 海外と日本の違い(円の上乗せ・遅れ・制度)を使う / (c) bitFlyer の中だけ |
| 水準とその出所 | 原文に書いてある値だけ。無ければ「未定(W4 で測る前に決める)」 |
| 使うデータと遅れ | 系列の名前、区分(A/B/C)、使えるようになる時刻の規則(分かる範囲。分からなければ「未確認」) |
| 約定の模型 | 成行か指値か |

- 書いてはいけないもの: 効く・効かない・有望などの評価、数値の見込み、過去の結果への参照(`docs/STRATEGY_IDEAS.md` の冒頭、L-019)。
- **注(なぜの 3 問の出所の訂正)**: 第 4 版 §3-1 と W1 の仕様 C6 は、この 3 問を「研究手順書 §0.2 の 3 問」と書いたが、§0.2 の 3 問は測った後の「どこで負けた/勝ったか・その分解から言える機構・設計のどこに触れば動くか」で、別のものである。測る前の 3 問はリードが第 4 版で決めたもので、手順書に出所は無い。測った後に §0.2 の 3 問を足す。

## 4. 置き場と、委任の分け方

- 升の表: `docs/RESEARCH/ideas/round1/DERIVATION.md`(114 行)。
- 案: `docs/RESEARCH/ideas/round1/IDEAS.md`(案ごとに §3 の欄)。案の番号は `D1-<連番>`(① 由来)・`X1-<連番>`(③ 由来)。
- `docs/STRATEGY_IDEAS.md` には §4 として、案の名前と機構の平文と、IDEAS.md の番号だけを足す(リードが取り込むときに書く)。
- 委任: 行を 4 つの組に分け、4 人の下位モデルに並べて渡す(組 A = P1〜P5、組 B = P6〜P10、組 C = P11〜P15、組 D = P16〜P19)。どの組も §2-1 の恒等式と §3 の書式を同じ文で受け取る。

## 5. 終わる条件と、リードの読み

- 終わる条件: 114 升すべてに §2-3 の 6 欄があり、案のすべてに §3 の欄があり、組ごとの時間とトークンが記録されている。
- 機械の数え(リードが打つ): DERIVATION.md の升の行が 114 であること、IDEAS.md の案の番号が DERIVATION.md の ① と ③ の欄の番号とすべて対応していること。
- リードの読み(コードを変えない委任なので LLM の批評家は通さない。O-5): 全案を読み、次のどれかに当たる案を差し戻す。どの項にも効かない / 評価や数値の見込みを書いている / 「無い」「取れない」を調べずに書いている / 原文が要約になっている。
- 差し戻しが 2 回目になったら、直し続けずに止めて、なぜ 1 回で通らなかったかの原因を出す(計画 §4-1)。
- この周の終わりに出すもの(計画 §4 の「この周の終わりに出すもの」の「案の量産の速さ」): 経路ごと・組ごとの案の数、1 案あたりの時間とトークン、114 升のうち案が出なかった升とその理由。
