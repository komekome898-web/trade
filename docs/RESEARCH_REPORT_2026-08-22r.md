# 為替FX参入・フェーズA(2026-08-22 第18報)

オーナー指示「為替FXで安定収入の自動bot。市場差異に留意し全資産を活かし、BTCとの相乗を構築」のフェーズA(地形調査・データ基盤・相乗第1弾)。詳細な実測値は `docs/KNOWLEDGE_FX.md`(新設)に恒久記録。

## 1. 地形の結論: コストの壁が1/9になり、初めて「バーに届く」市場

USD/JPY往復0.71bps(実測)vs BTC CFD 6.35bps。変動/コスト比0.39→**0.94**。ただしKNOWLEDGE§2の法則「コストが低い場所に遅れはない」が最も強く効く地球最効率市場でもある — 低いのはバーであってエッジではない、を銘記。

## 2. ブローカー判定: GMOコイン外国為替FX API

- 資格ゲートなし・最小100通貨(≒1.6万円)・HMAC認証・Private WSで約定push・注文種豊富 [検証済]
- **per-fill手数料0.002%が指値にも課金 → maker逃げ道なし**(スプレッド0.31bps<手数料0.4bps)。バックテストはper-fill費用で符号化
- OANDA証券は「月50万ドル取引を継続」というGold要件が事前登録型研究と非両立、API対応コースはスプレッド2倍 → 却下(フォールバック記録のみ)
- デモ環境なし → PAPERは自前(既存 `paper.py` を公開API価格に接続 — 本プロジェクトの得意分野)

## 3. データ基盤(即日稼働)

- **Dukascopy**(インターバンク、2005年〜、認証不要)のURL規約・バイナリ形式を三角測量で確定し、フェッチャー実装・USD/JPY 1分足3.5年分を収集中(冪等・恒久スナップショット)
- 経済カレンダーJSON(ForexFactory)・CFTC建玉・FOMC/BOJ確定日程・MOF介入実績のドメインを検証済み

## 4. 相乗第1弾の成果(BTC 210日×米指標カレンダー)

1. NFP/CPIはBTC嵐を予告しない(日付シフト対照と区別不能)。FOMCのみ全対照生存(n=5・係属)
2. **嵐の時計法則はセッション効果と確定**(非イベント日でリフト3.43無傷)。しかもDST分解で**ET 9:30(米株オープン)アンカー**を発見(サンプル内リフト4.06 vs 現行3.37)— 新鮮データ限定の再検定として登録、採用せず
3. 指標発表の局所ボラ上昇は実在(順位0.767、p=0.002)だが固定%閾値では不可視 → **FXイベント研究は連続レンジ指標で設計**という原則を輸出

さらに調査自体が2つの相乗を発見: **USD/JPYのボラピークはBTC嵐時計と同一のUTC12-15**(市場横断の米セッション法則)、ゴトー日仲値は測定済みヌル(棄却索引に登録し再発見を防止)。
