# 日経225マイクロ先物・国内株価指数先物 机上調査

調査日: 2026-08-28 / 机上のみ(発注・口座操作なし)
前提: `docs/SURVEY_JP_EQUITIES.md`(個別株クロスセクショナルは最低資本¥20Mで no-go 確定)の続き。
本調査は「小資本で成立し、日次〜週次で判定可能な、指数固有の構造効果」を探す。

**結論の先出し**: 商品と資本適合性は**クリア**(1枚あたり ¥30〜50万の推定要件)。
効果の事前分布では**オーバーナイト効果だけが単独で生き残り**、他の暦アノマリー
(月初月末・SQ・曜日・祝日前・日銀ETF)は本調査の実測でも文献でも**全滅**。
ただしオーバーナイト効果は**コスト床に極めて敏感**(往復1bps増ごとに年率-2.5%)で、
往復コストの前提 1.1 bps は**スプレッド1ティックという未実測の仮定に依存**している。
取引所が保証するのは最大4ティック(往復3.0 bps)であり、その水準では戦略は死ぬ。
⇒ **条件付き go。ゲートは「実効スプレッドの実測」**(§4)。

### 1.4 コスト床の再検証 — 前回推定 1.1 bps は「1ティックスプレッド」の仮定に依存

想定元本 ¥664,350(2026年7月実測、N225 ≈ 66,435)を分母として:

```
呼値 5円  ÷ 664,350 = 0.753 bps   (スプレッド1ティック = 往復コスト1ティック)
手数料 22円 ÷ 664,350 = 0.331 bps  (往復)
------------------------------------------------
往復コスト床(1ティック仮定)        = 1.08 bps ≒ 1.1 bps   [推定 — §1.6 の前回値を再現]
```

**ただしスプレッド1ティックは本調査でも実測できていない。**
取引所が制度として保証しているのはこれより広い:

出典: [JPX マーケットメイカー制度](https://www.jpx.co.jp/derivatives/rules/market-maker/index.html)(2026/08/03 更新)
の「マーケットメイカー制度の取扱い」PDF p.22

| 日経225マイクロ先物 PMM 義務 | 日中(直近マンスリー限月) | 日中(直近四半期限月) | 夜間(直近四半期限月) |
|---|---|---|---|
| 呼値の最大スプレッド幅 | 6ティック(30円) | **4ティック(20円)** | **4ティック(20円)** |
| 最低数量 | 50単位 | 50単位 | 50単位 |
| インセンティブ受領基準(充足率) | 60%以上 | 60%以上 | 50%以上 |

同PDF p.3 で日経225マイクロ先物は PMM 対象(LP は対象外)。同制度のマーケットメイカーには
ABN AMRO Clearing、Barclays、Nissan Securities 等が「日経225mini・マイクロ(日中タイプ1/2、夜間)」で指定されている。
出典: [指定マーケットメイカー一覧 2026/8/3](https://www.jpx.co.jp/derivatives/rules/market-maker/tvdivq0000003l9t-att/nlsgeu000001qqqb.pdf)

```
往復コスト上限(制度が保証する最悪値, 4ティック) = 20円/664,350 + 0.331 = 3.34 bps
```

**1.1 bps と 3.3 bps の差は戦略の生死を分ける(§3.2 の感応度表)。実測が必須。**
なお呼値5円は N225=66,435 に対して 0.75 bps と**相対的に粗い**刻みで、
粗いティックは流動的なレジームでは 1ティック板を機械的に固定しやすい(1ティックが現実的である間接的根拠)が、
これは**論拠であって実測ではない**。

## 3. 効果の事前分布

### 3.1 本調査での実測(**探索的・多重検定未補正・事前登録なし**)

データ: Yahoo Finance `^N225` 日次四本値 1985-01-02〜2026-08-28(10,231本の有効バー)。
**現物指数**であり先物ではない。10日超の間隔があるバーは除外。

分解: `overnight = O(t)/C(t−1) − 1`、`intraday = C(t)/O(t) − 1`。

| 期間 | overnight 年率 | t | intraday 年率 | t | 合計(C→C) 年率 | t |
|---|---|---|---|---|---|---|
| 1985–1999 | **+11.26%** | 4.67 | −5.68% | −1.15 | +5.76% | 1.01 |
| 2000–2009 | **+8.12%** | 2.45 | −11.43% | −1.72 | −2.63% | −0.32 |
| 2010–2019 | **+13.12%** | 3.21 | −2.77% | −0.60 | +10.63% | 1.60 |
| 2020–2026 | **+14.11%** | 2.95 | +4.09% | 0.63 | +18.80% | 2.05 |
| 2016–2026 | **+12.37%** | 3.35 | +1.84% | 0.38 | +14.66% | 2.17 |
| 1985–2026 | **+11.40%** | 6.67 | −4.81% | −1.70 | +6.98% | 1.94 |

**日経平均のリターンはほぼ全て夜間(引け→翌寄り)に発生している。40年間一貫。**

戦略形態別(2016–2026, n=2,603):

| 形態 | 年率 | t | Sharpe | t=2 に必要な年数 |
|---|---|---|---|---|
| **オーバーナイトのみ(ロング)** | **+12.37%** | **3.35** | **1.04** | **3.7年** |
| 日中ショート脚のみ | −1.84% | −0.38 | −0.12 | 284年 |
| オーバーナイト − 日中(2脚) | +10.53% | 1.99 | 0.62 | 10.4年 |
| バイ&ホールド(参照) | +14.21% | 2.10 | 0.65 | 9.4年 |

**米国SPYで有名な「夜間ロング + 日中ショート」の2脚版は日本では成立しない。**

2脚にするとコストが2倍になって Sharpe が 1.04 → 0.62 に悪化する。
**採るべきは「オーバーナイトのみロング」の1脚。**

### 3.2 コスト感応度 — ここが判断の核心

| 往復コスト | 2016–2026 年率 | CAGR | vol | Sharpe | t | MDD |
|---|---|---|---|---|---|---|
| 0.0 bps | +12.37% | +11.98% | 11.9% | 1.04 | 3.35 | −17.3% |
| **1.1 bps**(1ティック仮定) | **+9.59%** | **+9.01%** | 11.9% | **0.81** | **2.60** | −20.3% |
| 2.0 bps | +7.33% | +6.64% | 11.9% | 0.62 | 1.99 | −22.7% |
| **3.0 bps**(≒MM義務の4ティック) | **+4.81%** | +4.06% | 11.9% | **0.41** | **1.30** | −25.9% |
| 4.0 bps | +2.29% | +1.55% | 11.9% | 0.19 | 0.62 | −29.4% |
| (参照)バイ&ホールド | +14.66% | +12.67% | 21.7% | 0.67 | — | −31.3% |

**往復コストが 1 bps 増えるごとに年率 −2.5%(252往復/年 × 1bps)。**
1.1 bps なら Sharpe 0.81 で生きるが、3.0 bps なら 0.41 でバイ&ホールド(0.67)に劣る。
**スプレッドの実測値が go/no-go を直接決める。**

**重要な性格づけ**: これは市場中立アルファではなく**ベータのタイミング**。
2016–2026 でバイ&ホールドを**リターンでは下回り**(9.0% vs 12.7%)、
**リスク調整後で上回る**(Sharpe 0.81 vs 0.67、MDD −20% vs −31%)。
先物は証拠金取引なのでレバレッジで Sharpe 差は換金できるが、
指数との相関は高く、暴落時の損失は避けられない。ポジション・サイジング方針も事前登録すること。

  ETF **年間3,300億円程度(簿価)**、J-REIT 年間50億円程度。
  簿価3,300億円は2025年3月末の時価換算で約6,200億円、

**買入れそのものが2024年3月に終了しているため、2024年4月以降は存在しない**。
売却側のフローは売買代金の 0.05%・比例配分・時期分散であり、**タイミング取引の対象にならない**。
**no-go(構造消滅)。**

## 4. go/no-go 推奨(判断はリードに委ねる)

### 4.1 推奨: **条件付き go**

**go の根拠**:
1. 資本適合性がクリア(1枚 ¥30〜50万推定、¥300万で6〜10枚)。個別株の ¥20M 制約が消える
2. 流動性が桁違い(マイクロ 1.06M枚/日・7,028億円/日)。1〜10枚は板に無影響
3. 効果が1つ、明確に生き残った。オーバーナイト・ロングは 40年一貫・17年中14年プラス・減衰なし・
   コスト控除後 Sharpe 0.81・**t=2 まで 3.7年**。BTC/FX の「効果 < 床」とは構図が違う
4. データ導線が確立している(J-Quants Premium で公式セッション分離、無料の 225Labo で先に回せる)
5. 発注 API(kabuステーション)が先物・板情報・IOC指値に対応し、既存の Windows 運用に載る

**no-go に転ぶ条件(=ゲート)**: 実効往復スプレッドが 2.0 bps を超えること。
3.0 bps でバイ&ホールドに劣後する(§3.2)。

**追加で明示すべきリスク**:
- これは**ベータのタイミングであってアルファではない**。指数と高相関、暴落時に MDD −20%
- 証拠金が年内 1.9倍に膨張しうる(§1.5)。追証で強制的に降ろされる経路が実在する
- 執行が毎日 2回・引けと寄りに集中する。**寄り引けはオークション**であり、
  §3.1 の効果は「引け値で買い、翌日の始値で売る」という**オークション価格そのもの**で測っている。
  実際の約定がオークション価格から乖離する分は §3.2 のコスト行に上乗せされる

### 4.2 Step 0(PREREG の前提条件・これ自体は仮説検証ではない)

**実効スプレッドの実測。** これが済むまで PREREG に進まない。

- 手段: kabuステーション API(PUSH の板情報)で **日経225マイクロ 直近四半期限月**の
  最良気配を 15営業日以上・**日中クロージング(15:40–15:45)と日中オープニング(8:45)を必ず含めて**記録
- 集計: 最良気配スプレッドの ティック数分布、時間帯別(寄り / ザラ場 / 引け / 夜間)、
  最良気配の数量、`(ask−bid)/mid` の bps 分布
- 判定基準(事前に置く):
  - 引け・寄りの実効往復スプレッド **≤ 1.5 bps → go**(§3.2 で Sharpe 0.75 以上)
  - 1.5–2.5 bps → 縮小して継続検討(サイジングを下げるか、条件付け(§3.3 休場明け)で回数を絞る)
  - **> 2.5 bps → no-go**
- **重要**: 記録のみ。発注しない

### 4.3 最初の PREREG 候補

**仮説**: 日経225先物を**日中セッションの終値で買い、翌日中セッションの始値で売る**戦略の
リターンは、Step 0 で実測した往復コストを控除した後もゼロより有意に大きい。

| 項目 | 内容 |
|---|---|
| **データ** | 主系列: 225Labo 日経225先物「日中のみ日足」1990年〜(無料・`backtest_data/` に恒久スナップショット)。<br>正系列(Step 0 通過後に切替): J-Quants Premium `/derivatives/bars/daily/futures` `NK225F`、`CCMFlag=1` で中心限月を選択、`AC`(日中終値)/`AO`(日中始値)を使用。2008/5/7〜 |
| **測る量** | `r(t) = AO(t)/AC(t−1) − 1 − cost`。`cost` は Step 0 の実測往復 bps を定数で控除 |
| **Train** | 2008–2018(11年)。ここでのみ仕様を決める(コスト定数・限月ロール規則・欠損処理) |
| **Val** | 2019–2022(4年) |
| **OOS** | 2023–2026(**一度だけ**) |
| **フレッシュデータ追試** | `NK225MCF`(マイクロ、2023/5/29〜)で同一仕様を再実行。ラージとマイクロで乖離があればマイクロ固有の執行問題 |
| **事前登録する合格基準** | OOS で ①`t ≥ 2` ②`Sharpe ≥ 0.5` ③年次勝率 ≥ 65%(4年中3年プラス) ④MDD ≤ 30% を**すべて**満たす |
| **最重要の帰無仮説** | **「現物指数のオーバーナイト・ギャップは、先物ではナイトセッション中に既に価格形成されている」**。<br>先物の `AC(t−1)→AO(t)` リターンが現物の `C(t−1)→O(t)` リターンより有意に小さければ、§3.1 の効果は先物で取れない。<br>**検定: 両者の平均差の t 検定。差が現物効果の 30% を超えるなら仮説棄却**。これが本調査最大の未検証リスク |
| **副次的に事前登録する条件付け** | 「休場明け」ダミー(+17.3bps, t=2.79)。**Train でのみ有効性を判定し、Val/OOS では追加チューニングしない** |
| **サイジング方針(事前登録)** | 目標年率ボラ 12% を上限。証拠金が JSCC 値で前月比 +30% 以上になった日は新規建て停止(§1.5 のプロシクリカリティ対策) |
| **コスト・モデルの有効期限** | 呼値・手数料・証拠金は改定される。**2027-03-01 を再較正期限として PREREG に明記**(マーケットメイカー・インセンティブの一部にも 2027年3月末の期限あり) |

**回さない方針を明記しておくもの**(§3.3・§3.5・§3.6):
月末・月初、SQ日/SQ週、祝日前、曜日効果、日銀ETFフロー、NT倍率。
これらは本調査で棄却済み。`docs/KNOWLEDGE.md` に「棄却済み仮説」として索引すること。

## 付録: 数値の性格

| 記号 | 意味 |
|---|---|
| 実額 | 一次資料に記載された数値をそのまま引用 |
| 実測 | 本調査が公開データから計算した値(§1.2 の想定元本、§3.1・§3.2・§3.3 のリターン統計) |
| 推定 | 仮定を置いた計算(§1.4 の 1.1 bps、§1.7 の最低資金) |
| 不明 | 一次資料に到達できなかったもの(取引所レベルの建玉制限、NT倍率の効果サイズ、実効スプレッドの実測値) |

**§3.1〜§3.3 の本調査実測は探索的であり、事前登録されていない。多重検定の補正もしていない。
これらは PREREG を設計するための事前分布であって、検証結果ではない。**

|---|---|---|
| 2016–2026 | **+11.30%/年 (t=+3.15)** | +0.49% (t=+0.11) |
| 1990–2015 | **+8.46%/年 (t=+4.65)** | **−11.20% (t=−2.84)** |
| 2023–2026 | +18.42%/年 (t=+3.02) | +7.29% (t=+0.80) |

本文§3の数字(+12.37%、t=3.35)と整合(差は窓・日数規約)。追加の知見:
**効果は1990年から現在まで36年間符号が安定**しており、1990–2015は日中が有意に負
