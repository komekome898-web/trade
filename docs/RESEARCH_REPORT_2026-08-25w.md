## 2. 診断 — どこで負けたか

### 2.1 損失の全額はストップ損切りバケット

- シグナル決済バケットの平均は **ほぼゼロ**(+0.012%)。エントリ後の条件付き
  ドリフトそのものが消えている。
- ストップは名目 −0.5% に対し実現 **−0.56〜−0.68%**(平均 −0.598%)。
  発火は保有 3〜23分の初動で、バースト時のスリッページ・ギャップが

  (−0.6%)を賄えない。

### 2.2 採用時バックテストとの乖離 — 薄い n の合格が新鮮データで消滅

| | 採用時(第c報、maker執行) | ペーパー実測(taker) |
|---|---|---|

  (往復 ≒ 0.13%/取引。実測の往復 6.35bps より**約2倍保守的**)。
  これを全額戻してもグロス ≒ **−0.02%/取引** — バックテストのグロス
  +0.19〜+0.36% は再現されない。**棄却はコストモデルの保守性では説明できない。**
- 頻度10倍は選択期間(7/21〜8/20、比較的平穏)と判定期間(8/20〜25、
  嵐クラスタ)のレジーム差。8/21 単日で 13取引・−3.15%(全損失の過半)。

  30分スイングの中に置かれてホイップソーの餌になる。
- 分類: **ヒゲ逆張り族と同型の「薄い n の合格 → 新鮮死」**(§3 の d→g, j と同じ
  棄却署名)。採用時の n=15 は偶然を排除できる規模ではなかった。
  機構の再監査は、独立に正である証拠(例: C2 窓内サブセットの正の判定)なしには行わない。
