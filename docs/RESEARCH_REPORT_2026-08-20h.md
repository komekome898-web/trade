# ストームレーダー研究報告(2026-08-20 第8報)

オーナー発案「OI・出来高等から激動の予兆を捉えるシステム」の設計・検証・実装の記録。

## 検証設計(事前登録)

- 嵐 = Binance BTCの|30分リターン| ≥ 0.8%(主戦略トリガーと同一)。2時間デデュープでイベント化
- 採用基準 = 評価区間で発生確率**リフト2.0以上**・再現率0.10以上・嵐30件以上
- フェーズA評価区間の検証力不足(嵐22件)を受け、価格データを210日に拡張し、**どの研究も一度も見ていない2026/1/24〜5/22(118日・嵐234件)**を主評価区間とした

## 検証した13の予兆仮説と結果

| 系統 | 仮説 | 判定 |
|---|---|---|
| 価格・出来高(A) | 出来高上昇×静穏 / スクイーズ / 解放初動 / FR偏り / bitFlyer吸収 / 出来高加速 / 合成 | **全て不合格**(最大リフト1.57、合成は逆相関、出来高加速は嵐の冒頭検知=先行性なし) |
| オプション市場(B) | DVOL低位(油断) / DVOL上昇 | 不合格(0.76〜1.11。時計と重ねるとリフトを**下げる**) |
| 大口検出(B) | 平均約定サイズ大×静穏 | 不合格(逆方向) |
| ポジション(B) | OI急増 / OI増×静穏 / L-S比極値 | **歴史検証不能**(OKXの履歴は約30日固定でページング不可と実証)→ ライブ蓄積で将来判定 |
| **時刻(B)** | **UTC 12:30〜15:00(米セッション開始帯)** | ✅ **唯一の合格**: リフト2.23・再現率0.33・234件。月次でも1.84〜4.05と全月安定、既知90日でも2.21と再現 |

**結論**: このサンプルにおいて、嵐は市場内部の力学よりも**外生的スケジュール(米国時間帯)**に最も強く支配されている。複雑なデータ(IV・OI・フロー)は時計が持つ情報を超えなかった。

## 実装(storm radar v1)

1. `src/bot/radar.py` — 時計窓レーダー(既定 12:30–15:00 UTC)
2. **スキャルパー武装モード**: レーダー点灯中はエントリー閾値10→8bps(感度アップ)。点灯/消灯とエントリー時のレーダー状態を全てJSONLに記録 → 武装時間帯の成績を分離検証できる
3. `scripts/record_oi.py` — OKX OI(USDT/USD)・L-S比・Deribit DVOL・perp OIを15分毎にスナップショット蓄積(`data/oi_snapshots.csv`)。**歴史APIが提供しない履歴を自前で構築**し、オーナーのOI仮説を数週間後に再判定可能にする
4. ダッシュボードにレーダー状態ピル(武装中/待機)とOIスナップショット鮮度を追加

テスト204件全パス。

## 事後検証の予約

- 武装モード自体の効き: スキャルパーのJSONLで「武装中エントリー vs 平常エントリー」の期待値を比較(ペーパー実績が30件貯まり次第)
- OI系仮説: スナップショットが30日分(≒2,900行)に達した時点でフェーズC判定
