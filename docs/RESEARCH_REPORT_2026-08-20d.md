# オーナー手法(いなご/ヒゲ/スプレッド/レンジ)検証報告(2026-08-20 第4報)

## 検証条件

- データ: FX_BTC_JPY 約定58.2万件から生成した1分足フローデータ(出来高のtaker売買内訳付き)21日分。ヒゲは15分足にリサンプル
- コスト: FX実測(手数料0%・スプレッド0.0235%・スリッページ0.02%・スワップ0.04%/日)
- 手順: Train+Validationのみでパラメータ選択(最低取引数条件付き)→ 選ばれた1構成をOOSで判定。taker/maker両執行
- 追加実装: エンジンにバー内TP/SL(同一バー両到達時はSL優先の保守的処理)、フローローソク足生成、ライブ用の約定ベースキャンドル(`use_flow_candles`)、板気配の常時記録(`SpreadRecorder`)

## 解釈(正直な評価)

1. **①④が機能しない理由は市場効率化と整合的**: いなご・レンジ反発は2017-2021年の高ボラ・高スプレッド・裁定不足の環境で機能した手法であり、現在のFX_BTC_JPYはBinanceと同一分内で同期する効率的な市場になっている。手法が悪いのではなく、環境が変わった
2. **②ヒゲ逆張りは唯一プラス方向**: 「行き過ぎた価格の拒絶を拾う」は効率的市場でも残りやすいミクロ構造の歪みであり、方向性は良い。ただし15分足では21日でイベントが少なすぎる(28取引)。データ蓄積で検証継続
3. **組み合わせ(いなご確認付き大変動追随など)は現時点で見送り**: 条件を重ねるほどサンプルが細り、21日分では統計的に無意味になる。これはグリッドを深掘りしない理由でもある(探索を増やすほど偶然の当たりを拾う=過学習)
