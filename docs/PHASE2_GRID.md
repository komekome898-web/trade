## 提案順位グループの基準

- **G1**: ON1・ONR・JPX夜間市場横断、および JPX日次型ユニット(暦アノマリー・米国型2脚・NT倍率・入替反転)。
  ライブ/PAPER候補で日次データのため安価。
- **G2**: メインBOT champion一族(現行PAPER稼働)とその変種(TP上限・C3ロングオンリー・C2窓内・S11フェード)。
- **G3**: 旧taker床(コスト前提)で棄却された bitFlyer CFD taker型ユニット。データはスナップショット済み
  (板不均衡・S12時計バースト・嵐ブラケット/雪崩・テクニカル/モメンタム/出来高/レンジ/アンカー・スキャル系、
  WS化ラインはスキャル系への執行速度乗数として同居)。
- **G4**: maker/MM/リベート/bot狩り/両側フロー/5分回転/M2/M3+M4/壁 など maker型ユニット全て。
  **maker型の既知正解テスト合格がゲート**(taker/板寄せ/日次側は各既知正解テストが未整備でも設計自体は進められる)。
- **G5**: FX(USDJPY)ユニット。
- **G6**: 着手条件が未達(引き金あり)なユニット、および元データが未スナップショットで再構成が要るユニット。

グループ内の並びは「データ即応性→期待トークンコスト(安価優先)」。件数: G1=7 / G2=5 / G3=12 / G4=14(うちM3+M4は1行) / G5=11 / G6=14。
行数合計63(64ユニットのうちM3+M4のみ1行に統合、按分除去軸を追加)。全行「状態」は未着手。
