# PREREG — ON1 フォワード・ペーパー追跡(2段目)

**凍結日: 2026-08-28。** 第36報(全バー通過)を受け、オーナーが枠組み **(c) リスク調整
(Sharpe・maxDD込み)** を選択。本文書はフォワード追跡の記録規則・評価規則・停止規則を
運用開始前に固定する。**ペーパーのみ。実弾は別途(口座・リスク上限新設計・明示承認)。**

## 1. 記録規則

- 商品: **日経225マイクロ先物**。建玉: 常に**1枚・ロングのみ**(倍率×10)。
- 対象限月: その日の**日中セッション取引高が最大のマイクロ限月**(=中心限月。
  ロールは自動的に追随)。エントリーとエグジットは**同一限月**で行う。
- 約定値: エントリー = 当日**日中セッション終値**(クロージング・オークション約定値)、
  エグジット = 翌営業日**日中セッション始値**(オープニング・オークション約定値)。
  値はJPX公式日報 `sif_dyr_YYYYMMDD.pdf`(大阪取引所、翌営業日9時公表・無料)から取得。
- コスト: 手数料 **11円/枚/片道**(往復22円)。スリッページは**計上しない**代わりに、
  ラージ約定値との乖離を診断列として毎日記録する(下記)。
- 診断列: 同日のラージ(日経225先物)の日中始値・終値、および
  `micro − large` 乖離(円)。**マイクロのオークション摩擦の実測**が本段の副目的
  (観測例: 2026-08-27 引けで −30円 = 4.5bps)。
- 欠測規則: 中心限月の始値/終値が欠測の日は取引をスキップし理由を記録
  (事後にペーパー成績へ補完しない)。
- 実装: `scripts/fetch_jpx_daily.py`(日報取得・PDF解析→ `data/jpx_daily/`)+
  `scripts/paper_on1.py`(台帳 `data/paper_on1/ledger.csv` 構築)。
  Windows `deploy/fetch_all.bat` から毎日実行。

## 2. 評価規則(月次レビュー)

毎月: 累積 net P&L(円・bps)/ 年率換算・Sharpe / 同期間 B&H(終日保有)との
リスク調整比較 / micro−large 乖離の分布。判断枠組みは (c): **Sharpe と maxDD を含めて
B&H と比較**する。素リターン単独では判定しない。

## 3. 停止・警告規則(バックテスト分布から事前固定)

保守コスト後のヒストリカル・ローリング窓(1990-2026, n≈8,800-9,000)から:

| 窓 | p05 | p01 |
|---|---|---|
| 3ヶ月(63営業日) | −11.1% | −22.4% |
| 6ヶ月(126営業日) | −14.2% | −42.5% |
| 12ヶ月(245営業日) | −20.4% | −51.1% |

- **警告(要レビュー)**: いずれかの窓の実績がヒストリカル **p05 を下回る**。
- **停止(ペーパー中断・原因調査)**: いずれかの窓が **p01 を下回る**、または
  micro−large の**符号付き往復摩擦コスト**(= exit乖離 − entry乖離 の直近21取引平均、
  n≥15 で評価)が **−10円(マイクロ2ティック)を下回る**。

> **改訂 2026-08-28(追跡開始前)**: 当初この停止線を「乖離の絶対値の月次平均 >10円」と
> 定義したが、実装検証(2026-08-17〜27 の実データ8日)で乖離は対称ノイズであり
> (entry側平均 −8.75円=買い手有利、exit側 −8.1円、**符号付き純コスト +0.6円 ≈ 0**)、
> 絶対値は執行コストを測らないことが判明。コストを測る符号付き定義に置換した。
> 絶対値は診断として記録を継続する。
- 注意: 3ヶ月窓の39%は歴史的にも負。**短期の負けは想定内**であり、上記の線を
  下回らない限り「効いていない」とは判定しない(1年でのt≈0.4しか出ない効果であり、
  フォワードの役割は点推定ではなく**レジーム破綻と執行摩擦の検出**)。

## 4. 完了条件

明確な合格ラインは設けない(統計的に1年では判定不能)。**12ヶ月経過時点**で
月次レビューを総括し、(i) 停止規則に非抵触 (ii) micro−large 乖離が保守コスト内
(iii) Sharpe が B&H 同期間比で遜色なし、の3点をもって実弾判断の材料として
オーナーに提示する。実弾移行は常にオーナー明示承認制。
