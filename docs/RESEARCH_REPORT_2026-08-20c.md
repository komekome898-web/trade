# FX_BTC_JPY 研究報告(2026-08-20 第3報)

## 背景

オーナー指示により対象を bitFlyer Lightning 全商品に拡大。APIで取引可能なのは現物8ペア+FX_BTC_JPYの9商品(CFDはLightning API非対応)。FX_BTC_JPY は taker/maker手数料0%・実測スプレッド0.0235%・ショート可・レバレッジ2倍で、**往復コスト約0.06%(taker)/約0%+約定リスク(maker)と、XRP現物の約1/10**。

データ: FX_BTC_JPY 公開約定58.2万件から1分足30,251本(21日分)を生成し、Binance BTCUSDT 1分足と整合。スナップショット: `backtest_data/candles_FX_BTC_JPY_20260820.csv`。

## 発見1: 効率的な市場には「遅れ」がない

| 対象 | Binanceとの1分遅行相関(lag1) | 往復コスト |
|---|---|---|
| bitFlyer XRP_JPY(薄い) | +0.176 | 0.55% |
| bitFlyer BTC_JPY現物 | +0.160 | 0.55% |
| **bitFlyer FX_BTC_JPY(厚い)** | **+0.019**(同時相関+0.878) | **0.06%** |

流動性の高いFXは裁定によりBinanceと同一分内で同期しており、単純な「先行市場フォロー」の余地はほぼ消滅。**コストが低い場所には遅れがなく、遅れがある場所はコストが高い** — 市場効率性の教科書どおりの結果。

## 発見2: 通常規模のモメンタム追随は全滅(事前登録手順による判定)

閾値0.05〜0.25%の12構成×taker/maker: Train+Validationで全構成マイナスまたは実質ゼロ。takerは期待値≒-0.06%/取引(=コスト)、makerは-0.008〜-0.04%/取引でほぼゼロサム。採用構成なし。

## 発見3: 大変動追随のみ、選択手順を通過(ただしサンプル極小)

高閾値(leaderが10〜30分で0.4〜0.8%動いた後に追随、maker執行):

| 構成 | Train+Val | OOS |
|---|---|---|
| **k=30, thr=0.8%** | **+1,488円 / 7取引 / +0.19%/取引 / PF 2.12** | **+3,140円 / 8取引 / +0.36%/取引 / PF 2.40** |
| k=10, thr=0.4% | +401円 / 40取引 / +0.009%/取引 | +2,246円 / 21取引 / +0.097%/取引 |
| その他高閾値構成 | ほぼマイナス | プラス(OOS期間に大変動が偏在) |

- T+V・OOSの両方でプラスなのは実質 k=30/thr=0.8 のみ(事前登録した「T+Vのみで選択→OOSで判定」の手順に合致)
- **重大な留保**: 合計15取引/21日。この規模で統計的有意性はない。OOS期間(8/16-20)に大変動が偏っていた regime luck の可能性も排除できない
- ただし「大変動後の追随」は XRP(+1.19%/60分)、BTC現物(+0.37%/15分)、FX(本報告)の**3つの独立データセットで一貫して現れており**、仮説としての蓄積は増している

## 実装済み(前コミット)

FX対応一式: 商品レジストリ / ショート・証拠金対応(エンジン・ポートフォリオ・ペーパー執行)/ CLOSEシグナル / 保護ストップロス(0.5%)/ SFDガード(乖離4.5%で新規停止)/ レバレッジ・最低数量チェック / 統合テスト(101件)。

## 結論と設定変更

1. **実運用可能な検証済み戦略は依然として存在しない**(この結論は変わらない)
2. ペーパー検証対象を **FX_BTC_JPY × xborder_momentum(k=30, thr=0.8%, exit=0.05%)** に変更。仮想証拠金20万円(FX最低数量0.01 BTC≒11万円のため。実資金とは無関係のシミュレーション値)
3. 判定基準(更新・事前固定): **ペーパーで30取引以上蓄積し、コスト込み期待値が+0.15%/取引以上、かつ最大DDが10%未満**なら少額実運用の提案を行う。シグナル頻度は約0.7回/日なので約6〜8週間を要する見込み。未達ならその事実を報告する
4. 実運用に進む場合の追加条件(現時点で確定している事実): FXの最低証拠金は実質約6万円(0.01 BTC×2倍レバ+余裕)であり、現在の6,000円では不可。**入金の判断はオーナーに属し、検証通過後に改めて提案する**
