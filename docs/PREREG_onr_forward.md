# PREREG — ONR フォワード追跡(J-REIT ETF 1343 夜間、ペーパー → 最小実弾1口)

**凍結日: 2026-09-04。** 判定本体は `PREREG_overnight_onr.md`(仮通過、第40報 §5)。本書は
フォワード段の記録規則・停止線・実弾移行条件を先に決める。ON1 forward(`PREREG_on1_forward.md`)
と同型。

## 1. 何を記録するか(毎営業日、`data/paper_onr/ledger.csv`)

- 取引: 東証クロージング・オークション(15:30)で 1343 を 10口 買い → 翌営業日オープニング・
  オークション(9:00)で 10口 売り。**毎日・無条件・サイズ固定**(SQ・権利落ち・祝日前も除外なし)。
- 価格: 当日の **ETF 終値(=引け板寄せ値)** と翌日の **ETF 始値(=寄り板寄せ値)**。
  併記: 東証REIT指数の始値・終値(kabutan 日次表)、分配金(権利落ち日の額)、売買代金。
- 損益: `pnl_yen = (open_{t+1} − close_t) × 10 + 分配金`(手数料 0 = SOR 板寄せ)。
  **ETF−指数 乖離** `gap_bps = ETF夜間 − 指数夜間` を毎日記録(帰属判定の主データ)。
- 出所: Yahoo Finance 日足(open/close は板寄せ値)。欠損は翌日以降に自己修復で埋める。

## 2. 見方(月次レビュー。選択には使わない)

- 累積損益・日数・勝率・平均 bps/日・ETF−指数 乖離の平均と t。
- **帰属**: 乖離平均が夜間平均の 50% 超なら「ETF 約定プレミアム主体」(脆い)、50% 未満なら
  「指数プレミアム主体」。どちらでも継続するが、前者は実弾で自注文が約定値を取れるかが要点。

## 3. 停止線(ガード。到達したら停止し、リードが原因を書いてから再開判断)

過去 1343 全期間(2008-09〜2026-09、汚染面だが停止線の校正にのみ使用)の夜間累積リターンの
ローリング分布から、以下の分位を実装時に機械的に算出して付録Aに書く(選択の余地なし):
- 3ヶ月(63営業日)累積 < 過去分布の p05 → **注意**、< p01 → **停止**
- 6ヶ月(126日)・12ヶ月(252日)も同様に p05/p01
- 実弾期のみ: **摩擦停止線** = 自約定値 − 板寄せ値 の符号付き往復差の平均が直近 21 取引
  (n≥15)で **< −1.0円/口**(= 5.2bps、1/4ティック相当の恒常的不利)なら停止。

## 4. 実弾移行(L1: 10口 = ≈¥19k、オーナー明示承認が前提)

- L0: 口座入金・SOR 有効・kabu ステーション API(検証ポート 18081 → 本番)で 1343 の
  **SOR + 引指(後場)買い / 寄指(前場)売り**(指値は値幅上限/下限側 = 実質 引成/寄成)が
  受け付けられることを `scripts/check_kabu_api.py` 系の読み取り専用チェックで確認。
- L1 = ペーパーと並走で **10口固定**。約定値と板寄せ値の一致(≤1ティック 95%)、損益照合、
  未解決 STATE_UNKNOWN 0、ガード未到達を **20営業日**満たしたら L2(サイズはオーナー決定、
  上限は `config/risk_limits.yaml` に追記して承認制)。
- 安全不変条件は CLAUDE.md §1 と ON1 と同一(三重ゲート、発注系は再送しない、
  建玉 ∈ {0, +10口}、1日 4 発注、時間窓 15:00–15:29 / 8:00–8:59)。

署名: リード。実装: `scripts/paper_onr.py`(ledger 生成、fetch_all.bat 組込み)、
ダッシュボードのペーパートレード区画に ON1 と並べて表示。
