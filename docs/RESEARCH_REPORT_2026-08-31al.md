# 第37報(al): 探索 — 加熱度と短期ボラティリティの相関(採用なし)

日付: 2026-08-31。オーナー質問「短期の値動きにも加熱度と相関があるのか(嵐との相関があればベスト)」。
スクリプト: `scripts/research_attention_vol.py`(日次パネル2015-2026・n≈3,700、
**公開ラグ厳守**: Wikipedia D-2 / GDELT D-0、交絡統制 = 直近5日レンジ三分位の二重ソート)。
**探索であり事前登録なし — 何も採用しない。** 方向は既閉鎖(§3)、本件は規模のみ。

## 1. 答え: 相関は実在する。ただし中身は2層

| 系列 | 同日ρ | 翌日ρ(公開ラグ込) |
|---|---|---|
| WP日本語 | +0.234 (t=14.7) | +0.211 (t=13.2) |
| WP英語 | +0.237 | +0.223 |
| GDELT報道 | +0.300 (t=17.6) | +0.235 |

## 2. 二重ソートが示す構造(翌日レンジ%、行=直近ボラ三分位×列=加熱Z三分位)

例(WP日本語): 静穏行 3.24/2.83/3.08(**勾配なし**)、中間行 4.48/4.30/4.50、
**高ボラ行 6.04/6.00/8.32(z-highで+38%)**。3系列とも同型。

- **静かな市場では、加熱度は明日の嵐を予告しない**(列間フラット)
- **既に荒れている市場では、加熱が翌日のレンジをさらに増幅する**(6.0→8.0-8.3%)—
  ボラ・クラスタリング統制後も残る増分。これが相関の実質のすべて
- 静穏レジームでの嵐リフトは P(|ret|≥3%) 14.4%→18.2% 等、係数1.2-1.3倍の弱い正
  (z-高セル n≈250、確立には遠い)

## 3. 先行遅行(GDELT): ρは k=0 で最大(+0.300)、k=−1 +0.235 / k=+1 +0.261

報道は値動きと**同時**にピークし、わずかに後を引く。注目は嵐の予報ではなく
**嵐の共鳴体**である — 既知の時計窓・トレードスルー法則群と整合。

## 4. 帰結

- 「加熱×既存ボラ→翌日増幅」は将来の**ボラ・ゲート型PREREG候補**として §4 に記録
  (例: S12型の建玉サイズやレーダー武装の増幅条件)。単独戦略の材料ではない
- 二重ソート内の残余交絡(三分位内の傾き)未統制・複数系列×複数指標の探索であることを明記
