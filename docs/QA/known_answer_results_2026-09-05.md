## 2. 何が起きたか — 道具の側の欠陥

3 名とも封印値より互いに近い数字を出し、封印値を再現した者はいない。上位監査者が原因を特定した。

| 欠陥 | 内容 |

| 価格がティック格子に乗っていない | 気配 51,517 行のうち格子上は 0 行(生成器が連続値で価格を動かしている)。同じ価格の再印字がほぼ起きず、「同一価格の印字が待ち行列を消化する」という待ち行列モデルが成立しない |

| 「正解」が参照シミュレータの出力 | 生成器は自分の注文の約定を**構成で決めていない**。合理的な約定規則が複数あり(3 名で 3 通り)、答えが 20 倍以上開く |

## 3. 判断

# 第 3 世代(maker 約定モデル、構成による真実)— 第 1 版の結果 2026-09-05

パケット `backtest_data/qa_known_answer_maker3_20260907/`(5 日、気配 200,747 行、約定 37,223 行、全価格が格子上、
自注文の約定は全て公開印字に対応)。約定規則を全主張に明記。監査者 3 名(下位 2 + 上位 1)。

## 1. 上位監査者が生成器の欠陥を発見(第 1 版は不成立)

- 主張 1・5・6(全体平均 −1.47、非強制決済の平均 +2.08、強制決済率 23.8%)から、強制決済の平均は −12.8bps でなければ
  ならないが、テープの 300 秒後の最悪変動は約 −9bps。**主張の組が算術的に成立しない**ことを約定モデルと無関係に示した。
- 原因: 生成器が強制決済に **12 ティック(12bps)の隠れスリッページ**を課していた(`TAKER_SLIPPAGE_TICKS`)。主張文にも
  manifest にも無く、公開テープから観測できない。「最良気配 maker は負」という植え込みはこの隠れ定数だけで作られており、
  規則どおりに計算すると S1 は約 +0.7bps。
- これは本プロジェクトで最も高くついた誤りの型(**観測できないコスト定数が結論を決める**、taker 床 5.8bps と同型)を、
  生成器を作った下位モデルが再演し、リードの事前検証(格子・印字対応・manifest)もすり抜けた。
  上位監査者の算術整合チェックだけが捕まえた。

## 2. 判断

- 第 1 版の採点は無効(正解が偽)。ただし「偽の主張 3 件を退ける」「印字即約定と生存者除外の誤りを説明する」は上位監査者が達成。
- 下位監査者 2 名の報告は、算術不整合を検出できたかの記録として採点し保存する。
- 修正版(v2): 強制決済は公開気配の touch で約定(追加コストなし)、逆選択は情報フローで観測可能に(5 秒で +0.5〜1.5bps、
  t ≥ 5)、S1 の符号は狙わず実現値から主張を書く、自己検査(平均の分解恒等式・強制決済価格 = touch・約定 = 公開印字)を追加。
- 得られた手続き上の教訓(即時適用): 既知正解パケットの主張は**主張同士の算術整合**(部分集合平均と比率の分解)を
  生成器の自己検査に含める。監査 PROTOCOL の質問 9(一貫性)に「同一母集団の主張間の恒等式を検算する」を明記する。
