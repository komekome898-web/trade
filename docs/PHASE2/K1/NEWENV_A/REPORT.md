## 2. 一致が確かめたこと・確かめていないこと

- **確かめた(平均の経路)**: データ層の日ファイルの読み → 足の畳み(新設の `bars_from_bars`)→ 核の事象の順 → 約定(足の終値)→ 往復 → 実行記録 `trades.json` → 表の平均。この経路は新しいコード。
- **独立に確かめた範囲は 4 升だけ**: 批評家が畳んだ足を csv で直接読み、規則の文を自分のループで回した計算で、4 升(60|s19/b24|both、15|soff/b40|weak、30|s-/b-|strong、5|s30/b40|both)の取引数・平均・保有本数の中央値が一致し、**その 4 升の**全取引の約定値が足の終値と一致した(k1a-c-06)。残り 230 升は当時の表との一致だけで、独立の計算は無い。批評家はさらに乱数の足で核の上の K1 と規則の文を読み直した実装を往復ごとに比べる試験 117 件を足し、全部通った。`int()` の切り捨てを外すと 39 升中 23 升で落ちる(k1a-c-07)。
- **写したもの(訂正)**: 建玉の機械の分岐と、`*` の区間の統計(分位の添字と乱数の消費順)は当時のスクリプトの形に合わせてある。したがって **`*` の一致は環境の検査にならない**(当時の統計を写した代理)。
- **確かめていない**: 約定の値付けは戦略側に書いた `BarCloseMarketFill` で、**環境の約定の模型・費用・口座(項目 2)は通っていない**。平均・区間は表の側の計算で、**環境の指標・検証の部品(項目 3)は通っていない**。
