## 2. 規則(H3: 1 つだけ変える)

```
delay_signals(sigs):
    out[0] = (0, 0.0, csign[0], "")                                  # 最初の足には前の足が無い
    out[j] = (sig[j-1], lc[j-1], csign[j], strength[j-1])   for j >= 1  # 行動(向き・ライン・強さ)は前の足のもの、色は実際の足のもの
simulate(bars, delay_signals(sigs), keep, use_invalid)                # 4 分岐・決済は原典のまま
```

- **足 j で行う行動は足 j−1 のシグナルに基づき、約定価格は足 j の終値**。建玉の入口・ドテン・反対シグナルによる決済のすべてが 1 本遅れる
- 無効化(H2a を使わない腕)は足 j の**実際の色**と終値で判定する(ラインは前の足のヒゲ先端 = 原典と同じ線)
- 期末の最後の足のシグナルは行動されない(1 本先が無い)。取引数は原典より最大 1 減る
- `delay=False`(既定)の出力は原典と同一(テストで固定)
- **これは第 9 部 D3 の量(`close[i+h] / close[i+1]`)を機構に載せたもの**。D3 は建玉を持たないので、本周の取引数・保有は D3 からは読めない(オーナーの指摘どおり)
