## 2. 規則(1 つだけ変える)

```
signals(bars, small, big, trunc=True, flip_body=False):
    (原典どおり向き・門・強さを決めたあと、門を通った足について)
    if flip_body and body >= w:          # 実体 ≥ 勝った側のヒゲ。小門の枝は w > body を要求するので、この足は大門の枝だけが通す
        sig = -csign                     # 実体と逆
        lc  = h if sig == -1 else l      # 新しい向きの側の極値
        strength = "strong" if sig == csign else "weak"   # 必ず "weak" になる
```

- **変えないもの**: 向きの決め方(`int()` 比較)、門(13 通り)、強さの定義、機構の 4 分岐、決済ルール、ホライズン、統計(日ブロック 200 回・セルごとの種)
- `flip_body=False`(既定)の出力は**原典と 1 bit も変わらない**(テストで固定。既存の全 JSON の再現ゲートも変わらない)
- 大門の枝を使わない門(`s*/b-`)では `body >= w` の足は門を通らないので、**反転は起きない**(出力が原典と一致することを確認する)
- `body == w` は反転側に含める(`>=`)。原典の小門は `w > body`(厳密)なので、境界は原典の定義と整合する
