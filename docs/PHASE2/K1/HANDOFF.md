### 出ている結果(要点だけ。詳細は `RESULT.md`)

- **「強い」(下ヒゲ陽線 → 買い / 上ヒゲ陰線 → 売り)の向きは、後続の値動きと逆。**
  **「弱い」(上ヒゲ陽線 → 売り / 下ヒゲ陰線 → 買い)は合っている。**

- **オーナーの記憶「上ヒゲ陰線・下ヒゲ陽線が最も強い反発」は、この区間・この定義では逆向きだった**
- **効果は年を追って消える**: その年だけで 95% 区間が 0 を跨がないセルの割合が
  **2017 39.9% → 2018 29.3% → 2019 16.5%**。「弱い」の平均効果が **+3.63 → +1.44 → +0.70 bp**
- **1 分足だけ符号が逆**(強いが正、弱いが負)。**切り捨てが原因ではない**(第 6 部)。
  1 分足では実体の戻りが無く、ヒゲの古典的な効きだけが残るため
- 機構(決済ルール込み)を通すと、シグナル単体より **1.7〜2.5 bp 悪くなる**。
  **その 2/3 は決済ルール、とくにヒゲ先端の損切りが戻る前に閉じているため**(第 7 部)。
  外すと弱いは +5.7〜+9.2 bp になるが sd 1.35 倍・5% 裾 1.6 倍。**改良は設計していない**
- **「強い」が逆を向く主因は実体の色の戻り**(第 5 部)。実体 > ヒゲ の足(大門の枝だけが通す)が
  「強い」の 17〜29% で負の 47〜73% を作る。ヒゲの側そのものの情報は、実体が小さい足・1〜15 分で
  だけ古典的な向きに残る(+1〜+5 bp)

### 手 1 — 機構の仮説を測る(**最優先**)

`RESULT.md` §4.5 に書いた仮説を検証する。**現在これは仮説であって測っていない。**

> **足の中で戻りが終わっているかどうか**が符号を決める。
> 下ヒゲ + 陽線(戻り切った)→ その後は下がる。
> 下ヒゲ + 陰線(戻り切っていない)→ その後に戻る。

**測り方**: ヒゲ長を層に切って固定し、**実体の符号だけを動かして**後続リターンを比べる。
さらに実体の**大きさ**(`|実体| / ヒゲ長`)でも切る。仮説が正しければ、
**同じヒゲ長でも実体が大きい陽線ほど、その後の下げが大きい**はずである。

**なぜ最優先か**: L-020 の「案 → 検証 → **なぜ** → 改良 → 再検証」で、いま **なぜ** の段にいる。
ここを飛ばして改良に進むと総当たりになる。

**基準線の再現ゲート**: 新スクリプトは `measure_katsuo_signal_horizon.py` の
`signals()` と `fold()` を **import して再利用**すること。書き写すと乖離する。
層を全部合わせたときに `signal_horizon.json` の該当セルと **一致すること**を確認してから進む。

### 手 2 — 1 分足の符号反転は `int()` の切り捨てか

原典は `int(top) > int(under)` とドル単位に切り捨てて向きを決める。
**1 分足では 68.2% の足が同点になりシグナルにならない**(60 分足は 7.2%)。
残った 1 分足シグナルは「ヒゲの差が 1 ドルを超えた足」だけなので、母集団が他の足と違う。

**測り方**: 切り捨てを外して(`top > under` の生比較で)同じ族を測り直し、
1 分足の符号が反転するかを見る。**これは原典からの逸脱なので、
「原典どおり」と「切り捨て無し」を並べて出す。片方に差し替えない。**

### 手 3 — 「弱い」だけを機構に載せると何が起きるか

シグナル単体では「弱い」が +2〜5 bp、機構を通すと +0.2〜1.1 bp に落ちる。
**決済ルールが取り分を削っているのか、母集団が違うだけなのかは分かっていない**(§4.6)。

**測り方**: `measure_katsuo_effect.py` の `simulate()` を使い、決済ルールを 1 つずつ差し替える
(無効化のみ / 反対シグナル決済のみ / 固定 h 本保有)。**アブレーションであって改良ではない。**
**「弱いだけを使う BOT」を設計しない。** それは流れの ③ の話で、まだ ① にいる。

## 4. オーナーの判断が要る 1 件(**勝手に進めない**)

> **2026-09-09 追記(手 1〜3 の後)**: 3 手の結果は §4 の判断材料を変えない。効果の減衰(§4.4)は
> 手 3 の変種でも同じ(損切りを外した「弱い」も 5 分で +10.2 → +6.1 → +1.0)。
> **リードの推奨は変わらず B → C → A。** 加えて、B を選ぶなら「実体の戻り」(第 5 部 表 E)が
> Binance 現物でも出るかを**同じ層で**測ると、機構が取引所を跨ぐかが直接読める。

**効果は 2019 に向かって消えている。「今も残っているか」をどう確かめるか。**

| 案 | 内容 | 代償 |
|---|---|---|
| **A** | BitMEX の**判定区間 2020-2021 を開ける** | **封印を使い切る。一度きり。** 「今も残っているか」には 2021 までしか答えない |
| **B** | **Binance 現物 BTCUSDT 2017-2023** で同じ測定をする(`backtest_data/binance_BTCUSDT_1m_20170801_20231231/` に在庫あり。2024-2026 も別スナップショットにある) | 封印を使わない。**別の取引所・現物**なので「同じ機構か」は保証されない |
| **C** | 手 1〜3 を終えてから決める | 決定を遅らせる |

**リードの推奨は B → C → A の順。** 理由:

- B は**封印を使わずに 2020-2026 まで見られる**。しかも流れの **② 現在の取引所での流用先の選定**
  そのものに近い問い(「他の取引所でも成立するか」)である
- 取引所の比較は既に一度やってあり(§3.4(c))、**Binance の方が下ヒゲの偏りが大きい**ことが分かっている。
  つまり Binance で消えているなら「BitMEX 固有の劣化」ではないと言える
- A は取り返しがつかない。**手 1 の「なぜ」が出る前に開けると、悪い結果を実装のせいにできてしまう**
  (CLAUDE.md §5.2 の 3 原因のうち後ろ 2 つを潰す前に判定してはいけない)

**これは枠組みの変更なので、オーナーに提示してから進めること**(CLAUDE.md §8)。
