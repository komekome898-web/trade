**「ばらつき」= 標準偏差。** 平均がどれだけ当てにならないかの尺度で、
**大きいほど同じ結論を出すのに多くの標本が要る**。

### A.2 MDE(最小検出可能効果)

**MDE** = Minimum Detectable Effect。「**この n とこのばらつきで、検出できる最小の効果**」。

たとえば `sd_trade = 92.8 bp`、取引 38,609 本なら、MDE は 1 bp 台になる。
**それより小さい効果は、あってもノイズに埋もれて見えない。**

- **MDE ∝ 1 / √n**。取引が 4 倍になると MDE は半分になる
- **MDE を書かずに出した「効果なし」は、陰性ではなく不明**(CLAUDE.md §5.2)
- 本単位には経費バーが無いので(§5.1)、**MDE がそのまま陰性の射程になる** —
  結論は「効果が無い」ではなく「**MDE(= X bp)を超える効果は不在**」

### A.3 帰無 / 巡回シフト / 多重性(§6 で使う)

**問題**: **162 通り試すと、エッジが全く無くても「一番良かった構成」はそこそこ良い数字を出す。**
サイコロを 162 回振れば 6 は必ず出る。「最良は +8 bp でした」だけでは何も言っていない。

**帰無(帰無仮説)** = 「**エッジは無い**」という仮定。統計はここを出発点にして、
「エッジが無いとしたら、この結果はどのくらい珍しいか」を測る。

**やること**:

1. **「エッジが無い偽の世界」を 1,000 個作る**
2. 各世界で**同じ 162 通りの掃引を丸ごと実行**し、**その世界での最良成績**を記録する
3. 1,000 個の「最良成績」の分布ができる
4. **本物の最良成績**がその分布の**上位 5%** より上にあれば陽性。無ければ陽性と呼ばない

**巡回シフト** = 偽の世界の作り方。**リターンの時系列を丸ごとランダムな量だけずらす**
(末尾は先頭に回り込むので「巡回」)。シグナルの発生時刻は動かさない。

```
本物   : [1日目][2日目][3日目]…[1095日目]
シフト : [173日目][174日目]…[1095日目][1日目][2日目]…
                                       ↑ここで回り込む
```

- リターンの**内部構造**(ボラの塊・日内周期・自己相関)は**そのまま残る**
- **シグナルとリターンの対応だけがデタラメになる** = 「他は全部同じで、エッジだけ無い世界」
- **ランダムに並べ替えてはいけない**: 構造が壊れて偽の世界が易しくなり、
  本物が簡単にバーを超える(**偽陽性の方向に倒れる**)
- **ずらす単位は「シグナル 1 本」ではなく「時系列全体」**: カツオは保有が重なる
  (中央値 8 本)ので、1 本ずつ動かすと重なり方が壊れる

**多重性** = たくさん試すと偶然の当たりが出る問題。対処は
**「本物の 162 通り中の最良」を「偽世界の 162 通り中の最良」と比べる**こと。
162 通り試したことによる下駄が両側に等しく乗るので相殺される。

### A.4 アブレーション(§7 で使う)

**要素を 1 つずつ抜く / 切り替えて、成績がどう変わるかを見る**こと
(医学の「成分 A を抜いたらどうなるか」と同じ)。

**なぜ要るか**: 「+8 bp でした」だけでは**「なぜ」が書けない**。
CLAUDE.md §5.2(L-020)は「**なぜを出さずに判定だけ返す報告は不合格**」と決めている。
カツオは 7 つ以上の要素の組み合わせなので、**どれが効いているかを分けないと、
② の「流用先の選定」で何を持っていけばよいか分からない。**

### A.5 サニティ(§8 で使う)

**サニティチェック** = 「正気か」の確認。**エッジの有無ではなく、計算が壊れていないか**を見る。
意図マップ §0 の 3 原因のうち **「3. 機構のバグ」を潰す**のがこれ。

**全部通してから結果を読む。** 順序が逆だと、結果を見てからバグを探すことになり、
**都合の良いバグだけ直す**余地が生まれる。

### 4.2 主指標(改訂)

**カツオ自身の決済ルールで持ったときの符号付きリターン**:

- 建値 = シグナルが出た足の**終値**
- 決済 = 次のどちらか早い方
  1. **無効化**: 終値がヒゲ先端(`lcprice`)を割った足(I-8。終値で見る = L-044)。
     **判定するのは `signal == 0` の足だけ**(原典どおり。意図マップ §3-b)。
     → 出荷前検査の読み A が「**条項に書かれていない選択を実装が黙って決めていた**」として
     検出した(A-1、L-050)。**§7 アブレーション 7 で両方測る**ので選択自体は争点にならないが、
     **既定がどちらかを文書に書いていなかったこと**が欠陥だった
  2. **反対シグナル**: 反対向きのシグナルが出た足(原典の 4 分岐どおり)
- **上限 96 本**で打ち切る(原典に上限は無い。**これは検証の都合で入れる制約**なので、
  上限に達した割合を必ず報告し、48 本 / 192 本での感度も併記する)

```
r = signal × (close[決済] / close[建玉] - 1) × 10^4
```

### 4.3 保有期間は「掃引軸」ではなく「報告する曲線」にする

`h = 1 … 96` の各時点での `mean(r)` を**曲線として報告する**。ただし
**これは記述であって選択には使わない**(曲線の最良点を選べば、それは h の掃引と同じになる)。

曲線が答えるのは、まさにオーナーが問うたこと:

- **最初の 1〜2 本で終わる山**なら → 「即座の反発」であって、トレンド転換ではない
- **数十本かけて伸びる**なら → トレンド転換の予測として筋が通る
- **すぐ立って、その後戻る**なら → 執行が速くないと取れない(層 ② の話になる)

**選択に使うのは §4.2 の主指標だけ。** 曲線は「なぜそうなるのか」(規約 §0.2)に使う。

- MDE が大きすぎて実用上どんな主張もできない組み合わせ(例: MDE > `sd_trade`)は

## 6. 帰無と多重性

- **帰無**: 同じ足の集合に対し、シグナルの**発生時刻を巡回シフト**して族全体(**162**、§3)を
  同じ置換世界で計算し、**最大 `mean(r)` の分布**を作る(1,000 回)。

> **1,000 回で足りるかを、判定の前に確かめる**(読み B の指摘 B-1、L-050)。
> 1,000 回は**計算量の都合**で置いた数で、仮説から出ていない。
> 95 パーセンタイルを 1,000 標本から推定すると**上位 50 標本しか使わない**ので、
> **その点自体がばらつく**。族の最大統計量は裾が重くなりやすく、判定が回ごとに揺れうる。
> **手続き**: まず 1,000 回で走らせ、**95 点のブートストラップ標準誤差を報告する**。
> 実測の最大がその誤差の範囲に入るなら、**10,000 回に増やしてから判定する**。
> 「揺れていないこと」を確認してから判定する、を**実行前に登録しておく**。
  (旧版はここだけ **324** と書いていた。`h` を軸から外した L-046 の改訂で §3 は 162 に
  なったのに、本節の数字を直し忘れていた。**族の大きさは §3 が唯一の定義**。)
  実測の最大がこの分布の 95 点を超えなければ、**族として陽性と呼ばない**。
- 時刻の巡回シフトを使う理由: ランダム並べ替えだと日内周期と自己相関が壊れ、
  帰無が**楽になりすぎる**(偽陽性側に倒れる)。
- **族からの除外はしない**(L-048 で変更)。旧版は「MDE が経費バーを超えたら族から除外」と
  していたが、**その経費バーが消えた**ので除外の基準も消える。代わりに **162 通り全部を測り、
  各組み合わせの実 n・MDE・効果量・信頼区間を並べて報告する**。
  MDE が大きい組み合わせは**陰性ではなく不明**として区別する(§5.2)。
  → 族が縮まないので**帰無の最大統計量も 162 のまま**で取る(除外に伴う取り直しは不要になった)。
- **保有が重複するので、シフトの単位は「シグナル 1 本」ではなく「時系列全体」**にする。
  リターン系列ごと巡回シフトすることで、保有区間の重なりも自己相関も帰無側に保存される。

| **6** | **ヒゲの測り方**: 原典(足の向きで測り分け)vs 単純式 `High - max(O,C)` | 原典の凝った測り方に意味があるか。同じなら ②③ では単純式でよい |
| **7** | **無効化ラインの 2 つの未確認点**: ① 建玉に紐付ける / 原典どおりグローバル(§3-a) ② 新シグナルの足でも無効化を見る / 見ない(§3-b) | **オーナーに確認できていない 2 点**(意図マップ §7)。どちらが意図か分からないので**両方測って並べる**。差が小さければ確認しなくても結論は変わらない |

**5 と 7 は性質が違う**: 1〜4・6 は「カツオのどの部品が効くか」だが、
**5 は私の制約が結果を汚していないかの確認**、**7 は意図が不明な点の両論併記**である。

## 10. この単位が言えないこと(**射程。陰性のときに必ず併記する**)

- **代理の妥当性は本単位では測れない。** 陰性なら「ヒゲでは捉えられない」までしか言えず、
  「清算連鎖のあとに反転が無い」とは言えない。それは K2(層 ①-b)が答える。
- BitMEX に清算履歴が無いため、**同一ベニュー・同一期間で ①-a と ①-b を突き合わせられない**。
- **執行を含んでいない。** 陽性でも「取れる」ことは意味しない。層 ② が必要。
- **建玉の重複を許して測っている。** 実際には資金と建玉上限があるので、
  同時に全部は取れない。**取引可能性ではなく予測力の測定**である。
- **打ち切り上限 96 本は原典に無い制約**。ただし**主指標では到達率 0.0〜0.1%** と
  実測されたので、**この制約はほぼ効いていない**(§4.1-a)。
  旧版はここに「17〜20% が到達」と書いていたが、**それは決済ルールを実装し損ねた測定
  (`invalid` のみ)の数字**だった → I-005。
  なお §7 アブレーション 5 で 48 / 192 本の感度は依然として出す。
- 期間の選び方(2017-2021)は探索面の一部であり、他の期間での再現は測っていない。
- **「何本後」と「何分後」は一致しない**(読み A の指摘 A-2、L-050)。§1 のとおり
  約定 0 秒の足は行を作らないので、**足は時間軸上で連続していない**。
  欠測の割合は **1 分 3.4% / 3 分 0.9% / 5 分 0.4% / 15 分 0.06% / 30 分 0.03% / 60 分 0.02%**。
  **15 分以上では無視できるが、1 分足の「時間あたり」の議論は 3.4% ずれる。**
- **経費を一切含んでいない**(L-048、§5.1)。手数料・スプレッド・逆選択・遅延のどれも
  引いていないし、それらの水準を仮定してもいない。**したがって「儲かったか」には答えていない。**
  答えているのは「**シグナルとしての強度が何 bp あったか**」だけである。
  経費との差し引きは **④(現代ベニュー + bitFlyer 執行)の関門**で行う。
- **逆選択を測っていない。** post only の約定は不利な瞬間に偏るが、板の履歴が無いと測れない。
  本単位の陽性は「執行前の予測力」までで、「取れる」ことは意味しない。
- **陰性の言い方には必ず MDE を付ける。** 「効果が無い」ではなく
  「**MDE(= X bp)を超える効果は不在**」。X が大きければ、それは陰性ではなく**不明**である。
