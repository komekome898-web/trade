## 4. 読み方(バーではない。第 15 部と同じ言葉を 2022〜2026 に当てる)

| 読み | 条件(主統計 2 セル、2022〜2026 の 5 年) |
|---|---|
| **効きが続く** | 5 年の総損益の合計が正で、2022〜2026 全体の平均の区間が 0 を跨がず、年別で 4 年以上が正 |
| **減衰しながら残る** | 5 年の合計が正だが、区間が 0 を跨ぐ、または正の年が 3 年以下 |
| **消えている** | 5 年の合計が負、または正の年が 2 年以下で平均の区間内に 0 |
| **ボラの読み** | 高ボラ三分位だけの 5 年合計と年別を同じ言葉で読む(**高ボラ条件を設計に入れるかの材料。入れるなら新しい設計 = 別の確認が要る**) |
| **取引所差の読み** | 2017〜2021 の年別平均の bitFlyer / BitMEX 比(参考量、区間なし) |

**どの読みでも、次の手は「なぜ」からオーナーが決める。** 設計を直して bitFlyer で再確認することはできない。
