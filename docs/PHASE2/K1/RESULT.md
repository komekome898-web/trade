## 1.2 足を作る

秒バーを UTC の壁時計で `foot` 分ごとに畳む。始値 = 窓内最初の秒の `o`、高値 = 最大の `h`、
安値 = 最小の `l`、終値 = 最後の秒の `c`。

**約定が 1 秒も無い足は行を作らない**(値動きなしではなく欠測として扱う)。

## 1.3 1 本の足からシグナルを決める(全足について)

```python
candle = c - o
csign  = +1 (陽線) / -1 (陰線) / 0 (同値 → シグナル無しで確定)

陽線なら  top = h - c,  under = o - l
陰線なら  top = h - o,  under = c - l

# 条件 3: 向きを決める。int() で切り捨ててから比較(原典どおり)
int(top) > int(under)   → 売り候補 (sig=-1, w=top,   lcprice=h)
int(under) > int(top)   → 買い候補 (sig=+1, w=under, lcprice=l)
同値                     → シグナル無し

wbp = w / c * 10000                      # ヒゲ長を終値に対する bp に直す

# 条件 1・2 = 小門の枝、条件 = 大門の枝。**どちらか成立でシグナル**
小門の枝 = (s != "off") かつ (s is None または wbp >= s) かつ (w > |candle|)
大門の枝 = (b is not None) かつ (wbp >= b)
シグナルあり ⇔ 小門の枝 または 大門の枝

強さ = "強い" if sig == csign else "弱い"
      強い = 下ヒゲ陽線(買い)/ 上ヒゲ陰線(売り)
      弱い = 上ヒゲ陽線(売り)/ 下ヒゲ陰線(買い)
```

**掃引した水準**:

| 軸 | 水準 | 数 |
|---|---|---|
| 足 `foot` | 1 / 3 / 5 / 15 / 30 / 60 分 | 6 |
| 小門 `s` | `off`(枝を使わない)/ `-`(最小長なし)/ 10 / 19 / 30 **bp** | 5 |
| 大門 `b` | `-`(枝を使わない)/ 24 / 40 **bp** | 3 |
| 強さ | 強い / 弱い / 両方 | 3 |

`s=off, b=-` は条件が空なので除外。`s > b` は `(off, b)` と同じ規則になるので除外。
→ **門は 13 通り、族は 6 × 13 × 3 = 234 セル。**

## 1.4 建玉を 1 単位持って回す(足を 1 本ずつ、先頭から)

```
その足のシグナルが「行動対象」か(強さの絞りを通ったか)を判定

行動対象でない場合:
    建玉があり、かつ **足の色が建玉と反対** なら:
        買い建玉で 終値 <= lcline  → 決済(理由: invalidated)
        売り建玉で 終値 >= lcline  → 決済(理由: invalidated)
    ※ 足の色が建玉と同じ向きなら、何も見ない(原典どおり)

行動対象の場合:
    建玉が同じ向き    → 何もしない。lcline だけ更新(増し玉はしない)
    建玉が反対向き    → 決済
                        強いシグナルなら、その足の終値で **逆に建て直す**(ドテン、理由: reversed)
                        弱いシグナルなら、**建て直さない**(理由: opposite_weak)
    建玉が無い        → その足の終値で新規(強弱を問わず)
```

**建値も決済値も「その足の終値」。** 板も気配も使っていない。

**1 取引のリターン**: `r = sig × (決済の終値 / 建玉の終値 − 1) × 10⁴` [bp]。
**経費は引いていない。**

## 4.1 何を測ったか

シグナルの出た足 `i` について、**h 本先の終値までの符号付きリターン**:

```
r_h = sig × ( close[i+h] / close[i] − 1 ) × 10⁴   [bp]
```

| | |
|---|---|
| 建玉状態 | **持たない**。同じ足に重なるシグナルも独立に数える |
| 決済ルール | **使わない**(無効化もドテンも無い) |
| ホライズン `h` | **1 / 2 / 3 / 5 / 10 / 20 / 50 本**(時間ではなく**足の本数**) |
| 族 | 足 6 × 門 13 × 強さ 3 × ホライズン 7 = **1,638 セル** |
| 信頼区間 | 窓が重なるので**日単位のブロックブートストラップ**(200 回、種 20260909) |
| 経費 | **引いていない** |
| 判定区間 | **2020-2021 は開いていない** |

**この測定は `sig` について線形**(`r = sig × 前方リターン`)である。
したがって**向きを反転すれば平均も厳密に符号が反転する**。
第 2 部の `mean(r)` は決済ルールが非対称なため反転しなかった(§3.3-a)。
**§3.3-a が「答えていない」と書いた問いに、この測定は答えている。**

**引き算はしない**(L-057)。代わりに横に 3 列を並べる:

- **買い側** = 買いシグナルの後の値動き(**符号を付けない**)
- **売り側** = 売りシグナルの後の値動き(**符号を付けない**)
- **相場** = 同じ足・同じ h の**全足の無条件平均**

**買い側が相場より上、かつ売り側が相場より下なら、向きの偏りでは説明できない。**

### 機構の仮説(**測っていない。仮説として書く**)

数字の並びと整合する読みは「**足の中で戻りが終わっているかどうか**」である。

- **下ヒゲ + 陽線**(強い買い)= 下げて**戻り切った**。→ その後は下がる
- **下ヒゲ + 陰線**(弱い買い)= 下げて**戻り切っていない**。→ その後に戻る

同じ長さのヒゲでも、**終値が始値を超えたかどうか**で後続が反転する。
**これは仮説であって測っていない。** 検証するなら、
ヒゲの長さを固定して実体の符号だけを動かす測定になる。

## 4.6 機構(第 2 部)との差

同じ門・同じ足で並べる(第 2 部は保有本数の中央値が 5 分足で 3 本なので h=3 と近い)。

| 足 | 強さ | 機構(第 2 部) | シグナル単体 h=3 | 差 |
|---|---|---|---|---|
| 5 分 | 強い | −5.32 | −2.78 | −2.54 |
| 5 分 | 弱い | +1.14 | +2.80 | −1.66 |
| 15 分 | 強い | −5.55 | −3.54 | −2.01 |
| 15 分 | 弱い | +0.21 | +2.17 | −1.96 |

**どちらの強さでも、機構を通すと 1.7〜2.5 bp 悪くなる。**

**ただし母集団が違う**(機構は建玉が無いか反対のときしか建てない、保有本数も一定でない)ので、
**この差を「決済ルールのコスト」と呼べるかは分からない。** 数字の並びとしてだけ載せる。
