## 1. 何を測ったか

### 1.1 シグナル(オーナー確定、L-052 / L-053)

```
勝った側のヒゲ w = 反対側のヒゲより長い方(int() で切り捨てて比較)
シグナルあり ⇔ ( w ≥ s かつ w > |実体| ) または ( w ≥ b )
```

`s`(小門)は絞り、`b`(大門)は**実体条件を飛ばして増やす**。門は **bp 建て**。

### 1.2 行動 — **建玉を 1 単位持ち、原典の 4 分岐どおりに動かす**

| 場面 | 行動 |
|---|---|
| **強い**(下ヒゲ陽線 = 買い / 上ヒゲ陰線 = 売り) | 反対建玉 → **ドテン** / 建玉なし → 新規 / 同じ向き → 何もしない |
| **弱い**(上ヒゲ陽線 = 売り / 下ヒゲ陰線 = 買い) | 反対建玉 → **決済のみ** / 建玉なし → 新規 / 同じ向き → 何もしない |
| シグナル無し | **足の色が建玉と反対のときだけ**、終値がヒゲ先端を割ったか見る → 割ったら決済 |

**増し玉・2 本目の指値・固定ドル階段は外した**(意図に無い実装)。

### 1.3 出した量

**1 取引の符号付きリターン** `r = signal × (決済の終値 / 建玉の終値 − 1) × 10⁴` [bp]。
経費は引いていない。信頼区間は**日単位のブロックブートストラップ**(200 回、種 20260909)。

### 1.4 測っていないもの

**帰無・MDE・判定バーは作っていない。** 判定区間には触れていない。

## 3. **この数字が何を意味しないか** — 符号の検査が反転しなかった

**最も重要な確認結果。**

シグナルの向きを反転して同じ測定を回した(2019・5 分足・`s19/b24`):

| | 原 | **向きを反転** |
|---|---|---|
| 両方 | −1.67 bp | **−1.07 bp** |
| 強い | −3.49 bp | −1.87 bp |

**反転しても負のままである。**
シグナルの向きに情報があるなら、反転すれば符号が裏返るはずだが、裏返らない。

→ **負の値は「ヒゲの向きが逆に効いている」からではない。**

### 3.1 どこから来ているか — 決済の構造

決済理由ごとの内訳(2019・5 分足・`s19/b24`・両方、n = 3,944):

| 決済理由 | 件数 | 平均 | 合計への寄与 |
|---|---|---|---|
| **反対の弱いシグナルで決済** | 1,641(41.6%) | **+46.13 bp** | **+19.19** |
| **無効化(ヒゲ先端を割った)** | 1,413(35.8%) | **−57.52 bp** | **−20.61** |
| ドテン | 890(22.6%) | −1.13 bp | −0.26 |
| **合計** | 3,944 | | **−1.67** |

**±20 bp が打ち消し合って、残りが −1.67 bp。**
ヒゲ先端の損切りが 1 回 −57.5 bp、反対シグナルでの決済が 1 回 +46.1 bp。

### 3.2 対照 — 入口の向きをコイン投げにする

同じ足・同じ門・同じ決済ルールで、**向きだけランダム**にした(2019・5 分足):

| 試行 | n | `mean(r)` |
|---|---|---|
| 1 | 4,901 | **−4.35 bp** |
| 2 | 4,833 | **+1.01 bp** |
| 3 | 4,898 | **−0.73 bp** |

**本物のシグナル(−1.67 bp)は、この 3 試行の範囲の中にある。**

## 4. したがって、この測定で言えること / 言えないこと

### 言えること

1. **大きな効果は無い。** 234 セルのどこにも、信用できる形で +20 bp のようなものは無い。
   最大は `30分/soff/b40/弱い` の **+6.92 bp**[+0.07, +13.83] だが、
   **234 セル中の最大**なので、これ単独では何も言えない。
2. **「強い」は「弱い」より一貫して悪い**(1 分足を除く 5 足で 4〜6.5 bp、3 年とも同符号)。
   **これは同じ決済ルールの中での比較**なので、3.1 の構造とは別の情報である。
   ただし**強いシグナルはドテンし、弱いシグナルは決済しかしない**ので、
   取引の母集団が違う。**完全な統制ではない。**
3. **決済の構造が損益の大半を作っている**: 損切り −57.5 bp × 36% と
   利確 +46.1 bp × 42% が打ち消し合っている。

### 言えないこと(**これが一番重要**)

**「ヒゲに予測力があるか」に、この測定は答えていない。**

`mean(r)` は「**シグナルの向きの情報**」と「**決済ルールの構造的な差し引き**」を
混ぜた量である。3.2 の対照が示すとおり、**向きをコイン投げにしても同じくらいの値が出る**。

**分離するには、全セルで「向きをランダムにした対照」を測り、
各セルの `mean(r)` を『対照からの超過』に直す必要がある。**

> **これは有意性の判定装置ではない。** 合否のバーを作る話ではなく、
> **報告する数字の意味を確定させる**話である。
> いま報告している `mean(r)` は、単独では「ヒゲの予測力」と読めない。
>
> 対照は 1 セルにつき数試行で足り、**全 234 セルで回しても本測定と同程度の時間**で終わる。
> **やるかどうかはオーナーの判断。**
