## 4. 読み方(バーではない。開封前に決めた言葉)

| 読み | 条件(主統計 2 セル、2020 と 2021) | 意味 |
|---|---|---|
| **効きが続く** | 両年とも総損益が正で、平均の区間が少なくとも片方の年で 0 を跨がない、かつ平均が 2019 以上 | in-sample の効果が未見の 2 年に持ち越された |
| **減衰しながら残る** | 両年とも総損益が正だが、平均が 2019 より小さい、または区間が両年とも 0 を跨ぐ | 2017 → 2019 の減衰が続いている。Binance 2022 以降の ≈ 0 と整合 |
| **消えている** | どちらかの年の総損益が負、または両年の平均が 0 の区間内で 2019 より小さい | 未見データでは効かない。**それでも「なぜ」を書く**(高ボラなのに効かないなら、効果はボラでは説明できない) |
| **経年劣化の読み** | 2017〜2021 の年別平均を並べ、単調に下がっているか、2020 で戻るか(ボラで説明できるか = 第 9 部 D8 の三分位を 2020〜2021 に当てて同じ表を出す) | オーナーの問い(L-083) |

**どの読みでも、次に取る手は「なぜ」からオーナーが決める**(判定は出口ではない、L-020)。**この設計を直してもう一度封印で確かめることはできない。**
