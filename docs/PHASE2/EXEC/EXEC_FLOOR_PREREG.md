## 0. 問い

**bitFlyer FX_BTC_JPY で、1 回の往復に最低いくら払うか。**(a) 成行の往復(スプレッド + 板の厚さによる滑り)を注文サイズ別に、(b) 指値(best に置く)が触れられる確率と触れられた後の逆選択の代理量、(c) 遅延、(d) 資金調達率(SFD の後継)の水準。**とくに K1 型のシグナルが出た分(海外のヒゲの直後 = 局所ボラが高い)での床**を、無条件の床と並べる。

## 2. 出すもの(生成物。単位 bp、mid = (best_bid + best_ask) / 2 基準)

| 表 | 量 | 分け方 |
|---|---|---|
| **E-a 気配スプレッド** | (ask − bid) / mid の分布(p10 / p50 / p90、時間加重) | 全期間 / UTC の時間帯 8 区分 / 曜日 / 局所ボラ三分位(直前 100 分の \|close/close−1\| 平均、bitFlyer 分足) |
| **E-b 成行の片道コスト(板を歩く)** | サイズ X ∈ {0.01, 0.05, 0.1, 0.5} BTC を best から順に食ったときの平均約定価格と mid の差(bp)。5 段で足りないときは「板の外」件数 | 板の 7 日、1 秒ごとの標本を時間帯・ボラで層別。**往復 = 買い片道 + 売り片道** |
| **E-c 実現スプレッド** | 各約定について \|約定価格 − 直前の mid\| / mid(bp)。テイカー側別 | 全期間 / 時間帯 / ボラ / 約定サイズのビン |
| **E-d 逆選択(代理)** | 約定の 10 秒・60 秒・300 秒後の mid の変化を、テイカー側の向きに符号を付けて平均(bp)= 成行で入った後に相場がどれだけ逆行 / 順行するか | 同上 |
| **E-e 指値の代理量** | 1 分ごとに「best bid に買い指値を置いた」と仮定し、T ∈ {60, 300} 秒以内に約定テープがその価格以下で取引されたか(**触れられた = 約定の上限の代理。列の順番・部分約定は分からない**)。触れられた場合の T 秒後の mid の変化(逆選択の代理) | 時間帯 / ボラ |
| **E-f シグナル分の床** | 海外(Binance / Bybit)の K1 シグナルが出た分(2026-08-20〜08-31)の、次の 1 分の E-a・E-b(0.01 BTC)・E-e と、同じ日の無条件の値を横に | 5 分・15 分、弱い、門 `s19/b24`。**件数を出す**(12 日では数十〜百件の桁) |
| **E-g 資金調達率** | 8 時間ごとの率の水準(絶対値の p50 / p90)、日次換算 | 標本が短いことを明記 |
| **E-h 遅延** | WS 受信遅れの分布(この VM)。注文応答の遅延は**未測定**と明記 | — |
| **E-i 床のまとめ** | 往復の成行コスト(0.01 BTC)の p50 と p90: 無条件 / 高ボラ / K1 シグナル分。指値の触れられ率と逆選択。**K1 の経費前の値(5 分 +0.7、15 分 +1.75 bp / 取引)と並べる**(引き算はしない。並べる) | — |

## 3. 見込み(実行前に書く。**過去の数値は使わない**。桁の見込みだけ)

| 量 | 見込み | 根拠 |
|---|---|---|
| E-a p50 | 数 bp の桁(1〜10 bp) | 手数料 0% の CFD は市場のスプレッドが唯一の明示コスト。桁以上は書かない |
| E-b 0.01 BTC 片道 | ≈ 半スプレッド(best のサイズが 0.01 を超えることが多いはず) | 板の常識。0.5 BTC は数段食う |
| 高ボラ / シグナル分の床 | 無条件の 1.5〜3 倍 | ヒゲの直後は板が薄い(第 9 部: 効果が高ボラに住む = 経費も高ボラに住む、という対称の仮説) |
| E-d 逆選択 | テイカー側の向きに 60 秒で正(成行で買った後は上がる = 情報のある注文が多い)。大きさは E-a の半分の桁 | 板の常識。**測るまで分からない** |
| E-e 触れられ率 | T = 60 秒で 3〜6 割(高ボラで高い)。触れられた後の mid は逆行(逆選択) | 代理量。上限 |
| E-i の読み | **K1 の経費前 +0.7〜+1.75 bp は、E-b 往復 p50 より小さい**可能性が高い(見込み) | K1 第 18 部 |

## 4. 読み方(バーではない)

| 読み | 条件 |
|---|---|
| **床 < 案の経費前の値** | E-i の往復 p50(シグナル分)が、案の経費前の平均より小さい → ④ へ進む価値がある |
| **床 ≈ 案** | p50 が同じ桁 → 指値(E-e)で床を下げられるかが次の問い |
| **床 > 案** | p50 が案より大きい → その案は成行では成り立たない。**指値の代理量の読みを添える** |
| **篩の規則(提案、`research-protocol` に書く候補)** | 以後の案の段 1(軽い篩)で、経費前の平均 < 2 × E-i(無条件の往復 p50)なら段 2 に進まない(**オーナー承認後に規則化**) |

## 5. 前提(バイアスの向きつき)

| 前提 | 向き | 出所 |
|---|---|---|
| 16 日(板は 7 日)の標本 | 相場の状態に偏る(2026 年 8〜9 月)。**季節・大相場は入っていない**。床は甘い側にも辛い側にも外れうる | §1 |
| 板 5 段 | 大きい注文の滑りは**下限**(辛くない側に偏る) | §1 |
| 指値の「触れられた」= 約定 | **上限**(列の順番・部分約定・取り消しを無視) | E-e |
| 逆選択の代理は mid の後の変化 | 自分の注文が相場に与える影響は入っていない(小さい注文なら小さい) | E-d |
| 注文の応答遅延が無い | 実際は遅延の分だけ床が上がる。**未測定** | E-h |
| 資金調達率 | 3 日の標本。頻度・大きさの統計にはならない | E-g |
| 海外のシグナルとの重なり 12 日 | 件数が少ない。層別は粗い | E-f |
