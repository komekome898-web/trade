## リターンの定義
- 夜間リターン r_night(t) = open(t+1) / close(t) − 1。権利落ち日が t+1 の場合は分配金額を open(t+1) に加算した値で計算し、補正前も併記。
- 日中リターン r_day(t) = close(t) / open(t) − 1(対照)。
- 「先物と同様」の判定: 同じ定義で計算した日経 225 ETF(1321)の r_night と符号が一致し、双方の 95% CI が正であること。
- 「取引可能な形で捕捉できる」の判定: 保守コスト(下記)後の平均が正で 95% CI が正、かつ 1 口固定の最大ドローダウンが年間期待利益の 3 倍以内。

  (反復として台帳に記録)。

## 指標と分母
- 主指標: 保守コスト後の平均夜間リターン(bps/日)と 95% CI。分母 = 開発セットの営業日ペア、n ≈ 3,000。
- 副指標: 夜間 − 日中の差と CI、Sharpe(年率)、最大ドローダウン、勝率、権利落ち補正の有無での差、1321 との相関と残差。
- MDE(α 0.05、検出力 0.8): 日次標準偏差を約 80bps とすると SE ≈ 1.5bps → MDE ≈ 4bps/日。保守コスト 10bps/往復を
  上回るには平均 ≥ 14bps/日が必要で、MDE の 3 倍以上。効果がそれに届かない場合は「存在するが取引不能」として棄却側に分類する。

## 対照(反事実)
1. シャッフル(符号の無作為化 1,000 回)。
2. 全時刻無作為 + 20 日実現ボラ三分位内の無作為保有(診断のみ)。
3. 符号反転(夜間売り持ち)。
4. 日経 225 ETF(1321)を同時に同じ手順で評価し、REIT 固有か市場全体かを分ける。

## 最終評価(封印データ、1 回のみ)
- 封印期間 2021-04-13 .. 2026-09-03 とフォワード。
- バー: 累計 N の帰無 95 点超、かつ保守コスト後の平均夜間リターンの 95% CI が正、かつ 1321 と符号一致。
