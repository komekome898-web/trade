## 2. 機構の手がかり(フォワード診断、298 日、判定には使わない)
東証 REIT 指数自体は夜間 −0.1bps、日中 ≈ 0 なのに、ETF は指数に対して**寄付きで +9.4bps 高く、引けで −9.0bps 安く**印字される。
つまり 1343 の「夜間プレミアム」の大半は、指数の値動きではなく **ETF の引け値と寄付き値の印字位置の差**(引けは安く、寄りは高く付く)。
その大きさ(約 9bps)は想定した呼値 1 円分(約 5bps/片側)と同じ桁で、板寄せの成行が実際にどの価格で約定するか次第で、
取れる差にも消える差にもなる。

## 3. 判定案: **保留**(引き金を具体化)。次点は棄却。
- 保留の理由: 「存在」は両期間で楽観 CI 正。「取引可能」は費用の**仮定**(呼値 1 ティック/片側)で決まっており、上の機構から、
  実際の板寄せ約定価格の測定だけが残る不確実性。これは測れる。
- 引き金(事前に固定): 引け板寄せ買い・翌寄付き板寄せ売りを**最小口数(1 口 ≈ 2,000 円)**で実際に発注し、約定価格と直前の
  ETF 印字・指数の差を 50 往復記録する(オーナー承認制、実弾だが金額は無視できる)。測定した往復費用 c の 95% 上限が
  楽観平均 8.3bps の CI 下限 6.1bps を下回れば再評価(新しいフォワード期間で)、上回れば棄却。
- 棄却を選ぶ場合の理由(上位層の指摘): 保守コスト後の CI 上限 +0.7bps が MDE 2.8bps を下回るため、想定費用の下では
  「取引価値のある大きさ」が上から排除されている。費用の仮定を変えない限り結論は動かない。
- どちらの場合も「先物と同様」(日経 225 ETF と同方向)はネット基準で不成立、グロス基準では成立。上位層の指摘どおり
  事前登録文の基準が曖昧だった(実装は反復 0 からネット基準で一貫、事後変更ではない)。記録に残す。

## 4. 記録に残す事実
- 開発セットより封印期間の方がプレミアムが大きい(楽観 +5.5 → +8.3bps)。エッジ推移モジュールで記述する(判定には使わない)。
- 旧手数料制度(55 円/約定)を遡及すると −24bps/夜で、2026-05-18 の SOR 手数料 0 円化以前は取引不能だった。
- 権利落ち日の導出規則(権利確定日 → T+2/T+3)は封印期間でも検証合格(補正前 −91.8 → 補正後 +10.7bps)。
