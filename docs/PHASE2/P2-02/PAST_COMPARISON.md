# J-REIT ETF(1343)夜間プレミアム戦略 — 過去との照合(2026-09-06)

## 1. 過去の結論(第40報、探索段階)
- 「儲かる新戦略」横断探索の中で発見。1343 の ETF 約定水準(2011-09〜2026-09、探索で全面的に見た汚染データ)で
  夜間 +4.77bps/日 t=+4.60(年率 +11.0%、分配金込み +14.4%)、日中 −5.6%/年、N225 夜間との相関 +0.51、
  ON専業 Sharpe 0.87〜1.19。事前登録(`PREREG_overnight_onr.md`)で判定を試みたが、**東証REIT指数の全期間四本値が
  無料入手不能**だったため、指数水準のバー(機構・台地・コスト後)は全て「未検証」。新鮮期間(2008-08〜2011-09、n=714)
  の符号一致のみ PASS。**総合判定は「仮通過(指数水準未確認)」**。コストは固定の保守引当 1.0bps/日往復(ON1と同水準の想定)。
  298日分の指数データ(2025-06〜)で ETF−指数の乖離を見ると、夜間の大半が「引けで安く・寄りで高く」という ETF の
  印字位置の偏り(+9.0bps)であり、指数自体はほぼ動いていないという診断は当時から得ていた。監査は行っていない
  (探索直後の一度きりの事前登録実行)。

## 2. フェーズ2の結論
最終評価(封印期間 2021-04-13〜2026-09-03、n=1,317、下位・上位の盲検監査ともに再現)。**判定はオーナー: 保留**
(次点は棄却)。楽観(丸め0)は両期間で正(開発 +5.5bps、封印 +8.3bps CI[+6.1,+10.5]) = 「存在」は支持。
保守(呼値1ティック/片側、約9.9bps往復)後は封印期間 −1.6bps CI[−3.8,+0.7](ゼロを含む)、
1321(日経225 ETF)とネット基準で符号不一致 = 「取引可能」の3条件(帰無超え・CI正・符号一致)はいずれも不成立。
反証文「保守後CIがゼロを含む」が発動、保留区分「楽観のみ正」に該当。引き金 = 最小1口の実約定を50往復記録し、
測定した往復費用の95%上限が楽観CI下限6.1bpsを下回れば再評価、上回れば棄却。

## 4. 上書き・確認・未検証
- **上書き**: 「仮通過」という総合評価は上書き。取引可能性は数値上棄却相当(CI上限がMDEを下回る)まで踏み込んだ。
- **確認**: グロスの夜間プレミアムの存在(符号・おおよその大きさ)は両期間で一致。ETF−指数乖離の診断(寄り高・引け安の印字偏り、
  約9bps)は、当時の298日診断とフェーズ2独自の同一窓再計算(+9.4bps)でほぼ同じ値に再現された。夜間>日中の非対称も確認。
- **未検証のまま**: 東証REIT指数の全期間四本値によるバー①②④は依然未検証(指数データは今も299日分しかない)。
  実際の板寄せ発注の約定価格(自注文がどの値を取れるか)は過去もフェーズ2も未計測 — 両者が同じ引き金を指している。
