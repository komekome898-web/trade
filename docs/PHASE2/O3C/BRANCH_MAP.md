### 1.2 鎖の定義

| 節 | 定義 |
|---|---|
| **② 清算(カスケード)** | 同じ向きの清算注文を、隣り合う時刻の間隔が **60秒以内**なら同じ塊にまとめる。塊の合計額が **5万USD以上**のものを「カスケード」と呼ぶ。`t0`=最初の注文時刻、`tend`=最後の注文時刻 |
| **① 値動き** | `t0` の価格と、`t0` から 1分 / 5分 / 15分 / 1時間 / 4時間 さかのぼった価格の変化(bps)。**基準は 15分**(他は感度として §2.4) |
| **③ 燃料** | `metrics` の建玉(`sum_open_interest`)。`t0-5分` の値と `tend+5分` の値の変化率(%)を基本とし、+30分 / +2時間 / 直前1時間 / 直前4時間 も測った(§3.3)。資金調達率は `t0` 直前の確定値 |
| **④ 分岐** | `tend` を起点に 10秒/30秒/1分/5分/15分/30分/1時間/4時間/12時間/24時間 後の価格。①の向きを `d`(上昇=+1 / 下落=−1)、①の大きさを `M`(bps, 絶対値)として、戻り比率 **ρ = −d × (④の変化 bps) / M**。**ρ ≥ θ を「転換」、ρ ≤ −θ を「継続」、その間を「無風」**。**基準 θ = 0.25**(= ①の動きの25%を打ち消したら転換) |

**無風の線引きはこちらで決めた(仮定)**: θ = 0.25 を基準に、0.10 / 0.50 でも全部出した(§2.2)。

- 価格(1秒足)は t0・tend とも 100.0% 取れた。時間軸ごとの除外率は各表の「除外%」列にそのまま出してある(24時間で最大 0.2%。データ末尾 2024-10-14 の後が無いため)

# §8 理論(リード、2026-09-13)

観測から素直に読める理論を書く。**判定ではない。**次に何を作るかの材料。

## 8.1 清算は「燃料」そのものである

起点の取り方で分岐が反転したことが、この観測で一番大きい。

| 起点 | 1 分後 |
|---|---|
| カスケードの**開始** | 転換 9.4% / **継続 31.7%** |
| カスケードの**終了** | **転換 39.8%** / 継続 3.9% |

**カスケードが走っている間は動きが延び、止まった瞬間に戻る。**

これは「清算が価格を動かす」ではなく、**「強制的に出される注文が、その瞬間だけ価格を押している」**と読むのが自然である。
**押しているのは意思ではなく、清算という装置である。**装置が止まれば押す力は消え、価格は戻る。

**これがオーナーの言う「燃料が尽きる」の、直接の絵である。**燃料 = 強制的に出される注文。
燃えている間は動きが延び、燃え尽きた瞬間に支えが無くなる。

対照(カスケードの前後 1 時間を避けた無作為 35,251 点)は 1 分で 14.2 / 13.6 と**ほぼ対称**である。
**この非対称はカスケード固有**であって、相場一般の性質ではない。

## 8.2 燃料切れの物差しは、建玉ではなく「清算の量 ÷ 動いた幅」

**建玉の増減は 5 通りの測り方すべてで分岐を分けなかった**(最大でも 44.9% 対 41.4%)。
一方、**清算の規模 ÷ ①の動きの比**が、単一軸で最も強く分けた(1 分 30.4% → 48.5%)。
清算の向きと組むと **22.0% → 52.6%(30 ポイント)**、4 分位すべて単調。

読み方はこうなる。

- **比が大きい = 少ししか動いていないのに大量の清算**
  → **その動きは強制注文が作った。中身が無い。だから戻る。**
- **比が小さい = 大きく動いたのに清算は少ない**
  → **本物の売買が押している。清算は巻き添えにすぎない。だからトレンドになる。**

**これが分岐の正体である。**「転換か、トレンドになるか」は、**その動きが燃料で作られたか、意思で作られたか**で決まる。

建玉が効かなかった理由は、**建玉が「燃料の在庫」であって「燃焼」ではない**からだと考える(推定)。
在庫が減ったかどうかより、**いま燃えている量と、それが生んだ値幅の比**が、尽きたかどうかを直接表す。
(なお建玉は 5 分粒度・取得率 68.8% の代理観測なので、「無関係」とは書かない。**測り方が粗い**可能性が残る。)

## 8.3 カツオのヒゲとの関係 — 同じものを、上流から見ている

ヒゲは「大きく動いて、戻った」という**結果の形**である。形が出たときには、もう戻り終わっている。

**比は、動いている最中に、燃料か本物かを分ける。**同じ現象を**上流で**見ている。
オーナーが背景に書いた「**更に他の燃料切れとトレンド転換の裏付けの根拠**」は、これに当たる。

## 8.4 効き方の偏り

- **ロング清算(強制売り)の方が戻りやすい**: 1 分の転換 44.5% 対 ショート清算 31.4%。
  下向きのカスケードの方が、跳ね返りが素直。
- **資金調達率は長い時間軸でだけ効く**: 大きく正(ロングが混んでいる)群は 24 時間の転換 64.1% 対 50.9%。
  **混んだロングは、いずれ下で解ける**という形。短期の分岐には効かない。
- **時間軸**: 分のスケールが本番。1 時間を超えると対照との差は 3 ポイント程度しか残らない。
  **この機構は分の現象である。**

## 8.5 bitFlyer に届いているか

1 分足では **99.5% 対応**し、出来高は中央値 **2.85 倍**に跳ねる。**海外の清算は bitFlyer に届いている。**

**ただし跳ね返りは半分以下**(1 分の戻り幅 2.3 bp 対 Binance 9.3 bp)で、1 時間以上では収束する。
**2.3 bp は bitFlyer の往復の経費と同じ桁である。**ここが、戦略にする上での勝負どころになる。
**経費を測り直して、正面からぶつける必要がある。**(この観測は収益性を測っていない。)

## 8.6 この理論が立っている足場の弱さ(先に書く)

- **カスケードは固まって起きる。**対象の 53.0% は終了から 1 時間以内に次が始まり、24 時間以内では 97.7%。
  **長い時間軸の数ポイント差は、独立な出来事の数ではない。**8.4 の資金調達率の話はここに乗っている。
- **塊のまとめ方(60 秒)が短期の数字を 30〜65% 動かす。**8.1 の非対称の**向き**は頑健だが、**大きさは頑健ではない。**
- **bitFlyer 側は 1 分足しかない**(重なる期間に約定テープと板が無い)。**秒スケールは bitFlyer では測れていない。**
- 他の海外取引所(Gate / BitMEX / Bybit)の清算はこの窓と重なりが無く、**1 取引所でしか見ていない。**

## 8.7 オーナーの要望のうち、答えていないもの

- **「価格毎の約定履歴の積み上げから、どの価格帯で清算が起きるかの予測」** — **答えていない。**
  補遺 A に記述だけ置いた(ロング清算は直近 24 時間レンジの下から 18.6% の位置が中央値、
  直近高値から中央値 308 bp 下)。**予測として作っていない。**
- **「エントリーや利確に活かせるか」** — **答えていない。**収益性・約定可否・経費を測っていない。
- **カスケードの事前検知** — 測っていない。本観測はすべて**カスケードが終わった後**からの記述である。

## 8.8 次に作るもの(リードの判断)

1. **比を引き金にした形を書き下す。**「カスケード終了 + 比が上位 + ロング清算 → 買い」。
   これを bitFlyer 側の 1 分足で、**経費を入れて**なぞる。**2.3 bp と経費の勝負**をまず見る。
2. **8.7 の「事前検知」**へ進む価値がある。**比は事後にしか計算できない**が、
   **カスケードが走っている最中に比を更新し続ければ、終了を待たずに読める**可能性がある(推定)。
3. **建玉の測り方を上げる。**5 分粒度では燃料の在庫を見られない。より細かい経路を探す。
