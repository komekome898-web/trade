# 清算を起点とした値動きの予測可能性 — 方策の模擬(清算の列に沿って判断を繋ぐ)の設計(2026-09-20)

**探索段**(research-protocol §0.0)。456 日は **8 度目の読み**(後半 228 日だけを使う)。判定語(陽性 / 陰性 / 有意 / 差あり / 検出されず)は使わない。判定は自前記録(触らない、L-246)で一度だけ。
前段: 続く / 止まるの単位(`SIGNAL_CONTINUE_DESIGN_2026-09-20.md`、反証者 6)は「全プリントで必ず入り、固定時間で出る」格子で、オーナーの L-269「**必ずt0でエントリーは意図不明**」「**60秒固定保有も上限値の計算も筋が違う間違った測定**」のとおり筋違いだった。この設計はその置き換え。

## 用語

| 記号 | 意味 |
|---|---|
| 連鎖 | 同じ側の清算のプリントを、直前から 60 秒以内なら繋いだもの(L-271)。1 件だけ = 単発。**終わり** = 最後のプリント + 60 秒(そこまで同じ側の清算が来ない)。終わりはその時点まで分からない |
| 判断 | 各プリントの瞬間(ts 以前の情報だけ)に返す 3 択: **止まる / 続く / わからない**(L-269) |
| 行動(建玉なし) | 止まる → 逆張りで入る / 続く → 順張りで入る / わからない → 入らない(L-269 逐語) |
| 行動(建玉あり) | 次のプリントで、判断が建玉の向きと合う → ホールド / 合わない → **決済**(型 A)または**ドテン**(型 B)/ わからない → ホールド(順張りの建玉は L-269 逐語、逆張りの建玉も同じ 3 択 = L-274) |
| 出口 | 建玉を持ったまま次の清算が来ない = 連鎖の終わり(最後のプリント + 60 秒)で決済(L-272) |
| 約定価格 | 入る・出る・ドテンはすべて「その時刻 + 遅れ」以後の最初の約定(`at_or_after`)。遅れ = 1 秒(主)/ 3 秒(併記)。**リードの選択** |
| 損益 | 連鎖 1 本ごとの、全ての建玉の bp の合計(建玉の向きが正)。費用は含めない(A-8) |
| 完全な判断 | 各プリントで事後のラベル(この後 60 秒以内に同じ側の次の清算が来るか)をそのまま判断に使う = 上限。連鎖 1 本の道筋で計算(L-269) |
| 基準の方策 | (i) 最初のプリントで順張り → 終わりまで持つ / (ii) 最初のプリントで逆張り → 終わりまで持つ / (iii) 入らない(0) |
