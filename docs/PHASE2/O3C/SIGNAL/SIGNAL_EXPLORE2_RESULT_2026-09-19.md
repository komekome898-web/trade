## 6. 次の単位の候補(推定。**リードの案**。次の設計の前に §0.1 の表を改めて作る)

この段で残った問いは 1 つ: **60 秒の戻りは「行き過ぎの修正」か「一時的インパクトの減衰」か。**さらに、全体で「1 分以後は平ら」に見える形は後続の清算の有無で割れる(§0 の 4)ので、**「平ら」を前提に置かない**。分ける量は**清算の前の価格を基準にした値**:
- 基準 = 束の最初の清算の直前の約定(`start_ms` の直前、価格を見ない規則)。量 = 基準から h 後の価格までの符号付き変化 `r_pre(h)`。**h 後の価格が基準を清算と逆の側に越えていれば行き過ぎの修正、基準と束の終わりの間にあれば一時的インパクトの減衰。**越える割合と、越えた幅(bp)の分布を h = 60 秒 / 5 分 / 15 分で出す。
- 後続の清算の扱い: 条件付けせず(コライダーを避ける)、全体と「次の束まで 180 秒以上」を**併記**し、後者を結果依存と明記。
- 対照: (ii) 薄さ合わせ + (i) 日集約版。日クラスタ SE。日で等重みの点推定を併記。
- gap: 60 を主、30 / 180 を併記(固定しない。条件付けの強さとして読む)。
- bitFlyer: 窓を明記(1 分足)。
- **456 日で探索(4 度目の読み)、判定は自前記録で一度だけ**(L-246)。周回数 870 + 90 + この段の行数を算入。
