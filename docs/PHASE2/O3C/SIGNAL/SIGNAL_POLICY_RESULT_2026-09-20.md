## 1. オーナーの目的への答え(推定)

オーナーのロジック(L-262「**清算を検知→jevでこの清算は続くか判断→続くなら乗る、続かないなら逆張り**」)を、判断を code にして連鎖の列に沿って通した結果:

1. **判断して乗る / 逆張りを分ける方策は、全部逆張りに届かない。** 後半 2,000 本、遅れ 1 秒、連鎖 1 本の損益(bp、費用なし): logistic 3 択(型 A)は中央値 0.00(26.5% は入らない)、日等重み平均 −0.58(日クラスタ SE 0.27)、負の割合 37%。入らなかった連鎖を除くと中央値 −0.02、平均 −0.75。全部逆張りは中央値 +2.25、平均 +2.14(SE 0.26)、負の割合 39%。全部順張りはその符号反転(−2.25 / −2.14)。
2. **「続く → 順張り」の枝が損を出している。** 3 択で 1 件目に入った 1,245 本の中央値は −0.46(負の割合 52%)、連鎖の途中で入った 225 本は +2.58(41%)。2 値(0.5 / 基準率)や前段の規則も平均 −1.6〜+0.3 で、順張りの枝を持つ方策はどれも全部逆張りを下回る。
3. **事後のラベルをそのまま使った参照点(完全な判断)は +5.2(型 A)/ +7.6(型 B)**で、全部逆張り(+2.1)の 2.4〜3.5 倍。最初に入った行動で分けると(型 A、遅れ 1 秒、`prints_policy` の新規の行と `cascades` の突合): 逆張りで入った 1,350 本は中央値 +3.13(平均 +4.10、負 33%)、順張りで入った 650 本は中央値 +6.58(平均 +9.70、負 10%)。損益の合計では順張りの分が 53%、逆張りの分が 47%。**ラベルを完全に知っていれば、続く連鎖に乗る分は小さくない**(監査 1 回目の指摘 2 で測り直し。前の版の「半分以上は逆張りの分」は建玉数の比からの推定で、誤り)。
4. **遅れ 0.5 / 1 / 2 秒で結果はほとんど変わらない**(全部逆張りの平均 2.15 / 2.14 / 2.05。3 択 −0.56 / −0.58 / −0.49)。連鎖の終わりまで持つ形では、入口の 1 秒の差は連鎖全体の動きに埋もれる。

**なぜそうなるか(リードの読み、事実ではなく推定。数は `cascades.csv.gz` と `prints_policy.csv.gz` から、型 A・遅れ 1 秒)**: ラベル「60 秒以内に同じ側の次の清算が来るか」を完全に知っていれば、続く連鎖に乗る分は正(上の +6.58)で、値段はラベルと同じ向きに動く。問題は判断の精度である。前半で固定した logistic は後半で順位分離 1 件目 0.674 / 連鎖の中 0.663(§7.7)で、この強さでは (a) 「続く」と言って順張りした 572 本は中央値 −2.55、平均 −4.02、負 60%(2 値・基準率でも 1,248 本で −1.92 / −2.84 / 58%)= 続かない連鎖を多く含み、外れたときの損が当たったときの得を上回る、(b) 「止まる」と言って逆張りした 898 本は中央値 +0.87(全部逆張りの +2.25 より小さい)。判断が「止まる」に寄せるのは戻りの小さい連鎖で、戻りの大きい連鎖は「続く」か「わからない」に振り分けられる — **これは監査 2 回目の指摘 4 で測った(事実)**: 全部逆張りの連鎖 1 本の損益を、3 択の**最初の清算での判断**で分けると(型 A、遅れ 1 秒、2,000 本)、「止まる」690 本は中央値 +0.66(平均 +0.27、負 45%)、「わからない」755 本は +2.71(+2.01、38%)、「続く」555 本は +5.17(+4.96、34%)。2 値 0.5 でも「止まる」1,040 本 +1.13 / 「続く」960 本 +3.70。**つまり logistic が「続く」と言う連鎖ほど、逆張りの取り分が大きい。**判断はラベル(次の清算が来るか)を当てているが、その連鎖は値段が戻る連鎖でもある。つまり判断はラベルを 0.67 で当てるが、損益に効く方向(大きく戻る連鎖を逆張り、本当に続く連鎖に乗る)には並んでいない。前段(`SIGNAL_CONTINUE_RESULT`)で Q7 として測った「値段の続き」(p₀ から 5 bp 進むか)を判断の対象にすれば損益と同じ向きになるが、**この記録はそれを測っていない。**
