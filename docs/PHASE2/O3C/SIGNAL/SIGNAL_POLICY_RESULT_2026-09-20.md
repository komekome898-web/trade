## 1. オーナーの目的への答え(推定)

オーナーのロジック(L-262「**清算を検知→jevでこの清算は続くか判断→続くなら乗る、続かないなら逆張り**」)を、判断を code にして連鎖の列に沿って通した結果:

1. **判断して乗る / 逆張りを分ける方策は、全部逆張りに届かない。** 後半 2,000 本、遅れ 1 秒、連鎖 1 本の損益(bp、費用なし): logistic 3 択(型 A)は中央値 0.00(26.5% は入らない)、日等重み平均 −0.58(日クラスタ SE 0.27)、負の割合 37%。入らなかった連鎖を除くと中央値 −0.02、平均 −0.75。全部逆張りは中央値 +2.25、平均 +2.14(SE 0.26)、負の割合 39%。全部順張りはその符号反転(−2.25 / −2.14)。
2. **「続く → 順張り」の枝が損を出している。** 3 択で 1 件目に入った 1,245 本の中央値は −0.46(負の割合 52%)、連鎖の途中で入った 225 本は +2.58(41%)。2 値(0.5 / 基準率)や前段の規則も平均 −1.6〜+0.3 で、順張りの枝を持つ方策はどれも全部逆張りを下回る。
3. **事後のラベルをそのまま使った参照点(完全な判断)でも +5.2(型 A)/ +7.6(型 B)**で、全部逆張り(+2.1)の 2.4〜3.5 倍にとどまる。ラベルを完全に知っても、その半分以上は「止まる連鎖を逆張りする」分で、「続く連鎖に乗る」分は小さい。
4. **遅れ 0.5 / 1 / 2 秒で結果はほとんど変わらない**(全部逆張りの平均 2.15 / 2.14 / 2.05。3 択 −0.56 / −0.58 / −0.49)。連鎖の終わりまで持つ形では、入口の 1 秒の差は連鎖全体の動きに埋もれる。

**なぜそうなるか(リードの読み、事実ではなく推定)**: この単位のラベル「60 秒以内に同じ側の次の清算が来るか」は、前半で固定した logistic が後半で順位分離 0.67 で当てられる(§7.7)。しかし**次の強制の清算が来ることと、値段が清算の向きに進み続けることは別**で、連鎖の終わりまでの値段は、次の清算が来ても来なくても、清算の向きと逆に戻る方が多い(全部逆張りが正、全部順張りが負)。だから「続く」と正しく読んで順張りしても損をし、判断の当たり外れは損益に効かない。前段(`SIGNAL_CONTINUE_RESULT`)で Q7 として測った「値段の続き」(p₀ から 5 bp 進むか)の方が、乗る / 逆張るの判断の対象として筋が通る。**この記録はそれを測っていない。**
