## 0. オーナーの目的(逐語)への答え(先に書く)

オーナー逐語(L-243): 「**燃料が尽きる尽きないに関わらず、値動きの予想ができるなら戦略のシグナルとしての価値がある**」。原文 §1: 「**清算の監視による値段の上がりすぎ下がりすぎやトレンド転換を捉えることができるか確認し、戦略へ落とし込む材料を見つける**」。

**この 456 日の観測では(推定)**: 清算の束の直後 1 分で、価格は清算と逆の向きへ平均 6.8 bp 動き、束の 0.737(約 4 本に 3 本)が逆へ動く(対照は 0.498)。**しかし、この 1 分の値は「値動きの予想」とは言えない。**理由は 2 つ(反証者レビューの致命 1・2、リードが再計算して一致 = `docs/DATA/probes/20260919_o3c_signal_refuter_verify.log`):

1. **起点が清算自身の約定である。**清算側は 79.5% の束で起点の約定が最後の清算イベントと同じミリ秒(= 板を掃いた終端の価格)、対照側は 0.2%(中央値 632 ms 後)。だから清算自身の板掃きの戻り(機械的な跳ね)が定義上すべて差に入る。h の最小が 1 分なので、この表では跳ねと予測を分けられない。幅 0 ms の単発の清算(12,029 束 = 56.8%)でも 1 分 −4.0 bp が出る = 連鎖でも燃料でもない 1 プリントで出ている。

- **起点を清算の約定から離す**(致命 1 の分離): 束の最後の清算から Δ 秒後の最初の約定を起点にし(Δ ∈ {1, 10, 30, 60} を事前登録で並べる)、対照も同じ Δ で取る。Δ を伸ばして 1 分の値が消えるなら跳ね、残るなら跳ね以外。

- **反転の割合は r < 0 / r = 0 / r > 0 の 3 つで出す。**
