## 1. オーナーの目的への答え(推定。反証者の致命 6 件を通したあと)

原文 §1「**清算の監視による値段の上がりすぎ下がりすぎやトレンド転換を捉えることができるか確認し、戦略へ落とし込む材料を見つける**」、L-243「**燃料が尽きる尽きないに関わらず、値動きの予想ができるなら戦略のシグナルとしての価値がある**」。

**問い**: 清算直後 60 秒の数 bp の戻り(探索段 2、−6.8 bp)は「行き過ぎの修正」(基準を越えて戻る)か「一時的インパクトの減衰」(基準までしか戻らない)か。

**答え**: **表の見出しの数(f > 1 が 50.1%、f の中央値 1.006、r_pre(60 秒)−0.12 ± 0.10)はどれも読めない。**f > 1 の割合と f の中央値は分母が微小な束(掃き 1 ティック以下が sweep > 0 の 24%)が作った数(致命 1)、r_pre ≈ 0 は大きい掃きと小さい掃きの打ち消し(致命 2)。さらに **f の 3 区分の母集団(sweep > 0 の 14,229 束)と r_pre の母集団(21,198 束)は別物**で、3 区分の母集団の r_pre(60 秒)は **+1.89 ± 0.15 bp**(基準の清算側)、除いた 6,969 束は **−4.23 ± 0.13 bp** と符号が逆(致命 3)。**「r_pre はほぼ 0 だが半分は基準を越えている」という文は、どちらの母集団にも当てはまらないので取り下げる。**掃きの大きさで切り直すと、2 つの別のものが同時に見える:

1. **掃きが大きい束(sweep 上位 3 分位 > 8.08 bp、n = 4,743、掃き平均 26.8 bp)では「減衰」の形。**戻り率の中央値は 60 秒 0.514 → 5 分 0.622 → 15 分 0.734、f > 1 は 23.5 / 36.9 / 43.7%。基準からは 15 分たっても清算の側に **+11.3 ± 1.1 bp** 残る(F5・反証者、リード一致)。基準を越えて戻る形はこの群からは出ない。
2. **掃きがほぼ無い束では、掃きと無関係な数 bp の逆行。**sweep = 0(p_end = p_pre、4,468 束 = 21.1%)で 60 秒後 **−2.85 ± 0.14 bp**、sweep < 0(2,501 束)で **−6.06 ± 0.21 bp**(r_end。リード一致)。減衰すべき掃きが無いところで清算の反対側へ動いている。**設計の 2 分法はこの 3 つ目の形を受け取る箱を持っていなかった。**

**どちらが「予想の材料」かは、この表では決まらない = 不明**(陰性ではない。反証者の総括「支えない。否定もしない」と同じ)。

**なぜそうなるか(推定、次で測る)**: 基準が最初の清算の **96 ms 前**(中央値)にある。清算を引き起こした値動きはそれより前に起きているので、単発の束では「掃き」がその値動きを含まず(sweep = 0 が 21%)、束の後の逆行が「掃きの戻り」として測れない。**基準をもっと前(60 秒・5 分前)に置いた測定が要る。**
