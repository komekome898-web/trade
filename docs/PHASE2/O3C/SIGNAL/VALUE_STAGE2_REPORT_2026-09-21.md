### 4-3. その機構は設計のどこに触れば動くか

- 機構 1(順張りの枝)に触れる場所は **§3 の帯**である。帯は前半の基準率で作り、後半には
  読むだけ(設計どおり)。**後半の基準率で帯を引き直せば「続く」の回数は減る**が、それは
  この単位の設計が禁じている(判定のあとの改良)。**そのずれの大きさは Q1 の併記で測った**:
  基準率は 1 件目 0.4343 → 0.5453、連鎖の中 0.5999 → 0.7027 と上がり、この 5,000 件で
  帯を作り直すと 1 件目 (0.38, 0.50) → (0.34, 0.60)、連鎖の中 (0.56, 0.66) → (0.58, 0.70) と
  **上にずれる**((3) Q1 併記)。凍結帯が「続く」と読む 0.50–0.60 の 472 件・0.66–0.70 の
  475 件は、後半の基準率では基準率と 2 SE 以内である。
  **これは事後の観察で、帯は作り直していない**(Q2・Q4 の数値は凍結帯のまま)。
- 機構 2(「わからない」)は触る必要が無い。帯の下端・上端の外側が問題で、**帯を広げる**
  (「入らない」を増やす)方向は測っていない = **未測定**。
- 機構 3(入る位置)は **§5 のノブ**で、前半で選んで後半で通した。これ以上触る場所は
  この単位には無い(次の単位の改良の対象)。
- 機構 4(出口)は §5 のノブで、参照行で測った。**300 秒より長い出口は格子に入れていない**
  = 未測定。
- 機構 5(側)に触れる場所は**設計にも格子にも無い**(側は層別に出すだけで、ノブではない)。
  **触れる場所が無いこと自体が読みである。**
- 機構 6(費用)に触れる場所も無い。c は実測で、設計が選べるのは入る回数だけ。
