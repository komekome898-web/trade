## 用語(記号の式と、日常語の説明)

| 記号 | 意味 |
|---|---|
| プリント / ts / t₀ / p₀ | 探索段 5 と同じ。清算 1 件、その時刻、ts 以後の最初の約定の時刻(= 判断の時点)と価格 |
| **続く(ラベル)** | このプリントの後、**同じ側の次のプリントが 60 秒以内**に来る(1 / 0)。30 秒・120 秒も併記。**判断の対象であって層ではない** |
| 基準率 | 何も見ずに「続く」と言ったときの的中率 = 続くの割合(探索段 5 の H1 で 58.5%、60 秒) |
| 材料 | t₀ に手元にある数字(§3)。ts より後の約定・清算は使わない(p₀ だけは使う) |
| 判断 | 材料から「続く」か「止まる」かを返すもの。**規則**(前半の日で作る)と **Jev**(状態を渡して確率を返させる)の 2 通り |
| 2 枝の損益 | 続く → 清算の向きに入る、止まる → 逆に入る。入る時点 t₀ + 1 / 3 / 5 秒、出る時点 入ってから 30 / 60 / 300 秒。1 件あたり bp(符号は判断の向きが正)。費用は含めない(A-8) |
| 前半 / 後半 | 456 日を日付順に 228 日ずつ。切り値・規則は前半だけで作り、**的中率と損益は後半だけで測る** |
