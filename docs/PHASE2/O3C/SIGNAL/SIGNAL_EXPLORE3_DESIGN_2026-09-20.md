## 用語(この文書と報告で使う記号。オーナーの問い L-247 の直前「h ってなに？」への答えを固定する)

| 記号 | 意味 |
|---|---|
| 束 | gap 秒以内に続いた清算をひとつにまとめたもの(1 周目の `build_cascades`、gap 60 秒を主)。`start_ms` = 最初の清算の時刻、`end_ms` = 最後の清算の時刻 |
| 基準(p_pre) | **束の最初の清算より前の最後の約定の価格**(`at_or_before(start_ms − 1)`。規則は時刻だけで決まり、価格を見ない)。清算が始まる前の水準 |
| 終端(p_end) | 束の最後の清算の直後の約定の価格(探索段 1・2 の Δ = 0 の起点と同じ) |
| h | **起点から何秒後の価格を見るかの時間幅**。この段の起点は終端(`end_ms`)。h = 60 秒 / 5 分 / 15 分 |
| r_pre(h) | 基準から h 後の価格までの符号付き変化(bp)。符号は清算の向きで付け、**負 = 基準より清算と逆の側**、正 = 基準より清算の側 |
| sweep | 基準から終端までの符号付き変化(bp)= 掃きの大きさ。定義上 正(清算の向き)になるはず(実測で確かめる) |
| 戻り率 f(h) | (終端 − h 後の価格)/(終端 − 基準)。0 = 戻っていない、1 = 基準まで戻った、**> 1 = 基準を越えた(行き過ぎの修正)**、< 0 = 清算の向きへ続いた |
| Δ | 探索段 2 の記号(起点を終端から Δ 秒離す)。この段では使わない |

## 4. 対照

清算の無い時刻には「基準 → 終端」に当たる掃きが無いので、r_pre と f は対照で定義できない。対照は 2 つの形で置く:
- **(a) 掃き合わせ**: 対照 (ii)(薄さ合わせ、1 周目の行)の時刻に、清算側の sweep と同じ大きさ・同じ向きの価格変化が**たまたま**起きた区間を要求する = 「同じ大きさの値動きの後、どれだけ戻るか」の比較。実装: 対照時刻から前へ遡って、直近 W 分(束の幅の中央値)の符号付き変化が sweep の分位帯に入るものを 1 対 1 で取る。**取れない対照の数を報告する。**
- **(b) 無条件**: 対照 (i) 日集約版と (ii) の h 後の符号付き変化(探索段 2 と同じ)。基準からの量ではないので、F2 の 3 区分は清算側だけ。
