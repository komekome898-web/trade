## 2. 問い

量 `r(Δ, h)` = 束の最後の清算から **Δ 秒以上あとの最初の約定**を起点にし、その起点から h 秒後の価格変化に清算の向きの符号を付けたもの(bp)。負 = 反転、正 = 継続。対照も同じ Δ で起点を取る。Δ = 0 が探索段 1 の量(`after_shift`)。

| # | 問い | 見る形 |
|---|---|---|
| E1 | 起点を離すと 1 分の戻りは消えるか(致命 1 の分離) | 清算側の `r(Δ, 60 秒)` の平均 ± 日クラスタ SE を Δ = 0 / 1 / 5 / 10 / 30 / 60 秒で並べる。**Δ で消える分 = 掃きの戻り、残る分 = 起点の後に起きる値動き**。`bounce(Δ)` = Δ = 0 の起点から Δ の起点までの符号付き変化も併記 |
| E2 | 秒単位の h の形 | 清算側の `r(Δ, h)` の平均を h(9 本)で並べる。**清算側の形をそれ自身で読む**(対照との差で読まない = 致命 2 の分離)。対照 (i)(一様)と (ii)(薄さ合わせ)は別の列に併記し、差は参考 |
| E3 | 束ね方の感度 | gap 30 / 60 / 180 秒で E1 を繰り返す。**Δ を離したときに gap への感度が下がるか**(致命 3。掃きをどれだけ起点の手前に取り込むかで動くなら、起点を離せば動かなくなるはず) |
| E4 | 属性の順序は Δ を離しても残るか | 探索段 1 の 3 属性(束の件数・換算レバレッジ・側)の 3 分位で `r(Δ, 60 秒)` を Δ = 0 / 10 / 60 で並べる |

**答えない問い**: Q4(分岐を分ける条件)・Q5(bitFlyer との相関の判定。併記だけ)・Q6(価格帯の事前予測)。

## 7. 走らせる前に決めること(リードの決定)

- Δ ∈ {0, 1, 5, 10, 30, 60} 秒。0 = 探索段 1 と同じ(一致の確認に使う)。60 秒より先は h の最小 1 分の外側なので置かない。
- h ∈ {1, 5, 10, 30, 60, 300, 900, 3600, 14400} 秒(9 本)。
- 起点の穴の上限: Δ の後 5 分以内に約定が無ければ NaN(1 周目の `anchor_max_staleness_ms` と同じ)。
- SE は**日でクラスタ**(反証者 #2)。naive も併記。
- 反転の割合は **r < 0 / r = 0 / r > 0** の 3 つ(反証者 #5)。
- 対照 (i) を表に併記(反証者 #3)。
- gap は E3 の結果で次の単位に固定する(根拠を書く)。
- 多重性: 探索段なので検定はしない。表の数(行)を数えて次の単位の事前登録に引き継ぐ。探索段 1 の 552 行 / 180 比較に足す。
