## 3. なぜそうなるか(§0.2 の 3 問。リードの読み、推定)

- **どこで負けたか**: ① は 1 件目の「続く → 順張り」で負ける(88%)。負ける日は素が勝つ日(大きく戻る日)。②opt は 3 件以上の連鎖の逆張りを 300 秒持って取り、素はその領域で終わり(60 秒)に出て損をしている。
- **機構**: (a) 値段のラベルは「5 bp 進むか」であって「その後戻らないか」ではない。後半はラベルの割合 0.625 で、5 bp 進んだ後に戻る連鎖が多い = 順張りは 5 bp を取る前に戻りに食われる(到達時間の中央値 8 秒、遅れ 1 秒の後になお 5 bp 動くのは 74% だが、出口は連鎖の終わりで、そのときには戻っている)。(b) 逆張りの取り分は「戻り」で、戻りは連鎖の終わり(最後 + 60 秒)では終わらず 300 秒まで続く。3 件以上の連鎖は行き過ぎが大きく、戻りも大きい。(c) 費用 c = 2.0 bp は素の 1 本の取り分(費用なし +2.1)と同じ桁で、判断で入る回数を減らさない限り費用が食う。
- **設計のどこに触れば動くか**: ① の順張りの枝を止める(= 3 択を「止まる → 逆張り / それ以外 → 入らない」にする)と、① は「判断で選んだ連鎖だけ逆張り」になる = ② の「入る条件」のノブと同じ問い。① の判断に「入る位置」(3 件目以降)と「出口 300 秒」を足すのは ② の格子で測った 2 ノブの流用。**どちらも新しい単位**(この単位では測っていない)。ラベルを「5 bp 進んで、その後 300 秒で戻らないか」に替えるのは判断の対象の再定義で、これも新しい単位。
