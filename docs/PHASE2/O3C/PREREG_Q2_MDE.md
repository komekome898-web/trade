## 1. 入力(すべて探索区間 251 日のみ。的中率は読んでいない)

出典 `POWER_INPUTS_Q2.md`。帰無 p0 = 候補の帯が価格の範囲に占める割合(当てずっぽうで入る確率)。
範囲は 起点価格 × (1 ± 1/5)。X = 20% は手法(c)自身のレバレッジ仮定の最小値(5 倍)から導いた
(外部の新しい仮定を持ち込んでいない)。

## 2. 有効な n の取り方(**保守側に倒す**)

判定区間の清算イベント数は **long 17,476 / short 8,538(合計 26,014)**(実測 2026-09-13。件数のみ)。
**しかしこれを n には使わない。**同じカスケードの中の清算はほぼ同じ価格に当たるので、
イベントを独立に数えると独立性を過大評価する。**有効な n はカスケード数
(long 3,314 / short 2,288)**とする。イベント数を使えば MDE は約 2.3 倍甘くなる。

## 4. 読み方(3 値。Q1 と同じ規則)

- **予測できている**: 的中率の 95% 信頼区間の下端が p0 を上回る
- **予測できていない(陰性)**: 区間が p0 を跨ぎ、かつ **区間の幅が ±MDE に収まる**
- **不明**: 区間が p0 を跨ぎ、かつ 区間が MDE より広い(検出力不足)

**6 セルすべてが「陰性」でなければ、Q2 を陰性と書かない。**
