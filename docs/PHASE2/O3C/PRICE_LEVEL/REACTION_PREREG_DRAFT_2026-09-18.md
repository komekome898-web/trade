## 6. 主指標と帰無(§4.2)

- **主指標** = **実群 − 対照群の差**(h ごと、群ごと、観測量ごと)。
- **帰無は対照群である**(計算式の帰無ではない。§4.2「**対照群が作れるなら、計算式の帰無ではなく
  対照群を使う**」)。対照は 2 本:
  - **(i) `control_uniform`**: 同じ日の一様時刻、どの清算からも ±5 分以上(**実測**の実装
    `base.sample_control_times`)。
  - **(ii) `control_matched`**: `bin_pct` を ±5 ポイントで合わせた同日・置換なし(**実測**の実装
    `matched_controls`)。**主たる帰無はこちら**(一様対照は `bin_pct` が liq と大きく違う =
    RUN12 §4.10 で 31.25 対 66.67)。
- **対照が作れなかった束の件数と `bin_pct` の分布を必ず出す**(欠測の非対称。REPORT §0.0 の J 行)。
  標本 6 日での除外率の差 = liq 0% / 合わせた対照 **5.33%**(12 / 225。**実測**、RUN12 §4.10)。
- **`research-protocol` §4.2 の最後**:「**結果が全セル一様に同じ向きで出たら、まず帰無を疑う。**」
  これを結果の読みのチェックリストに入れる。

### 6.1 対照 (i) の、向きの要る量の比較規則(**ここで固定する**)

**2026-09-18 の監査の指摘 22 への対応。**設計 §5 (i) は
「向きの要る量は対照では上下の両方を出し、**実群と比べるときは実群の side の分布で重み付ける**」と
書いていたが、前版の §6 にこの規則が無かった。**式で固定する。**

1. 実群の side 比を**判定区間で**数える:
   `w_SELL = n_SELL / (n_SELL + n_BUY)`、`w_BUY = 1 − w_SELL`。
   **探索段(標本 6 日)の値は使わない**(参考値は標本 6 日で SELL 117 / BUY 107 →
   `w_SELL` = 0.5223。**実測**)。
2. 対照 (i) の、向きの要る量 `x`(到達率・到達までの時間)は、
   **下向きの値と上向きの値を別々に出してから**次で 1 本にする:
   `x̄_ctl = w_SELL × x̄_ctl(下向き) + w_BUY × x̄_ctl(上向き)`。
   **理由**: SELL 清算の順方向は下向き、BUY 清算の順方向は上向きなので(設計 §3 の符号の約束)。
3. 標準誤差も同じ重みで合成する: `SE² = w_SELL² SE(下)² + w_BUY² SE(上)²`
   (下向きと上向きは同じ対照行から作るので独立ではない。**この式は独立を仮定している =
   SE を小さく見る向きの近似である**(**仮定**、委任先)。**結果にこの向きを併記する。**)
4. **対照 (ii)(`control_matched`)は実群と 1 対 1 で対応するので、重み付けは要らない。**

### 6.2 対照 (ii) のマッチングは順序に依る(実測。**射程**)

### 8.1 計算式

**2 標本の比率の差**(両側、正規近似):

```
MDE = ( z_{1-α/2} + z_{1-β} ) × sqrt( p1(1-p1)/n1 + p2(1-p2)/n2 )
```

**2 標本の平均の差**(両側、正規近似):

```
MDE = ( z_{1-α/2} + z_{1-β} ) × sqrt( s1²/n1 + s2²/n2 )
```

`z` は標準正規の分位点(`scipy.stats.norm.ppf`)。
