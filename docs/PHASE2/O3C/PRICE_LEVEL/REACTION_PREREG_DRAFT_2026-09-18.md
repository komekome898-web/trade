### 6.1 対照 (i) の、向きの要る量の比較規則(**ここで固定する**)

**2026-09-18 の監査の指摘 22 への対応。**設計 §5 (i) は
「向きの要る量は対照では上下の両方を出し、**実群と比べるときは実群の side の分布で重み付ける**」と
書いていたが、前版の §6 にこの規則が無かった。**式で固定する。**

1. 実群の side 比を**判定区間で**数える:
   `w_SELL = n_SELL / (n_SELL + n_BUY)`、`w_BUY = 1 − w_SELL`。
   **探索段(標本 6 日)の値は使わない**(参考値は標本 6 日で SELL 117 / BUY 107 →
   `w_SELL` = 0.5223。**実測**)。
2. 対照 (i) の、向きの要る量 `x`(到達率・到達までの時間)は、
   **下向きの値と上向きの値を別々に出してから**次で 1 本にする:

   **理由**: SELL 清算の順方向は下向き、BUY 清算の順方向は上向きなので(設計 §3 の符号の約束)。
3. 標準誤差も同じ重みで合成する: `SE² = w_SELL² SE(下)² + w_BUY² SE(上)²`
   (下向きと上向きは同じ対照行から作るので独立ではない。**この式は独立を仮定している =
   SE を小さく見る向きの近似である**(**仮定**、委任先)。**結果にこの向きを併記する。**)
4. **対照 (ii)(`control_matched`)は実群と 1 対 1 で対応するので、重み付けは要らない。**

## 7. 1 周目の機構仮説(**F1 だけ**)

設計 §11 のとおり、**1 周目に判定の対象にするのは F1 だけ**である。
F2・F3 は同じ走行で観測量を出すが、**1 周目では判定しない(探索の記録として残す)**。

> 観測量: **`doi_pre_1h` が負の群**で、**戻り到達**が対照との差で大きい。
> 反証の形: その群で戻り到達の差が出ない。

> **【本版で直した・2026-09-18 の監査の指摘 16】前版の F1 は「`doi_pre_1h` が負
> (**または `doi_in` が大きく負**)の群」と書いていた。`doi_in` は 224 束のうち 15 束
> (6.7%)でしか作れない(**実測**、RUN12 §4.7)ので、**1 周目に判定する唯一の仮説の観測量から外した。**
> `doi_in` は観測量の表には残す(探索の記録)。**

**主たる観測量** = **戻り到達率**(重心版 `reach_back_vwap_{h}m` と ノード版
`reach_back_node_{h}m` の 2 系統)。
**主たる軸** = **D(`doi_pre_1h` の 3 分位)**。他の 47 群は副次で、多重性に算入する。

## 8. 検出力(MDE)— **走らせる前に書く**(§4.1)

### 8.1 計算式

**2 標本の比率の差**(両側、正規近似):

```
MDE = ( z_{1-α/2} + z_{1-β} ) × sqrt( p1(1-p1)/n1 + p2(1-p2)/n2 )
```

**2 標本の平均の差**(両側、正規近似):

```
MDE = ( z_{1-α/2} + z_{1-β} ) × sqrt( s1²/n1 + s2²/n2 )
```

`z` は標準正規の分位点(`scipy.stats.norm.ppf`)。

### 8.6 MDE をどう使うか(§4.1)

- **欲しい効果 < MDE なら、その単位は実行しない。**
  **「欲しい効果」の大きさはこの下書きでは決めない**(**該当語なし**。オーナー / リードが決める)。
- 実行後、効果が MDE 未満だった場合の結論は「**不明**」であって「効かない」ではない。
- **射程**: §8.3 は**全体 + 主軸 D の 3 群**だけを出した。**残り 44 群の MDE は出していない。**
  3 分位の群では n が約 1/3 になるので MDE は概ね √3 = 1.73 倍になる(**推定**: 式から。
  実測の D1〜D3 は 1.4〜2.0 倍の範囲にばらついた = 群ごとに分散と欠測が違うため)。
- **建玉プロファイルから作る軸(A4・A5)と `implied_leverage`(E)は埋まる行がさらに減る**
  (標本 6 日で A4・A5 が 203/224 = 90.6%、E が 190/224 = 84.8%。**実測**、RUN12 §4.9)。
  **主軸 D(`doi_pre_1h`)は減らない = 224/224、欠測 0**(**実測**)。
  > **【訂正・2026-09-18】前版は「建玉側の軸(A4・A5・**D**・E)は埋まる行がさらに減る
  > (標本 6 日で 203/224)」と書いていた。誤りだった**(監査の指摘 11)。
