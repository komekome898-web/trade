## 4. 実装で置いた判断

**設計に逐語がある行**:

| 置いたこと | 設計の該当語(逐語) |
|---|---|
| ビン = `floor(log(price) / log(1 + b))` の固定対数ビン、b = 0.1% | 「**実装は `floor(log(price) / log(1 + 0.001))` で固定の対数ビン**」 |
| 窓 W = 24 時間、清算時刻の直前 | 「**清算時刻 t の直前 W = 24 時間**」 |
| 清算 1 行 = 1 観測。束ねない。`time` を残す | 「**束ねない**」「**後で束ねられるように `time` を残す**」 |
| 対照 = 同じ日、清算から ±5 分以上、一様に 1 点 | 「**同じ日の中で清算から ±5 分以上離れた時刻を一様に 1 点引く**」 |
| 対照行は p_liq の代わりに p_0 で計算 | 「**直前価格 p_0 を p_liq の代わりに**」 |
| W・b を引数で変えられる | 「**W・b を変えた表も同じスクリプトで出せるようにする**(引数)」 |

## 5. 「なぜそうなるか」の候補(**仮定**。判定ではない)

- **仮定**: `bin_pct` の中央値が清算行 28.6 に対し対照行 64.0(**事実**)なのは、清算の約定が**直近 24 時間の
  中で相対的に薄い価格帯**で起きているためかもしれない。`price` 版の「中央値 0・49.2% が窓の外」は
  **指値の帯が作っていた見かけ**であり(**事実**、§3b)、直すと差は小さくなるが**消えてはいない**。
- **仮定**: `|dist_gap_bp|` 清算 30.2 / 対照 68.1、`|dist_node_bp|` 清算 55.3 / 対照 26.5(**事実**)という
  向きの揃い方は、清算が**空白ビンの近くでノードから離れた位置**で約定していることと整合する。ただし
  「薄い所で清算が起きる」と「清算が起きたから薄くなる」は本表では分離できていない(**事実**。窓は清算
  **より前**の 24 時間だけなので後者の直接の混入は無いが、同方向の連鎖清算が先に薄くした可能性は残る)。
- **仮定**: `dist_node_bp` と `dist_vwap_bp` の符号が side で反転する(SELL +58 / BUY −38、**事実**)のは、
  ロングの強制決済は下方向に進んだ後に起きるのでノードと重心が上に残り、ショートではその逆になる、
  という向きの非対称のためかもしれない。**推定**: `vol_between_ratio` が清算行 0.018・対照行 0.049
  (**事実**)と清算行の方が小さいのは、約定価格が p0 の ±0.4bp 以内(§3b)にあり間に挟まる帯が
  薄いだけ、という説明で足りる可能性がある。
