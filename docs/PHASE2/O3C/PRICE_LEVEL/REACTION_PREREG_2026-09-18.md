## 8. 検出力(MDE)— **走らせる前に書く**(§4.1)

### 8.1 計算式

**2 標本の比率の差**(両側、正規近似):

```
MDE = ( z_{1-α/2} + z_{1-β} ) × sqrt( p1(1-p1)/n1 + p2(1-p2)/n2 )
```

**2 標本の平均の差**(両側、正規近似):

```
MDE = ( z_{1-α/2} + z_{1-β} ) × sqrt( s1²/n1 + s2²/n2 )
```

`z` は標準正規の分位点(`scipy.stats.norm.ppf`)。

  代わりに **MDE を「検出できる最小」として結果に併記し、MDE より小さい差は「不明」と読む**
  (**陰性にしない**)。
- 実行後、効果が MDE 未満だった場合の結論は「**不明**」であって「効かない」ではない。
- **MDE の入力は「p・s は標本 6 日で固定、n だけ走行後に取る」**(2026-09-18 の監査の指摘 4 /
  リードの決定 4。**開封後に境界を動かす余地を閉じるための規約である**):

  | 入力 | どこから取るか | 開封後に動くか |
  |---|---|---|

  | `z_{1−α/2}` / `z_{1−β}` | α = 0.05/576 と 1−β = 0.80 で固定(§8.2) | **動かない** |
  | 群ごとの `n1` / `n2` | **走行後の群の件数**(欠測を引いた後) | **件数だけ動く**(結果ではない) |

  **`n` は観測量ではなく件数である。**§8.3 の 44 群ぶんの値を先に書けないのは、群ごとの件数が
  判定区間で何件になるかを走らせる前に数えられないためで、**判定の向きに効く量(p・s・α・β)は
  すべて走行の前に固定してある。**

  実測の D1〜D3 は 1.4〜2.0 倍の範囲にばらついた = 群ごとに分散と欠測が違うため)。
