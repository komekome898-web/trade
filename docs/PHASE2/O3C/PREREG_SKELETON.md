## 1. 問い(2 つに分ける。混ぜない)

- **Q1 観測**: 清算の連鎖(カスケード)の後に、価格は戻るか。**「行きすぎ」と「転換」を別の 2 主張として測る**
  (INTENT_MAP §4.2 の決定 3)。
- **Q2 予測**: 清算が起きる価格帯を事前に当てられるか。入力は 3 通りを**並べて**測る
  (約定の積み上げ / 建玉の積み上げ + 資金調達率 + L/S 比 / 現在値からの乖離)。

Q1 と Q2 は別の検定単位。Q2 が当たっても Q1 が無ければ執行の根拠にならず、逆も同じ。

## 2. 段(データで決まった順序)

| 段 | 何を測るか | 場所 | 理由 |
|---|---|---|---|
| **段 0** | 清算 → **自市場**の価格反応 | Binance COIN-M(1 取引所内) | 発生源で機構の有無を先に確かめる(差分表 §7: 3 対 1)。Gate ではなく COIN-M にするのは、Gate の価格がマーク価格しか無く、実約定でないため |
| **段 1** | 清算 → **bitFlyer** の価格反応(横断) | 海外の清算 × bitFlyer 1 分足 | 段 0 で機構があった場合にのみ進む |
| **段 2(Q2)** | 価格帯の予測 | Binance COIN-M | 清算・約定・建玉が揃う唯一の場所 |

**段 0 で機構が無ければ段 1 に進まない。** 進む条件は事前に書く(下の空欄)。

## 3. 族(何を 1 つの検定にするか)

- 検定単位 = **カスケード**(個々の清算ではない)。
- 軸: 取引所 × 向き(ロング清算 / ショート清算)× 反応窓(1・5・15・60 分)。
- **取引所ごとに別の族**にし、混ぜない(清算方式と時刻精度が違う。INTENT_MAP §4.2 の決定 5)。
- **ローソク足の時間軸は族に入れない**(同 決定 1)。
- **取引所を跨いで規模を比べない**(契約単位の差を吸収していないため。INTENT_MAP §4.3 の #5)。
- 族の大きさ = ( ) セル ← **空欄。段 0 は 1 取引所なので 向き 3 × 窓 4 = 12 が上限の見込み**

## 4. 対照(偽陽性を機構から分ける)

1. **プラセボ**: 規模を揃えた「清算を伴わない出来高の急増」。
2. **清算の無い時間帯**。

清算のカスケードの後の動きが、単なる出来高の急増の後の動きと変わらないなら、機構は清算ではなく出来高。

## 5. データと期間

- 段 0・段 2: Binance COIN-M **375 日・7 塊**(最長 124 日 = 2024-06-13〜10-14)。連続ではない。
  **塊ごとに測って束ねる**(連続を前提にした設計にしない)。
- 段 1: 上と同じ期間の bitFlyer 1 分足(手元にあり、この期間を覆う)。
- **探索と判定の分け方**: ( ) ← **空欄。7 塊のどれを探索に使い、どれを判定に残すかを、測る前に決めて書く**

## 6. 測る前に固定する値(INTENT_MAP §4.3)

カスケードを切る閾値(60 秒)/ プラセボの規模の許容誤差(0.25)/ 価格を遡って許す時間(5 分)/
再抽選の上限(200)/ 価格の刻みと遡る期間(Q2)/ レバレッジの仮定倍率(Q2)。
**すべて本文に数値で書く。**測ってから動かさない。動かすなら族に入れて多重性に算入する。

## 7. MDE と反証(**最重要の空欄**)

- MDE: ( ) ← **空欄。清算の規模あたりの価格インパクト(bp / 規模)の検出力で決める**
  (再枠組みの微細構造の役の指摘。経費の床では決めない。上流ではコストを判定バーにしない = R-091)
- 欲しい効果 < MDE なら**実行しない**(CLAUDE.md §5.2)。
- 反証の条件: ( ) ← **空欄。どういう結果なら「この機構は無い」と言えるかを、測る前に書く**
- **なぜ陰性になりうるか**(事前に列挙する): データ技術者の役が挙げた偽陰性の 3 条件
  (記録停止と「清算なし」の区別がつかない / 時刻のずれ / 秒の清算を分に丸める)。
  それぞれを除く方法を本文に書く。

## 8. オーナーに見せる点(判断を求めるもの)

1. **BitMEX を最初に使うという原文の方針は実行できない。** 保全した約 246 GB に清算イベントが無いため
   (2026-09-08 と 09-12 の 2 回、全経路で確認)。使えるのは保険基金の日次残高だけで、これは清算の
   **強度の代理**であって清算そのものではない。
2. **段 0 の場所を Gate ではなく Binance COIN-M にする。** 再枠組みでは 5 役全員が Gate を挙げたが、
   Gate の価格はマーク価格のみで実約定ではない。マーク価格は操作されにくいよう平滑化された指標で、
   「清算が値段に跡を残すか」を測る変数として筋が悪い。COIN-B は実約定が 375 日ある。
3. **Q2 の入力を原文の「約定の積み上げ」だけにせず、建玉の積み上げも並べて測る。** 原文の入力も
   同じ場所で測るので、どちらが良いかは結果で決まる。
