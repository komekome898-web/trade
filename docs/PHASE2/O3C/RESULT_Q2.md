# リードの読み(2026-09-13)

## §5 判定: **この測定は問いに答えていない。帰無の置き方が間違っている(リードの誤り、I-009)**

6 セルすべてが「予測できている」と出た。**この形は疑うべき形である。**Q1 がほぼ空振りだったのに、
同じデータで Q2 だけが全セル一様に大勝ちする理由が機構として説明できない。診断した。

**帰無 p0 は「清算は起点価格の ±20% の範囲に一様に起きる」を前提にしていた。**
`PREREG_Q2_MDE.md` §1 に「範囲は 起点価格 × (1 ± 1/5)」と書いてある。リードがこれを封じた。

**実測(判定区間の 5,600 カスケード、2026-09-13)**: 清算価格のその日の中央値からのずれは
**中央値 0.73%、90 パーセンタイルで 2.22%、99 パーセンタイルで 4.35%、最大 8.79%**。
**±2% 以内に 87.4%、±5% 以内に 99.4% が収まっている。**

**つまり清算は ±20% に一様どころか、±5% にほぼ全部が入る。**帯は起点価格の近くに置かれる
(出来高の山も建玉の山も直近の値段の近くにあり、レバレッジの線も 1〜20% 手前にある)。
**近くに置いた帯が、近くに集まっている清算に当たるのは当たり前**であって、予測の腕前ではない。

**粗い補正**: 実効の範囲を ±5% と見れば帰無はおよそ 4 倍になる。
手法(a)(b) の p0 約 1.0〜1.3% → 約 4〜5%。**実測の的中率 3.26〜3.85% はこれを下回る。**
手法(c) の p0 約 10.6〜11.9% → 約 42〜48%。**実測 27.4〜30.3% もこれを下回る。**
**正しい帰無なら、6 セルすべてが逆に転ぶ可能性が高い。**(4 倍は粗い当てはめであって、
正式な帰無ではない。正式には帯を同じ幅のままランダムな位置に置き直す並べ替えで作る。)

**したがって Q2 は「予測できた」でも「できなかった」でもない。測れていない。**

## §6 なぜ起きたか(リードの誤り)

帰無を「帯の幅 ÷ 価格の範囲」と定義した時点で、**「清算はその範囲に一様に起きる」という仮定**を
置いていた。その仮定を確かめなかった。委任先は範囲の取り方(±20%、レバレッジ 5 倍から導出)を
明記して報告しており、**隠していない。読んだリードが、一様性の妥当性を問わずに封じた。**

Q1 では帰無を置かず、プラセボという**対照群**を作った。だから機構と出来高を分離できた。
**Q2 では同じことをせず、計算で作った帰無に頼った。**対照群を作る手間を惜しんだのが原因である。
正しくは Q1 と同じく、**帯を同じ幅のままランダムな位置に置いた「プラセボの帯」**を対照にすべきだった。
