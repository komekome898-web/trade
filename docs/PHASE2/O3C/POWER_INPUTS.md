# O-3c 検出力計算用の入力値(探索区間のみ)

**本票は検出力の計算に要る件数とばらつきのみ。効果(平均・符号)は含まない。探索区間のみ使用、
判定区間 2024-06-13〜10-14 は件数以外触れていない。**

対象: Binance COIN-M BTCUSD_PERP。既定値は `PREREG_SKELETON.md` §6 のまま
(カスケード切断 60 秒 / 起点・反応窓とも遡り上限 5 分 / プラセボ規模許容 ±0.25 / 反応窓 1・5・15・60 分)。
価格系列は aggTrades の 1 分足終値(全 tick を読むと実時間予算を超えるための近似。5 分の遡り許容と比べ精度は足りる)。
出来高急増プラセボの候補探索は測定器 (`liq_response.sample_placebo_windows`) と同じ規則
(規模±0.25・清算を含まない窓・選出済みと非重複・候補から乱択)を numpy で書き直した高速版を使用
(素の実装は塊が大きいと候補探索が O(カスケード数×バー数) で終わらないため。規則は変えていない)。
