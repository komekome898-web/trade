## §1 手順

3. 統計量は判定時と同じ「プールした平均の差」。クラスタ版は日ごとの合計と件数を足し上げた

### 課題 B(「60分の下方ドリフト」の実測)

1. 判定時と同じ集約(`ts - ts % 60_000`、終値)で判定区間 124 日の **1 分バー**を再構築した。
   **本数 178,523 は判定時のログと完全一致**(**事実**)。
2. **その日の相場の方向** = その日に属する全 1 分バーを起点とした **同じ窓の先行リターンの中央値**
   (`at_or_before` の遡り許容も判定時と同じ 300,000 ms)。
3. 日内比較は **実カスケードとプラセボの両方がある日だけ**を使い、日ごとに平均を取ってから
   日の差 `m_real,d − m_placebo,d` を作る。集計は 2 通り:
   - **等重み**: 日の差の単純平均(日を 1 票ずつ数える)
   - **件数重み**: `w_d = n_real,d · n_pb,d / (n_real,d + n_pb,d)`(等分散を仮定した精度最適重み)
   区間は**日を単位にした復元抽出 10,000 回**、種は同じ `default_rng(20260913)`。
4. 比較のため、同じ対象日に絞った**プール差**(日の効果を除いていない)も併記する。
   `全体プール → 対象日プール → 日内` の 3 段で、日の除外の効きと日の効果の除去の効きを分ける。

## §4 課題 B — 「60分の下方ドリフト」という交絡の疑い

   **|差| 18.69 bp を作るには 2 桁足りない。**
2. **「プラセボが 0 件の日に実カスケードが偏っているせいだ」は排除される。**
   偏りは逆向き(プラセボ 0 件の日は実カスケードも少ない)で、
   日構成だけで説明される差は long −1.87 bp / short **+1.43 bp**(short では符号が逆で、差を説明しない)。
3. **「差が日の相場の方向で符号づけられている」は排除される。**
   60 分の corr(差, ドリフト)は両向きとも**正**(+0.20 / +0.19)で、下方ドリフト仮説が要求する負ではない。
4. **long 60分 の −5.805 bp が日の効果を除いても残る、とは言えない。**
   日内比較で等重み +7.66 [−0.44, +15.73] / 件数重み −3.21 [−13.88, +7.63] のどちらも 0 を跨ぐ。
   **リードの §6 が「向きに依らず 60 分で下へ流れている」の根拠にした long 側の −5.8 は、日の効果を除くと消える。**
5. **short 60分 の −18.692 bp が日の効果だけの産物だ、とは言えない。**
   日内比較でも等重み −11.28 [−20.63, −1.94] / 件数重み −17.97 [−35.76, −2.62] で、
   どちらも 0 を跨がない。**日の効果を差し引いても残る。**

**排除しないこと**(§6 に再掲):

1. **少数日への集中は排除していない。**2024-08-05 を 1 日除くだけで short 60分 は −18.69 → −11.00、

2. **プラセボ側の裾は排除していない。**60 分の差の主因はプラセボの +9.1 / +14.7 という
   右の裾(中央値は +1.0 / +3.6)である。**なぜプラセボ窓の 60 分後だけ大きく上がるのかは測っていない。**
3. **日より細かい交絡(時間帯・同時刻性)は測っていない。**
4. **日より長い相関(週・月)は測っていない。**

## §6 自分が置いた仮定と、この診断が排除できないこと

### 置いた仮定

1. **【仮定】クラスタは「UTC の暦日」。** 前の診断と同じ切り方に揃えた。
   **UTC 以外の切り方(資金調達時刻・日本時間)は測っていない。**
2. **【仮定】「日ごとの相場の方向」= その日の全 1 分バーを起点にした同じ窓の先行リターンの中央値。**
   素朴な指標を 1 つ選んだだけで、日次リターン・実現ボラティリティ・出来高加重などは測っていない
   (日次の始値→終値リターンも計算したが、本文では使っていない)。
3. **【仮定】日内比較の集計は「等重み」と「件数重み(精度最適)」の 2 通り。**
   どちらが正しい推定量かは事前登録に書かれていない。**2 つの答えが食い違う 60分 long では、
   どちらを採るかで符号が変わる**(§4.3・§4.4)。**本診断はどちらかを選んでいない。**
4. **【仮定】副の対照の 16 セルは「行きすぎ(平均bp)+ 転換」で数えた。**
   これは事前登録の族(向き 2 × 窓 4 × 主張 2)に合わせた数え方で、
   `RESULT_STAGE0.md` §6 の「16/16」とは数える対象が違う(§3.0)。

### この診断が排除できないこと

   日内比較はその日の平均差を残す。**「1 日の中で起きた極端な出来事が機構なのか事故なのか」は測っていない。

   中央値は +1.0 / +3.6 しかない(§4.5)。**なぜ「規模を揃えた清算なしの出来高急増」の 60 分後が
   大きく上がるのかは測っていない。**外れ値を落とした版・中央値の差の版は計算していない
