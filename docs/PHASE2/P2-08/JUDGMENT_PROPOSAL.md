## 2. 解釈(リード)
- 仮説「ストップ設計とコストを見直せば収益化するか」→ **否**。ストップ幅 3 水準・費用 2 水準のどの組でも無条件構成は負。損失の原因はストップ(旧 AR-57)ではなく、
  分足でのグロスのエッジ不在(現行構成のグロス ≈ 0)。【推定】
- 「Binance 先行」は分足では同一分内に織り込まれる(先読み診断で正、遅延で負、相関が lag 0 に集中)。秒スケールの先行は既に棄却済み(`KNOWLEDGE.md`)。【推定】
- 低ボラ三分位の正の値は、n = 137 / 6.3 年(年 22 回、0.01 BTC で年間数百円規模)で経済的意味が薄く、val の CI はゼロを含む。best-of-108 の帰無 n(中央値 1,834)と
  観測 n(33)が乖離するため帰無バーの通過は信頼できない。【推定】

## 3. 判定案
**棄却候補(封印を開けずに記録)**。理由: 無条件構成は開発セット 6.3 年で正の候補ゼロ。封印期間(2023-12-18..2026-09-06)の最終評価で判定が変わる見込みは薄く、
選ばれた構成(n = 33 のセル)を封印期間で 1 回評価しても検出力が無い(封印期間 2.7 年で見込み n ≈ 60、MDE ≈ 35bps)。【推定】
現行 champion の PAPER 稼働は「執行差の実測目的」に限定し、実弾検討は終了(P2-01 と同じ扱い)。
