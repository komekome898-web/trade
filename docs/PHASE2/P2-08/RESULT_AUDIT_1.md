## 総合判定

**結論変更(条件付き)**。下層は全項目が浮動小数の精度で再現(三分位境界 差 0.0、最良台帳 137 取引・平均 25.770・val 33 取引の entry/exit 全件一致、帰無 95 点 6 統計量、best-of-27 の反復 0 との差 0.0、MDE 46.752、反復 0 出力の md5 不変)、封印漏洩なし、テスト 29 件合格。上層は探索面 N = 108・置換世界の共有・ゲートの定義・look-ahead 回避が事前登録どおりで、解釈は §11 に開示されている。
結論を左右するのは停止規則の「MDE」の読みだけである。台帳は登録値 1.54 を採って「続行」としたが、PREREG 自身が梯子のセルにはセル別の MDE が立つと書いており、比較対象セルで公式を評価する読み(46.75)が文言に最も忠実で、その読みでは val 改善 24.06 < 46.75 で反復 2 を行わない。加えて「検出力は十分」の前提(n ≈ 3,000〜8,200)は選ばれたセル(n = 33)で不成立、帰無バーは n ≈ 1,800 の平均の分布であり n = 33 の平均の散らばりを表していない。数値は再現するが、台帳の「続行」は読みの裁定なしには支持されない。
