## 信号と執行の定義(実行に一致)
- 先行モメンタム m(t) = Binance BTCUSDT の close(t) / close(t−k) − 1(1 分足、k 本)。
- 建玉: m(t) > +thr で買い、m(t) < −thr で売り(bitFlyer で成行、次の 1 分足の始値で約定と仮定 + 実測の片道費用)。
- 手仕舞い: |m(t)| < exit で成行決済。保護ストップ: 建値から stop% の逆行で成行決済(同じ足の安値/高値で判定、次足の始値で約定)。
- 同時に 1 建玉のみ、サイズ固定(0.01 BTC = 最小)。スワップ 0.06%/日(建玉の日跨ぎ分に按分、`funding_swap_daily_pct`)。

## 指標と分母
- 主指標: 保守コスト後の 1 取引あたり平均リターン(bps)と 95% CI(取引を日で束ねたクラスタ・ブートストラップ 2,000 回)、
  および日次損益の Sharpe(年率)。分母 = 開発セットの取引数(構成ごとに n を報告。現行構成で 45 日 ≈ 数十〜百数十件の見込み)。
- MDE: σ(取引リターン)は実装時に実測(見込み 30〜60bps)。n=100 で MDE ≈ 8〜17bps/取引。往復費用 2.6bps + スワップを上回る
  期待値が要る。**45 日では検出力が弱い**ことを最初から記す。フォワードで n を増やす。
- 副指標: 勝率、最大 DD、平均保有時間、ストップ発動率、構成ごとの train/val(暦日 2/3 : 1/3)、エッジ推移 §5(単位 = 週、窓 = 50 取引)。

## 対照(反事実)
1. 全時刻無作為 + 状態内無作為: 同じ保有時間分布で無作為な時刻に建玉(1,000 回)。
2. 符号シャッフル(建玉方向の無作為化、1,000 回)。
3. 先行市場のシャッフル: Binance 系列を日単位でブロック置換して信号を作り直す(信号と bitFlyer の対応を壊す帰無)。
4. 先行なし対照: 同じ規則を bitFlyer 自身の m(t) に適用(他市場情報の寄与を分離)。

## 停止規則
直近 3 反復の val 主指標の改善 < MDE、または反復 8 回。

## 最終評価(封印 = フォワード、1 回のみ)
- 凍結日以降のフォワードで、最良構成(開発セットの val で選ぶ 1 点)の取引数が n ≥ 200 に達した時点。
- バー: 「累計 N 通りの最良」の帰無 95 点超、かつ保守コスト後の 1 取引平均の 95% CI が正、かつ日次 Sharpe > 0 の CI。
- 反証文: フォワード n ≥ 200 で「保守コスト後の平均の 95% CI がゼロを含む」なら本仮説(ストップとコストの見直しで収益化)は棄却。
- 保留区分: 楽観のみ正 → 「存在するが執行次第」、引き金 = 執行差の実測(台帳)。
