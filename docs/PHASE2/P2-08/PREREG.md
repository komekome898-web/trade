## 信号と執行の定義(実行に一致)
- 先行モメンタム m(t) = Binance BTCUSDT の close(t) / close(t−k) − 1(1 分足、k 本)。
- 建玉: m(t) > +thr で買い、m(t) < −thr で売り(bitFlyer で成行、**次の 1 分足の始値**で約定 + 片道費用)。
- 手仕舞い: |m(t)| < exit で成行決済。保護ストップ: 建値から stop% の逆行を足の安値/高値で判定し、**次足の始値**で約定(ギャップは不利側)。
- 同時に 1 建玉のみ(構成ごとに独立に評価、構成間で建玉は共有しない)、サイズ固定 0.01 BTC(最小)。
- 資金調達(スワップ)0.06%/日: 実際の仕組みは **1 日 3 回(UTC 05:00 / 13:00 / 21:00)の決済**(`config/products.yaml`)。各決済時刻をまたいで保有した建玉に
  0.02% を課す(監査 2 回目の指摘で規約に合わせた)。
- 時間帯の区分(条件分析)は UTC 固定(0-8 / 8-16 / 16-24)と明記し、夏時間の影響は診断の注記に留める。

## 指標と分母
- 主指標: 保守コスト後の 1 取引あたり平均リターン(bps)と 95% CI(取引を日で束ねたクラスタ・ブートストラップ 2,000 回)、
  および日次損益の Sharpe(年率)。分母 = 開発セットの取引数(構成ごとに n を報告。現行構成で約 9,000 件の見込み、推定)。
- MDE: σ(取引リターン)は開発セットで**実測して台帳の反復 0 に確定**(2.8016 × σ / √n、クラスタ・ブートストラップの SE でも併記)。
  現行構成(thr 0.8%)は Binance 2 年で 1 日約 4.2 取引 → 開発セット 6.3 年で約 9,000 取引の見込み(推定)。検出力は十分。
- 副指標: 勝率、最大 DD、平均保有時間、ストップ発動率、構成ごとの train/val(暦日 2/3 : 1/3)、エッジ推移 §5(単位 = 週、窓 = 50 取引)。

## 対照(反事実)
1. 全時刻無作為 + 状態内無作為: 同じ保有時間分布で無作為な時刻に建玉(1,000 回)。
2. 符号シャッフル(建玉方向の無作為化、1,000 回)。
3. 先行市場のシャッフル: Binance 系列を日単位でブロック置換して信号を作り直す(信号と bitFlyer の対応を壊す帰無)。
4. 先行なし対照: 同じ規則を bitFlyer 自身の m(t) に適用(他市場情報の寄与を分離)。
5. **円換算対照(盲点監査)**: 信号を BTCUSDT × USDJPY(Dukascopy 1 分足、取得中)で作り直し、USD 建て信号との差を報告(為替の寄与の分離)。
6. 診断(判定に使わない): (a) 分の境界のずれの頑健性 — Binance 系列を ±1、±2 分ずらした信号で主指標を再計算し、符号と大きさの変化を報告。
   (b) m(t) を lightchart と WS 記録由来の分足の両方で計算し、重なり期間の一致率。(c) Binance と bitFlyer の対数リターンの交差相関(±10 分)で
   先行の向きと最良ラグを記述(k の候補は変えない)。(d) 現物 BTC_JPY(lightchart)との乖離(CFD ベーシス)の年別分布、SFD 期の注記。

## 停止規則

## 最終評価(封印データ 2023-12-19 .. 2026-09-06、1 回のみ)
- 最良構成(開発セットの val で選ぶ 1 点)を封印期間で 1 回評価。フォワード(2026-09-06 以降、PAPER 台帳)は併記。
- バー: 帰無 A・B(累計 N 通りの最良)の 95 点超、かつ保守コスト後(バースト係数込み)の 1 取引平均の 95% CI が正、かつ日次 Sharpe の CI が正。
- 反証文: 封印期間で「保守コスト後の 1 取引平均の 95% CI がゼロを含む」なら本仮説(ストップとコストの見直しで収益化)は棄却。
- 保留区分: 楽観(バースト係数 1)のみ正 → 「存在するが執行次第」、引き金 = 執行差の実測(台帳 n ≥ 200)。
- 制度区分(SFD 期 2017〜2018、2023 の空分異常、それ以降)と lightchart/公式の差の併記は判定に使わない。
