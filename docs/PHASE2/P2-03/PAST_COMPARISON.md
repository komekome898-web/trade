# TOPIX/JPX400/グロース250 ETF 夜間プレミアム戦略 — 過去との照合(2026-09-06)

## 1. 過去の結論(第40報、探索段階)
横断探索(2011-09〜2026-09、Yahoo日足、汚染データ)で夜間(引け→翌寄り)の年率換算リターンを算出:
TOPIX(1306)+12.5% t+3.3、JPX400(1591)+17.4% t+4.2、グロース250(2516)+14.1% t+2.0、参照の日経225(1321)+13.4% t+3.2。
日中(寄り→引け)はTOPIX −1.0%、JPX400 −8.3% t−2.4、グロース250 −18.1% t−2.2 と全てゼロ以下。
「夜間プレミアムはJPX市場横断で存在する」という**法則**として、判定手続き(事前登録・封印・監査)を経ないまま
`KNOWLEDGE_JP.md` の確立知識に記載された。コスト後の値は一切計算していない(グロスの年率%のみ)。分割・誤プリント・
出来高0行などのデータ欠陥を扱った形跡はない。2026年9月の別枠の事後ブラインド監査(`docs/AUDIT_2026-09/H_jpx_cross_market_overnight.md`、
1事前登録によらない単発チェック)は、日足終値の誤プリント15日を除去した上で1306 t=3.42・1591 t=4.67・2516 t=1.79・
1321 t=3.39と方向を再現し、「薄いETFの夜間は純粋なアーティファクト」という付随主張には留保を付けた(方向は本物、
大きさの一部は市場の情報を反映)。

## 2. フェーズ2の結論
最終評価(封印期間 2022-03-05〜2026-09-04、各系列 n≈1,100、両層の盲検監査で再現)。判定はオーナー:
**存在(市場横断)= 採用**(2/3以上がゼロ含みでない)。取引可能性は系列ごとに割れた:
JPX400(1591)= **採用候補**(保守後 +7.3bps CI[+1.3,+13.4]、日経225と符号一致、帰無超え — 事前登録の3条件を全て満たした唯一の系列。
ただし採用ではなく候補: バーはスプレッド0という未実測の仮定の上に成立し、効果は2024-11-05の制度変更以降に集中)。
TOPIX(1306)= **保留**(楽観は正だが保守後CIはゼロを含む。さらに2026-04-01の10:1分割で1口が約430円まで下がり、
現行の呼値だと往復46.8bpsとなって現物のこの銘柄では実質取引不能。引き金 = 高価格の代替ETF 1348.T の取得)。
グロース250(2516)= **取引可能性は棄却**(保守後 −30.3bps)、**存在は判定不能**(検出力不足、n≈1,000でMDE10.5bpsに対し実測5.9bps)。

## 4. 上書き・確認・未検証
- **上書き**: 「市場横断で存在する」を無条件の法則として書いていた点は上書き。存在(グロス)は生きているが、
  取引可能かどうかは銘柄ごとに全く異なる(1591のみ生存、1306は分割で死亡、2516は費用で死亡)。
- **確認**: グロスの夜間プレミアムの方向・おおよその大きさ(市場横断で正、日中はゼロ以下)は両期間・両手法で一致。
  事後監査(節H)が指摘した「薄いETFの過大表示」も、フェーズ2で厚み(呼値)がそのままコストの生死を分けた事実と整合する。
- **未検証のまま**: 板のスプレッド実測(1591の唯一の合格はスプレッド0の仮定に依存。1ティック足すとCIがゼロを含む)。
  1306の高価格代替(1348.T)の取得と再評価。1591のフォワード250夜でのCI維持。効果が2024-11-05以降に集中している理由
  (制度変更か流動性変化か)は過去にも今にも説明がない。
