# P2-08b Binance 先行の秒スケール捕捉(メイン BOT champion の秒足版)— 事前登録(第 2 稿 2026-09-07、設計監査 1 回目の要修正 8 件を反映、2 回目待ち)

## 仮説(`docs/PHASE2_TRIAGE.md` #28b、オーナー指示 L-011)
Binance の秒スケールの値動きは bitFlyer FX_BTC_JPY に有限の時間で伝播する。その伝播が完了する前に追随する taker 取引に、
実測費用後で正となる窓(閾値・レイテンシ・保有)が存在し、かつ日次の円換算がサーバ費を上回るか。

**旧棄却との差(問いの差別化)**: 旧研究は 1 窓の断面で閾値 × 遅延の面を走査し棄却した(数値はリードのみ保持、実装者・監査者には開示しない)。本単位が新たに問うのは
(i) 分足 P2-08 で見えた「Binance を先読みすると正」が分内のどの秒に存在するか(分内分解)、(ii) 条件の向き(低ボラと高ボラの両側を同じ格子で)、
(iii) 伝播時間分布の長期変化(2019〜2026)。閉じる条件は §第 1 層に数値で書く。(i)〜(iii) のいずれも出せなければ「重複・判定不能」で閉じる。

## 格子セル
市場 = bitFlyer Crypto CFD(FX_BTC_JPY)/ 執行様式 = taker(成行)/ 時間スケール = 秒 / 情報源 = 他市場(Binance BTCUSDT 現物 aggTrades。無期限・Bybit は対照)

## 第 1 層: 伝播の計測(取引なし、存在の層)
- 事象 = Binance aggTrades から作る直近 w 秒のリターン |r_B| ≥ s(s ∈ {10, 20, 30} bps、w ∈ {1, 2, 5} 秒)。t0 = 事象を確定させた aggTrade の取引所刻印。重複規則は既知欠陥 (8)。
- 応答 A(τ1, τ2) = bitFlyer の t0+τ1 以降の最初の約定価格から t0+τ2 以降の最初の約定価格へのリターン(bps、r_B の符号に揃える)。
- **主量 = A(τ, τ+5)**(τ から 5 秒保有した場合の粗リターン、第 2 層の保有と同一)、τ ∈ {0.1, 0.2, 0.5, 1, 2, 5, 10, 30} 秒。併記 = A(0, τ)/|r_B|(織り込み率)。
  95% CI は事象を日でクラスタしたブートストラップ 2,000 回、seed 20260907。
- **実用窓 τ*** = A(τ, τ+5) の CI 下限が往復の保守費用(§コスト)を超える最大の τ。τ* < λ(0.1 秒)なら第 2 層は形式的に実行するが反証文が成立(§最終評価)。
- 条件分析(標準 §6): ボラ三分位(60 秒実現ボラ、train で境界固定)× 主量。**(ii) の閉じる条件**: 低ボラ − 高ボラ の A(0.1, 5.1) の差の CI が差の MDE 未満なら「判定不能」。
- **(i) 分内分解**: P2-08 の分足信号(k=15/30/60、thr 0.4/0.8/1.2)が発火した分について、60 秒応答のうち 0〜5 / 5〜15 / 15〜60 秒に帰属する割合を CI つきで出す。
  0〜5 秒の割合の CI 幅 > 50pp なら「判定不能」。
- **(iii) 長期変化**(標準 §5): Tardis サンプル日(2019-09〜2026-08、毎月 1 日、最大 84 日)で年別に A(0.1, 5.1) と τ* を出す。単位 U = 年、窓 W = 12 サンプル日、ブロック長 = 1 日、
  傾き(bps/年)と傾きの MDE、判定文は §5.7 の規則。「縮小していない」= 傾きの CI 上限 > 0。年別 n が 12 日分しか無いので MDE を先に出し、MDE > |傾き| なら「判定不能」。
  bitbank 9 年でも同じ表(円市場の代理、判定に使わない)。

## 第 2 層: 取引可能性(探索面、事前に固定)
| パラメータ | 候補 | 備考 |
|---|---|---|
| s(bps) | 10, 20, 30 | 発火閾値 |
| w(秒) | 1, 2, 5 | 信号窓 |
| λ(ms) | 100 固定(判定)、50 / 500 は感度 | 受信 p50 61ms + 判断 + REST 46ms ≈ 110ms(既存実測) |
| 手仕舞い | t0 + λ + 5 秒以降の最初の約定で成行(固定)。保護ストップなし | |
N0 = 3 × 3 = **9**。サイズ 0.01 BTC。**監査 1 回目の見込み**(3 日の外挿、嵐日込み【推定】): 開発 31 日の n は s=10 で 440〜2,000、s=20 で 60〜370、s=30 で 40〜120。
5 秒応答 sd 13〜37bps から MDE = (10,1) 2.8 / (10,2) 1.3 / (10,5) 0.8 / (20,1) 8.5 / (20,2) 10.9 / (20,5) 3.6 / (30,1) 8.1 / (30,2) 11.1 / (30,5) 8.8 bps。
**s ≥ 20 かつ w ≤ 2 の 4 構成は MDE が往復費用の 2〜4 倍で、着手前の棄却候補**(実行はするが、最終評価の対象になり得るのは MDE ≤ 往復費用 × 2 の構成のみ)。反復 0 で実測し確定。
**約定価格の規則(一意)**: 建玉 = t0 + λ 以降の最初の bitFlyer 約定の刻印束のうち、買いなら束内最高値・売りなら束内最安値(不利側)+ 片道費用。
その約定が t0 + λ + 1 秒より後なら「約定なし」で取引しない(件数報告)。手仕舞い = t0 + λ + 5 秒以降の最初の束の不利側価格。待ちが 30 秒を超える取引は除外(件数報告)。
**主指標** = val の保守費用後・1 取引平均 net(bps)と CI(日クラスタ・ブートストラップ 2,000 回)。**選択統計量はこれ一本**。日次円換算 = 取引数/日 × 0.01 BTC × 価格 × net は経済の停止条件と最終バーにのみ使う。
**経済の停止条件(主検定より前)**: 開発セットで val 最良構成の日次円の**点推定** < 100 円/日(サーバ費 50 円/日 × 2)なら、封印を開けずに棄却。
帰無の構成(累計 N 通りの最良): Binance の秒リターンを日ブロックで置換して事象を作り直し(bitFlyer 側はそのまま)、9 構成の最良、2,000 回、95 点(帰無 A = 1 取引平均、帰無 B = 日次円)。
反復の梯子(2 段で終了): 反復 1 = ボラ三分位(9 × 3、N = 36)。反復 2 = なし。停止規則: 反復 1 の val 改善 < 選ばれたセルの MDE で早期停止。

## 対照(反事実)
1. 全時刻無作為(同じ保有、1,000 回)。2. 符号シャッフル(1,000 回)。3. Binance 秒リターンの日ブロック置換(帰無と同じ)。4. 先行なし: bitFlyer 自身の秒リターンで同じ規則。
5. 信号源の置換: Binance USDT 無期限、Bybit 現物。6. 診断: (a) λ 感度 50 / 100 / 500 ms(δ_clock 込み)、(b) WS 欠けを REST で補った場合の差(重なり 08-20〜23)、(c) 束内の最良側価格を採った場合の差(執行の上限)。

## 停止規則
経済の停止条件 → 反復 1 で終了。反復 8 回の一般規則は使わない。

## 最終評価
- 対象 = val 最良構成 1 点(選択統計量 = val 1 取引平均 net)。構成ごとに **n_X = (2.8016 × σ / 2.0)²**(MDE を 2.0bps にするための取引数、σ は開発セット実測)を反復 0 で表にし、
  封印 + フォワードで **n ≥ n_X かつ暦 ≥ 14 日** に到達した時点で 1 回評価。到達判定は **Binance 側の事象数だけを数える count-only スクリプト**(bitFlyer 側の結果を読まない、実行ログを `UNSEAL_LOG` に残す)で行う。
  到達見込みが 180 日超なら「判定不能・頻度不足」で閉じる。
- バー: 帰無 A・B の 95 点超、かつ保守費用後の 1 取引平均の CI が正、かつ日次円の点推定 > 100 円/日。
- 反証文: 「第 1 層で τ* < λ(0.1 秒)」または「経済の停止条件に該当」または「最終評価で 1 取引平均の CI がゼロを含む」なら本仮説は棄却。
- 引き金(資源化): 第 1 層で τ* ≥ 0.5 秒かつ (iii) で縮小していない場合のみ、Tardis 購入($350/月、四半期払い)を週次要約の判断項目に載せる。
