# P2-08b Binance 先行の秒スケール捕捉(メイン BOT champion の秒足版)— 事前登録(第 1 稿 2026-09-07、設計監査待ち)

## 仮説(`docs/PHASE2_TRIAGE.md` #28b、オーナー指示 L-011)
Binance の秒スケールの値動きは bitFlyer FX_BTC_JPY に有限の時間で伝播する。その伝播が完了する前に追随する taker 取引に、
実測費用後で正となる窓(閾値・レイテンシ・保有)が存在し、かつ日次の円換算がサーバ費を上回るか。

**旧棄却との差(問いの差別化、盲点監査 B-7)**: 旧 (e)(p)(x)(ah) は「2026-07/08 の 1 窓で thr × 遅延 δ の面を taker/maker で走査」し、
エッジは最初の 0.2 秒に集中・頻度 0.84 回/日で費用線と区別不能とした。本単位が新たに問うのは
(i) 分足 P2-08 で見えた「Binance を 1〜2 分先読みすると +10〜+29bps」が分内のどの秒に存在するか(分内分解)、
(ii) 条件の向き — P2-08 は**低ボラ**で正、(e) は **20bps 級の激変**で正。両側を同じ格子で測る、
(iii) 伝播時間分布の**長期変化**(2019〜2026、Tardis 無料サンプル 84 日 + bitbank 約定 9 年)。旧研究は 1 窓の断面のみ。
同じ 2026-07/08 窓で thr × δ の面を再測するだけなら本単位は不要(重複)であり、(i)〜(iii) のいずれも出せなければ「重複・判定不能」で閉じる。

## 格子セル
市場 = bitFlyer Crypto CFD(FX_BTC_JPY)/ 執行様式 = taker(成行)/ 時間スケール = 秒 / 情報源 = 他市場(Binance BTCUSDT 現物。無期限は対照)

## 第 1 層: 伝播の計測(取引なし、存在の層)
- 事象 = Binance の直近 w 秒のリターン |r_B| ≥ s(s ∈ {5, 10, 20} bps、w ∈ {1, 2, 5} 秒)。事象時刻 t0 = 事象を確定させた Binance 約定の取引所刻印。
- 応答 = bitFlyer の最終約定価格の t0 + τ における t0 比リターン(τ ∈ {0.1, 0.2, 0.5, 1, 2, 5, 10, 30, 60} 秒)、符号は r_B に揃える。
- 主量: **残存伝播量** R(τ) = E[応答(τ=60) − 応答(τ)](τ 時点でまだ織り込まれていない分、bps)と、その 95% CI(事象を日でクラスタしたブートストラップ 2,000 回、seed 20260907)。
  R(τ) が費用(往復の実効スプレッド、バースト係数込み)を超える τ の上限 = **実用窓** τ*。
- 年別(2019〜2026、Tardis サンプル日)・ボラ三分位(60 秒実現ボラ、両方向)・時間帯(UTC 8 時間帯)で R(τ) と τ* を併記(条件分析 §6)。
- 診断 (i): P2-08 の分足信号(k=15/30/60、thr)が発火した分について、分内の秒別の応答を出し、「1 分先読み +10〜+29bps」がどの秒に存在するかを分解。
- bitbank 9 年: 同じ R(τ) を bitbank 約定で年別に(円市場の長期代理、判定に使わない)。

## 第 2 層: 取引可能性(探索面、事前に固定)
| パラメータ | 候補 | 備考 |
|---|---|---|
| s(bps) | 10, 20, 30 | 発火閾値 |
| w(秒) | 1, 2, 5 | 信号窓 |
| λ(ms) | 100 固定(判定)、50 / 500 は感度 | クラウド東京 40〜70ms、自宅 61ms(ah)の実測値 |
| 手仕舞い | τ = 5 秒で成行(固定)。保護ストップ なし(保有 5 秒) | 旧 (ah) と同じ E 系出口は使わない(重複回避) |
N0 = 3 × 3 = **9**。サイズ 0.01 BTC。約定 = t0 + λ 以降の最初の bitFlyer 約定価格 + 片道費用(実効半スプレッドをバースト係数込みで実測、`P2-08` の手続きを再利用)。
**主指標** = (a) 1 取引平均 net(bps)と CI、(b) **日次円換算** = 取引数/日 × 0.01 BTC × 価格 × net bps(CI は日ブロック・ブートストラップ)。
**経済の停止条件(主検定より前、盲点監査 D-11)**: 開発セットの最良構成の日次円の 95% CI 上限 < サーバ費 50 円/日 × 2 = 100 円/日 なら、封印を開けずに棄却。
帰無の構成(累計 N 通りの最良): Binance の秒リターンを日ブロックで置換して事象を作り直し(bitFlyer 側はそのまま)、9 構成の最良の主指標、2,000 回、95 点(帰無 A = 1 取引平均、帰無 B = 日次円)。
反復の梯子(2 段で終了): 反復 1 = ボラ三分位(両方向、9 × 3、N = 36)。反復 2 = なし。停止規則: 反復 1 の val 改善 < 選ばれたセルの MDE で早期停止(P2-08 の裁定を踏襲)。

## 最終評価
- 封印(08-23..09-06)+ フォワードで最良構成の **n ≥ 100** に到達した時点で 1 回(到達見込み日数は反復 0 で表にする。見込みが 180 日超なら「判定不能・頻度不足」で閉じる)。
- バー: 帰無 A・B の 95 点超、かつ保守費用後の 1 取引平均の CI が正、かつ日次円の CI 下限 > 100 円/日。
- 反証文: 「実用窓 τ* < λ(100ms)」または「日次円の CI 上限 < 100 円/日」なら本仮説は棄却。
- 引き金(資源化): 第 1 層で τ* ≥ 500ms かつ年別で縮小していない場合のみ、Tardis 購入($350/月、四半期払い)を週次要約の判断項目に載せる。それ以外は購入しない。
