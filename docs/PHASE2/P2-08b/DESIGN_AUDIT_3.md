### #3 「val 最良構成」の未定義が単位の結論を反転させる — **新規・大**

一方 §第 2 層は「**9 構成すべて実行**し帰無も 9 で取るが、最終評価の対象になり得るのは到達見込み ≤ 180 日の構成のみ」とも書く。
「val 最良構成」がどちらの集合の最良かが定義されていない。実測すると:

- **9 構成の val 最良 = s30w2(val 1 取引平均 +12.75 bps、n = 18)** → 開発 31 日 **99.5 円/日**(全日)/ **60.3 円/日**(最大日除外)= **両方 < 100 → 本単位は封印を開けずに棄却**。
- **s=10 の 3 構成に限った val 最良 = s10w1(+1.86 bps、n = 323)** → **286.9 / 208.4 円/日 = 両方 ≥ 100 → 続行**。

**単語 1 つで単位の生死が決まる**。しかも棄却側を引き当てる s30w2 は、PREREG 自身が「頻度不足の着手前棄却候補(到達 1,113〜2,193 日)」と宣言している構成であり、
最終評価の対象になり得ない構成の val 点推定で全体を殺す設計になっている。加えて 99.5 円/日 は閾値 100 円/日 の **0.5% 下**で、
バースト係数(未登録、1.0 で計算)を 1.01 にするだけで符号が変わる境界値である。

### #4 帰無「9 構成の最大」が s=10 の実測を構造的に通さない(P2-08 反復 1 と同型)— **新規・大**

帰無 = Binance の日ブロック置換(31 日の Binance 日を bitFlyer 日に無作為対応、bitFlyer 側はそのまま)。100 抽選、seed 20260907。
統計量は帰無 A = 1 取引平均 net(bps)。

| 帰無の取り方 | 95 点 | 中央値 | 最大 |
|---|---|---|---|
| **9 構成の最大**(第 3 稿の規定) | **+11.11 bps** | −1.20 | +22.65 |
| s=10 の 3 構成の最大 | **+0.11 bps** | −2.27 | +1.08 |

構成別の帰無 95 点: s10w1 +0.11 / s10w2 −0.91 / s10w5 −1.19 / s20w1 +3.17 / s20w2 +1.34 / s20w5 +0.63 / **s30w1 +2.12(帰無 n 中央値 2)** / **s30w2 +6.99(帰無 n 中央値 3)** / s30w5 +1.40。
最大を取った構成の内訳(100 抽選): s30w2 36 回・s30w1 18 回・s20w1 17 回・s20w2 10 回 = **小 n セルが 81%** を占める。

**結果**: 実測の s10w1 は 1 取引平均 +1.83 bps(val +1.86)。帰無 95 点 +11.11 bps を **6 倍下回る**。
s=10 の粗応答は数 bps の量なので、**この帰無バーは s=10 では原理的に超えられない**。
一方 s=10 だけで帰無を取れば 95 点 +0.11 bps で s10w1 は通る。第 3 稿は「実質の探索面は s=10 の 3 構成」と書きながら
帰無だけ 9 構成で取るため、**探索面と帰無の非対称が、単位が唯一通り得る構成を殺す**。
(帰無 B = 日次円 の 95 点は 9 構成で 21.7 円/日、s=10 で 11.2 円/日。実測 286.9 円/日 なので帰無 B は問題にならない。**効くのは帰無 A 一本**。)

**副次的な欠陥**: 日ブロック置換は帰無の n を実測の n から大きく引き離す。s10w1 の帰無 n 中央値は **68**(実測 441)、s10w5 は 210(実測 1,276)。
理由は「t0+λ+1 秒以内に約定が無ければ約定なし」の規則が、嵐日の Binance 事象を閑散日の bitFlyer に貼り付けると大量に発動するため(両市場の活動が同日に共起する構造を置換が壊す)。
帰無の n が実測の 1/6 なら帰無の平均の分散は √6 倍で、**95 点は自動的に押し上がる**。等 n でない帰無との比較は成立しない。

**対策案(いずれか、または併用。どれも探索面 N には加算しない)**:
1. **帰無の集合を探索面と一致させる**: 最終評価の対象になり得る構成(到達見込み ≤ 180 日)だけで帰無の最大を取る。事前登録で集合の決め方を数値規則にする(実測 #5 参照)。
2. **統計量を studentize する**(帰無・実測とも 1 取引平均 → t = 平均 / SE)。実測: 帰無 t の 9 構成最大の 95 点 = **+1.96**(別 seed 20260908、100 抽選)。s10w1 の t は dev 3.52 / val 2.82 で **通る**。ただし s30w1 は帰無 n 中央値 2 で t の 95 点が 11.35 と退化するので、3 と併用が要る。
3. **最小 n の床を帰無側にも実測側にも課す**(抽選ごとに n < n_min の構成を最大の候補から外す)。実測: 床 30 で 9 構成最大の 95 点は **11.11 → 0.64 bps**、床 50 で 0.29 bps。s10w1(+1.83)は通る。床 30 のとき最大を取る構成は s10w1 45 回 / s10w2 24 回 / s20w5 15 回 / s10w5 12 回 = 探索面と整合する。
4. 置換の単位を「無条件の日」から「同ボラ三分位の日の中でのみ入れ替え」に変えて活動の共起を保つ(帰無 n の乖離を減らす)。

### #6 λ 感度と δ_clock の相互作用 — **新規・小(ただし解釈は重い)**

s=10 の 3 構成、λ を振ったときの 1 取引平均 net(31 日、他は同規則):

|---|---|---|---|---|
| 50 ms | **+2.63** | +0.88 | +0.17 | 1.8 / 3.5 / 8.0 % |
