# P2-04 設計監査(第2回・盲検)

対象: PREREG 第2稿。`load_unsealed`で開発セット(1990-01-04..2015-08-28、n=6,306)を再現し、
6項目すべてを実測で再検算した。

## 修正6項目の判定

**1. Q1: PH n訂正+MDE再計算 → 部分**
n=298を独自再導出で完全一致(1990s116/2000s116/2010s66)。ただしMDE計算の前提σ≈140bpsは過小:
実測σは規則ごとに147〜166bps(例: PH生n=298でσ=165.6bps → MDE≈26.9bps、本文記載の23bpsを17%上回る)。
さらに新設のSQ隣接除外(下記2)を適用した後のn・MDEが表に無い。実測(除外後): PH n=285(σ=160.6,MDE=26.7)、
TOM n=1230(σ≈157,MDE=12.5、ほぼ無変化)。曜日別は次項参照。

**2. Q3: メジャーSQ隣接ペア除外の明記 → 部分**
除外規則自体は実装可能で機能する(実測で確認)。ただし本文は「金曜規則はメジャーSQ日を約8%含む」としか書いていない
のに、除外は「ペアの**どちらかの端点**がSQq日または前営業日」なので、SQq(金曜)の前日(木)と翌営業日(月)にも
等しく波及する。実測(除外前→後、%): WD-Mon 1184→1092(-7.8%,MDE13.61→13.99)、WD-Thu 1283→1180(-8.0%,
MDE12.10→12.51)、WD-Fri 1282→1180(-8.0%,MDE11.99→12.14)、WD-Tue/Wed/TOM/PHは≦1%で無視できる。
影響幅は小さい(MDE変化≦3.5%、結論を左右しない)が、**本文の記述は月・木への波及を開示していない**。

**3. Q4: 9通り最良の同時置換帰無 → 部分**
「1回の抽選で20日ブロック置換→9規則の統計量→最大値、2,000回」の手順自体は構造上実装可能(規則は日付集合が
固定でリターン系列だけ並べ替えるため、計算コストも問題なし)。**しかし「統計量」が何を指すか本文中で一度も定義
されていない**。主指標は(1)保守コスト後平均と(2)D_R−非D_R差の2本立てで、判定は「両方」を要求するのに、置換
帰無の最大値化はどちらか一方の値でなければ定義できない(2本のベクトル最大は非可換で別の帰無になる)。第1回監査
はこの構成法の欠落だけを指摘しており、第2稿はその構成法を採用したが統計量の指定を落としたままである。
**要修正**: 「置換の統計量 = (1)の保守コスト後平均」等と明記するか、(1)(2)それぞれに独立な置換帰無を回し両方
95点超を要求する旨を明記すること。

**4. Q5: プラセボのシフト単位・折り返し規則 → 解決**
シフト単位=取引日インデックス、折り返し除外規則を実装し、9規則×k∈{−2,−1,+1,+2}の全36通りを実測。
**全て非空**(最小はSQq k=+2でn=102、他は最小でもWD-Mon等でn>1,000台〜TOMの308)。月末/週末境界の帰属も
一意に計算できた。致命なし。

**5. Q6: 開示緩和策 → 解決**
封印解除タイミングを停止規則(反復8回orΔ<MDE×3)で機械化しリード裁量を除去、上位層監査者による判定案の整合性
採点を追加——第1回が指摘した2経路(解除タイミングの裁量、判定文の非レビュー)を両方閉じている。

**6. Q7-1: 銘柄不整合(マイクロ/ラージ)の代替前提 → 解決**
「商品の置換(事前の仮定)」節に、収益率=ラージ系列・費用=マイクロ仕様・両者価格パリティの仮定を明記、当時ラージ
仕様での費用も感度として併記。README_SOURCE.mdの「ラージの継続系列」記載とも整合。
