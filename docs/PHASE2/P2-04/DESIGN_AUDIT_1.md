# P2-04 設計監査(第1回・盲検)

対象: `docs/PHASE2/P2-04/PREREG.md` 第1稿。手元で `load_unsealed` により開発セット(1990-01-04..2015-08-28、
先物 full_day_daily、n=6,306)を再現し、暦規則を再導出して数値を検算した。

## Q1 暦規則の機械的定義
祝日集合・第2金曜集合を独立に再導出できた(定義は明文で再現可能)。ただし数値が食い違う。
- PH(祝日前)= 「翌暦日が平日かつ非取引日」の直前営業日、と機械的に再導出すると **n=298**(1990s 116 / 2000s 116 /
  2010s(〜2015-08) 66 → 年あたり約11.5日)。PREREG 分母表の「PH 約380」と一致しない(約 22% の過大見積り)。
  年末年始・GW は正しく捕捉(例: 1995-12-29、2005-12-22/30、2013-04-26・05-02)。土曜取引日はデータ上ゼロ(1990-01-04
  開始で1989年のOSE週休二日制移行後のため混入なし、これは確認済みで問題なし)。
- TOM: n=1,229(PREREG「約1,200」と整合)。WD: 各曜日1,184〜1,284(PREREG「約1,250」と整合。月曜が少ないのは
  ハッピーマンデー化した祝日の影響で説明がつく)。
**判定: 要修正**(PH の n 見積りを実測298に訂正し、MDE を再計算すること)。

## Q2 σ・n・MDE、SQ規則の検出力
PH の実測 n=298 なら MDE は「n=380」前提より大きくなる(σ一定なら √(380/298)≈1.13倍)。SQm(1321.T、
2011-09..2015-08)n≈49、SQq n≈16 は極小標本で、PREREG 自身が「判定不能が最も起こりやすい」と明記している点は誠実。
ただし「テスト可能か」への回答が「CIは計算できるが検出力はほぼゼロ」で足りるかは要検討 — 事前に "判定不能"
が確定的な規則を N0=9 の一員として数える(=最終バーを押し上げる)ことの是非を一言明記すべき。
**判定: 可**(PHのnのみQ1で修正)。

## Q3 コスト定式化とSQロールの整合性
`cost_bps(t) = 122/(close(t-1)×10)×10^4` は建玉時点(t-1引け)の名目を分母にしており close→close 保有の
コスト化として整合(明確)。
未対応の穴: 継続系列の接合日(SQ当日か否か不明)を理由にSQ専用規則だけ1321.Tへ退避しているが、**WD(金曜)規則は
先物のまま評価される**。SQq日(n=102、四半期)はほぼ全て金曜(SQm∩金曜=302/308)であり、もしロール接合が
SQ当日なら、WD(金曜)のサンプルの約8%(102/1,282)が正体不明のロール価格差を含んだまま計測される。
TOM∩PH=85(PHの約29%)も年末年始が月替わりと機構的に重なるための恒常的な共変であり偶然ではない。
**判定: 要修正**(WD/TOMがSQqのロール接合日を含む場合の除外・印付け方針を明記すること)。

## Q4 探索面 N0=9 と規則重複
実測した重複: SQm∩TOM=2、SQm∩PH=51(SQmの約17%)、TOM∩PH=85。「9通りの最良」の帰無分布の構成法が本文に
書かれていない。規則が重複する以上、9つを別々に1,000回シャッフルしてそれぞれの95点と比べる方式では多重性補正
にならない(同じ乱数世界の中で9統計量の最大を取る必要がある)。
**提案する具体構成**: 同一の1回の並べ替え(対照1〜3のいずれか、例えば日次リターン列の年内シャッフル)を適用し、
その1回の並べ替え結果に対して9規則すべての統計量を再計算し、その中の最大値を記録する。これを2,000回繰り返し、
得られた「最大値の分布」の95点を最終バーとする(規則間の重複由来の相関を自動的に反映する)。
**判定: 要修正**(構成法を上記のように明文化してから実行)。

## Q5 対照(反事実)
層化無作為日集合(年ごと)はTOM/WD/PHの反事実として妥当(規模・年次分布を合わせている)。
プラセボ±1/±2営業日シフトは月境界での定義が曖昧: TOMの「月末最終営業日+翌月最初3日」を+2営業日シフトすると
シフト後集合が自身の定義域(翌月4〜5日目)にはみ出し、規則本体と近接して二重の要因が混ざる。PH/SQmも週境界を
またぐシフトでどちらの月・週に属するかの帰属規則が書かれていない。「営業日」シフトが暦日ではなく取引日インデックス
基準であることも明記されていない。
**判定: 要修正**(シフト単位=取引日インデックス、月/週またぎの帰属規則を明文化)。

## Q6 開示(P2-01既見情報)と封印境界
2015-08-29 は `calendar_seal_boundary`(全期間1990-2026の70%点)による機械算出値で、P2-01が晒した
2020-12..2026-08 の窓を完全に開発セット外へ追いやる(むしろ night_session 単独の自然な境界は2020-12-21で
P2-01の窓の起点と際どく重なるところだった — 主系列基準の一律境界を採ったことは安全側の選択で、これは可)。
一方、開示緩和策「実装者・監査者は盲検」は計算経路の遮断であり、リード自身が最終判定文(JUDGMENT.md)を書く
段や、反復延長・封印解除タイミングの承認を求める場面でP2-01既見の定性的印象(2020-2026台のボラ体制など)が
判断に混ざる経路は塞がれていない。
**判定: 要修正**(リードは本単位のJUDGMENT.md起案から外れるか、封印解除の承認を別人にするなど追加の遮断を明記)。
