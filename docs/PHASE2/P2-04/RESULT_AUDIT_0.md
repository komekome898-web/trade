系列別分割の方が統計的に妥当(自分の結合案は小標本SQ規則のノイズが先物側の分母を歪める点で劣る、と監査後に判断)。
ただし数値としては3倍規模の乖離があるため**この図表単体は数値差異**。結論への影響: 全規則の保守ネット平均が
負(SQqのみ+25.2だがCI算出不能n<block)なので、どちらのバーを採っても「候補」規則ゼロという結論は不変。
