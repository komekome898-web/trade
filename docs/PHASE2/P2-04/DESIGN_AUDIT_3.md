## 監査2回目の指摘2件

**(a) Q3除外の波及(月・木)開示 → 解決**
既知欠陥欄でWD-Mon 1,184→1,092、WD-Thu 1,283→1,180、WD-Fri 1,282→1,180、PH 298→285、TOM±1%を明記。

**(b) Q4 置換帰無の統計量 → 解決**
「帰無A=主指標(1)の9規則最大、帰無B=主指標(2)の9規則最大。バーはA・Bの両方を超えること」と明記。2本立てが解消。
ただし最終評価節のバー文言は「『9通りの最良』の帰無95点超」と単数形に戻っており、A・B両方が対象である旨を再掲していない
(探索面節に戻れば読めるが、判定基準の核心なので最終評価節でも「帰無A・Bとも95点超」と明示すべき)。**軽微**。

## 条件分析・反復の梯子(標準§6)の整合性

1. 状態変数(実現ボラ三分位・直前日リターン符号・年代・泊数)はいずれも建玉時点で観測可能。テンプレ候補群の部分集合として妥当。
2. 追加構成数は「規則9×水準数」という式のみで、反復1(ボラ三分位=3)・反復2(符号=2)の水準数は既に確定しているのに
   具体数(27・18)も累計N(9→36→54)もどこにも書かれていない。**反復1後・反復2後の累計Nが本文から一意に決まらない**。
3. さらに反復2が反復1の状態と独立な別集合(9×2を単純加算)なのか、反復1の3水準と組み合わさる入れ子(9×3×2)なのか
   文言上区別できない。「反復kで追加する状態変数」という書き方はテンプレ§6-5の例示と同じだが、結合方法が未定義。
   Nの数え方が変わる(54 vs 累計計算が別物になる)ため**要修正**。
4. 状態ごとのMDE膨張(nが1/3なら約1.7倍)の明記、および「差が見えない」と「差が無い」を区別する旨の記載が条件分析節に無い
   (テンプレ§6-2は「必ず併記」と指定)。出力表にMDE列はあるが、膨張の注記自体が欠落。**要修正**。
5. テンプレ§6-4は「候補水準に達した状態は条件付き仮説として新規単位を事前登録」だが、本稿の反復の梯子は候補規則を
   同一最終評価の「累計N通りの最良」に混ぜる設計(新規単位化しない)。単一の封印開封でNを正しく膨らませる代替設計として
   一貫してはいるが、テンプレ文言とは字義的に異なるため、意図的な逸脱であることをオーナー確認のうえ明記した方がよい(**軽微**)。
