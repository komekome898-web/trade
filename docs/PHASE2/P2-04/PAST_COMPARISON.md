## 1. 旧結論(フェーズ2着手前)
- 出典: `SURVEY_JP_INDEX_FUTURES.md` §3.3(本調査実測)+ 監査 `docs/AUDIT_2026-09/AL_jp_feasibility_calendar.md`(JPL2/JPR2)。
- 規則: 月初日・月末日(単日 C→C)、SQ日(第2金、単日)、休場前日(単日)、曜日(月・金 C→C、火 overnight)。
- データ窓: 実測は2006–2026(20.6年)。監査の再計算は`^N225` 1990–2026(36年、n=8,995)全期間平均+年代別セル。
- コスト前提: **グロスのみ**。往復コストを引いていない(存在検定のみ、取引可否は別枠)。
- 数値: 月初 t=0.31 / 月末 t=−0.56 / SQ日 t=0.48 / 休場前日 t=−0.45 / 月曜 t=0.03 / 金曜 t=−0.39。**全て \|t\|<2**、月末は「t=2に265年」。
- 監査の判定: 「再現」。ただし追記あり — **1990年代の月曜だけ t=−2.32(n=478、平均−18.3bps)** が例外で、全期間平均がこれを薄めていると明記(JPL2の脚注)。

- 規則: 9本(TOM=月替わり窓4日、WD=曜日5本、PH=祝日前、SQm/SQq)。反復1でボラ三分位条件付け(+27、N=36)、反復2で直前日符号条件付け(+18、N=54)。
- コスト前提: **保守 = 手数料+1ティック/片側**(先物マイクロ122円/往復、組ごとcost_bps中央値7.9bps)。判定は保守ネット。

## 4. 判定
- **確認(旧と一致)**: TOM・PH・火水木金曜・SQ日は正方向でバー未達 = 「暦だけで取引可能」ではない、という結論は不変。
- **修正(旧が上書きされる)**: 「月曜C→Cは効果なし」は1990–2015・保守コスト後では成立しない(有意に負)。旧の全期間平均がこれを希薄化していただけで、旧監査自身が1990年代セルで既に同じ兆候(t=−2.32)を記録していた。矛盾ではなく**期間分割の粒度の違いによる発見**。
- **未検証(旧に存在しない新規探索)**: ボラ三分位・直前日符号による条件付け45構成は旧調査になし。フェーズ2でも全てMDE未達で「判定不能」または「差なし」に留まる。
