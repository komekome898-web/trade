# 日経225先物オーバーナイト戦略 — 過去フェーズとフェーズ2の比較

## 1. 過去フェーズの結論(2026-08-28、第36報)

**判定: 全バー通過 → オーナーへ提示 → フォワード・ペーパー追跡を開始(採用ではない)**。
- 数字: 全期間(1990-2026、日次約9,037組)でグロス平均 +3.80bps/日(年率+9.31%、t=3.42)。
  保守コスト控除後 +2.70bps/日(年率+6.62%、t=2.43)。4つの時代区分すべてで平均プラス。
  Buy&Hold比較: 全期間ではON1が年率・Sharpe・最大下落幅の全てで上回るが、直近10年は
  素リターンでB&Hが上回りSharpeのみON1優位。
- コスト方法: **固定bps定数**(往復1.10bps/日)。2026年時点の想定元本(66万円)で1回だけ
  算出し、1990年から2026年まで一律に適用。
- データ窓: 1990-2026の全期間を1回で使い切り(訓練・検証・封印の分割なし)。選定は現物
  指数側で行い、判定は先物側の全期間データをそのまま使った(時間方向の新鮮データなし)。
- 監査: 実施(ブラインド監査1件、`docs/AUDIT_2026-09/A_on1_overnight.md`)。**「再現」**判定。
  ただし注記: (a) 効果は高ボラ局面に偏り低ボラ局面では非有意、(b) 日中の「1990-2015年に
  有意に負」の主張は2008-2015年単体では非有意、(c) 「夜間セッション本体が主因」は日付整列
  修正後でようやく確認でき、それでも夜間後の効果の約2/3〜相関0.77しか説明しない、
  (d) 限月ロールの接続方法は監査できなかった。

## 2. フェーズ2の結論(2026-09-06)

**判定: 棄却**。開発セット(2007-2020)・封印期間(2020-2026)のいずれも、コスト控除後の
平均は95%信頼区間がゼロを跨ぎ、「夜間保有が日中保有より高い」という核心主張も同様に
非有意。訓練/検証の反復では平均ネットが**マイナス**(-3.96〜-4.59bps/組)、封印期間では
+2.49bps(CI [-2.56, +7.45])とプラスに転じたが、それでもゼロを含む。グロスの夜間プレミアム
自体は封印期間でCIがプラス(+6.06bps)——存在は否定していない。監査は上下2層とも実施し、
いずれも「再現」、判定の帰結も一致。

## 4. 過去の主張の扱い

- **上書き(もはや成立しない)**: 「保守コスト後も有意にプラス(+2.70bps/日、t=2.43)」→
  フェーズ2では開発セットでマイナス、封印期間でもCIがゼロを跨ぎ非有意。固定コスト定数が
  過去の低指数水準期のコストを過小評価していたことが主因。
- **確認された**: グロスの夜間プレミアムが存在すること自体(境界アーティファクトではない)は
  フェーズ2でも封印期間でCIプラスとして再確認。ボラ・時代に偏りがあるという過去監査の注記も
  フェーズ2の年別内訳(2022年は大きくマイナス等)と整合。
- **未検証のまま**: 限月ロールの正確な接続日、板寄せの実約定コスト(フォワード台帳は
  過去・フェーズ2とも n=9のみで判定に使えるレベルではない)。
- **新しい手がかり(判定には未使用)**: 2024-11-05の引け時刻延長(15:15→15:45)以降だけを
  見るとコスト後ネットが+7.3bps(n=442、非有意)で改善している。オーナー指示によりこの
  「直近ほど改善している」仮説は新規単位として別途事前登録する。
