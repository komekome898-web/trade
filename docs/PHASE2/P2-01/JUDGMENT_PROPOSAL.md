## 2. 判定案

**棄却**。理由:
1. 仮説の核心「夜間は日中より高い」は、開発セット・封印期間の両方で CI がゼロを含み、費用と無関係に成立しない。
2. 「取引可能な形」も、保守コストでは CI がゼロを含み、丸めを 0 と置いても実務上の最小値に届かない。
3. 反証文 A・B の両方が成立している。

保留を選ばない理由: 保留の引き金(板寄せ執行差の実測)が最良の結果(丸め 0)を出しても、封印期間の MDE を下回るため判定が変わらない。
