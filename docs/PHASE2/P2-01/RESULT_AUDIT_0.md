## 個別判定

- 分母・除外段階: 再現(誤プリント3件・四半期159件・端点規則n=3,240は完全一致)。月次ロールのみ数値差異(結論維持)。
- 主指標1(保守コスト後平均ネット): 再現。両者とも負でCIがゼロを含まない → 「保守コストで夜間プレミアムは消える」で一致。
- 主指標2(夜間−日中): 再現。両者ともCIがゼロを跨ぎ有意でない。
- グロス・帰無95点・対照3: 再現。
- 整列検証: 再現(20円/110円が完全一致、監査3の取引日慣行の結論を支持)。
- 着手前の関門(グロス14.9bps必要): 両者ともグロス平均(4.93〜4.94bps)が大幅未達 → 関門不通過で一致。

**総合判定: 数値差異(結論維持)**(月次ロール件数とCI境界の一部が10%バンド外だが、結論(保守コスト後は
夜間プレミアムが消え、夜間−日中差は非有意、着手前関門も不通過)はどの副指標でも変わらない)。

## 実装者の申告した逸脱(n 2,768 vs 2,769)の検証

RUN.json の `n_at_each_step` は roll_adjacent_monthly=471(PREREG一致)、その内側に誤プリント2件、
ロール集合外に残る誤プリント1件、よって n=2,769−1=2,768。この算出過程はRESULTS.md §7で開示されており、
恣意的な後出し変更ではなく事前登録の2つの記述(「分母n=2,769」と「判定は誤プリント除外後」)が両立しない
ことの機械的な帰結。**問題なし**。
