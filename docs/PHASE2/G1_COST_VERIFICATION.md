  (「約定1枚あたり手数料(**税込**)」列)。**別業者の裏取り** = 松井証券の 2023-08-04 告知「10円(**税込11円**)
  へ引き下げ」と同社先物トップ「約定1枚当たり税込11円」。→ 11 円/片側は正しい。

- **抜けている費用があるか**: 上記 2 社のページに、顧客へ別建てで課される取引所手数料や
  SQ 最終決済手数料の記載は無い(先物欄は立会手数料と J-NET 手数料のみ)。SQ 決済は本戦略に無関係

  **404** で確認できず → 残る不確実性(小)。丸めは「1 ティック/片側」の事前登録どおり。
- **CSV の実装確認**: `p2_01_run.py` は `notional = close_t × 10`、`cost_bps_cons = 122 / notional × 1e4`。
  `pairs.csv` 3,240 行すべてで手計算との最大差 **1.8e-15**(楽観側 22 円も同様)。
  手検算 5 ペア(原系列 `day_session_daily` の close と一致):

## 3. P2-03(TOPIX / JPX400 / グロース250 の ETF)

- **帯の参照は close(t)**: `analyze_series` は各ペアの date_t・close_t から `band_price_t` を作り、
  そこから呼値と bps を出す。実データでも `band_price_t` は close(t)(1306 は ×10)と一致。
- **1306 の ×10 補正の範囲**: `pairs_1306T.csv` で `band_price_t / close_t` は 2015-01-05〜2026-03-31 の行で
  **ちょうど 10.0**、それ以外の行で **1.0**。窓外への漏れ無し。境界の妥当性: 2014-12-30 の生値 1,442 円に対し
  2015-01-05 の補正値 1,433 円 — 連続しており ×10 が正しい。リターンは反復 0 と**完全一致**(補正は価格のみ)。
  一次資料(野村 AM 適時開示 2026-02-17、分割効力 2026-04-01)と独立ソース(Yahoo Japan の 2022-03-04
  生終値 1,920.5 円 vs CSV 192.05)も MD5 照合込みで確認。
- **手検算(各系列 5 ペア、原 CSV の close と照合)**: 全系列で `cost = 2 × 呼値 / band_price × 1e4` と
  CSV の差の最大は 7e-15、帯判定の不一致 0 件。例: 1306 2016-11-16 生 145.4 → 補正 1,454 円・呼値 1 円 → 13.7552;

- **帯またぎ**: 1321 は開発セットで 1 / 5 / 10 円の 3 帯にまたがり、**ペアごと**に切り替わる(9,900 → 1 円、
  10,040 → 5 円、29,900 → 5 円、30,250 → 10 円 = 呼値表の「以下」規則どおり)。切替 33 回は
