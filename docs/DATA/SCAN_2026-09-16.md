**spot と CFD は同じ商品か(監査 2 巡目の指摘 10、リードが実測)**:
- TradingView の `symbols/FXBTCJPY/?exchange=BITFLYER` は HTTP 200、題名 "FX Bitcoin / Yen Price Today — FXBTCJPY Chart"。本文に `cfd` の語は無い(CSS のハッシュに含まれる `cfd` 1 件を除く)。TradingView の分類 "spot" は同社の型分類であり、商品の法的な区分ではない(**推定**)。
- bitFlyer の公開 API `https://api.bitflyer.com/v1/getmarkets` は HTTP 200 で `{"product_code":"FX_BTC_JPY","market_type":"FX"}` を返した(**事実**。生ログ末尾に応答の全文 435 バイトを保存。先頭 200 文字の記録には写っていなかったため、監査 3 巡目の指摘で全文を足した)。
- TradingView の `BITFLYER:FXBTCJPY`("FX Bitcoin / Yen")と bitFlyer の `FX_BTC_JPY`(market_type "FX")は、名称と取引所が一致する。**同一商品と読む(推定)**。TradingView が bitFlyer のどの配信を元にしているかを示す一次資料は見つけていないので、事実には上げない。照合用途(候補 5)は、この推定が外れても「別商品だった」と分かるだけで害が無いので、候補として残す。

- TradingView の公開シンボル検索 `symbol-search.tradingview.com/symbol_search/v3/?text=FXBTCJPY` は HTTP 200 で、

  MCP の `get_ohlcv` が受ける形式は "EXCHANGE:TICKER" なので、`BITFLYER:FXBTCJPY` を渡せば取れると読める(**推定**。MCP の銘柄集合が本体と同じかは、有料プランで実際にツールを呼ぶまで未確認)。
