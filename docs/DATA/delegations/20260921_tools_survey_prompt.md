## 5. 到達・導入・実行の規則(甘えを無くす)

3. 入れられない(鍵・地域・容量・依存の衝突)ときは何で止まったかを書き、1 の手段を替えて続ける。
4. **最小の実行は「読み込めた」で終わらせない。**種別の中核を 1 回動かす: バックテスト系 = 合成のティック列で成行と**指値**の 1 往復を通し損益を出す / 執行系 = paper か dry-run の接続を鍵なしで試す(鍵の要る操作は「鍵が要る」と記録して止める)/ データ系 = 小さい標本 1 件(数 KB〜数百 KB)を取り形式を確かめる / 研究・検証系 = 合成データで代表的な関数 1 つ / 監視系 = 合成の 1 件を表示か通知の dry-run / LLM 系 = 鍵なしで動く範囲(構造・入力の形)まで。**当方の実データ・鍵・記録(`data/` `paper_logs/` `.env` `config/*.yaml` の秘密)は使わない。**合成データだけ。
