## 3. 回し方(Workflow)
1. 項目 0 を「作る → 批評 → 盲検」の周回で先に仕上げる。
2. 項目 1〜12 を並列で回す。各項目: 比較資料を作る(名前を伏せる)→ 作る → 批評 → 盲検 3 体 → 未達なら指摘を渡して作り直す。
3. 項目 13 を同じ周回で回す。最後に「欠けているものは何か」の批評家 1 体。出たものは新しい項目として同じ周回に入れる。

**完了の条件**: 1 項目の完了 = 圧倒の判定(§0 の最後の 2 行)を満たした、または周回の上限か同じ未達理由 3 周で「未達」として止めた(未達は理由つきで報告する。完了と書かない)。全体の完了 = 項目 0〜13 がすべて完了 + 「欠けているもの」の批評家が新しい項目を 0 件返した + `PYTHONPATH=src python -m pytest` が全件通る。**作業者 1 体の完了 = §5 の報告を返したとき。**

**批評家**: 要件の表と調査結果の該当行を手元に置き、**自分で試験を書いて壊しにいく**。出力は [止める] / [直す] / [示唆] つきの指摘と根拠(ファイル:行 か 実行したコマンドと出力)。「良さそう」で通さない。

**盲検の審査員**: 甲・乙・丙の 3 つの資料(新実装 / 当方の現状 / 調査結果の最良の機構。**どれがどれかは知らされない。並び順は審査員ごとに変える**)を、信頼性と再現性の観点で比べて順位をつけ、理由と 1 位以外に足りないものを書く。資料を作る者は、道具の名前・パス・当方の語彙を消す。
