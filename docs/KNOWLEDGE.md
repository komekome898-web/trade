## 1. コスト実測(FX_BTC_JPY / Crypto CFD)

- 手数料は taker/maker とも **0%**。コストは実質「半スプレッド + スリッページ2bps」だけ (`config/products.yaml`, `docs/NOTE_CRYPTO_CFD_2026-08-20.md`)
- **taker 片道 ≒ 3.2bps**(半スプレッド1.18 + スリッページ2.0)、**往復 6.35bps** (e)
- **バースト時は 3.96bps**(1.96+2.0)、平穏時は 2.93bps(0.93+2.0)— **スプレッドはバースト時に約2倍** (i)
- 板記録での実測スプレッド 1.56〜2.22bps(mid比)は、30秒以下の全条件付きドリフトを上回る (f, g)
- maker 建ては手数料もスプレッドも払わないが、**逆選択で6〜9bps失う**(§2)。3つの独立研究で実測 (i, j, k)

## 2. 市場構造の法則

- **コストの壁** — 単一銘柄テクニカル(ema_cross / rsi_reversion / breakout、全時間足・パラメータ探索込み)は例外なくコスト未満。損失 ≒ 取引回数 × 往復コスト (BT, b)
- **消えた遅れ** — 分単位のリード・ラグは高流動性市場では裁定済み。薄いXRP_JPY は lag1 +0.176 だが厚い FX_BTC_JPY は **+0.019**(同時相関+0.878)。**コストが低い場所に遅れはなく、遅れがある場所はコストが高い** (b, c)
- **秒単位にだけ遅れが残る** — 1秒足では lag1 +0.11〜0.25、吸収に1〜2秒。ただし通常規模のイベントではコストに負け、閾値20bps級の激変時のみプラス (e)
- **予測可能な脚は取引不能な側** — ベーシス乖離を閉じるのは遅行する現物側であり、CFD自身は同方向にドリフトする。効率性は一貫した論理で貫かれている (f)
- **逆選択の壁・シグナル文脈の顔** — シグナル発火文脈では逆選択は約定率の低下として現れない。発火直後の成行フローは逆側指値を中央値1.6秒で**96%約定**させ、約定群はその後もシグナル方向へ 5分4.5bps・240分14.9bps 走り続ける。**約定の速さと確実さは優位性ではなく逆選択の強度そのものである**。また符号反転で移せるのはグロスのみで、コストと逆選択は反転しない(champion 反転の全11執行型で最良 +0.018%/取引 = バーの1/8.2) (x)
- **バースト面の法則(全面地図、約1,190セル)** — バーストは面のほぼ全域で**平均として継続**する(無条件の反転領域は900セル中3・全て非有意)。thr に単調、**地平600〜1800秒で最大化**(S9 の30分タッチと S10 の120秒地平は面の谷側の点だった)。中央値はほぼ全域ゼロ近傍 = 平均は右裾駆動。素の面でコスト線(往復7.92bps)を超える78セルの全量は**窓重複の幻**(非重複標本で +9.40→+1.46bps)。正直な標本で線の上に出るのは**時計窓内×エピソード先頭×20bps/30–60s×30分保有の交点のみ**(+23.71bps コスト前、CI [+7.92,+37.27]、n=40、1.44回/日)— 既知3法則(h時計・k継続・e閾値階段)の交点であり新法則ではない → S12 として係属登録。**旧「taker族はコスト線の下」(v,x)はこの交点についてのみ反証**。「雪崩は120秒で戻す」(x)は**TP約定群の選択後の性質**であり無条件には成立しない(訂正)。maker反転は逆選択の壁の第4の独立実測(約定群 全地平負/取り逃し群 正、差最大+32bps)で機構水準で閉鎖 (y)
- **リーダー追随族の死亡診断(機構水準)** — 1分スケールにリード・ラグは存在しない(同時相関+0.890、lag1 +0.016)= 分スケールの「Binance追随」は自己モメンタムと同一機構。210日で全25セル×5地平のドリフト −0.06〜+0.09% < コスト床0.079%、n≥400セルの taker 線超え **0.0%**(面の正領域は n が2桁の測定不能領域と一致、corr=−0.568)。出口では救えない: 必要勝負比5.55 対 実現2.29(n=898)、ストップ有無・時間切れとも210日全セル負。レジームが変えるのは**頻度だけ**(嵐日27.5倍)— 発火条件付きドリフトは嵐日でも悪くない。採用時 +0.19%(n=15)は同一分布の中央値的標本(P=0.52) (y)
- **逆選択の壁** — 指値は「価格が突き抜ける瞬間」にだけ約定する。逆張りでは敵(レンジ逆張り: 約定は置いた指値の0.86%のみ、約定後平均−6.5bps逆行 / アンカー乖離: 約定群+0.34 vs 取り逃し群+6.50、差6.2bps / スキャルパー: 差9.3bps)、順張りの出口では味方(TP指値は勝ちトレードを選んで約定、選択効果+33bps)。1分足スケールでも再現し**+88bps**と更に大きい(トーナメントC1)。**いずれもシグナルの符号は変えられない** (i, j, k, T)
- **レンジ端タッチは順張りイベント** — 穏やか相場の23,642件のバリアレースで **10bps戻り31.7% vs 10bps突破61.4%**。「ブレイクはフェードに勝る」 (k)。**レジーム条件付けでも生存**: vr下位四分位(深部静穏、duty 25%)は戻りを+6〜7pp動かすが最良でも34.5% vs 61.1% — コイントスにすら届かない (o)。**市場横断で生存**: USD/JPY 3.5年・コスト1/9でも非重複レース戻り40% vs BTC 34% — BTCの性質ではなく価格の性質 (s)
- **嵐は時計に支配される** — 予兆13仮説のうち合格は **UTC 12:30–15:00(米セッション開始帯)のみ**(リフト2.23・再現率0.33・n=234、月次1.84〜4.05で安定)。IV・OI・フローは時計の情報を超えず、DVOLを重ねるとリフトは**下がる** (h)
- **嵐の方向は事前予測不能** — 上下は49.3/50.7%で無偏。定義窓の内側を読むと「予測」に見えるのはトートロジーで、31分前読みではコイントスに崩壊 (i)
- **出口チューニングの限界** — 曲面に尾根はなく、fallback軸は隣接ステップで符号反転するノイズ。適応型TP(ボラ/シグナル強度/出来高連動)は定数の大TPと有意差なし=「特徴量に応じたTP」ではなく単に「大きいTP」を発見していただけ (k, l)
- **時計窓はタッチ継続を増幅する** — 30分極値タッチ後の順方向ドリフトは時計窓内 +6.81bps@30分 vs 全日 +1.15bps(n=821/7,157、bitFlyer 30日足)— レンジ端継続則(k)と嵐時計則(h)の**相互作用**の初の直接測定であり C2 の機構的裏付け。ただし平均は右裾駆動(中央値タッチはフェード側)で、往復taker 7.92bps に届かない — 候補はコスト線の下 (v)
- **確率面の法則(3,008セル)** — 「条件成立時に高確率で X 動く」は**規模については成立し、方向については成立しない**。規模は条件で1〜2桁動く(バースト直後 lift 245、低ボラ lift 0.03、時計窓 lift 2.2〜8.8 = 報告 h の 2.23 の X・T 分解)が、方向は推定可能な n(n_dec≥5000)で全特徴 lift 0.93〜1.16 に潰れる(唯一の例外「週末」lift 1.30 は週末8日の正味ドリフト −73.7bps/日 の記憶)。**必要p線(0.5+コスト/2X)を通り、かつ正直な1試行EVも正になるセルは面全体で0** — 線を通る253セルは偶然期待204とほぼ同数で、確率が高いセルほど決着が稀(勝率74.7%のセルの決着率0.65% → EV −7.8bps)。**確率の高さと稀さは同じもの**。X が小さいほど必要pは遠のく(X=10 で 89.6%)ため「小さく速く当てる」経路は算術で閉じている。規模予測の用途は**ゲートのみ**: 水準はレジーム依存(月次19〜80%)で再現せず、**順序だけが210日で不変**(rv60 T3−T1 は差が測れる全セルで符号反転0回)。ゲート診断: 時計窓ゲートは両族で正(+13〜18bps)= S12 の独立再現、**S7両側フロー窓は taker 順張りのゲートにはならない**(非重複 −4.85bps — あれは maker のレジームであって方向情報ではない)、バースト直後2分は長地平順張りの除外ゲート候補(n=11、診断水準) (z)
- **JFSA市場の効率ギャップ地図(11ベニュー/ペア実測)** — コスト床(taker往復)は Coincheck BTC 5.4 / GMO取引所レバ 5.6 / bitFlyer CFD 5.8 bps で最下位3所が拮抗、手数料を取る所は14.7〜51.9bps。**手数料とスプレッドは代替物**(相関+0.41)だが総コストは非保存(手数料所の床は2.5〜4.5倍)。**bitFlyer CFD が円市場の価格発見側**(全6ベニューに先行)で、「消えた遅れ」則を6ベニュー同時計測で直接確認 — ラグが残る薄い所は床24〜52bpsがそれを食う。**GMO 取引所レバレッジ BTC_JPY は bitFlyer CFD のほぼ同等品**(f 48.6% vs 43.5%、makerネット −0.60 vs −0.67)で、carry は JST06:00 跨ぎのみ = 日中フラット族はゼロ(bitFlyer は8h毎3回、13:00 UTC は S12 窓内)。GMO Public REST の実効スロットル ≈1req/s(実測) (ac)
- **時間による出口緩和は taker の別名(短スケール限定)** — 5秒スケールでは緩和指値は既に突き抜けられた価格 = 実質 taker 執行で、損失は緩和(T1)に集中(−7〜−15bps/回) (ad)。**40分スケールでは再現しない**(緩和の92〜97%は maker 約定 — 中心が市場から遠く置き直しが突き抜けない)が、逆行の**値幅そのもの**で同等を失う(−10〜−29bps/unit)。精密形: 「時間トリガの片側譲歩は、短スケールでは手数料で・長スケールでは値幅で、同じものを払う」 (ad, ae)
- **日足トレンドフィルタは「時定数より速いクラッシュ」を避けられない** — BTC 15年でSMA/TSMOM 6セルのmaxDD床は−70〜−82%(2013年の89日クラッシュが刺さる)。フィルタが避けられるのは遅いベア(2014/2018/2022の数百日型)だけで、maxDD比率バー(≤0.6×B&H)には構造的に届かない。また**BTCトレンドプレミアはサイクル毎に単調減衰**(超過CAGR +100.6→+19.6→−5.7→−27.7pp)し、**2023年以降は6セル全てがCAGRでB&Hに劣後** — ETF化以降のレジームでプレミア消滅と整合 (ai)
- **エッジ×レイテンシ曲線とWS化ラインの閉鎖** — バースト追随のエッジは「最初の0.2秒」に集中(傾き ≈ −1bps/100ms)。**低閾値セルは λ=0 でも開かない**(thr5 −1.6、thr10 −0.03 — 階段の下段は発火時2倍スプレッドが食う)。到達可能λはクラウド東京で推定40〜70ms(VM実測: WS受信p50 61ms・判断7µs・REST最小46ms)と**ハードは第23報の再開条件を満たすが、経済が閉じる**: 長期頻度0.84回/日×板厚上限0.02BTC で、最良シナリオ+27円/日 vs サーバ費33〜50円/日 — **費用線と統計的に区別できない**(正セルのCIは全て0を含む)。S10 再開条件は経済側で恒久閉鎖。副産物: **ticker刻印は板更新より約0.2秒遅い** / **自宅PC時計は0.44秒以上遅れ週内0.8秒ドリフト(NTP同期必須、既存board_top5はサブ秒用途不可)** (ah)
- **maker往復の閉じ脚のはさみ撃ち(maker線閉鎖の機構)** — 対称MMの対約定は速い(p50 7〜15秒、maker閉率99.8%)が、第1脚の約定は逆行の開始点を選び、脚間にmidが−3.2〜−3.6bps動く。閉じ脚を**追従**させればそのドリフトを実現価格として確定し(SM: capture×2 = +2.2 < ドリフト3.3)、**待たせれば**逆行の尾を在庫で受ける(M3/M4: 床−2.2)。両極が実測で負 → S7理想天井(+0.38〜0.76/脚、f=100%・追従も待機もしない仮想機)は実装可能などの執行でも到達不能。**「capture×2 > 脚間逆行」が成らない限り対称MMは成立しない** (ag)
- **在庫型片側ミーンリバージョンの床は −2.2bps/unit 近傍** — 按分・TP幅・段数(1〜10)・グリッド間隔(等間隔/逓増)・嵐オーバーレイの5軸×210日(51セル)で 0.66bps しか動かない。按分除去は勝ちのk比例性を完全回復するが負け尾が同率で膨らみ EV 不変。段数は単価を0.15bps未満しか動かさず notional/maxDD をほぼ線形に増やす(集計は N=1 が5倍優位)。逓増間隔は maxDD −41% だが単価劣化 = **幾何はDD制御装置であって単価装置ではない**。細粒度水準も実測バイアス補正後 ≤0(最良 −0.005) (af)
- **v37 レンジ上限ゲートは嵐フィルタ** — 40分実体レンジ ≤82bps の凍結ゲートが嵐分の99.9%を排除(嵐中の40分レンジ中央値145bps vs 平常35bps)。嵐回避オーバーレイはこの族に構造的に空振りし、嵐前在庫の最悪時 taker 撤退だけを足して悪化させる (af)
- **嵐後2〜6hは maker 回転に最も優しいレジーム** — 嵐終了後 ≤2h のエントリは平常比 **+1.2bps/unit**、210日近似と細粒度週の両方で再現(診断水準・事後観察)。ただし単独では床を越えない(到達 −1.7)。対称族のゲート候補 (af)
- **candle近似の手法バイアス実測 +1.27bps/unit(悲観)** — 高安タッチ=全約定の参加率過大による。窓差と混同しないこと(第30報の2.2は手法+窓の混合) (af)
- **按分TPは勝ち固定装置** — TP幅を在庫数で割る「収益平滑化」は、往復粗利を 0.8×vola に**在庫段数と無関係に固定**する恒等式(実測 width×k の中央値 0.80〜1.05×vola で一定)。損失は k 単位全部に乗るため、勝ち90.5%×+5.3 に対し負け9.5%×−85.7(平均k 5.0)。勝ち幅は在庫リスクに比例させなければならない (ae)
- **在庫平均化は1単位を救うが集計を悪化させる** — グリッド平均化の寄与は実測 +2.4〜+3.5bps/unit と実在するが、ゼロに届かず(残 −2.3〜−3.4)、notional 1.7倍の代償で集計損失は拡大。片側の在庫では閉じない — 対称族は反対側 capture の獲得(両側同時性)で稼ぐしかない(u §6.7 と一致) (ad)
- **壁板は吸収体ではない** — M24比10倍超の「壁」の63〜65%は10秒以内に取引で説明できない形で消える(引かれる)。10秒生存は13%、フローが到達しても約半分は突き抜ける。壁を障壁・支持線として扱う仮説すべての事前分布 (ab)
- **f(fill率)の実測と支配軸** — 実板7日で queue-realistic/追い越し取消/寿命10秒の f = 18.1%(両側窓内 23.0%)。f を支配するのは**滞在時間**: 取消方針 4.33x > スプレッド 2.04x > 寿命 1.63x > レジーム 1.31x > 約定モデル 1.22x > vr 1.08x。実現クオート寿命は中央値1.0秒(ベストは約1秒毎に動く)。広いスプレッドは到達を減らすのではなく取消を増やす。S8 §6.5 の 52/47/41% は同一5.6時間で再現した上で7日では12pp低い(朝の上振れ) (aa)
- **capture と f は同じつまみの両端** — 約定するクオートの capture は名目半スプレッドの約半分(+0.60bps)。全額(+1.07bps)取れる執行(ベスト不離脱のみ)は f 8.7%。**両端のどこでも単発クオートの capture+adverse(5s) は負**(−0.09〜−0.86bps)。両側フロー窓が買うのは**行列(f +5.38pp)であって単価ではない**(cap+adv の窓内外差は測定不能)。窓外の逆選択倍増(S7)は実板クオート単位では再現せず(飽和 1.02、陰性記録)。→ maker 戦略の可否は「反対脚が逆選択に食われる前に約定するか」(往復の閉じ速度)に帰着 (aa)

## 5. 検証済みの実務決定

- **スキャルパー出口 E2**(TP指値+10bps / 120秒で taker フォールバック)を採用。エッジ採用ではなく**分散改善**(中央値・勝率・sd・損失有界性で旧E0を支配)。ペーパー30イベントのカウントは切替時点から再スタート (k, l)
- **メインBOTの戦略切替もカウント再スタート** — `config/config.yaml: strategy.name` の変更(例 `xborder_momentum` → `composite`)は E2 と同じ先例に従い、ペーパー**30取引のカウントを切替時点から数え直す**(切替前後の取引を混ぜて基準を判定しない)。なお `data/overlay_state.json` は戦略に依らず蓄積されるため、リスクオーバーレイのブレーキは切替直後の1ティック目から有効になる
- **武装閾値の撤回** — `run_scalp_paper.py --thr-armed-bps` 既定を 8→10 に戻す。レーダーの武装状態はJSONL記録を継続し「同一閾値での窓内 vs 窓外」を検証 (i)
- **メインBOT出口は現行維持** — 54構成監査で事前登録の変更条件を満たさず。バックテストエンジンに決済理由(signal / stop_loss / take_profit / time_exit)を恒久記録。現行は実データの約2割が0.5%保護損切りで終了し、時間切れ(240本)は一度も発火していない (k)
- 事前登録の採用基準:
