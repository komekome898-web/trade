# 文書索引

文書は4種類に分かれる。新しい文書を作る前にどの種類か決め、既存の対応文書に追記できないか先に確認する。

## 状態(いま何がどうなっているか。更新され続ける)
- `docs/OWNER_STATUS.md` — オーナー側の状態板(単一の真実)
- `docs/DATA.md` — データ登録簿(何を持っている/どこにあるか)
- `docs/DATA_CONSUMPTION_LOG.md` — 何を見て何を選んだか(選択に消費 vs 未消費)
- `docs/NEGATIVE_FACTS.md` — 否定的事実(賞味期限つき)

## 記録(起きたことの履歴。追記のみ・削除禁止)
- `docs/OWNER_LOG.md` — オーナー報告の記録(L-番号)
- `docs/INCIDENTS.md` — インシデント(I-番号)
- `docs/DISCUSSIONS/` — 議論の記録
- `docs/DATA/probes/` — 調達調査のプローブ生ログ
- `docs/DATA/SCAN_<date>.md` — 市場・環境調査(scan)の出力

## 手順(やり方。どうやるかを定義する)
- `docs/OWNER_PROCEDURES.md` — オーナー側の手順(P番号)
- `docs/OPERATIONS.md` — 運用手順
- `docs/DELEGATION.md` — 委任表
- `.claude/skills/` — 各skill(`research-squad`・`research-protocol`・`delegated-study`・`owner-procedure`・`tournament`)

## 結果(検証・研究の成果物)
- `docs/PHASE2/` — フェーズ2の事前登録・結果(`K1/`・`EXEC/` 等)
- `docs/STRATEGY_IDEAS.md` — 戦略案(判定なし)
- `docs/legacy/` — 過去の手本(例: `KATSUO_INTENT_MAP.md`)
