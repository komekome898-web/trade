## 1. fill率 f の実測 — f を支配するのは「自分の価格に何秒いられるか」

queue-realistic / 追い越し取消(C1)/ 寿命10秒で **f = 18.1%(全体)/ 23.0%(両側窓内)**。
単軸レンジ: **取消方針 4.33x > スプレッド状態 2.04x > 寿命 1.63x > レジーム 1.31x >
約定モデル 1.22x > vr 1.08x**。実現クオート寿命は**中央値 1.01秒**(ベストは約1秒毎に動く)。
取消をやめるとスプレッド間の f 差はほぼ消える(1.13x)— 広いスプレッドは到達を減らすの
ではなく**ベストを速く動かして自分を追い越す**。交差面の最良は窓内×時計内×狭スプレッドで
43.5%(n=124)、最悪は全外×広で 11.0%。

**S8 §6.5 の 52/47/41% は同一暦区間(5.6時間)で完全再現した上で、7日に伸ばすと
12pp 下がる** — あれは「ある朝」の値であって板の性質ではなかった。副産物として
S8 の queue 定義に入れ子性違反(突き抜けクローズ欠落)があったことを特定・補正済み。

## 2. capture と f のトレードオフ則(新しい機構)

実際に約定するクオートの capture は名目半スプレッド(1.11bps)の**約半分**(+0.60bps)
しかない — 約定は「mid が既に自分の側へ動いた瞬間」に選択的に起きる。
半スプレッド全額(+1.07bps)を取れるのは「ベストが一度も離れなかったクオート」(C2)
だけで、その f は 8.7%。**capture と f は同じつまみの両端であり、両端のどこでも
capture+adverse(5s) は負である**(−0.09〜−0.86bps)。
