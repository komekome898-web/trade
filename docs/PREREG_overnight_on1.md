# PREREG — ON1: 日経225先物オーバーナイト効果の先物セッション実測判定

**凍結日: 2026-08-28。以降の変更は「事前登録の破棄」。**
**本文書は、先物データでのオーバーナイト統計を一切計算する前に凍結した**
(実施済みはデータQCのみ: OHLC整合・現物終値との水準照合・1分足との再構成一致・欠損走査)。

## 0. 位置づけ

- 候補は `SURVEY_JP_INDEX_FUTURES.md` の机上調査で、**現物指数(^N225)** 上で
  約8系統の構造効果から唯一生き残ったもの(現物実測: 2016-26 +11.3%/年 t=+3.2、
  1990-2015 +8.5%/年 t=+4.7、日中はゼロ〜負。リード追試済み)。
- **最大の帰無仮説(未検証)**: 現物の「引け→翌寄りギャップ」は、先物では
  ナイトセッション中に連続的に価格形成されており、**取引可能なセッション区切り
  (日中引け15:45 → 翌日中寄り8:45)で測ると効果が縮む/消える**可能性。
- 本判定はこの帰無仮説ごと一発で決める。データはオーナーが 225Labo から取得した
  先物日足(日中セッション区切り、1990-2026)。スナップショット:
  `backtest_data/n225f_225labo_20260828/`(MD5SUMS つき、個人利用限定ライセンス)。

## 1. 判定セル(唯一・パラメータゼロ。変更・追加禁止)

- **毎営業日**: 日中クロージング・オークション(15:45)で買い →
  翌営業日の日中オープニング・オークション(8:45)で売り。フィルタなし、調整なし。
- リターン定義: `r_t = ln(day_open(t+1) / day_close(t))`(日中日足の open/close)。
- 判定窓: **1990-01-04 〜 2026-08-27 全部**(n≈9,037)。
- 執行はオークション(板寄せ)参加であり、スプレッド越えは発生しない。

## 2. コストモデル(凍結)

- 基準: 手数料 11円/枚/片道(マイクロ、kabu/松井/楽天横並び)
  ≈ **0.35bps/日 往復**(今日の想定元本 ¥664,350 基準)。
- 保守: 基準 + オークション不利約定の引当 1ティック往復(5円×往復/元本 ≈0.75bps)
  = **1.10bps/日 往復**。
- 両シナリオを bps 定数として全期間のリターン系列から控除する(円建て換算は
  近年サブセットで参考報告)。

## 3. 判定基準(凍結)

1. **① 機構(グロス)**: 全窓の平均 > 0 かつ **t ≥ 2.0**(素のt。確認として
   定常ブロック・ブートストラップ 平均ブロック10日・10,000回・seed 20260828 の
   95%CI 下限 > 0 も要求)。
2. **② 台地(時代安定)**: 4分割 [1990-1998][1999-2007][2008-2016][2017-2026] のうち
   **3つ以上で平均 > 0**、かつ **[2017-2026] が正**であること。
3. **③ コスト後**: 保守コスト(1.10bps/日)控除後の平均 > 0 かつ **t ≥ 1.5**。

## 4. 必須報告(選択には使わない)

現物^N225 との縮小率(先物ON平均 ÷ 現物ON平均、同一日付集合)/
ナイト分解 2007-26(夜間セッション本体 vs 15:45→17:00・6:00→8:45 の2ギャップ)/
年次表・曜日別/ B&H(終日保有)との比較表(年率・Sharpe・maxDD、
およびボラ一致レバレッジ換算)/ マイクロ実在期(2023-05-29〜)サブセット/
1分足によるオークション出来高の実在確認(8:45・15:45 の約定量)/
決定性(2回実行ハッシュ一致)・ルックアヘッド0の構造説明。

## 5. 多重性

- 候補は現物データ上の約8系統から選ばれた(他は全て |t|<2 で死亡 — 台帳は
  SURVEY_JP_INDEX_FUTURES.md §3)。本判定はセル1・自由パラメータ0。
- 時間方向の新鮮データは存在しない(選択に全期間の現物を見ている)。代替は
  (a) **楽器方向の新鮮性**(選択は現物、判定は取引可能な先物セッション価格)と
  (b) 通過時の2段目 = **フォワード・ペーパー追跡**(オーナー承認制)。

## 6. 読み方(先に決める)

| 結果 | 結論 |
|---|---|
| ①②③すべて通過 | オーナーへ提示: (i) B&H 比較の枠組み(素リターンで劣る場合、Sharpe/レバ換算をどう扱うか)の合意 → (ii) フォワード・ペーパー追跡の開始判断。**採用ではない** |
| ① or ② が落ちる | **現物のギャップはセッション境界のアーティファクトで、取引可能な形では存在しない** → 棄却(機構水準) |
| ③のみ落ちる | コスト律速として記録。格下げ通過はしない |

B&H 超えの採否基準は**意図的に事前登録しない** — それはオーナーの価値判断
(素リターン重視か、リスク調整重視か)であり、通過時に両方の数字を提示して決める。
