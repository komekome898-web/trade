## matilda(bitFlyer FX_BTC_JPY)

- `matilda_for_TaroCamp37.py`(2019-09-04、1分足)— オーナーが本来意図した系統。
  40分レンジ/ボラを毎分計算し、中心から `entry_setting×vola` 離れるとエントリを開始。
  厚い板の手前に指値を撒き、前の段から `vola×step_setting` 以上あけて段を追加。
  利確は**建値から** `vola×step_exit÷(積んだ段数)`(按分)の幅。20分で中心まで緩和、40分で成行。
  レンジ幅の上下限ゲート、ブレイク時の順張り反転、SFD ガード。
  実装の細部は**原典を直接読むこと**(戦略の言語化は `docs/STRATEGY_IDEAS.md` O-1〜O-5)。
- `matilda_v52.py`(2020、5秒足)— 上記の後継。`vr = レンジ幅 ÷ ボラ` によるレンジ/トレンド判定
  (原典コメント「vr が大きくなれば一方的なトレンドって判断」)を追加。出荷設定では無効化されていた。

## katsuo_v03.py(BitMEX XBTUSD・15分足)

**ヒゲの「反発の強さ」を 4 通りに区別する機械**(オーナーの言語化 2026-09-08 + 原典 485-533 行で確認)。

シグナル条件は共通(485 行以降の分岐、166-186 行の判定):
**ヒゲ > 実体の絶対値 かつ ヒゲ > 反対側のヒゲ**。ヒゲは実体の端から測る(陽線なら上ヒゲ = 高値−終値、
陰線なら上ヒゲ = 高値−始値)。**強さの区別は「反対建玉をどうするか」で表現されている**:

| バー | 反発の強さ | 反対建玉があるとき | 建玉が無いとき |
|---|---|---|---|
| **上ヒゲ陰線** | **強**(突いて戻し、しかも陰転して終えた) | **ドテン**(`order_sell()` を無条件で呼ぶ) | 売り |
| **下ヒゲ陽線** | **強**(突いて戻し、しかも陽転して終えた) | **ドテン**(`order_buy()` を無条件で呼ぶ) | 買い |
| 上ヒゲ陽線 | 中(拒否されたが実体は陽線のまま) | **決済のみ**(`order_exit()`。ドテンしない) | 売り |
| 下ヒゲ陰線 | 中(拒否されたが実体は陰線のまま) | **決済のみ**(`order_exit()`。ドテンしない) | 買い |

- **ヒゲ先端 = 無効化ライン** (`lcprice`): シグナルの無い足では、終値がヒゲ先端を超えるまで逆行に耐え、
  超えたら決済する(507・529 行)。
- **増し玉**: ヒゲ先端までの**半値**に指値(308・345 行 `prize2`)。
- **出口ラダー**: reduce-only post-only 指値 → ストップ 2 段 → 成行。
- **原典の環境**: 足は `api.cryptowat.ch` の `bitmex/btcusd-perpetual-futures`(サービス終了)。
  `beardline = 19` / `bigbeardline = 24` は **2019 年の BitMEX の USD 建て絶対値**であり、現在は意味を持たない。
