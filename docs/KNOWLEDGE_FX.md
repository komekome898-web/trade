## 1. コスト実測(USD/JPY 基準)

- **往復コスト 0.71bps**(GMOコインFX API: スプレッド0.5銭=0.314bps + API手数料0.002%×2=0.4bps)[M+V] — **BTC CFDの約1/9**
- 変動/コスト比(平均|1分リターン|÷往復コスト): **0.94**(BTC CFDは0.39)— 分足シグナルがコストバーに届き得る初めての市場 (r)
- スプレッドは分布ではなく**床**(p10=p75=0.5銭、24時間中21時間フラット)。バーストでは広がらず、**時計で広がる**: UTC21(ロールオーバー)のみ6.33bps=20倍 [M]
- API手数料は指値にも注文変更にも課金 → **maker逃げ道なし**。products.yaml では per-fill 費用として符号化(maker/taker区分ではなく)
- 週末ギャップ: 中央値4.4bps(コストの6倍)、最大26.7bps [M] → **週末フラットが既定**
- スワップ: 6:00 JST境界・決済時実現・水木は3日分。目安0.6〜1.6bps/日 ≒ 往復コストの1〜2倍 [T] → オーバーナイト戦略はスワップ実測が先決
- OANDA証券APIはGold要件(月50万ドル取引継続+プロコース+25万円)が研究プロトコルと構造的に非両立、プロコースはスプレッド2倍 (r)

## 2. 市場構造の実測

- **ボラのピークは UTC 12:00–15:00**(0.68/0.79/0.82bps)— **BTCの嵐時計と同一の窓**。独立市場で同じ答え=米セッション支配は市場横断の法則 [M]
- 第2ピーク UTC0(東京仲値前後)。谷は UTC21(0.24bps、スプレッド20倍と重なり**二重に取引不能**)と東京昼
- **東京仲値(9:55 JST)は実在のボライベント**: 9:54に平常の3.2倍(1.92bps)、フィックス**前**にピーク+10:01-02に巻き戻しバンプ。スプレッドは据え置き=コスト不変でボラ3倍の窓 [M] — 検証候補筆頭
- **ゴトー日仲値は測定済みヌル**: n=28、方向も逆符号(t=−0.42)。再発見禁止。復活はDukascopy 2005〜(ゴトー日約1,000件)での事前登録検証のみ (r)
- **介入テール**(USD/JPY固有): MOF介入は一方向・無制限・数百bps/分。予測ではなく**テールルール**で守る(建玉上限+5分100bps超でkill)。日次詳細の公表は四半期後 [T/V]
- BOJ声明は**発表時刻自体が漂う**(11:30〜15:00 JST)— それ自体がボラ源 [T]
- FOMC 2026-27 確定日程は取得済み。BOJ MPM の確定日程は調査報告本文にあり(2023-25は訓練知識・要検証)(r)
- **日銀会合の値動きは 11:30〜13:30 JST に集中**(13:30以降のピークはゼロ、中央値ピーク25bps)[M] (s)

## 3. BTC研究からの転移事前分布(相乗・第1弾実測済み)

- **指標発表は確実に局所ボラを上げる**(BTCで発表後30分レンジ順位0.767、16/19日、p=0.002、プラセボ無効)が、固定%閾値ではほぼ検出不能 → **FXのイベント研究は連続レンジ指標で設計**(第18報の設計原則)
- NFP/CPIはBTC嵐を予告しない(日付シフト対照と区別不能)。FOMCのみ全対照生存(n=5、係属)
- 逆選択の壁・レンジ端=順張りイベント・出口チューニング限界などBTC§2の法則群は、コスト1/9の環境で**経済条件が変わる**ため機構ごと再検定対象(棄却の自動転移はしない)

## 4. 係属中の仮説と判定条件

- **イベント・ティックライブラリ**(本命)— Dukascopyティック2005〜で発表直後数秒の構造を検証(嵐ライブラリの為替版、数百イベントの検定力)。基準は設計時登録
- **オーバーナイト/キャリー系** — スワップ実測後に設計
- **GBP/JPY頑健性検査** — USD/JPY結果の再現確認用
- **スリッページ実測** — 最小100通貨(≒1.6万円、手数料0.32円/約定)のライブ微量実験が最安の測定手段。ライブ承認プロセスは BTC と同一(オーナー明示承認必須)
