## 2. 棄却の水準(§10)

**② は機構水準の死。** 主セルの maxDD −71.1% は 2013年4月の**89日クラッシュ**で発生
しており、B&H の maxDD(2013-12〜2015-01 の**406日ベア**、−84.9%)とは別の事象。
日足フィルタが避けられるのは「フィルタの時定数より遅いベア」だけで、
**時定数より速いクラッシュは原理的に避けられない**。実測の床は6セル全てで
−70.3〜−82.4%(最速のSMA100でも−70.3)。「0.6×」比率バーには構造的に届かない。

**③と直近レジームは傾向水準の死。** 超過CAGRはサイクル毎に単調減衰:
C1(2011-15)**+100.6pp** → C2 +19.6 → C3 −5.7 → **C4(2022-26)−27.7pp**。
2023年以降は**6セル中6セルが CAGR で B&H に劣後**(Sharpeも6中5劣後)。
単一セルの不運ではなく、プレミア自体の消滅と整合する形。

**① は実質ゼロ。** +2.4pp の余裕は: コストを0.40%/スイッチにすると**反転**、
主系列を Yahoo に替えると**反転**、窓を2016年以降に揃えると3ソースとも**同点**。
PASS は 2012〜2015 の一区間(BTC時価総額が1桁小さい時代)が全部を運んでいる。
