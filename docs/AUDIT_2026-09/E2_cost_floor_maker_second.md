## 3. L2 — キュー位置つき maker 約定モデル

モデル: エポック時刻に best bid/ask 両側へ 0.01BTC。キュー先行 = その時の表示サイズ。同値約定(taker が自側を叩く)の累積が
「先行+自量」を超えたら約定、値段を抜けた約定は即約定。**best が有利側へ改善したら失権 → 新 best へ出し直し(chase)**、不利側
へ動けば先行キュー消滅で先頭に立つ。先に約定した脚が建玉方向、その時刻に反対側へ同規則で決済。上限300s。naive = キュー無視。

### 分解の定義依存(重要)

net = capture + ドリフト は恒等式だが、capture をどこで測るかで両項の見かけが変わる(n=1,311、epoch30s/queue):

- A: capture を**約定時 mid** 基準 → capture **+0.445**、ドリフト **−1.961**、net −1.516(t=−21.5)
- B: capture を**発注時の半スプレッド**(claim 流)→ capture **+1.787**、含意ドリフト **−3.303**、net 同じ

claim の「capture×2 = +2.2、ドリフト −3.2〜−3.6」は **B の流儀**で再現する(−3.30 は帯の中)。ただし capture は +2.2 ではなく
**+1.79**(スプレッド2.22bps 前提の過大評価)。**ドリフトは独立の実測量ではなく capture 定義に従属する残差**である。

## 4. 対照・頑健性(Q2/Q4〜Q10)

- **プラセボ(Q2/Q8)**: 同じ保有時間・同じ符号で**ランダム時刻**に切り出した mid 変化 = +0.18bps(t=1.44, n=1,044)→ 0 と
  区別できない。ドリフト −1.9 は「約定した側」に条件付いた効果であり、トレンド/ボラのクラスタリングでは説明できない。
- **符号反転(Q2)**: 反転すると net +1.44(鏡像)。建玉符号をランダム化すると drift は消える方向へ動く。
- **状態条件付き(Q4)**: capture 三分位で net −2.25/−1.25/−0.81(広いほどマシだが常に負)、保有時間三分位で −0.36/−1.62/−2.33
  (長く持つほど悪化=時間はコスト)、約定速度三分位で −1.11/−1.31/−1.89。**レベルの主張として測定した**。
- **定義の副作用(Q5)**: 「先に約定した脚が建玉方向」という定義自体が負のドリフトを生む(=逆選択の本体)。両脚約定を仮定する
  対称MM会計なら +スプレッドになるが在庫を無視した誤り。300s内の maker 決済率 99.7%・強制 taker 決済 0件で打ち切りバイアス
  は実質なし。自量 0.01BTC 固定 — min_size 0.001 ならキュー通過はさらに速く、未検証。
- **データ健全性(Q6)**: 保守窓 19:00–19:10Z を除外しても中央スプレッド 1.912 で不変。交差/非整列板 551行(0.10%)、
  board_round 335行(0.13%)、|実効半スプレッド|>50bps の約定 69件を除外。60s超欠測 72件はエポック開始条件で自動除外。
- **探索汚染(Q7)**: 自由度はエポック(3)×モデル(2)×レジーム(4)。**全12セルが同符号・全て |t|>8**。帰無下の最良セルは
  プラセボ分布(平均+0.18、sd 2.6、n≈1,000)から ±0.22bps 程度で、−1.3〜−1.8 は探索では作れない。
- **一致性(Q9)**: スプレッド中央値は ticker 1.91 / board_top5(独立1sスナップ)2.02 / board_round 5s 1.78bps。31日約定
  ファイル(2026-07-23〜08-23、別期間)の1分足 BUY-VWAP−SELL-VWAP = 0.99bps(下限値)。5.8〜7.9bps を支持する独立測定は皆無。
- **反証文 + MDE(Q10)**: 「対称 maker 往復の net が 0 以上なら L2 は誤り」。n=1,114、sd=2.64bps の下で MDE(80%検出力)=
  **0.22 bps/unit** → +2.2bps(claim の capture×2)級の効果があれば 10σ で検出できたはずであり、**検出できないのではなく無い**。
  L1 側は n=750k 約定で往復コストの標準誤差は 0.01bps 未満 — 5.8bps との差は測定精度の問題ではない。

## 6. 判定

- **L1: 結論変更**(コスト床は 5.8〜7.9bps ではなく **1.9〜3.1bps**。CFD の手数料は 0)。
- **L2: 再現(数値差異、結論維持)**。ただし内訳のうち **逆選択 6〜9bps は結論変更**(実測 0.9bps 級)、capture は 19% 過大、
  ドリフト −3.2〜−3.6 は独立測定ではなく capture 定義に従属する残差。**キュー位置を入れても maker 線は閉じたまま**
  (naive より 0.3〜0.4bps 悪化、12セル全て有意に負)。
- **L3: 数値差異(結論維持)**(2.22 → 1.91〜2.02bps、14〜16% 過大)。

理由: maker 側の結論(対称スプレッドMM は全レジームで負)は自前のキューモデル・chase 規則・独立プラセボのいずれでも崩れず、
金額でも −18.9 JPY/往復と明確。一方 taker 側の床は、手数料 0 の商品に対し 3方法どれもが 2〜3bps を返す。**maker が閉じる理由は
「床が高いから」ではなく「約定が逆選択されるから」**であり、床を根拠にした taker 戦略の棄却は再検討が要る(2〜3倍のハードル)。
