## 2. 実際の中核 — 按分恒等式(第30報 ae §3.1 が測ったもの)

```
exit_vola = vola * step_exit * (sizemin / mybtc)        # 881
往復の粗利 = mybtc × exit_vola = vola * step_exit * sizemin   # k に依存しない定数
```
**段数が何段積まれても、1 往復で狙う円建て利益は `0.8 × vola × sizemin` で一定。**
一方、損失は k 単位すべてに乗る。原典の変更履歴 71 行目「ポジ数によって利確値幅を按分して、
決済時の収益性を平滑化」がこれ。**「収益性の平滑化」装置は、取ったリスクと無関係に勝ちを
固定する装置と同一物**であり、第30報(ae)が M3 の死因として測ったのはこの恒等式である。【事実】
