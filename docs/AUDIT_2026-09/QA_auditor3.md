## QA-1

主張: QA_BRAVO の close→翌 open が +2.1bps/日、t=7.2(2011-01-03〜2026-08-31、平日のみ)。

| 項目 | 主張 | 再計算 |
|---|---|---|
| 母集団 | 平日のみ | 4086 行 = 期待営業日数 4086、欠損 0、重複 0、OHLC 整合違反 0 |
| overnight 平均 | +2.1 bps | **+2.134 bps**(n=4085 pairs) |
| t 値 | 7.2 | **7.26**(se=0.294、20日ブロックブートストラップでも t=7.54) |

1. 分母: overnight ペア n=4085(行数-1)。日付の穴なし。|x|>5% の外れ値 0 件。
2. 対照: ランダム再ペアリング(open[t+1] を無作為な過去 close に接続、500 反復)は +1192 bps ±18 と全く別物 = 隣接性が本質。符号反転で -2.134 bps。中央値 +2.05 bps で平均に近く、少数外れ値由来ではない。陽性率 54.8%(n=4085)。
3. 金銭換算: グロス 2.134bps/日 × 252 = 538bps/年。往復執行コスト床は本パケットのテープ実測で 3.60bps(fee key `taker_fee_bps`=0.0、スプレッド 2.000bps、片道スリッページ 0.799bps)。日次で建て落ちすると **ネット -1.46bps/日 = -368bps/年**。統計的には実在するが、この費用帯では取れない。
4. レジーム: 年別平均は 16 年中 15 年が正(-0.59〜+3.69bps)。vol 三分位で +2.13/+3.07/+1.30bps と全て正。カレンダー間隔別では 1日ギャップ +1.93bps(n=3268)、週末・休日ギャップ +2.94bps(n=817) — セッション単位でなく**カレンダー時間比例のドリフト**。主張は水準(level)の主張で、水準として測った。
5. 定義の副作用: 「平日のみ」は生成側の性質で、除外による選択は起きていない(欠損日 0)。
6. データ健全性: 非正価格 0、重複 0、|x|>5% 0 件 → 妥当性フィルタ有無で数値不変(+2.134/t=7.26)。
7. 選択汚染: 自由パラメータなし(単一系列・単一ホライズン)。ただし 3 系列から 1 本選ぶ探索なら、帰無下の最大 t は 3 本で概ね |t|<2.4 程度であり、t=7.26 はそれを大きく超える。
8. 代替説明: 日中 open→close は -0.161bps(t=-0.09、n=4086)で、overnight のみに集中。ボラクラスタリング・価格水準・出来高では説明されない(vol 三分位で符号一定)。
9. 一致性: 独立系列 QA_CHARLIE も overnight +4.97bps(t=16.8、n=4085)と同符号。QA_ALPHA は -0.23bps(下記)。
10. 反証文: 「overnight 平均が 0 と区別できない(|t|<2)」なら棄却。n=4085・sd=18.79 での MDE(α=.05, 検出力80%)= **0.82bps**。主張の 2.1bps は十分検出圏内。

Verdict: 再現

## QA-2

7. 選択汚染: 自由パラメータなし。問題は探索ではなくクレンジング欠如。
8. 代替説明: 断裂 2 点の寄与だけで +2445.95bps(全平均 +2445.7bps のほぼ全量)。他の説明は不要。
9. 一致性: 同一生成系の BRAVO(+2.13、t=7.26)、CHARLIE(+4.97、t=16.8)は外れ値ゼロで安定。ALPHA だけが不安定 = 系列固有のデータ欠陥。ALPHA の日中 open→close も -1.03bps(t=-0.54)で、どの区間にもプレミアムはない。
10. 反証文: 「妥当性フィルタ後の overnight 平均が +3.5bps から有意に乖離」なら棄却 → クリーン後 -0.234bps、+3.5bps との差は 3.73bps で se=0.295 の 12.6σ。MDE(検出力80%)= 0.83bps なので、+3.5bps が実在すれば確実に検出できたはず。存在しない。

Verdict: 結論変更(オーバーナイト・プレミアムは存在しない。主張値は未調整の 1000 倍スケール断裂 2 日分の産物)

## QA-3

主張: qa_autocorr のリターン lag-1 自己相関が +0.051 で有意に正(60日、qa_randomwalk 対照)。

| 項目 | 主張 | 再計算 |
|---|---|---|
| lag-1 自己相関 | +0.051 | **+0.0506**(n=86,399 リターン) |
| 有意性 | 有意 | t=**14.87**(Bartlett se=0.00340)、95%CI [+0.0439, +0.0573] |
| 対照系列 | 差がある | randomwalk +0.0047(t=1.38、非有意) |

1. 分母: 86,400 本の 1 分足(2026-06-01 00:00〜2026-07-30 23:59 UTC)、60 日連続、60 秒以外の間隔 0 件、重複 0。log(close) 差分 n=86,399。open[t+1]==close[t] が 100% で、バー連結に隙間はない。
2. 対照: シャッフル 300 回で平均 +0.00013、sd 0.0035、|ac1| の 95 パーセンタイル 0.0066 → 実測 0.0506 は完全に外側。並列系列 randomwalk は 0.0047 で有意でない。符号反転は自己相関に対して不変(ac1 は偶関数)なので、代わりに lag-2/3/5 を確認: +0.0057/+0.0019/+0.0046 と lag-1 のみ突出 = AR(1) 型。
3. 金銭換算: リターン sd 8.98bps、含意されるトレード当たり期待エッジは ac1×sd = **0.455bps/取引**。往復コスト床 3.60bps(fee 0.0 + スプレッド 2.000 + スリッページ 0.799×2)。1440 取引/日でグロス 655bps/日に対し、コストは 5184bps/日。**符号は正・有意だが、この費用帯では取れない**。
4. レジーム: 時間帯別 ac1 は 0.0144〜0.0954(24 時間、各 n≈3600)と全時間帯で正。10 日ブロック 6 分割で 0.0403〜0.0609 と全区間正 = 水準として安定。
5. 定義の副作用: リターン定義を close→close から open→close に変えても ac1=0.0506 で不変。ゼロリターン率 0.69%、最長フラット連 10 本 — 平坦区間の埋め込みによる人工的な相関は限定的。
6. データ健全性: 欠測・重複・メンテ窓の痕跡なし(60 秒間隔 100%)。フィルタ有無で数値不変。
7. 選択汚染: 自由パラメータは lag のみ。lag 1..5 の 5 通り探索でも帰無下の最大 |ac| は約 2.6×0.0034=0.0088。実測 0.0506 はその 5.7 倍。
8. 代替説明: bid-ask バウンスなら負、ボラクラスタリングなら |r| の自己相関に出るが符号付きリターンには出ない。実測は符号付きで正 → 単純な代替では説明できない。
9. 一致性: 同一フォーマットの独立系列(randomwalk)で 0.0047 = 生成系の差を正しく検出。ブロック 6 分割でも一致。
10. 反証文: 「ac1 の 95%CI が 0 を含む」なら棄却 → CI 下限 +0.0439。MDE(n=86,399)= 1.96/√n = **0.0067**。

Verdict: 再現

## QA-4

主張: qa_randomwalk のリターン lag-1 自己相関が +0.04 で有意なモメンタムが存在する(60日)。

| 項目 | 主張 | 再計算 |

| lag-1 自己相関 | +0.04 | **+0.00468**(n=86,399) |
| 有意性 | 有意 | t=**1.38**、95%CI [**-0.0020, +0.0113**] = 0 を含む |

1. 分母: QA-3 と同一設計の 86,400 バー(60日、間隔 60 秒 100%、重複 0)、リターン n=86,399。
2. 対照: シャッフル 300 回の sd=0.0032、|ac1| の 95 パーセンタイル 0.0061 → 実測 0.0047 は帰無分布の内側。lag-2/3/5 は +0.0020/+0.0015/-0.0016 と構造なし。
3. 金銭換算: 含意エッジ = 0.0047×9.00bps = **0.042bps/取引**、往復コスト床 3.60bps の 1/86。仮に +0.04 が真でも 0.36bps/取引でコスト割れ。
4. レジーム: 10 日ブロック 6 分割で -0.0033〜+0.0157 と符号が安定せず、時間帯別も -0.0219〜+0.0341 で 0 をまたぐ。水準としても変化としても検出できない。

6. データ健全性: 欠測・重複なし。フィルタ有無で不変。

9. 一致性: 並列系列 qa_autocorr は同じ手法で 0.0506(t=14.9)を検出しており、**手法の検出力は実証済み**。同手法で randomwalk が出さない = 系列の性質差。
10. 反証文: 「ac1 の 95%CI が 0 を含む、または +0.04 と有意に異なる」なら棄却 → CI は 0 を含み、+0.04 との差は 0.0353 = 10.4σ。MDE = **0.0067** なので +0.04 は余裕で検出できる大きさ。**検出力不足ではなく効果の不在**。

Verdict: 結論変更(有意なモメンタムは存在しない。主張の +0.04 は実測の 8.5 倍)

## QA-6

主張: 実測スプレッドは 1.2bps に縮小しており(全 quote 行の単純平均、交差板・メンテ窓等の除外なし)、往復床は 2.8bps まで圧縮できる。

| 項目 | 主張 | 再計算 |
|---|---|---|
| 全 quote 行の単純平均スプレッド | 1.2 bps | **1.9951 bps**(n=51,732、除外なし) |
| 有効 quote のみ | — | **2.0000 bps**(n=51,669) |
| 往復床 | 2.8 bps | **3.594 bps**(全行平均採用時)/ 3.598bps(有効のみ) |

1. 分母: 主張が指定した通り、交差板を含む全 51,732 行の単純平均 = 1.9951bps。主張の 1.2bps は**この分母では再現しない**。
2. 対照: 交差 63 行のみの平均は -2.0000bps。これらが全行平均を押し下げる量は **わずか 0.0049bps**(2.0000 → 1.9951)。「除外しないから小さく出る」という主張の論理自体は方向は正しいが、大きさが 160 倍過大。
3. 金銭換算: 主張の 2.8bps と実測 3.594bps の差 0.79bps = 平均 mid 1,043,866 で **83 円/単位・往復**。往復コストを 22% 過小評価する。
4. レジーム: 有効スプレッドは p05〜p95 すべて 2.0000bps で「縮小」のトレンド自体が存在しない。3 日間を通じて定数。
5. 定義の副作用: 主張は「除外を行っていない」ことを縮小の根拠にしているが、実データでは除外の有無が結論を変えない(差 0.005bps)。
6. データ健全性: 交差板 63 行(0.12%)、メンテ窓(19:00-19:10 UTC)343 行だが交差率 0%、60 秒超ギャップ 0。妥当性フィルタ適用前後で 1.9951 vs 2.0000bps。
7. 選択汚染: 1.2bps が出る分母を逆算探索した。(a) (ask-bid)/mid 全行 = 1.9951、(b) (ask-bid)/ask 全行 = 1.9949、(c) |ask-bid|/mid 全行 = 2.0000、(d) サイズ加重 = 1.9951、(e) 平均スプレッド円÷平均 mid = 1.9951、(f) 有効のみ = 2.0000。**いずれも 1.2bps を生まない**(半スプレッド 0.998bps とも一致しない)。1.2bps を出す再現可能な計算手順を特定できなかった。
8. 代替説明: 価格水準の上昇(mid 100.0万→105.1万)でも bps スプレッドは定数のまま。スケール効果でも説明できない。
9. 一致性: QA-5 の独立集計(中央値 2.0000bps、p05/p95 2.0000bps)と矛盾。同一テープに対する 2 つの主張(QA-5: 2.0bps / QA-6: 1.2bps)は両立しない。
10. 反証文: 「全行単純平均スプレッドが 1.2bps から 0.2bps 超乖離」なら棄却 → 乖離 0.795bps。スプレッドの分散はほぼゼロ(p05=p95)なので、MDE は 0.001bps 未満。**測定誤差では説明不能**。

Verdict: 結論変更(スプレッドは 2.0bps のまま縮小しておらず、往復床は 3.6bps。2.8bps は使えない)
