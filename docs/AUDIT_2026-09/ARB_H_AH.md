## 争点1 — JPL6「夜間プレミアムのJPX市場横断法則」(引け→翌寄りが全指数ETFで正)

**両者の立場**: 第1=再現(11/11銘柄で夜間>0)。第3=判定不能(グロース250が自前MDE未満、株式ETF4本の相関0.74–0.93で実質1ファクター、1306の未記載バッドプリント)。

**当方の再計算**(分母=各銘柄の close_{t-1}→open_t 対数収益、バッドプリント除外後の全営業日):
N225(1321) +5.72bps t=3.40 n=3687 / TOPIX(1306) +5.33 t=3.43 n=3685 / JPX400(1591) +7.81 t=4.68 n=3103 /
グロース250(2516) +5.30 t=1.80 n=2109(両側p=0.071、MDE(α.05,検出力80%)=8.23bps > 実測5.30bps)/ J-REIT(1343) +5.13 t=4.68 n=3687。
夜間収益の相関は株式4本で0.74–0.94、J-REIT対株式は0.45–0.49。よって独立な観測単位は「日本株ファクター」と「J-REIT」の2系統。
・日本株ファクター(4ETFの日次等加重、全履歴)= **+6.37bps t=3.97 n=3688**(MDE=4.50bps < 実測 → 検出力十分)
・J-REIT 単独 = +5.13bps t=4.68 n=3687
・グロース250 の N225 に対する残差αは **+0.59bps t=0.33(β=0.99)** — 独立な追加証拠ではなく、同一ファクターをノイズの大きい器(sd 135 vs N225 sd 102)で測り直したものにすぎない。

**裁定: 数値差異(結論維持)**。市場横断の主張自体は堅い(2系統ともt≈4、符号反転対照も清潔)。第3の依拠する「最悪サブ図優先」は独立情報を持つサブ図に適用すべきで、
β=0.99・残差t=0.33 の冗長な器(グロース250)一本で市場全体の主張を判定不能に落とすと、ノイズの大きい銘柄を claim に足すほどクラスが機械的に劣化する不合理を生む。
他方で第1の「再現」も採れない — 文言「全てで正」は5独立市場の合意を含意するが実効独立数は2、列挙5本の1本は単独では0と区別できない。
claim は「日本株ファクターとJ-REITの2系統で夜間プレミアムが正、グロース250は符号一致・単独では判定不能」と書き換えて維持する。
**各者の当否**: 第1=数値・バッドプリント処理・符号は全て正しい(1306の異常値も検出済み)、breadth の過大評価が誤り。
第3=検出力と1ファクター構造の指摘は正しい(スナップショットREADMEの銘柄名重複・未記載バッドプリントの発見も有効)、
市場横断claimの評価単位を銘柄に取り違えた点が誤り。

## 争点2 — JPL7 / JPR8「薄いETF(1311 TOPIX Core30)夜間の約定アーティファクト仮説」(売買代金0.3億円/日)

**両者の立場**: 第1=数値差異(維持)(売買代金は0.05億で0.3ではない、方向は再現、「純アーティファクト」は言い過ぎ)。
第3=判定不能(機構は日足OHLCで確認不能、¥2,143に対する1円ティック=4.7bpsが効果の約半分)。

**当方の再計算**(1311.T, n=3688日):
・売買代金 = 出来高×終値。全履歴 **平均0.127億円/日・中央値0.051億円/日**、直近2年(2023-09-05以降 n=732)**平均0.300億円/日**・中央値0.196。
 claim の 0.3億円は「直近期間の平均」読みなら誤差0%、全履歴なら2.4倍(平均)/6倍(中央値)ずれる。claim が分母を明示していないことが争いの実体で、
 数値そのものは片方の分母で完全に再現する。
・方向(薄い⇒夜間大)は再現: 11銘柄横断 corr(ln売買代金, 夜間平均) = **−0.682**、国内原資産6銘柄では **−0.795**。1311 の +9.04bps t=5.61 は国内6本で最大。
・機構(アーティファクト)の直接検定:
 (i) 1311 と自身の主要構成銘柄(トヨタ/ソニー/三菱UFJ/ソフトバンクG)等加重夜間の**対応差** = **+1.85bps t=1.32 n=3688(有意でない)**、相関0.759。
  第1が「+26%超過(t=3.34)」としたが、その t=3.34 は構成銘柄側の平均のtであり、超過分のtではない — **超過は0と区別できない**。
 (ii) corr(ln売買代金, 夜間収益sd) = **−0.038**(薄い⇒ノイズ大の関係なし)。
 (iii) ティック床 = 1円/¥2,143 = **4.67bps**(1321は0.15bps)、実測効果9.04bpsの52%。第3の指摘は正しい。
 (iv) 日中反転(アーティファクトなら寄り値の行き過ぎが日中に戻るはず): 1311 は日中 −4.43bps・corr(夜間,日中) = −0.125。
  ただし 1591(−4.08 / −0.137)・グロース250(−7.47 / −0.104)・J-REIT(−3.40 / −0.103)も同程度で、1311 固有ではない → 反転は薄さの証拠にならない。
 (v) `config/constants.yaml` の `etf_spread_bps` は null(未計測)で、コスト側からの検証路も塞がっている。

**裁定: 判定不能**。方向(薄い⇒夜間大)は再現、0.3億円も分母を直近平均と明示すれば再現。しかし claim の中核は「**アーティファクトで過大**」という因果主張であり、
日足OHLCで測れる範囲では超過分が非有意(t=1.32)、ティック床が効果の半分、薄さとノイズの関係なし、日中反転は薄さ非依存 —
**データはアーティファクト説とその否定(薄い銘柄の真の流動性プレミアム)を区別できない**。冗長サブ図ではなく claim 自身の機構が測定不能なので最悪サブ図ルールが素直に適用される。
**決着に必要な測定**(日足では原理的に不可能): (a) 1311 の寄り約定価格と同時刻の iNAV/指数フェアバリューの乖離を250日以上、(b) 寄り・引けの気配スプレッド実測
(= `etf_spread_bps` の空欄を埋める)、(c) 寄り乖離の日中戻り率を売買代金分位別に。この3点で初めて分離できる。それまでは未検証扱いとし
「1311 の夜間は国内最大だが超過分は測定限界内」とのみ記録する。
**各者の当否**: 第1=売買代金の分母問題を正しく突き、方向を再現した点が正しい。超過分のtを取り違え、機構検証不能を「維持」に丸めた点が誤り。
第3=分母の二重性(全履歴 vs 直近)とティック床、`etf_spread_bps` 未計測を正しく指摘。claim の再現する部分(方向・直近平均)も同時に明記すべきだった。

## 争点3 — R10「嵐の予兆(ストームレーダー前兆特徴量)棄却」(最大リフト1.57 < 採用基準2.0、合成は逆相関)

**両者の立場**: 第1=数値差異(維持)(非重複窓AUC 0.61–0.67)。第3=判定不能(合成の副主張はIV/大口データ皆無で検証不能、13変種の in-sample スイープが1.97で基準2.0に肉薄)。

**当方の再計算**(母集団=Binance BTCUSDT 1分足 302,403本 / 2026-01-22..08-20、嵐の定義=|30分対数収益|≥0.8% の初回、直前2時間に非該当。
**嵐 n=353**、基礎率0.117%/分。第1の352と一致、第3の539は不一致 — 539は連続クロス時の待機リセットが緩いためと推定):
リフト(上位10%マスク, n_sel≈30,235)は**特徴量窓が嵐の定義窓とどれだけ重なるかの単調関数**である:

| 窓の終端 | rvol | レンジ | 出来高 |
|---|---|---|---|
| t−1(定義窓とほぼ完全重複)|2.10|**7.03**|2.18|
| t−7 |1.44|2.27|1.33|
| t−12 |1.36|1.39|1.02|
| t−22 |0.82|0.74|0.71|
| t−32(完全非重複)|0.65|0.25|0.65|

claim の 1.57 も第3の 1.97 も、この表の「重複あり」領域(終端 t−7〜t−12 付近)に落ちる。**完全非重複窓 [t0−60, t0−31] に限れば
13変種の in-sample ベストは 0.963 で、ラベルシャッフル帰無の p95=1.416 を下回る**(200反復、帰無平均1.172)。
AND合成(rvol×出来高、非重複)は 0.352 で単独特徴量より悪い。一方 AUC(嵐 353本 vs 全時刻302,342本)は rvol 0.612・レンジ0.585・出来高0.565 で、
n=353 での AUC の MDE(α.05, 検出力80%)= 0.543 を上回る — **弱い実在の上昇はあるが、検出力は十分にあって、使える予兆ではないと積極的に言える**。

**裁定: 数値差異(結論維持)**。棄却(=レーダー特徴量として不採用)はデータが積極的に支持できる結論。リフト1.57 自体は非重複窓で再現しない(0.65–0.96、10%帯の外)ので再現ではないが、
基準2.0 に肉薄した1.97 は定義窓と重なる窓を許した場合にのみ現れる先読みで、判定不能の根拠にはならない。合成(IV/大口)の副主張はパケット行にデータ経路も公開取得先も無いため、
そのサブ図のみ**再計算不能→未検証**として台帳に落とす(判定不能ではない)。
**各者の当否**: 第1=定義窓との重複(先読み)を発見して非重複窓で測り直した点が決定的に正しい。「lift no」表現の不正確さの指摘も妥当。
第3=13仮説スイープの再現とシャッフル帰無、IV/大口欠落の明示は正しい。しかし特徴量窓を嵐の定義窓から離さなかったため 1.97 を過大に重く見た。
