# Packet B2 — S12「嵐時計バースト30分保有」第二次独立監査

対象クレーム（逐語記録）: UTC 12:30–15:00 の窓内で直近60秒 mid 変位 ±20bps 以上の秒に順張り taker 建て（発火秒の次の1秒以内の最初のプリント）、30分ちょうどで taker 決済、フラット時のみエントリ。汚染面で **コスト前 +23.71bps/取引, CI[+7.92,+37.27], n=40, 1.44回/日, 最悪 −62bps**。約1,190セルの探索面から4段で選択。

実装は独立（`audit_B2.py`）。秒足は「毎秒の最終約定 → 前方補完」で構築（丸め秒への reindex は不使用）。

## 10問への回答

**1. 分母/母集団.** 31日テープ `executions_FX_BTC_JPY_31d_20260823.csv.gz`: 982,000約定, 2026-07-23T12:09Z–08-23T12:25Z, 32暦日, id重複0。秒グリッド 2,679,368 秒のうちプリントのある秒は 13.4%（86.6% は補完）。窓内発火候補からフラット制約で非重複化 → n=51（22日に分布, 発火のあった日/全31日 = 71%）。ヘッドライン再計算は上表。

**2. 対照.**
- 窓外（24h走査・窓外エントリのみ）: n=153, +0.22 bps, CI[−6.07,+8.15], t=−0.05 → ゼロ。
- 全時間: n=204, +3.33, CI[−3.76,+11.67]。
- 逆張り（符号反転）: n=51, −11.99, CI[−26.85,+3.25] → 主効果の鏡像にすぎず、独立情報なし。
- プラセボ（窓内ランダム秒・日別本数一致・方向ランダム, 1000反復）: 平均 −0.22, sd 7.49, p95 +11.82, **P(≥ +11.99) = 0.050**。すなわち再計算値はプラセボの p95 相当＝ぎりぎり。主張値 +23.71 なら p<0.001 だが、その値自体が再現しない。
- ランダム150分窓 200本: 平均 +4.31, sd 12.59, p95 +19.72, 最大 +34.09。**主張窓の順位: 再計算値で 64パーセンタイル、主張値でも 96パーセンタイル**（=200窓中8本が主張値超）。「この窓が特別」という主張は再計算値では支持されない。

**3. 金額換算.** `config/products.yaml: FX_BTC_JPY.taker_fee_pct = 0.0`（手数料ゼロ）。よってコストは板を跨ぐ分＋ファンディング。`paper_logs/tape/ticker_*.csv.gz` 16日（1,589,458 tick）の中央スプレッド: 全時間 1.88bps、窓内 2.24bps。`swap_daily_pct=0.06` → 30分持ち 0.125bps。**自前ラウンドトリップ = 2.37bps（片道1.18）**。価格 12.5百万円想定で、自前コスト後 +9.62bps/取引 = 12,025 JPY/枚(1 BTC-CFD)、1.65回/日 → 15.8bps/日 ≈ 19,783 JPY/日/枚 ≈ 7.2百万 JPY/年/枚。ただし CI が 0 を含むため点推定の年換算は意味を持たない（下側 CI では −5.7bps/取引 = 年 −4.3百万 JPY/枚）。

**4. レジーム依存.** 発火強度 |60秒変位| 三分位: 弱 +37.13(n=17) / 中 −7.88(n=17) / 強 +6.73(n=17)。**効果は最も弱い発火に集中**しており、「規模が大きいほど継続する」というバースト論と逆向き。エントリ時刻の時間別: 12時台 +12.8(n=8), 13時台 +8.35(n=16), 14時台 +13.91(n=27)。閾値感度: 15bps → n=74, +12.77, CI[+1.69,+25.05]; 25bps → n=34, +17.25, CI[−4.07,+39.27]。水準ではなく変化（60秒変位）で測っており、そこは主張どおり。

**5. 定義の副作用.** (a)「フラット時のみ」は同一保有中の発火を全て捨てる。捨て方は先着順なので、日中の最初の発火に偏り、後続の（連鎖的な）発火が体系的に除外される。(b)「次の1秒以内の最初のプリント」は薄い秒でエントリ不能となり 19件を落とす（サンプルの 27%）。エントリ窓を60秒に緩めると n=51 のまま +13.36（除外は概ね中立）。(c) 決済は「エントリ+1800秒以降の最初のプリント（+120秒許容）」。

**6. データ妥当性.** id重複0、価格外れ値なし。保守作業帯 19:00–19:10 UTC は窓外（窓外対照にのみ影響、hour19 の発火率は最低 6.0/h）。31日スナップショットは同日のライブテープと一致（08-22: 45,693行 vs 45,432行, 1分終値相関 0.999998, 平均絶対差 0.01bps）→ **exec_date は UTC**（+9h/−9h シフトでは相関 −0.18）。妥当性フィルタ（外れ値トリム）の有無は第8問に記載（トリム後 +9.60 vs 全件 +11.99）。

**7. 選択汚染（best-of-N, N≈1,190）.** 実サンプル(n=51)の日符号を反転して疑似セル平均を生成し、1,190セルの最大値分布を2,000反復:
- 日符号反転: 最大値の p50 = **+23.98**, p95 = **+26.81**, p99 = +28.12
- 約定符号シャッフル: p50 = +24.18, p95 = **+27.73**, p99 = +29.76
**主張値 +23.71 bps は、1,190セル探索の帰無最大値の中央値（≈+24）にも届かない。** すなわち「1,190セルから最良を選ぶ」という手続きは、真の効果ゼロでもこの大きさの勝者を通常生む。再計算値 +11.99 は p95 バー(+26.8)の 45% にすぎない。フリーパラメータ: 窓開始・窓長・閾値(bps)・変位ホライズン(30/60s)・保有時間・先頭/全発火・エントリ遅延 の 7 系統。

**8. 最も単純な代替説明.** (i) 時刻効果（ボラのクラスタリング）— 大きな発火は 13–15時 UTC に集中し、そこは 30分リターンの分散も大きい。同じ時間帯にランダム方向で入るプラセボは平均 0 だが sd 7.49 と裾が厚く、n=51 の一標本は容易に +12 を出す。(ii) 単発依存 — 総グロスの **38% が1トレード**（+231bps）に由来。最良1件を落とすと平均 +7.61、上下1件ずつ落とすと +9.60、中央値は −0.13。(iii) ビッドアスク・バウンス — 約定価格系列で発火判定すると片側バウンス分だけ発火が水増しされる。フレッシュ面で真の mid 系列（ticker）で判定し直すと n=47→45、平均 +0.18→+3.11 と符号は変わらないが、いずれも CI は 0 を跨ぐ。

**9. 独立測定の一致.** フレッシュテープ（`paper_logs/tape/executions_2026*`、08-20..09-04, 750,191約定）: 全期間 n=47, **+0.18 bps**, CI[−11.07,+12.52], t=−0.28, 勝率 40.4%。汚染のない部分（≥2026-08-25T12:00Z）のみ n=31, +4.72, CI[−9.37,+21.77], t=+0.12, 勝率 45.2%、主張コストではネット **−3.20 bps**。窓外(フレッシュ) n=66, −1.03。方向は同符号だが**規模は 1/5 に縮み、有意性は消える**。二次測定は主張を支持しない。

**10. 反証文＋MDE.** 反証文: 「非重複・窓内サンプルの日クラスタ CI 下限が 0 以下、または探索補正後のバー（best-of-1190 の p95 ≈ +27bps）を下回れば、S12 の設計根拠は成立しない」→ **両方とも該当**。MDE（両側5%・検出力80%, 実測 sd 58.2bps/取引）: **n=40 で 25.8 bps**、n=30 で 29.8 bps（日クラスタ・22日基準では 19.8 bps）。**主張効果 +23.71bps は自らの n=40 における MDE を下回る**——つまり当初の実験は、主張する効果を検出する検出力を持っていなかった（CI が 0 を外れたのは選択の産物と整合）。

## 「時計窓が嵐」前提の検証

**bitFlyer 31日テープ**（分母 = UTC時間ごとの観測秒数, 各 111,600 秒）: ≥20bps/60秒 の発火率 12時台 18.4/h（リフト 0.885）, 13時台 57.5/h（2.77）, 14時台 57.8/h（2.79）, **15時台 45.4/h（2.19）**, 8時台 39.8/h（1.92）, 5時台 31.3/h（1.51）。窓に対応する 12–14時平均 44.5/h vs 全時間平均 20.7/h = **リフト 2.15**（主張 2.23 と近い）。ただし窓の前半（12:00–13:00）は平均以下で、窓外の 15–16時 は窓内 12時台の 2.5 倍。

**Binance BTCUSDT 1m, 2025-07-01..2026-07-31（13か月, 570,240本, ローリング30分リターン 570,210 標本）**: |30分リターン| ≥ 0.8% の基準率 3.009%。窓内 12:30–15:00 = **5.190%**(59,400標本) vs 窓外 2.755%(510,810標本) = **リフト 1.884**。時間別リフトの上位は **15時台 2.99, 14時台 2.69, 16時台 1.76, 17時台 1.75, 13時台 1.20**、12時台は 0.75（平均未満）。月別リフトは 0.99〜14.4 と不安定（2026-01 は 0.99 = 効果なし）。
→ 「12:30–15:00 が嵐」は**方向としては正しいが境界がズレている**: 真のピークは 14:00–16:00 UTC で、窓は最も静かな 12:30–13:00 を含み、最も荒れる 15:00–16:00 を除外している。窓の端は機構ではなく探索の産物。

**発火後スリッページ**（フレッシュ面, n=47）: 発火秒の mid に対する「次1秒の最初のプリント」の不利方向乖離 = 平均 **+0.72 bps**, 中央値 +0.95, p90 +3.56（参考: 窓内 half-spread 1.12bps）。主張の片道 3.96bps は実測の 3〜5 倍で**保守側**。
