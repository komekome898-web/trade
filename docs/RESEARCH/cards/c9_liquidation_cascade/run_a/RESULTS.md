## 7. なぜ(3 問)

測る前の 3 問(CARD.md「なぜ」)に、この走らせの表で答える。表から直接読めるものは【事実】、そこから先は【推定】。

**誰が損をしているか**
- 【事実: t1・t2・t1b】Binance COIN-M では、清算 1 件の後、5 秒〜240 分のどの h でも値段は清算の向きと逆へ動いた側が多く、合わせた時刻 (ii) と対にしても同じ符号。清算の後の振れ(最大順行・最大逆行・戻り)は対照より大きい。
- 【推定】損をしているのは、強制決済で清算の向きに成行を出させられた側(値段の行き過ぎた所で約定する)。その反対側に指値を置いていた側が戻りの分を受け取る形。起点の約定の多くが清算そのものの約定である(t16 の下 2 行: 起点の時刻が清算の時刻と同じ割合、起点の価格が `average_price` と同じ割合)ので、起点の値段は清算の約定値そのものに近い。
- 【事実: t6b・t6c】判断を使わずに連鎖の最初で清算の向きに乗る(`全部順張り`)は、両方の期間で日等重み平均が負。
- 【事実: t6d・t13b】ただし束の総量が一番大きい 3 分位(事後)と、清算の多い少数の日では、逆張りの損益が負、順張りの損益が正の側になる。大きな連鎖の日には、戻りを取りに行った逆張りの側が損をしている【推定】。

**なぜ続くか(この形が繰り返す理由)**
- 【事実: t11・t12】60 分の `react` が負になる形は、t11 の全部の月、封印の境の前後、9 月に開いた日の内外で同じ符号。
- 【推定】強制決済は値段を見ずにレバレッジの仕組みから機械的に出る注文で、情報ではない一時的な押しなので、押しが終わると戻る。人が判断を変えても強制決済そのものは止められないので、同じ形が繰り返す。CARD.md「なぜ」の推定と同じ向きの結果だが、この走らせで確かめたのは「戻る側が多い」までで、仕組み(誰の注文が戻しているか)は測っていない。
- 【事実: t9】連鎖のここまでの数量が大きいほど戻りの方向の動きが大きい(1 件の数量ではあまり変わらない)。【推定】押しの量が積み上がったほど行き過ぎも大きい、という読みと合う。

**何で崩れるか**
- 【事実: t6d・t13b】大きな連鎖(束の総量の一番大きい 3 分位、事後)と、少数の大きな日(2024-08-05 ほか)では、連鎖の最初から終わりまでの値動きが清算の向きに進む側になり、逆張りの総和の符号が日等重みの符号と逆になる。【推定】連鎖が大きくなるのは、値段の水準そのものが動く局面(ニュース・大きな相場の転換)で、そのとき清算は「行き過ぎ」ではなく「動きの一部」になる。
- 【事実: t6b・t10d】「次の清算が来るか」は材料から順に当たる(t10d)が、その判断で状態機械を回した損益は 0 の近く(t6b)。【推定】続く / 止まるのラベル(次の清算の有無)と値段の向きは別の量で、続くを当てても値段の側の損益にはつながっていない。
- 【事実: t8】fade の値動きは s が長いほど小さい(5 分・60 分)。【推定】最後の清算から時間がたつほど戻りはすでに進んでいて、待つほど残りが減る。
- 【推定】この走らせは Binance COIN-M の 1 銘柄だけで、USD-M・他の取引所の清算は見ていない(CARD.md「何で崩れるか」)。bitFlyer に同じ戻りが出るか(設計 §3.2 の (b))も測っていない。費用も入れていない(A-8、設計 §3.2「費用」の行)。
