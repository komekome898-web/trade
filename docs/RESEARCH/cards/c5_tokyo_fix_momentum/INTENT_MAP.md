## 4. △ と ✕ の切り分けの手段(測る前に決める。足すかはリードが決める)

### 4-1 I-1b(「前」の始まり = 日本時間 0 時)

- 持ち高のある足の損益を、日本時間の時(0 時台〜9 時台)ごとに分ける(W1 の C4 の場面の変数「時間帯・曜日」の「日本時間の時」)。仲値の直前(9 時台)だけで効くのか、夜からの続きで効くのかが分かる。カードの関数は変えない。

### 4-2 I-4(為替から FX_BTC_JPY への移し)

- 仲値の前の USDJPY の値動き(日本時間 0 時〜t)と、カードの持ち高の符号が一致する足の割合。一致する足と食い違う足で損益を分ければ、損益のうち円の項の分と BTC の側の分が分けられる【推定】。USDJPY は手元に 2017-08-01 から(2 つの置き場。調達票 §2)なので、この診断の期間は 2017-08 以後になる。

### 4-3 I-1c(祝日)

- 祝日の暦を置き場に足せば、「祝日か」を場面の変数にして分けられる。暦の調達は調達票 §2。足すまでは、祝日・年末年始を含めて測ったと報告に書く。

### 4-4 I-5(日本の時間帯と海外の時間帯の違い)

- カードの持ち高だけでは比べられない。比べるなら、同じ形(その日の始まりからの値動きに追随、決まった時刻で閉じる)を海外の時間帯に置いた対照のカードが要る。その時刻は原文に無い(CARD.md 迷った点 4)。

### 4-5 I-6(流れ)

- 観測する系列が無いので、このカードでは測らない。陰性・陽性のどちらでも、仲値の流れについては何も言えないと報告に書く。
