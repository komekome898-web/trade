## なぜ(リードの読み。【推定】)

1. **カツオ**: 決まり V4 で避ける区分は、2 つの候補ともない。どの候補も前の日が荒れた日ほど 1 日あたりが大きく、前の日が静かな日は 0 に近い(区間が 0 を含む)。避けるべき「損」の区分はなく、L-619 の「ほぼ得をしない取引」に当たるのは低の日【推定】。門 × 時間で降りる N = 9 では低の日が +0.28 [−3.67, +3.84] とほぼ 0 で、合図の時点の門(直前 365 日)がすでに静かな場面の取引を外しているので、日の門が足すものは小さい【推定】。荒れた日に強いのは K-013(高ボラで短い保有の勝ちが大きくなる)と同じ向き。
2. **マチルダ(良い側)**: どの区分も正で、避ける区分はない。荒れた日ほど大きい。
3. **マチルダ(悪い側)**: 3 つの区分とも区間が 0 より下で、決まり V4 は全部の区分を避ける = その形で取引しない、になる。門の取り分 +24.02 は「取引しない」ことの値で、日の門が悪い側の損を場面で分けられたのではない。1 分足の中の順序の仮定が悪い側なら、この形はどの日の場面でも負ける(K-047 の仮定の幅と同じ問題)。
4. **段取り 3 の結論(リードの決め)**: 前の日の荒れ具合の門(日の版)は、改良した形には足さない(V4 で避ける区分が出ないか、全部を避けるかのどちらかで、場面を選ぶ門にならない)。窓で試す形は、カツオの 2 つの候補とマチルダの過去だけの門 × 利確 4:3 のまま。日の区分は段 4(組み合わせ)の場面の変数として残す(荒れた日ほど 2 枚とも大きい = 同じ日にそろう、K-026 と同じ形)【推定】。
