## なぜ

## 約定の模型

- 成行。足の終わり t に出した持ち高 e_t は、次の足の始値で約定したとみなす(W1 の仕様 C2)。原文には約定の模型が無い。
- セッションの最後の足(終わりがセッションの区切りちょうどの足)では 0 を出す。その持ち高の約定は次の足の始値 = 次のセッションの中なので、出すとセッションをまたいで持つことになる(I-5)。次のセッションの最初の足は平均 = 自分の終値で 0。だから区切りをまたぐ 2 分は持たない。
- **例外**: セッションの最後の 1 分に約定が無いと、カードは区切りちょうどの足では呼ばれず、その前の足の持ち高が次の約定のある足(次のセッションの中)まで残る(測定器の決まり)。"bf_maint" では保守で 18:59〜19:1x の空きが多い(上の集計)が、空きの前の最後の足は 18:59 の足(終わり 19:00 = 区切りちょうど)なので 0 が出る。最後の足が 18:58 以前で終わる日は残る。その回数を測定の回に出す(INTENT_MAP.md §5)。
- 経費は入れない(段 2・3 は経費前。W1 の仕様 §0)。持ち高はほぼ毎足 ±1 で、平均をまたぐたびに持ち替える。持ち替えの回数(C5 の f)は測定器が出す。
- 持ち高が 0 の足も測定の分母に入る。

3. **セッションの最後の足で 0 にすること(I-5、C-8)**: 原文の「セッション内」を、持ち高をセッションの外に持ち越さないことと読んだ。別の形: 最後の足も同じ式で持ち高を出し、次のセッションの最初の 1 分にまたがせる(区切りを水準の決め直しだけに使う)。最後の 1 分に約定が無い日に持ち越しが残る例外(約定の模型の欄)は、測定の回に回数を出す。
4. **強弱と入る条件(C-9・C-10)**: 符号だけで、平均から少しでも離れたら毎足持つ。離れの大きさで強弱を付ける・一定の離れまで待つ・平均に戻ったら利確して次の離れまで待つ、には閾値か物差し(過去の窓の分布など)が要り、原文に無い(A-12)。W1 の C4 の局所ボラで離れを割る形(離れ ÷ 窓のボラ)は、強弱の符号を変えないので、符号だけのカードでは同じ持ち高になる【推定】。
