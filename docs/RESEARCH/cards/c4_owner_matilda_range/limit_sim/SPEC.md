# カード 4 段 1: v37 を 1 分足で指値として再現する(仕様)

出所: INTENT_MAP §10・§11(L-577〜L-583)。原典 = `docs/legacy/matilda_for_TaroCamp37.py`(以下「v37 の n 行」)。
カードの口(持ち高を毎分返す形)は指値を表せないので使わない。持ち高の決め方の考え方はカード 4(`src/bot/research/cards/library/c4_owner_matilda_range.py`)の第 4 稿と同じ所は同じにする。

## 1. 入力
- bitFlyer FX_BTC_JPY の 1 分足(`scripts/w4_measure/common.py` の `load_bars(FX_DIR, "FX_BTC_JPY", lo, hi)`。封印の門を通る)。期間の既定 2015-11-28T15:00Z〜2023-12-17T15:00Z。暦年ごとに読み、状態を引き継いでつなぐ(`run_b2.run_chunks` と同じ考え)。
- 出来高 0 の足・値段が有限でない足は窓に入れない(カードと同じ)。

## 2. 足 k が確定したときに作る量(足 k までの確定した足だけ)
- 窓 W 分(既定 40、時刻で切る: 始まり ≥ 足 k の終わり − W)。足の長さ B 分(既定 1)。B > 1 なら UTC 0 時からの B 分ごとにまとめる(カードと同じ)。
- 上端 hi・下端 lo: 既定は実体の端(range_from="body"。v37 458〜478 行がヒゲを捨てるため)。変種 "wick" は高値・安値。
- 幅 width = hi − lo、中心 center = (hi + lo) / 2、ボラ vola = 窓の中の足の |終値 − 始値| の平均。
- 2 倍の窓(2W 分)の上端 hi2・下端 lo2(v37 494・498 行)。
- ブレイクの判定値(v37 504〜509 行。足 k の確定で更新): `hi != hi2 or brk != 0` なら bup = hi + width/2、`lo != lo2 or brk != 0` なら bdp = lo − width/2。初めは未定(v37 208・210 行の 9999999 / 0 = ブレイクしない)。

## 3. 足 k+1 の間に起きること(足 k までの量を使う。v37 は確定した足で計算し、次の 1 分のあいだ 0.6 秒ごとに生きた値段と比べる)
足 k+1 の始値 O・高値 H・安値 L・終値 C。

### 3-1. ブレイク(v37 930〜965 行。b_signal は使わない = 0)
- 上: bup が決まっていて max(bup, hi2) < H かつ brk != 1 → brk = 1。下: bdp が決まっていて min(bdp, lo2) > L かつ brk != −1 → brk = −1(上を先に見る)。
- 判定値の値段 = 上なら max(bup, hi2)、下なら min(bdp, lo2)(ブレイクが起きた値段)。
- 解ける(break_off): brk = 1 で C < center、brk = −1 で C > center → brk = 0(足の終わりで判定)。
- `break_delay`(v37 144 行): 1(既定)は上のとおり。3 は判定値に 3 回前に更新された bup / bdp を使う(`break_up_priceList[-3]`)。0 はブレイクしない。

### 3-2. 入り(v37 970〜1005 行、order_buy / order_sell 828〜877 行)
brk == 0(レンジ)のとき:
- 幅の門(v37 976・993 行): width < MIN_WIDTH_RATIO × 足 k の終値 なら入らない(MIN_WIDTH_RATIO = 150 / 1,152,502、カードと同じ)。width_gate=False で外す。
- 売り: 1 段目の値段 S1 = center + entry × vola。H > S1 なら S1 で約定。持ち高が売りで n 段あるとき、次の段の値段 = max(S1, 前の段の約定の値段 + step × vola)(v37 867 行 `price > sell_status['price'] + step`)。H がその値段を越えるごとに 1 段ずつ約定(1 本の足で越えた段は全部)。段の数の上限 N(既定 7、v37 118 行)。
- 買いは対称(B1 = center − entry × vola、L < その値段)。
- 持ち高が買いのときに売りの合図の値段を越えた → 3-4 の「反対の入り」で閉じる(v37 1011・1019 行 exit_flg = 3)。閉じた後、同じ足でその向きに入るかは決まらない足として扱う(悪い側 = 入らない、良い側 = 入る)。
brk != 0 のとき(v37 1002〜1005 行、b_signal = 0):
- 持ち高 0 なら入らない。持ち高がブレイクの向きと同じなら、段の規則で足す(上と同じ値段の規則)。反対なら 3-4 で閉じる。
- on_trend="follow"(変種): 持ち高 0 ならブレイクの向きに 1 段、その足の判定値の値段で約定。
- 時計: 持ち高の向きが変わった時刻(0 → 売り・買い、v37 1050〜1066 行 possideList の変化)を t0 とする。段を足しても戻さない。

### 3-3. 利確の指値(v37 exit_judge 1007〜1036 行・order_exit 879〜928 行)
持ち高 n 段(各 1 段の量は同じ)、建値 E = 約定した段の値段の平均、exit_vola = step_exit × vola × (1 / n)(v37 881 行の sizemin / mybtc)。
- brk == 0 のとき:
  - exit_flg 3(成行): 足 k+1 の終わりで t − t0 ≥ 2 × alert(既定 40 分)、または反対の入りの値段を越えた → 3-4。
  - exit_flg 2: t − t0 ≥ alert(既定 20 分)、または建値が中心より悪い側(売りで E < center、買いで E > center)→ 利確の値段 = 売りは max(center, E − exit_vola)、買いは min(center, E + exit_vola)。
  - exit_flg 1: それ以外 → 売りは E − exit_vola、買いは E + exit_vola。
  - 約定: 売りの持ち高の買い戻しは L < 利確の値段、買いの持ち高の売りは H > 利確の値段。約定の値段 = 利確の値段。
- brk != 0 のとき: 持ち高がブレイクと反対 → 3-4。同じ向き → exit_flg 1 の値段(v37 1033 行 `elif b_signal == 0: exit_flg = 1`)。
- 利確の形の変種 exit_form="center"(v37 138〜139 行のコメントの定義): 売りは center + exit_setting × vola、買いは center − exit_setting × vola で利確(exit_setting は族の値)。
- B5 ブレイク時の利確(v37 113 行 breakexitsize = 3、1035 行): brk != 0 で同じ向きの持ち高が breakexitsize 段以上なら exit_flg 1 の値段に利確を置く(b_signal = 0 のとき 1033 行で既に exit_flg 1 になるので、b_signal を使わない再現では B5 の有無で動きが変わらない。そのことを報告に書き、変種としては作らない)。

### 3-4. 成行で閉じる(v37 reflesh 703〜714 行)
- 反対の入りの値段を越えた: その値段で閉じる。
- 反対のブレイク: ブレイクが起きた値段で閉じる。
- 時間(40 分): 足 k+1 の終わりで判定し、次の足の始値で閉じる。

### 3-5. 1 本の足に 2 つ以上の出来事が入るとき(決まらない足)
1 分足は高値と安値のどちらが先かを持たない。次の組が同じ足に入ったら「決まらない足」とし、取引ごとに数える:
- 入り(1 段目または段の追加)と、その持ち高の利確
- 利確と、段の追加(持ち高があるときの反対の側)
- 利確と、成行で閉じる値段(反対の入り・反対のブレイク)
良い側 = 利確が先(利確は約定、その後の段の追加・閉じるは起きない。持ち高 0 から入った足なら、入り → 利確まで済む)。
悪い側 = 利確が後(段の追加・閉じるが先に起きる。利確はその足では約定しない)。
同じ足の中で、利確の後にまた入る(2 回目の往復)は数えない(1 分足の限界。L-581)。

## 4. 損益
- 1 段の損益(bp)= 向き × (出の値段 / 入りの値段 − 1) × 1e4 ÷ N(持ち高の最大を 1 とする。カードの |e| ≤ 1 と同じ尺度)。取引の損益 = その取引の段の和。
- 取引 = 持ち高が 0 から離れて 0 に戻るまで。
- 出す列: 入りの時刻・出の時刻・向き・段の数・建値・出の値段・終わり方(利確 1 / 利確 2 / 中心型の利確 / 反対の入り / 反対のブレイク / 時間 / 期間の終わり)・損益・決まらない足の数・入りの時の width・vola・比(width / vola)・brk・足 k の終値。
