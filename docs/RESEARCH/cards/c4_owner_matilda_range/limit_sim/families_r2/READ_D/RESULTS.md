## 1. 読み

### 1-1 閉じる位置を手前(0.5 × vola)にすると、両側とも 8 年すべてで悪くなった【事実: 表・analysis.json】
- 損益の差 −44.5(良)/ −43.0(悪)bp/日、年の一致 8/8・8/8、決まらない足を除いても同じ向き。
- 負けを閉じた損益(R8)の差 −46.2 / −46.6、大負けの差 −26.2 / −24.3。取引の数は +4.5 / +6.2 本/日。
- 負けを閉じた取引の本数は、v37 のブレイクで閉じた取引 41,052(良)・42,878(悪)本から、手前の止めで閉じた取引 57,803・60,585 本に約 4 割増えた。1 本あたりは v37 −21.96 / −24.31 bp、手前の止め −17.95 / −19.47 bp で、手前の方が小さい。和の差は本数が増えた分が主で、取引の顔ぶれの違う和どうしの比べ(損益の差の言い換えに近い)。前の版の「手前の止めで閉じた取引の和の方が負けが大きい」は、この中身を書いていなかったので書き直した(関門 ② の 1 回目の直す 2)。
- それ以外の取引(利確など)の本数は 1,137,490 → 1,133,875 本(良)とほとんど減らず、手前の止めで閉じた取引の増えた分の多くは新しい取引【事実: analysis.json の by_break】。
- なぜ【推定】: 手前の止めは、ブレイクが起きなかった持ち高まで閉じ、閉じた後にまた入る。止めで閉じる取引そのものが増えて、1 本あたりは小さくても負けの数が増える。前の版の「利確まで持てた持ち高の一部を負けとして確定させている」は、それ以外の取引がほとんど減っていないことと合わないので取り下げた。

### 1-2 閉じる位置を先にすると、良い側は良くなり、悪い側はほぼ変わらない【事実: 表】
- 損益の差 +10.0(良)/ −0.5(悪)、向きは「側で割れる」。年の一致 7/8・5/8。悪い側は決まらない足を除くと向きが変わる。
- 負けを閉じた損益の差 +10.4 / +0.7、大負けの差 +1.3 / −7.3。取引の数はほとんど変わらない(−0.03 / −0.02 本/日)。
- 良い側で良くなるのは、ブレイクの後に値が戻って、先の値段に届く前に利確などで閉じた持ち高がある分【推定】。悪い側との差は、決まらない足の読み方で変わる。

### 1-3 比の門は、両側とも 8 年すべてで良くなった。大負けが減り、小勝ちも減る【事実: 表】
- 損益の差 +39.4(良)/ +37.6(悪)、年の一致 8/8・8/8、決まらない足を除いても同じ向き。
- 大負けの差 +57.0 / +46.1、負けを閉じた損益の差 +50.6 / +39.4、小勝ちの差 −21.4 / −11.7。取引の数は −37.7 / −22.4 本/日(v37 は 400.7 / 240.7)。
- 損益の水準は良い側 −43.01・悪い側 −206.37 bp/日で、どちらも負のまま(v37 は −82.40 / −244.01)【事実: summary】。
- 外れた取引の中身(v37 と比の門の analysis.json の差、良い側): 外れた約 11 万本(1,178,542 → 1,067,598)のうち、ブレイクで閉じた取引は 4,570 本(4.1%。v37 全体は 3.5%)で、損益の和 −148,741 bp(1 本あたり約 −32.5 bp。v37 のブレイクで閉じた取引の平均は −21.96 bp)。それ以外の外れた取引の和は +32,892 bp。v37 の比の十分位(analysis.json の ratio_deciles)では、1 本あたりの損益は比が大きいほど下がり、十分位 6 から負【事実】。
- なぜ【推定】: 比の門が効くのは、比が大きいときに入った取引がブレイクで閉じる頻度が少し高く(4.1% 対 3.5%)、ブレイクで閉じたときの 1 本の損が大きい(−32.5 対 −22.0 bp)ため。前の版の「ブレイクの負けになりやすい」は頻度だけの言い方で、損の大きさの方が効いているので書き直した(関門 ② の 1 回目の直す 3)。
- 12.96 は走らせる期間と同じデータから決めた値で、この +39 bp/日には境を選んだ分の有利さが混ざる。

### 1-4 他の直しとの比べと、設計のどこに触れば動くか【推定】
- 比の門(良い側 +39.4)は、組み合わせ C の読み(K-042)の中心から測る利確(良い側 +95.62〜+174.64)や 5 分足の物差し(+80.39・+97.27)より小さい。比の門も「入りを減らして大負けを避ける」形で、物差しと同じ負けを取り合う可能性が高い(物差しありの形との重ね合わせは測っていない)。
- 閉じる位置の手前(0.5 × vola の 1 水準)は、どの側・どの年でも悪かった。ただし手前・先とも 1 水準しか測っておらず、比の門・物差しは複数の水準や全期間から選んだ値なので、選び方の違う水準どうしの比べになる。「閉じる位置を動かす型より入らない型の方が効く」とは、この表からは言えない(関門 ② の 1 回目の直す 4)。
- 先にする形は良い側で +10 だが、悪い側では効かない。

## 2. 限界
- 経費なし。比の門は取引の数を 1 割前後減らす。
- 足の頭で止めが足の値幅の外の値段で約定する扱いは、既定のブレイクと同じ(手前の止めで約 941 件・1,431bp 有利に傾く推定。R9)。手前の止めの結果は、それでも負。
- 止めで閉じた後、値段が止めの内側に戻ってからの入り直しは落としている(2019 年で道 224 回。R9)。
- 12.96 は全期間の値から決めた(in-sample)。
- 年の一致は 2016〜2023 年の 8 年の向きの数で、区間は無い。
