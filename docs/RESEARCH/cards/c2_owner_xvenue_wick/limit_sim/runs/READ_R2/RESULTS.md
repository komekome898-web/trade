## なぜ(リードの読み)

1. **仮説「時間で降りると門は別の取引に効くので、組むと足し算に近い」**: 取引の突き合わせ(R8)と合わない。時間で切られた長い負けの取引の 8〜9 割は、門がそもそも外す取引だった。2 つの改良は同じ取引(静かな場面の合図で建てて長く持つ負け)に効いていて、組むと時間で降りる分の効きがほとんど残らない【推定: 突き合わせは近似】。
2. **組むと門だけと同じ並びになる**: 門は B の取引の約 7 割を外し、外した取引には負けの塊(時間で切られる取引)と勝ちの塊(門だけで外れた +68,070 bp)の両方がある。時間で降りる改良は負けの塊を小さくしてから勝ちの塊を残すので、門より取り分が大きい【推定】。
3. **時間で降りるだけの形が改良の土台**: 時間だけは 6/7 の N で区間が 0 を含まず、N が小さいほど差が大きい(N = 6 の +12.00 が 7 通りの中の最良。両隣は N = 7 の +9.77)。ただし 7 通りの中の最良であり、K-041 の N = 6・12 と同じデータで選んでいる(探索の読み)。
4. **空きの扱い(内部結合)への敏感さ**: 時間だけ・組んだ形とも、結合ありで約 1.5〜2 bp/日下がるが向きは変わらない(区間なし)。本番に合わせた扱いは測っていない。
