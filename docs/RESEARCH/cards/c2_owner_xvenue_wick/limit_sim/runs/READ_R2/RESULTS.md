1. **仮説「時間で降りると門は別の取引に効くので、組むと足し算に近い」**: 取引の突き合わせ(R8)と合わない。時間で切られた長い負けの取引の 8〜9 割は、門がそもそも外す取引だった(2019 年以降でも 82%)。2 つの改良は同じ取引(静かな場面の合図で建てて長く持つ負け)に効いている【推定: 突き合わせは近似】。組んだ形に時間で降りる分がどれだけ残るかは**不明**: 組んだ形の差の区間は 0 を含むが MDE(15.4〜16.1)は時間だけの差(+5.75〜+12.00)より大きく、組んだ形と時間だけの差(dC − dT)には区間を付けていない。
2. **組むと門だけと同じ並びになる**: 門は B の取引の約 7 割を外し、外した取引には負けの塊(時間で切られる取引)と勝ちの塊(門だけで外れた +68,070 bp)の両方がある。時間で降りる改良は負けの塊を小さくしてから勝ちの塊を残すので、門より取り分が大きい【推定】。
3. **改良した形の候補は 2 つ残る**: 全期間では時間だけ(6/7 の N で区間が 0 を含まない)が組んだ形を上回るが、その差の多くは 2018 年(門の履歴が 1 年に満たない期間を含む年)から来る。2019〜2023 年では N = 6〜8 は時間だけ、N = 9〜12 は組んだ形が上回る(区間なし)。時間だけの差は N について単調ではなく(+12.00, +9.77, +7.50, +7.73, +5.75, +6.84, +6.08)、最良の N = 6 は走らせた範囲の端で、N = 5 以下は測っていない(最良が範囲の外にある可能性がある)。いずれも 7 通りの中の最良で、K-041 と同じデータで選んでいる(探索の読み)。
