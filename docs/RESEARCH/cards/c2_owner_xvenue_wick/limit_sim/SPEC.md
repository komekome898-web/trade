## 4. 1 本の足の中(決まらない足)
- 1 本の足を 2 通りの道(始値 → 高値 → 安値 / 始値 → 安値 → 高値)で通す。始値の時点で越えている値段は足の頭で起きたものとする(カード 4 の直しと同じ)。
- 2 通りで結果が違う足を「決まらない足」とし、取引ごとに数える。良い側 = その足の結果の損益が良い方の道、悪い側 = 悪い方の道。

- 1 分の中の何回もの往復は数えない(L-581)。1 回閉じた足では、その足で入り直さない。

## 5. 損益

- 取引 = 持ち高が 0 から離れて 0 に戻るまで(ドテンは前の取引の終わりと次の取引の始まり)。
- 出す列: 入りの時刻・出の時刻・向き・最大の量・建値・出の値段・終わり方(指値 / ストップ指値 1 / ストップ指値 2 / ストップ成行 / ドテン / 期間の終わり)・損益・決まらない足の数・入りの合図の 19・24 の枝・先端までの比 r。
