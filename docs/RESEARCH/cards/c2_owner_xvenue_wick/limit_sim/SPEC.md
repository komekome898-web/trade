### 3-1. 入り(原典 order_buy 299〜334 行・order_sell 336〜371 行・orderset 273〜296 行)
- まず置いてある注文を全部取り消す(原典 304・341 行 cancelAll)。
- 1 本目: 値段 P1 = 時刻 T の直前の bitFlyer の 1 分足の終値。【仮定】原典は板の最良気配(買いは最良の買値、売りは最良の売値。306・343 行)に post-only で置く。板は再現できないので、直前の約定の値段で代える(カード 4 の入りの値段と同じ扱い。L-579)。
- 2 本目: 値段 P2 = 先端までの半値。原典 308・345 行 `price1 ∓ |price1 − lcprice| / 2` は同じ取引所の値段どうし。ここでは海外の比 r = |海外の終値 − 先端| / 海外の終値 を使い、買いは P2 = P1 × (1 − r/2)、売りは P2 = P1 × (1 + r/2)【置いた形】。
- 量: 持ち高 0 → 1 本目 0.5・2 本目 0.5。同じ向きの持ち高 → 1 本目 0.5・2 本目 0.5(増し玉。上限で切る)。反対の持ち高 → 1 本目 = 0.5 + |持ち高|(ドテン)・2 本目 0.5。
  - 原典 314・351 行は `size + mybtc` で、売り持ち −0.5 からの買いでは 1 本目の量が 0 になる。オーナーの言葉の「ドテンポジションの確保」(L-024、意図の地図 I-3)に合わせて `size + |mybtc|` と読む【置いた形: 原典の誤りと読む】。
- 上限の検査(原典 303・340 行 `if abs(mybtc) >= sizemax`): 文字どおりでは持ち高 0 のとき注文を出さない(bot が一度も建てない)。「ポジションオーバー！注文はスルーするぜ」(320・357 行)の文から `<` の誤りと読む【置いた形】。
  - 持ち高が上限(|持ち高| = 1)のときの反対の合図: コードのとおりなら何もしない(取り消しもしない)。オーナーの言葉(L-024 ドテン)なら反転する。変種 `at_max` = "skip"(コード)/ "flip"(L-024)で両方を出す。
- 約定: 買いは、T 以降の足の安値 < 値段 で、その値段で約定(等号なし、カード 4 と同じ)。売りは高値 > 値段。置いた注文は次に注文を出すとき(取り消し)まで残る(原典に期限は無い)。

### 3-2. 降りる(原典 order_exit 411〜440 行・orderset_exit 373〜409 行)
- まず全部取り消す。持ち高の全量に、次の 4 本を置く(買い持ちなら売り、売り持ちなら買い。d = 持ち高の向き):
  1. 指値: 値段 X = 時刻 T の直前の bitFlyer の終値【仮定】(原典 419・423 行は板の最良気配。買い持ちは最良の売値に post-only)。買い持ちは高値 > X、売り持ちは安値 < X で約定。
  2. ストップ指値 1: 引き金 X − d × 1.5 ドル、指値 X − d × 1 ドル(原典 393〜395 行)。
  3. ストップ指値 2: 引き金 X − d × 3.5 ドル、指値 X − d × 3 ドル(398〜401 行)。
  4. ストップ成行: 引き金 X − d × 5 ドル(403〜407 行)。引き金の値段で約定とみなす【仮定】。
- ドルの幅は海外の終値に対する比にして X に掛ける(1.5 ドル → X × 1.5 / 海外の終値)【置いた形】。
- ストップ指値は、引き金を越えた後に値段が指値まで戻ったら約定(post-only)。どれか 1 本が約定したら残りは無くなる(reduce-only、全量)。
- 原典の成行の撤退 `order_out`(442 行〜)は本体から呼ばれないので使わない。

## 4. 1 本の足の中(決まらない足)
- 1 本の足を 2 通りの道(始値 → 高値 → 安値 / 始値 → 安値 → 高値)で通す。始値の時点で越えている値段は足の頭で起きたものとする(カード 4 の直しと同じ)。
- 2 通りで結果が違う足を「決まらない足」とし、取引ごとに数える。良い側 = その足の結果の損益が良い方の道、悪い側 = 悪い方の道。
  - 主に起きるのは、降りる注文の 1(上)と 2〜4(下)が同じ足に入るとき。入りの 1 本目と 2 本目は同じ側にあるので値段の順で決まる。
- 1 分の中の何回もの往復は数えない(L-581)。1 回閉じた足では、その足で入り直さない。

## 5. 損益
- 約定ごと: 向き × (出の値段 / 入りの値段 − 1) × 1e4 × 量(量の最大 1)。持ち高の建値は約定の量で重みを付けた平均。
- 取引 = 持ち高が 0 から離れて 0 に戻るまで(ドテンは前の取引の終わりと次の取引の始まり)。
- 出す列: 入りの時刻・出の時刻・向き・最大の量・建値・出の値段・終わり方(指値 / ストップ指値 1 / ストップ指値 2 / ストップ成行 / ドテン / 期間の終わり)・損益・決まらない足の数・入りの合図の 19・24 の枝・先端までの比 r。
- 注文ごとの数も出す: 出した入りの注文のうち約定した割合(1 本目・2 本目)、約定までの時間。
