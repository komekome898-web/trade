## 4. △ と ✕ の切り分けの手段(測る前に決める)

**リードの答え(2026-10-02)**: 下の 4-1 の (4)・4-2・4-3・4-4・4-6・4-7 は、**測定の回に出す(診断)**。検定の数には入れない。関数は変えない。

### 4-1 I-1b(海外の価格の代理)と I-1c の注

- (1) BTCUSDT と BTCUSD の差: 同じ期間の USDT/USD の値(または Coinbase BTCUSD と Binance BTCUSDT の比)を並べ、上乗せの分布の中の位置が、USDT の差を除いた位置と食い違う足の割合を出す。手元に USDT/USD の 1 分足は無い。今回は W4 の仕様どおり代理で測る(リードの答え 2026-10-02)。取得の候補は調達票 PROCUREMENT.md §2 に残した(到達確認は未)。射程: 陰性は「USDT の差を混ぜた上乗せでは戻りが取れない」までしか言えない。
- (2) Coinbase(原文の使うデータ)と Binance(W4 の指定)の差: 同上(Coinbase の 1 分足は手元に無い。取得の候補は調達票に残した)。
- (3) USDJPY が BID だけ: 上乗せの水準は半分の売り買いの幅だけずれるが、幅がほぼ一定なら窓の中の位置はほとんど変わらない【推定】。幅が急に開く時間(週明けの寄り付き・指標の発表)では位置がずれうる【推定】。
- (4) SFD の時代の FX の価格: bitFlyer FX と bitFlyer 現物の乖離が上乗せに含まれる【推定】。手元の置き場 `backtest_data/bitflyer_lightchart_BTC_JPY_1m_20260906/` に 2015-08-02〜2026-09-06 の 1 分足がある【事実: 同じ置き場の README と `candles_1m_index.json` を読んだ。中身は開いていない】。**測定の回に出す(診断)**: bitFlyer 現物で作った上乗せ(現物 ÷(Binance × USDJPY))と FX の上乗せとで、窓の中の位置が食い違う足の割合。

### 4-2 I-3b(門の代わりに位置)

- **測定の回に出す(診断)**: 持ち高の絶対値の 3 分位ごとの平均損益。分布の端に近い足だけで効くのか、真ん中でも効くのかが分かる。3 分位の境は測定の物差しで、カードの水準ではない。

### 4-3 I-6b・I-9(bitFlyer の脚だけ / どちらの市場が寄るか)

- **測定の回に出す(診断)**: 持ち高 e_t と、次の足の「上乗せの変化」(Δp_{t+1} = bitFlyer の対数の動き − Binance の対数の動き − USDJPY の対数の動き)の積の平均を、bitFlyer の脚の損益(W1 の P_t)と並べる。前者が戻りそのもの、後者がこのカードの損益。差が「海外の側で寄った分」と BTCUSD・USDJPY の混ざり。
- 射程: 戻りそのものは診断として並べるだけで、検定はしない。このカードの検定の結論は「bitFlyer の側で戻りが取れるか」までで、「上乗せが戻るか」ではない。

### 4-4 I-8(海外の価格の先行で開いた上乗せ)
