# Answer 1 (independent lower model, saw only w4s3_2026-10-04_questions.md; verbatim)

**Q1. Observables (ranked from most to least direct)**

1. (a) Per-class mean daily profit with 95% interval: **direct**. It shows, class by class, which classes lose or barely gain, and how uncertain that is.
2. (c) The gate's take (profit avoided per day): **direct**. It measures the benefit of avoiding classes, but only fairly out of sample, since the rule picks classes using the same data.
3. (b) High-minus-low difference with interval: **proxy**. It shows whether volatility matters, not whether a particular class loses or barely gains.
4. (f) Per-class share of total profit: **proxy**. It shows what avoiding a class would cost, not whether the class is bad.
5. (e) Per-class number of days: **proxy**. It gives sample size, which sets how much the interval in (a) can be trusted.
6. (d) Minimum detectable effect per class: **proxy**. It shows whether the rule could ever flag a class, not what the class earns.
7. (g) The same split applied to the pre-improvement version: **unrelated**. The owner wants the gate re-applied to the improved form. It is only a stability comparison.

**Q2. Fairness of the decision rule**

1. No, it is not a fair translation. The rule only avoids classes that are significantly negative. "Barely gain" is never caught, and noisy classes with wide intervals pass by default.
2. A fairer rule is to avoid a class if the upper end of its interval is at or below a pre-registered minimum worthwhile daily profit m > 0. The owner sets m, ideally cost-based, and not from the data. Also report the point estimate and interval for every class, so a wide interval is not silently turned into avoidance.

**Q3. Covariates**

1. Fill assumption inside a 1-minute bar: **match**. Use the same assumption across classes and versions, and report results under both optimistic and pessimistic.
2. Calendar year: **report**. Show per-year class means to check the volatility effect is stable and not driven by one year.
3. Days without a class (first year): **report**. State how many days are excluded and keep the same day set across compared versions.
4. Whether class thresholds were chosen in-sample: **match**. Require previous-year thresholds. Any in-sample variant is flagged and not used for the gate decision.
