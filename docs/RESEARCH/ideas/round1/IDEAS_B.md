# P6 ETF

## D1-B-1(升 P6-関心)ETF 名義の検索量でフロー(P6-移動)を先読みする

- 原文: 導出の升 P6-関心。機構の文: 「ETF を買う個人・助言業者の関心は、ETF 名義の語の検索に出てから、日次のフロー(P6-移動)になる」。
- 意図の地図: 入る条件 = ETF 名義の検索量が急に増えた時点(「急に」の定義は未定)。出る条件 = 未定。保有中の判断 = 未定。強弱の付け方 = 検索量の増え方(未定)。向き = 検索量の増に対して買い。
- なぜ: 誰が損をしているか = ETF フローの公表(翌営業日)を待ち、その前の関心の動きを見ない人。なぜ続くか = 関心から購入までに遅れがあるなら、毎回その遅れが残る。何で崩れるか = 購入の大半が検索に現れない機関の資金なら、検索量とフローが結びつかない。
- 期待する向きと場面: 効く項 = BTCUSD。注文の主 = ETF を買う投資家 → AP の設定(現物 BTC の購入)。向き = 買い。場面 = 米国の営業日の前の、ETF 名義の語の検索量が増えた日。
- 反証: 検索量の変化が、曜日などの時計の変数を除いても、その後の日次フロー(P6-移動の系列)を区別できないと測れたら、「関心 → フロー」の遅れの仮説は違う。
- 段 3 の種類: (a) 海外で見える跡で bitFlyer を持つ。
- 水準とその出所: 未定(W4 で測る前に決める)。
- 使うデータと遅れ: ETF 名義の語の検索量(Google Trends、区分 未確認。第 3 版 B-28 で回数制限 429)。日次フロー(Farside、区分 A、2024-01-11〜、翌営業日公表)。Google Trends の更新の時刻の規則は未確認。
- 約定の模型: 成行(位置を決める案)。

## D1-B-3(升 P6-移動)日次フローが同じ符号で続く日数を、設定・償還の継続として使う

- 原文: 導出の升 P6-移動。機構の文: 「米国の現物 ETF の純フローが同じ符号で続く日数は、AP の設定(または償還)の注文が続いている日数である」。
- 意図の地図: 入る条件 = 同じ符号の連続日数がある値に達した時点(値は未定)。出る条件 = 符号が反転した時点(未定)。保有中の判断 = 未定。強弱の付け方 = 連続日数と累積の規模(未定)。向き = 流入の連続 → 買い、流出の連続 → 売り。
- なぜ: 誰が損をしているか = フローの連続を見ず、1 日ごとの数字で判断する人。なぜ続くか = 投資家の資金が数日かけて入る・出るなら、設定・償還が続く。何で崩れるか = 設定・償還が先物やベーシスのヘッジで吸収され、現物の注文にならないとき。
- 期待する向きと場面: 効く項 = BTCUSD。注文の主 = AP の設定(現物 BTC の購入)と償還(現物 BTC の売却)。向き = 上記。場面 = 同じ符号のフローが連続している間。
- 反証: 連続日数で分けた後の BTCUSD の動きが、連続日数 1 日のときと区別できないと測れたら、この「なぜ」は違う。

- 原文: 導出の升 P6-移動。機構の文: 「フローが大きいのに BTCUSD が動かなかった日は、AP の現物の売買を受けた相手(売り手・買い手)がいる日である」。

## D1-B-6(升 P6-約定)ETF 株が取引される米国の立会時間の内と外で、BTCUSD に出る注文の種類が違う

- 原文: 導出の升 P6-約定。機構の文: 「ETF 株の約定は米国の立会時間にだけ起き、AP の設定・償還とそのヘッジの注文はその時間に集まる。bitFlyer は 24 時間なので、立会の内と外で BTCUSD に出る注文の種類が違う」。
- 意図の地図: 入る条件 = 立会の開始・終了の前後、または立会の外(時刻・曜日は暦から決める。窓の幅は未定)。出る条件 = 未定。保有中の判断 = 未定。強弱の付け方 = 未定。向き = 未定。
- なぜ: 誰が損をしているか = 立会の内外の違いを使わず、終日同じ規則で売買する人。なぜ続くか = 立会という制度が毎営業日ある。何で崩れるか = ETF の約定が BTC の値付けの主導でなくなる、または AP が立会の外でも動く。
- 期待する向きと場面: 効く項 = BTCUSD。注文の主 = ETF 株の買い手・売り手と、AP の設定・償還・ヘッジ。向き = 未定。場面 = 立会の開始・終了の前後、週末・米国の休日。
- 反証: 立会の内と外で、BTCUSD の値動きの性質(方向・戻り)が区別できないと測れたら、この「なぜ」は違う。
- 段 3 の種類: (b) 海外と日本の違い(ETF の立会は米国時間のみ、bitFlyer は 24 時間)。
- 水準とその出所: 未定(W4 で測る前に決める)。
- 使うデータと遅れ: 時計(米国の立会時間と休日の暦。区分 A。サマータイムで UTC の時刻が動く規則は暦から決まる)。遅れは無い。ETF の約定の履歴は使わない。
- 約定の模型: 成行。

- 期待する向きと場面: 効く項 = BTCUSD。注文の主 = AP の設定(現物 BTC の購入)・償還(現物 BTC の売却)。向き = 上記。場面 = 乖離が開いた米国の立会時間中。
