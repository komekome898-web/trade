## D1-D-1

- 由来: ① / 升 P16-関心
- 効く項と注文の主: 経費。当方の成行(建て・決済)の約定が、板を出す人(P16)の引いた・広げた気配に当たる。
- 原文: 升 P16-関心。機構の文: 「板を出す人は、予定の出来事(経済指標・政策の発表・資金調達の時刻)の前後で、気配を広げる・量を減らす・引くことがある。その気配の幅と深さは bitFlyer の板に残る。当方の成行は、その時間帯に広がった幅を払う。」
- 意図の地図: 入る条件 = 未定。出る条件 = 未定。保有中の判断 = 未定。強弱の付け方 = 予定の出来事までの時間と、気配の幅・深さの変化(未定)。この案はポジションの向きを決めず、建て・決済の執行の仕方(その時間帯に成行を出すか、待つか、指値にするか)を条件づける。
- なぜ: 誰が損をしているか = その時間帯に成行で入る人が、広がった気配幅を払う。なぜ続くか = 板を出す人は、予定の出来事が起きる時刻が分かっていて、在庫の危険に見合う幅を求めるから(出所 X1-D-1 の原文と同じ記述の系統)。何で崩れるか = 予定の出来事の前後で広がらなくなったとき(板を出す人の競争が強くなったとき)。
- 期待する向きと場面: 場面 = 予定の出来事の前後。向き = 経費が大きい側に振れる(建て・決済の費用の増)。効く項 = 経費。
- 反証: 予定の出来事の前後の bitFlyer の気配幅・深さが、それ以外の時間帯と変わらないと測れたら、この「なぜ」は違う。
- 段 3 の種類: (c) bitFlyer の中だけ
- 水準とその出所: 未定(W4 で測る前に決める)
- 使うデータと遅れ: bitFlyer の板の上位 10 段・気配(区分 C、オーナーの PC で 2026-08-26 から)。予定の時刻の暦(資金調達の時刻は区分 A。経済指標の予定は未確認)。予定は事前に分かるので遅れは無い。
- 約定の模型: 未定(成行と指値の切り替えを含む)

## D1-D-5

- 効く項と注文の主: 円の上乗せ。bitFlyer の板を出す人(P16)が、一方向の成行を受けて抱えた在庫を、気配の偏りで戻すときの動きが、bitFlyer だけの価格の動き(= 円の上乗せ)になる。
- 原文: 升 P16-約定。機構の文: 「売買の主導側が一方向に偏ると、板を出す人は反対側の在庫を抱える。在庫を戻すために、気配を偏らせる。bitFlyer の板を出す人の在庫の押し戻しは、bitFlyer の価格だけを動かし、海外の価格との差に出る。」
- 意図の地図: 入る条件 = 主導側の偏りが一方向に続いた後(偏りの定義は未定)。出る条件 = 未定。保有中の判断 = 未定。強弱の付け方 = 偏りの大きさ(未定)。向き = 偏りと逆(という読み)。
- なぜ: 誰が損をしているか = 偏りの側に成行を出し続けた人(押し戻しに当たる)。なぜ続くか = 板を出す人は在庫に上限があり、戻さなければならないから。何で崩れるか = 偏りが情報のある売買で、押し戻しが起きずに価格が動き続けるとき(X1-D-4 の原文は、指値の約定の確率と約定後の収益が逆に動くとして、この危険を述べている)。

- 反証: 偏りの直後の bitFlyer の価格の動きが、海外の価格の動きと同じで、差(円の上乗せ)に偏りとの関係が測れなければ、この「なぜ」は違う。
