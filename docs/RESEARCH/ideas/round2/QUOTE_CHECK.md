# 引用の逐語の機械照合(案の供給 第 3 周)

作業者が WebFetch で取った英語の逐語(「」の中で 25 字以上・英字が 6 割以上)が、同じ案に書かれた URL のページ本文に字句どおりあるかを、リードが台本で照合した。WebFetch はページを小さなモデルが読んで返す道具なので、返した文が字句どおりかは保証されない(作業者 B1・B2 の報告)。

- 台本: scratchpad の `verify_quotes.py`(取得は `curl -sS -L -A research-probe --max-time 30`。HTML は script・style・タグを除き、PDF は `pdftotext`。空白・引用符・ダッシュをそろえ、小文字にして部分文字列で照合)と `verify_fix.py`(不一致を、取得の失敗と、6 語ずつの並びの一致の割合で分けた)。ページの本文は scratchpad に置き、画面に出していない。x.com・BitMEX・bitflyer.com の URL は叩いていない。
- 「ページの本文に見つからない」は、作り話と決めたのではない。JavaScript で後から描くページ(取った HTML に本文が無い)と、WebFetch の言い換えの区別はこの台本では付かない【事実: 例 X2-A-06 の 1 件目は、ページに「arbitrageurs do narrow persistent spreads, but their capacity is finite」があり、引用の頭の「Cross-exchange」が無い】。
