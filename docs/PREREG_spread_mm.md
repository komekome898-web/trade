## 0. 位置づけ・事前分布・決定的な問い

- 土台となる唯一の正の実測: **両側フロー窓内の理想 maker ネット +0.38〜+0.76bps/脚**(S7、
  f=100%仮定)。無条件 maker(常時両建て)は**負**と実測済み(u)— よって無ゲート腕は
  族に含めない(死んだ腕に候補を使わない)。
- 校正の制約: 片脚単独は全域で負(cap+adv −0.1〜−0.9)。capture は半スプレッドの約半分
  (+0.60/脚)。窓が買うのは行列(f 23%)であって単価ではない。
- M系3ラウンドの制約(設計に織込み): 片側在庫の平均化では閉じない/撤退は反対側約定で
  行い時間譲歩をしない/在庫帯は浅く/嵐中在庫がトレンド脚を受ける事故が最大の敵。
- **決定的な問い(本判定が測るもの)**: 反対脚は、逆選択が capture 2本分(≈1.2bps)を
  食う前に約定するか。窓内の逆選択は5秒で飽和する(−1.3bps 頭打ち)ため、
  **対約定が速ければ算術は正、遅ければ在庫戦略に退化して死ぬ**。

## 1. 機械(構造定数 — 掃引しない・判定後も変えない)

| 定数 | 値 | 根拠 |
|---|---|---|
| クオート | best bid / best ask に各1単位(0.01 BTC)を**同時**に置く | 対称性が原資(capture×2) |
| 追従 | ベストが自価格から1ティック超離れたら**タッチへ置き直し**(行列は置き直しごとに最後尾 = queue-realistic、Q は置き直し時点のベストサイズ) | 校正の主モデル。滞在時間が f の支配軸 |
| 約定モデル | queue-realistic(第26報 §4 逐語。突き抜けクローズ含む入れ子性 assert) | |
| スキュー | \|在庫\| が K 未満: 両側タッチ。\|在庫\| = K: **増える側を全撤去**、減る側のみタッチ(価格スキューはしない — ノブを増やさない) | 在庫帯の実装 |
| 決済 | **反対側クオートの約定のみ**(在庫が0に戻る = 往復完成)。時間による譲歩なし | M系の教訓 |
| バックストップ | 窓クローズ後も在庫が残る場合: 減る側タッチのみ継続、**120秒**で未解消なら taker 全量(3.96bps) | E2 の損失有界化(エッジではない)。数値は E2 の120秒を継承 |
| 嵐フラグ | 因果的 \|30分リターン\| ≥0.8% 点灯中: 新規停止・減る側のみ・バックストップ即時適用 | M4: 嵐中在庫が最大の敵 |
| コスト | maker 0 / taker 3.96bps / ファンディング 0.06%/日を保有按分 | KNOWLEDGE §1 |
| 損益単位 | unit bps(1単位=0.01 BTC 基準)。往復 = 在庫が0に触れてから次に0に触れるまで | M系と同一の会計 |
