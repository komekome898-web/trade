# データ消費台帳 — 「私たちが何を見たか」の記録

作成 2026-09-08(全捨てと同時)。

**これは相場についての主張ではない。私たち自身の履歴である。** だから全捨ての対象外とした。
理由: 相場は測り直せるが、**私が過去にどのデータを見て何を選んだかは測り直せない**。
これを失うと、既に構成を選んだ区間で「新鮮な検証」を行い、自分を騙すことができてしまう。

用語: **選択に消費** = その区間を見て構成・閾値・窓・パラメータを選んだ。以後その区間の数値は
「新しい証拠」にはならない。**未消費** = 一度も見ていない。**封印** = 機械的に読み出しを禁止した。

## 5. 使い方

新しい研究を始めるとき、**選択に使う区間と判定に使う区間を決める前に本書を読む**。
「選択に消費」と書かれた区間で出た数値は、その区間を見て選んだ構成については新しい証拠にならない。
本書に無い区間は未消費とみなしてよいが、**消費したら必ずここに追記する**(追記のみ・削除禁止)。
