# 机上調査: 国内株式クロスセクショナル戦略の実現可能性

日付: 2026-08-28。担当: 調査エージェント(机上のみ。発注・取引・コミットなし)。
目的: BTC CFD(34報)と FX(10系統)が全て「効果サイズ < コスト床」で棄却された後の
横展開第2弾として、**本プロジェクト唯一の未検証戦略クラス = クロスセクショナル
(銘柄横断の相対評価)** が使える国内株式市場を、コスト床・データ・資本・事前分布の
4軸で判定する。日次スケールなのでレイテンシは無関係(自宅PC運用と整合)。

**本文書は推奨に留まる。go/no-go の決定はリードが行う。**

数値には全て出典URLを付す。推定値は「推定」と明記し算術を示す。見つからなかった数値は
「**不明**」と書き、埋めない。取得日は特記なき限り 2026-08-28。

## 0. 結論(先出し)

> **本市場でコスト床は束縛条件ではない。** 東証の流動性上位銘柄の往復コスト床は
> **約2.8bps**(手数料ゼロ・スプレッドのみ)で、BTC CFD 5.8bps より安く FX 0.71bps より高い。
> 日次〜週次のクロスセクショナル戦略の報告値(年率数%〜)に対して回転率を掛けても、
> コストが効果を食い切る構図には**ならない**。
>
> 代わりに束縛するのは **(a) 単元株100株制の粒度による最低資本(実測: 30銘柄で ¥10M〜¥50M)**、
> **(b) 統計的分解能(日本で唯一生き残る効果=バリューは SR 0.45 ⇒ t=2 に約20年)**、
> **(c) J-Quants の解約時データ削除義務(本リポジトリの `backtest_data/` 恒久スナップショット
> 慣行と正面衝突)** の3点である。
>
> つまり本市場は「これまでと同じ棄却法則(効果<床)では判定できない」市場であり、
> **判定基準そのものを作り直す必要がある**。これが横展開する場合の最大の設計上の争点。

### 1.4 スプレッド = STR × ティック・ウェイト

東証は名目スプレッドを呼値の単位で割った **STR(Spread to Tick Ratio)** を公表している。
これが「スプレッドは呼値何本分か」の一次データ。
出典: [売買制度ワーキング・グループ報告(参考資料編) 2026-04-22](https://www.jpx.co.jp/corporate/news/news-releases/1030/t13vrt0000010tsw-att/t13vrt0000010u1s.pdf)
(データ期間: 2025年6月2日〜6月30日の21営業日平均、Bloomberg より東証作成)

| 区分 | STR<1.5 | 1.5≤STR≤5.0 | STR>5.0 | 平均約定件数 |
|---|---|---|---|---|
| TOPIX100 | **52.0%** | 47.0% | 1.0% | 28,274件 |
| TOPIX Mid400 | 8.3% | **80.7%** | 11.1% | 9,578件 |
| Mid400 流動性上位 | 19.7% | 79.5% | 0.8% | 20,541件 |
| Mid400 流動性下位 | 3.0% | 68.4% | **28.6%** | 2,558件 |
| TOPIX Small | 21.6% | 62.0% | 16.4% | 1,467件 |
| スタンダード | 13.9% | 40.8% | **45.3%** | 605件 |
| グロース | 14.2% | 40.6% | **45.2%** | 1,883件 |

同資料に TOPIX100 の STR 中央値 = **1.50**、平均 3.50、平均(STR≤5のみ) 1.33 の記載あり。

**推定(算術を明示)**:

```
往復スプレッドコスト = (半スプレッド × 2) = 名目スプレッド1本分
                    = STR × ティック・ウェイト

TOPIX100級:  STR 1.0〜1.5 × 2.24 bps = 2.2 〜 3.4 bps   ← 中心 2.8 bps
Mid400:      STR 1.5〜5.0 × 2.24 bps = 3.4 〜 11.2 bps  ← 中心 5.6 bps(STR 2.5)
```

これは **上限**である。SOR は東証・PTS4市場の気配を参照し、東証最良気配と同等以上の
価格での約定を目指す(価格改善の可能性がある)ため、実効コストはこれ以下になりうる。
出典: [三菱UFJ eスマート証券 SOR注文](https://kabu.com/item/sor/default.html)

**板インパクト**: 個人サイズ(1銘柄あたり ≤¥1M)が TOPIX100 の最良気配数量を食い切るか
どうかの公開データは見つからなかった。**不明**。TOPIX100 の平均約定件数 28,274件/日
という水準から、最良気配数量が数百万円規模である蓋然性は高く、インパクト≈0 と仮置き
するのは妥当だが**未検証**。Mid400 下位・Small 以下では確実に無視できない。

### 1.7 キャリー(保有コスト) — ここが暗号資産・FXと構造的に違う点

三菱UFJ eスマート証券(2026年6月1日以降、通常プラン)。
出典: [5/18予定 国内株式取引手数料無料化等のお知らせ](https://kabu.com/company/pressrelease/20260408_1.html)

| 項目 | 年率 | 日率(÷365) |
|---|---|---|
| 制度信用 買方金利 | 2.80% | **0.767 bps/日** |
| 制度信用 貸株料(売方) | 1.10% | **0.301 bps/日** |
| 一般信用(長期) 金利 | 2.79% | 0.764 bps/日 |
| 一般信用(長期) 貸株料 | 1.10% | 0.301 bps/日 |
| 逆日歩(品貸料) | 変動・上限なし | **テールリスク** |

同資料によれば主要ネット5社(当社/SBI/楽天/マネックス/松井)中の最安水準。
逆日歩は貸借取引で株不足が生じたとき入札で決まり、**制度信用の売り顧客全員が支払う**。
出典: [JPX 品貸料](https://www.jpx.co.jp/markets/statistics-equities/margin/01.html)

**重要な構造上の発見** — ロング・ショートを組む際の資金調達の作り方でコストが桁で変わる:

| 構成 | 年率キャリー(ロング¥1 + ショート¥1 あたり) |
|---|---|
| 両脚とも制度信用(買建 + 売建) | 2.80% + 1.10% = **3.90%/年** |
| **ロング現物(自己資金) + それを代用有価証券にしてショート信用** | **1.10%/年** のみ |

代用有価証券の掛目はプライム/スタンダードで80%以下、委託保証金率は法令上30%以上、
最低委託保証金30万円。
出典: [楽天証券 信用取引の基本ルール](https://www.rakuten-sec.co.jp/web/domestic/margin/rule/ground_rules.html)
⇒ 現物¥1(掛目80% → 保証金¥0.8)を担保に、¥0.8/0.30 = 最大 ¥2.67 の売建が可能。
ドルニュートラル(1:1)なら余裕をもって組める。

**日本のバリュー効果(年率+4.85%、§4)を両脚信用で組むとキャリー3.90%で 80% が消える。
現物ロング + 代用ショートなら 1.10% で済む。** この差は戦略の生死を分ける。

### 2.2 Free プランで10年以上のバックテストは可能か → **不可**

- Free は「直近12週間を除く2年間」のみ。10年は **Standard(¥3,300/月)から**、20年は Premium。
- Free はデータが12週間遅延して配信される。
- **Free プランは1年間に限って利用可能で、1年後に自動解約される**(再登録は可能)。
  出典: [J-Quants ヘルプ: プラン・変更・キャンセルと退会](https://jpx-jquants.com/ja/help/plan)
- Free は CSV 取得不可(取引カレンダーを除く) + 5件/分のレート制限。
  全銘柄×2年の日足を API 経由で引くと、`/equities/bars/daily` は date 指定で全銘柄一括
  取得できるので営業日数 ≈ 490 リクエスト ≈ 98分。**取得自体は可能だが実用性は低い**。

### 3.2 シナリオA: 単元株 × 30銘柄

粒度比 `g = (1単元の金額) ÷ (1銘柄あたりの目標金額) = N × u ÷ C` で評価する
(g が小さいほど目標ウエイトに近づけられる)。

| 前提 | 必要資本 |
|---|---|
| 全銘柄1単元ずつ持つだけ(ウエイトは単元金額比例 = 制御不能) | 30 × ¥338k ≈ **¥10.1M** |
| g ≤ 0.5(±25%のウエイト誤差を許容) | 30 × ¥338k ÷ 0.5 = **¥20.3M** |
| g ≤ 0.2(±10%のウエイト誤差) | 30 × ¥338k ÷ 0.2 = **¥50.7M** |
| 銘柄を「1単元が安い方から」選ぶ制約を課す(u ≈ ¥150k)、g ≤ 0.2 | 30 × ¥150k ÷ 0.2 = **¥22.5M** |

**⇒ 実用的な最低資本は ¥20M〜¥50M。¥10M は「等ウエイトを諦める」ことと同義。**
なお「1単元が安い銘柄だけを選ぶ」制約は**低位株バイアスという未制御のファクター
エクスポージャーを持ち込む** — クロスセクショナル研究では致命的になりうる。
ロング・ショートなら両脚必要なので、上の数字はロング側だけの話であることに注意
(現物ロング + 代用ショートの構成なら追加現金は不要だが、ショート側にも同じ粒度問題が出る)。

**上位/下位 各50銘柄(計100)** にすると必要資本は上表の 3.3倍。g≤0.5 で ¥68M。

**判定: 小資本クロスセクショナルは単元未満株では成立しない。理由は3つとも独立に致命的:**

1. **自動化不能。** 単元未満株を発注できる個人向け API が事実上存在しない。
   30〜100銘柄を毎日手で発注するのは本プロジェクトの運用形態と両立しない。
2. **空売りができない。** 単元未満株に信用売りはない。ロング・ショートが原理的に不可。
3. **コストが桁で違う。** 楽天かぶミニのリアルタイムは片道22bps = **往復44bps** で、
   単元株の床 2.8bps の **約16倍**。これは BTC CFD(5.8bps)の 7.6倍で、
   本プロジェクトが「コスト負け」と判定してきた全ての市場より高い。
   寄付取引ならスプレッド0だが、始値成行に固定されるため執行タイミングを選べず、
   シグナルと執行の間に一晩のギャップが入る。

**唯一の抜け道**: SBI S株の寄付執行(手数料0・明示スプレッド0)を使う**ロングオンリー・
1日1回・手動または半自動**の構成。コスト床はほぼゼロだが、
実装ショートフォール(決定価格 → 翌寄付)が実質のコストになり、その大きさは**不明**。
かつ API がないので本プロジェクトの自動化方針から外れる。

> **§4.1 と Jacobs & Müller を合わせると重要な含意がある**:
> 「日本の HML が公表から数十年経っても減衰していない」ことは偶然ではなく、
> 米国外では公表後減衰が観測されないという体系的知見と整合する。
> **本プロジェクトが暗号資産/FXで繰り返し観測した「edge は既に食われている」
> という前提が、日本株では必ずしも成り立たない可能性がある。**
> ただし「減衰しない = 裁定障壁がある」であり、その障壁の一部は
> **まさに §3 の資本制約と §1.7 の空売りコスト**である点に注意。

**日本固有の注意**:
- 3月期決算集中 → 財務データの公表が年に極端に偏る。バリュー系シグナルの更新が
  年1回の断崖になり、実効的な独立観測数がさらに減る。
- 配当落ちが J-Quants の調整対象外(§2.4)。日本株の配当利回りは無視できないので、
  リターン計算を誤ると 1ヶ月リバーサルのようなシグナルに直接ノイズを注入する。
- 貸借銘柄でないと制度信用売りができない(2,672銘柄、§3.5)。下位分位が
  ユニバースから系統的に脱落するとロング・ショートの片脚が壊れる。
- 逆日歩は「売り建てが混んでいる銘柄」に発生する = **クロスセクショナル戦略が
  ショートしたい銘柄と正確に一致する**。これはランダムなコストではなく、
  シグナルと相関した敵対的コストである。

### 4.4 コスト床では死なない。では何が殺すか → **統計的分解能**

| 効果 | SR | t=2 に必要な年数 = (2/SR)² |
|---|---|---|
| HML(バリュー) | 0.45 | **19.8年** |
| WML(モメンタム) | 0.10 | 400年 |
| Asness の value+mom 50/50 | 0.65 | 9.5年 |
| 仮に短期リバーサルが SR 1.0 なら | 1.00 | 4.0年 |
| 仮に SR 1.5 なら | 1.50 | 1.8年 |

> **これが本市場の本当の壁である。**
> 本プロジェクトの規律(事前登録 → Train+Val のみで選択 → OOS一度きり →
> フレッシュデータ追試)は、**年次リバランスのファクターには適用不能**である。
> Light プランの5年では OOS 期間に独立観測が数個しか入らない。
> Premium の20年を買っても、HML の OOS を「一度だけ」引いて t=2 を出すのは無理。
>
> **年次〜月次のファクター(バリュー・クオリティ・投資)は、本プロジェクトの
> 判定プロトコルでは原理的に判定できない。** 明示的にスコープ外を宣言すべき。
>
> **判定可能なのは、1年のOOSで数十〜数百回のリバランスが入る短期リバーサル系だけ。**

**本プロジェクトへの含意**:
- 現行では **BTC CFD(雑所得・総合課税・最大55%・繰越なし)より、上場株式(20.315%・
  3年繰越)の方が税引後で大きく有利**。同じ税引前シャープでも税引後で差がつく。
- 株式(申告分離)と先物(先物取引に係る雑所得等)は**別枠**なので、
  §3.4 のロングオンリー+先物ヘッジ構成では、**株式の益と先物の損(またはその逆)が

  ロング・ショート(両脚とも株式 = 同一枠)にはない、ヘッジ構成固有のコストである。
  **定量化は税務の領域なので本調査では行わない。ただし設計判断に影響する。**
- 特定口座(源泉徴収あり)を使えば申告不要にできるが、上記の枠の分断は変わらない。

## 7. go/no-go 推奨(判断はリードが行う)

### 7.1 推奨: **条件付き go — ただし「コスト床で判定する」枠組みを捨てることが条件**

#### go を支持する事実

1. **コスト床が低い。** TOPIX100級で往復 2.8bps。BTC CFD の半分。
   週次リバランスまでは年率コスト 2.5% で収まり、報告されている効果サイズ
   (1ヶ月リバーサルのグロス年率10%台)を食い切らない。
   **本プロジェクトが34+10報かけて確立した「効果 < 床」という棄却法則が、
   この市場では初めて機能しない。** これ自体が測る価値のある事実。
2. **データが安価で、かつ生存バイアスがない。** ¥1,650/月で
   ポイントインタイムの上場銘柄一覧(規模コード・貸借区分つき)+ 5年の日足。
   暗号資産で31日制限に苦しんだ問題が構造的に存在しない。
3. **執行が無料で、既存の Windows 運用と適合する。**
4. **税制が有利。** 20.315% + 3年繰越 vs 暗号資産の最大55%・繰越なし。
5. **減衰していない。** 米国外では公表後減衰が観測されない(Jacobs & Müller 2020)。
   日本の HML は直近10年でも +5.30%/年。

#### no-go を支持する事実

1. **最低資本 ¥20M〜¥50M。** 100株制の粒度が、30銘柄の分散を要求する
   クロスセクショナルと正面から衝突する。単元未満株は API がなく空売りもできず
   コストが16倍で、抜け道にならない。**この数字がオーナーの運用可能額を超えるなら
   そこで終わり。他の全ての議論は無意味になる。**
2. **統計的分解能。** 日本で唯一生きている効果(バリュー、SR 0.45)は
   t=2 まで約20年。本プロジェクトの事前登録プロトコルでは判定不能。
3. **J-Quants の解約時削除義務。** 月額が撤退不能な固定費になり、
   `backtest_data/` の恒久スナップショット慣行が使えない。
4. **コスト・モデルに 2027-03-01 の期限がある。**(呼値制度の全面改定)
5. **逆日歩がシグナルと相関した敵対的コスト**であり、モデル化できない。

#### 判断が分岐する点(リードへ)

> **「最低資本 ¥20M〜¥50M」が満たせないなら、これは no-go である。**
> ¥10M でも「1単元ずつ持つ」ことはできるが、その場合ウエイトは
> 単元金額に比例した制御不能なものになり、クロスセクショナルの前提
> (シグナルどおりのウエイトを取る)が壊れる。バックテストを連続ウエイトで
> 回して合格させ、実装で整数単元にした瞬間に別物になる — これは
> 本プロジェクトが最も嫌う種類の失敗である。
>
> **したがって、もし go するなら、バックテストは最初から
> 「指定資本額・整数100株単位」で回すこと**を PREREG の必須要件にすべき。

### 7.2 go の場合の最初の PREREG 候補(推奨)

**測るべきもの: 短期(1週間・1ヶ月)クロスセクショナル・リバーサル、ロングオンリー。**

選定理由:
- 本プロジェクトのプロトコル(Train/Val/OOS 一度きり + フレッシュデータ追試)が
  **成立する唯一の頻度帯**。5年で週次260回、OOS 1年で50回。
- 日本固有の事前分布が最も強い効果(日本はリバーサル支配的、モメンタム不在)。
- **リターンが負け組=ロング側に集中**(Iihara et al.)ので、
  ロングオンリー + 先物ヘッジで効果の主要部分を取れる。
  → 逆日歩・貸借銘柄制約・空売り価格規制を全て回避できる。
- **コストで死ぬかどうかが最も微妙な帯**でもある(週次で年2.5%)。
  つまり「本市場でも効果 < 床の法則が効くのか」を最も情報量高く検証できる。

**PREREG に書くべき内容(骨子)**

| 項目 | 内容 |
|---|---|
| データ | J-Quants **Light**(¥1,650/月)。`/equities/master`(date指定でポイントインタイム、ScaleCat・Mrgn 取得)+ `/equities/bars/daily`(AdjFactor 累積で分割調整)+ `/indices/bars/daily/topix` |
| ユニバース | ポイントインタイムで `ScaleCat` ∈ {Core30, Large70, Mid400}(= TOPIX500 = 細かい呼値テーブル適用)。上場廃止銘柄を**含める**(退出日まで) |
| シグナル | 過去1週間・過去1ヶ月の(分割調整済み)リターンの断面ランク。上位/下位分位 |
| ポジション | **ロングオンリー**: 下位分位(負け組) N=30 を等ウエイト。**整数100株単位**で丸める。市場ベータは日経225マイクロ先物の売建で中立化(整数枚) |
| 資本 | **¥10M / ¥20M / ¥50M の3水準で同一シグナルを回す。**この3本のスプレッドが「粒度が効果を食う量」を直接測る |
| コスト・モデル(事前登録) | ScaleCat=Core30/Large70 → 往復 2.8bps、Mid400 → 往復 5.6bps。執行は翌営業日の始値または VWAP 代理。先物ヘッジ 往復 1.1bps + 四半期ロール。**信用は使わないのでキャリー0**。配当は J-Quants Light に無いので、**配当落ち日を跨ぐリターンをシグナル・評価から除外**(または除外しない版と両方報告) |
| フィージビリティ足切り | 資本 ¥20M 水準で、コスト後の年率リターンが 0 を上抜けること。これを満たさなければ Val に進まない |
| 分割 | 5年を Train 2021-2023 / Val 2024 / **OOS 2025-2026(一度だけ)** |
| 多重性 | 候補セル数を事前に固定(地平2 × 分位2 × 資本3 = 12 セル)。判定は資本¥20M・地平2つのみ |
| 期限 | コスト・モデルは **2027-02-28 まで有効**。以降は呼値制度改定により再較正が必要 |

**着手前に確認すべき未解決事項(全て本調査で「不明」だったもの)**

1. 個人サイズの板インパクト(TOPIX100 / Mid400 の最良気配数量)。
   → J-Quants の分足・ティックアドオン(+¥5,500/月)、または kabuステーションAPI の
   `/board` を数日記録すれば実測できる。**PREREG 前にやるべき**。
2. kabuステーションAPI の銘柄登録上限と、500銘柄規模のポーリング実現性。
3. 2027年3月の新呼値テーブル A/B/C の具体値(JPX ページの画像)。
4. 楽天かぶミニのリアルタイム対象銘柄数(シナリオB を再検討する場合のみ)。
5. 三菱UFJ eスマート証券プチ株の約定タイミングとスプレッド。

### 7.3 明示的にスコープ外を宣言すべきもの

- **バリュー(HML)・クオリティ・投資などの年次〜四半期ファクター。**
  効果は実在する(HML t=2.69)が、本プロジェクトの判定プロトコルで
  検証不能(t=2 に約20年)。「測れないから採らない」を明記して閉じる方が、
  中途半端に測って偽陽性を作るより安全。
- **単元未満株を使う構成。**API 不在・空売り不可・コスト16倍の3点で独立に不可。
- **日次リバランス。** 年率コスト 8.1% は、日本の日次リバーサルの
  報告値(**不明**)を上回る蓋然性が高い。週次で足りる。

## 7.4 判定(リード・2026-08-28 追記)

**no-go 確定。** §7.1 の分岐点「最低資本 ¥20M〜¥50M が満たせないならそこで終わり」に対し、
オーナー回答は「ありません」。単元株クロスセクショナルはここで閉じる(J-Quants 契約も不要)。
残る道として §1.6 で最安コスト床(往復≈1.1bps)と判明した日経225マイクロ先物線の
机上調査へ移行(→ `SURVEY_JP_INDEX_FUTURES.md`)。

## 付録: 本調査で行った実測の再現手順

いずれも公開エンドポイントへの読み取りのみ。発注・口座操作は一切行っていない。

1. **ティック・ウェイト分布(§1.3)**: Wikipedia "Nikkei 225" の Components 節から
   4桁コード223件を抽出 → Yahoo Finance `v8/finance/chart/{code}.T` の
   `meta.regularMarketPrice` を取得 → JPX 呼値表(TOPIX500列)を適用 → 分位数。
2. **単元金額分布(§3.1)**: 同じ株価 × 100株 の分位数。
3. **Fama/French Japan ファクター統計(§4.1)**: 上記2つの zip を取得し、
   月次系列の平均・標本標準偏差・t値(= 平均 ÷ (SD/√n))を計算。年率化は ×12(平均)、
   ×√12(SD)。WML の開始が 199011 のため、全ファクターを 199011 以降に揃えた。
4. **Yahoo の生存バイアス検証(§2.5)**: `6502.T`(東芝、2023年12月上場廃止)→ HTTP 404。
   `9432.T`(NTT、2023-07-01 に 25:1 分割)の 2023年6-7月の close/adjclose と
   `events.splits` を確認。
5. **貸借銘柄数(§3.5)**: JPX の 20260803_list.xlsx を読み、「信用区分」列を集計。
