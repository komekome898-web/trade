# バックテスト報告(2026-08-20)

## データ

- 銘柄: XRP_JPY(現物)。6,000円で発注可能な唯一の現実的候補(実測: BTC_JPY最低約11,000円、ETH_JPY最低約3,562円、XRP_JPY最低約18円)
- 期間: 2026-07-29 〜 2026-08-20(約3週間)、公開約定履歴32,500件から1分足30,693本を生成
- スナップショット: `backtest_data/candles_XRP_JPY_20260820.csv`(再現用)
- コストモデル: taker手数料0.15%/片道 + スプレッド0.15%(実測値) + スリッページ0.05%/片道 + 翌バー始値約定
  → **往復コスト ≒ 注文金額の0.55%**

## 結果1: 全戦略 × 全時間足(デフォルトパラメータ、Training/Validation/OOS分割)

| 時間足 | ema_cross OOS | rsi_reversion OOS | breakout OOS |
|---|---|---|---|
| 1分 | -1,831円 / 123回 | -26円 / 2回 | -823円 / 70回 |
| 5分 | -265円 / 26回 | 0円 / 0回 | -145円 / 19回 |
| 15分 | -269円 / 12回 | 0円 / 0回 | -67円 / 3回 |
| 1時間 | -109円 / 3回 | 0円 / 0回 | -53円 / 1回 |

損失 ≒ 取引回数 × 往復コスト。**戦略にコスト前の優位性がほぼ無い**ことを示す。

## 結果2: パラメータ探索(Train+Validationのみで選択 → OOSで最終検証)

- ema_cross 27通り / rsi_reversion 18通り / breakout 4通り を 15分足・1時間足で探索
- **最良パラメータでも Train+Validation 段階で全てマイナスまたは取引ゼロ**。「最良」は単に取引回数が最少の組合せ(=コスト曝露の最小化)であり、優位性の発見ではない
- OOS: 全て 0円以下

## 結論

1. **現時点で実運用に足る戦略は存在しない。** この検証結果に基づき、実運用(LIVE MODE)には進まない。
2. 構造的な問題: 往復0.55%のコストに対し、XRP_JPYの短期変動から取れる期待値がそれを下回る。「1取引あたり平均+0.6%以上の値幅を的中し続ける」必要があり、テストした指標群にその力はなかった。
3. サンプルの限界: 3週間・単一レジームのデータであり、他の相場環境での結論は保留。ただしコスト構造の問題は相場環境によらない。
