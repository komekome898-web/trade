# 分析の文書の置き場(L-694)

分析(測定の結果・データ・仕組みを読んで知見を書くこと)の文書は、ここにだけ置く。1 単位(カード 1 枚・問い 1 つ)= 1 ファイル `<日付>_<単位>.md`。

- 作り方: 分析のスキル `.claude/skills/analysis-lens` を呼び出してから、`python3 scripts/analysis/diag_skeleton.py --unit <単位>`。スキル第 2 部の手順(P・D0・D8・D1・D1b・D2〜D7・D9・D10)ごとの節ができ、各節の頭にスキルの本文の写しが入る。
- 書き方: 手順を上から 1 つずつ。各節の引用を読み直してから、その節の「当てたこと」を書く(コマンドと出力の在処 / 当てない理由 / 「止めた: <分かれ道>」)。
- フック `.claude/hooks/analysis_skeleton_gate.sh` が、この場所の `.md`(この README を除く)への書き込みで、手順の節が欠けた・順が違う・写しがスキルの本文と違う中身と、Bash での書き込みを止める。
- スキルを改訂した後に古い文書を直すときは、先に `python3 scripts/analysis/diag_skeleton.py --refresh <ファイル>` で写しを入れ替える。
- 限界: 見るのは形だけで、読みの正しさは見ない(L-688)。ここの外に書けば迂回できる(L-691)。
