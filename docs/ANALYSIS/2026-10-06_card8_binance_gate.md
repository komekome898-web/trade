>   - 正 → 正: 続いている(後半 − 前半 の区間が 0 より下なら「続いている(縮んだ)」)
>   - 正 → 含む・負: 後半 − 前半 の区間が 0 より下なら **崩れた**、そうでなければ 決まらない
>   - 含む・負 → 正: 後半だけ(成り立ち始めたのか偶然かは区別できない。「続いている」と言わない)
>   - 含む → 含む、負 → 含む: 決まらない
>   - 含む → 負: 後半は逆向き
>   - 負 → 負: 成り立たない(逆向き)
>   決まりの目的: 結果を見てから区切りの時点を選ぶと、偶然の上下でも「変わった」ように見え、前後の差が大きく出る(区切りの候補をたくさん試すほど、どこかで差が出る)。だから「崩れたか(変わったか)」の判定は、見る前に決めた区切りだけで行う。一方、崩れたと分かった後で「いつから」を年ごとの表で記述するのはよい。そのときは「年ごとの値の並びから読んだ時点(区切りは結果を見て選んだ)」と添え、その区切りで計算した前後の差を判定の根拠にしない。
