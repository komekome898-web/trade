> - 計算: (1) 年ごとの 1 日あたり・区間・MDE・区間が 0 を含むか(記述)(2) **前半・後半**(日数で 2 つに分ける。結果を見る前に決めた分け方。制度の変わり目が事前に分かっていれば、それも区切りに足す)の 1 日あたり・区間・MDE と、後半 − 前半 の区間(2 つの半分をそれぞれ日の塊で選び直した差)。

> - 読み方(`d1_outcome`。戦略の向きは「損益が正」で固定し、標本から決めない。各半分の状態 = 正(区間が 0 より上)/ 含む / 負(区間が 0 より下)):
>   - 正 → 正: 続いている(後半 − 前半 の区間が 0 より下なら「続いている(縮んだ)」)
>   - 正 → 含む・負: 後半 − 前半 の区間が 0 より下なら **崩れた**、そうでなければ 決まらない
>   - 含む・負 → 正: 後半だけ(成り立ち始めたのか偶然かは区別できない。「続いている」と言わない)
>   - 含む → 含む、負 → 含む: 決まらない

>   - 負 → 負: 成り立たない(逆向き)

## D3 稼ぎと損の集まり

<!-- step:D3 -->
> - 入力: 日ごとの損益、取引の行。
> - 計算: 上位・下位 5% の日の損益の和(全体の和と並べる)/ 取引の損益の分位(1・5・25・50・75・95・99%)/ 出の理由・合図の強さ・保有時間の帯ごとの取引の数・和・1 取引あたり(区間は日の塊で日を選び直して群の和 ÷ 群の数を作り直す)。保有時間の帯は四分位の境を重ならないようにまとめ、実際の範囲で名付ける。
> - 群は 2 種類に分け、表に印を付ける(読み口が付ける): 【建ての前に決まる群】(合図の強さ・場面・時間帯など、建てる時点で分かる値)と【結果で決まる群】(出の理由・保有時間など、取引が終わって決まる値)。
> - 読み方: 全体の和が少数の日・取引で作られているか。群の 1 取引あたりの区間が 0 を含まない群が、全体の稼ぎ・損のどこを作っているか(例: 「時間で降りた取引は 1 取引あたり −17 [−20, −15]」)。【建ての前に決まる群】の差は原因の候補(門・条件の案)になる。【結果で決まる群】の差は、どこで稼ぎ・損が出たかの記述にとどめ、「この群を避ければよい」とは書かない(例: 時間で降りた取引が負けるのは、戻らなかった取引が時間で降りるから。時間で降りる決まりが損を作ったとは言えない。それを言うには D7 で降り方を変えた走らせと比べる)。
> - 止めるもの: D8 か D1 で止めたときは、群の比べから改良を出さない(記述だけ)。
> - 決まりの目的: 結果で決まる群は、群の定義そのものが損益と結び付いているので、群の差が大きく出るのは当たり前で、原因の証拠にならない。
